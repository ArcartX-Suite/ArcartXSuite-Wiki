title: "分类与搜索"
description: "设置仓库物品分类、排序与搜索，便于玩家查找物资。"
---

Warehouse 模块提供基于 NBT/PDC 路径的物品分类、多字段排序方案和拼音/首字母搜索能力。这三套机制协同工作，帮助玩家在大量存储物品中快速定位目标。

## 用原版材质验证分类

在 `plugins/ArcartX-Suite/data/warehouse/config.yml` 现有的 `categories` 中合并这两项。测试前检查已有分类优先级，避免其他规则先匹配。修改后执行 `/axs reload warehouse`。

```yaml
categories:
  trial_ores:
    display-name: "试炼矿物"
    priority: 5
    nbt:
      path: material
      values: [diamond, emerald]
  other:
    display-name: "其他"
    priority: 9999
    default: true
```

重载 Warehouse 后，存入钻石、绿宝石和苹果。前两者应能在矿物分类找到，苹果应进入兜底视图。分类是查找物品的方式，调整分类不应被当成扩容或奖励发放。

接入自定义物品时，先读取物品真实的 PDC 键和值，再将 `nbt.path` 与 `values` 换成对应数据。示例键不会自动出现在物品上。先验证一个已知物品，再加入更多值，保留兜底分类以便发现未匹配物品。

### 分类匹配

物品存入仓库时自动判断归属分类，按 `priority` 升序依次匹配：

1. 按 `priority` 从小到大检查各个非兜底分类
2. 读取物品在 `nbt.path` 指定路径上的值
3. 该值（小写化后）存在于 `nbt.values` 列表中，则归入此分类
4. 均不匹配时归入兜底分类（`default: true`，默认 ID `other`）

### 支持的 NBT 路径类型

分类的 `nbt.path` 字段支持以下路径类型：

| 路径格式 | 说明 | 示例值 |
| --- | --- | --- |
| `pdc:<namespace>:<key>` | 读取 PersistentDataContainer 中的 STRING/INTEGER/LONG 值 | `pdc:arcartx:item_category` |
| `pdc:<key>` | 简写形式，namespace 默认为插件名 | `pdc:item_category` |
| `material` | 读取原版材质 ID（如 `DIAMOND_SWORD`） | `DIAMOND_SWORD` |
| `display-name` / `name` | 读取物品显示名称 | `钻石剑` |
| `custom-model-data` | 读取 CustomModelData 整数值 | `10001` |

> PDC 值读取优先尝试字符串类型，其次整数类型。

### 分类配置

分类在 `config.yml` 的 `categories` 节定义：

```yaml
categories:
  equipment:
    display-name: "装备"
    priority: 10
    nbt:
      path: "pdc:arcartx:item_category"
      values: ["equipment", "weapon", "armor"]
  material:
    display-name: "材料"
    priority: 20
    nbt:
      path: "pdc:arcartx:item_category"
      values: ["material"]
  consumable:
    display-name: "消耗品"
    priority: 30
    nbt:
      path: "pdc:arcartx:item_category"
      values: ["consumable", "food", "potion"]
  other:
    display-name: "其它"
    priority: 9999
    default: true
```

### 分类字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `display-name` | string | 分类在 UI 中显示的名称，支持 `&` 颜色码 |
| `priority` | int | 排序优先级，数字越小越靠前匹配。兜底分类建议设为最大值（如 `9999`） |
| `nbt.path` | string | NBT/PDC 读取路径，支持 `pdc:`、`material`、`display-name`、`custom-model-data` |
| `nbt.values` | `List<string>` | 匹配值列表，物品路径值（小写化）命中任一即归入此分类 |
| `default` | boolean | 是否为兜底分类。设为 `true` 的分类接收所有未匹配的物品 |

### 兜底分类

系统保证始终存在 ID 为 `other` 的兜底分类。如果配置中未定义 `other`，会自动创建默认兜底分类：

```yaml
# 自动创建的默认兜底分类（无需手动配置）
other:
  display-name: "其它"
  priority: 9999
  default: true
```

### 分类在 UI 中的展示

仓库存取界面的分类展示顺序为：

1. **全部**（`all`）— 显示所有分类的物品
2. 按配置 `priority` 升序排列的各分类

点击分类后显示对应物品，并回到第 1 页。分类只筛选显示内容，不划分独立容量。随身背包、工作台与熔炉中的仓库区也使用这些分类。

## 默认排序与物品置顶

默认排序先显示已置顶物品，其余按首次存入顺序排列。在随身背包、工作台或熔炉的仓库区，鼠标移到条目上会显示 ☆，点击可置顶；已置顶条目持续显示 ★，再次点击可取消。

置顶只在默认排序下影响顺序。选择时间、名称或数量等其他排序后，仍保留置顶状态，但按所选方案排列。

### 排序方案配置

排序方案在 `sort-profiles` 节定义，每个方案由一组排序字段组成，按字段顺序依次排序：

```yaml
sort-profiles:
  time:
    fields:
      - "updated:desc"
      - "name:asc"
  name:
    fields:
      - "name:asc"
  amount:
    fields:
      - "amount:desc"
      - "updated:desc"
```

### 排序字段

每个排序字段格式为 `key:direction`，支持的 key 与 direction 如下：

| 排序键 | 说明 | 支持的方向 |
| --- | --- | --- |
| `name` | 按物品显示名称排序（不区分大小写） | `asc` / `desc` |
| `amount` | 按物品聚合数量排序 | `asc` / `desc` |
| `updated` | 按最后更新时间排序 | `asc` / `desc` |
| `created` | 按存入时间排序 | `asc` / `desc` |
| `material` | 按原版材质 ID 排序（不区分大小写） | `asc` / `desc` |
| `category` | 按分类 ID 排序（不区分大小写） | `asc` / `desc` |
| `warehouse` | 按仓库 ID 排序（不区分大小写） | `asc` / `desc` |

| 方向 | 说明 |
| --- | --- |
| `asc` / `ascending` | 升序（默认） |
| `desc` / `descending` | 降序 |

### 内置排序方案

系统自动保证以下三个排序方案始终存在（配置中未定义时自动创建）：

| 方案 ID | 排序逻辑 |
| --- | --- |
| `time` | 先按更新时间降序，再按名称升序 |
| `name` | 按名称升序 |
| `amount` | 先按数量降序，再按更新时间降序 |

### 排序方案选择

默认使用 `search.default-sort` 指定的方案。随身背包、工作台和熔炉的仓库区可点击排序按钮展开列表，直接选择需要的方案。

## 搜索物品

在搜索框输入物品名称、无声调拼音或拼音首字母。英文不区分大小写；多个关键词用空格分隔，物品必须同时满足这些关键词。

| 搜索词 | 匹配方式 | 示例 |
| --- | --- | --- |
| `钻石` | 按名称匹配 | 匹配"钻石剑" |
| `zs` | 按拼音首字母匹配 | 匹配"钻石剑"（z=钻, s=石） |
| `zuanshi` | 按全拼匹配 | 匹配"钻石" |
| `zs jian` | 多关键词混合匹配 | 匹配"钻石剑"（zs 匹配首字母, jian 匹配拼音） |

### 搜索与分类联动

搜索和分类筛选同时生效。例如先选择装备分类，再搜索“钻石”，只显示装备分类中的匹配物品。找不到物品时，可先切回“全部”并清空搜索词。

### 搜索配置

```yaml
search:
  page-size: 18
  default-sort: "default"
```

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `page-size` | int | `18` | 搜索结果每页显示数量，最小 4 |
| `default-sort` | string | `default` | 默认排序：置顶优先，其余按首次存入顺序。其它 ID 对应 `sort-profiles` 的方案。 |

> `search.page-size` 的值如果小于 `ui.page-size`，则实际使用 `ui.page-size` 作为每页显示数量。

### 搜索词限制

搜索词最多 32 个字符，超出部分会被截断。物品名称中的颜色码不参与搜索。
