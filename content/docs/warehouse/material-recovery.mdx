## 开启自动存入

1. 在 `plugins/ArcartX-Suite/data/warehouse/config.yml` 中设置 `pickup.enabled: true`，执行 `/axs reload warehouse`。
2. 玩家打开仓库管理界面，开启普通物品自动存入。
3. 使用 MythicMobs 战利品时，还需启用服务器的 `pickup.mythic-loot-enabled` 和玩家自己的战利品自动存入选项。

玩家个人设置会保存，重载不会重置。物品黑名单、物品锁和仓库容量限制仍然生效，字段说明见[功能配置](/docs/warehouse/configuration)。

## 背包满时拾取

开启自动存入后，背包已满时仍可将拾取的物品存入仓库。成功存入的部分从地面移除，仓库放不下或不接收的部分留在地上。

此功能需要服务端支持满背包拾取尝试，配套 Paper 支持。若启动日志提示不支持，应更换支持此功能的服务端；普通拾取不受影响。其他插件禁止拾取的物品不会强制入库。

使用 Pickup 的扫描模式时，还需查看[附近战利品清单](/docs/pickup/scanner-mode)中的仓库联动设置。

## 关闭工作台

关闭工作台时，材料优先按原版规则退回背包，放不下的部分按下表处理。

| 情况 | 背包装不下的材料 |
| --- | --- |
| 已开启自动存入，仓库可接收 | 存入个人仓库 |
| 未开启自动存入 | 按原版规则掉落 |
| 仓库已满、物品被锁定或禁止入库 | 未能存入的部分按原版规则掉落 |

此功能由 Warehouse 提供，不要求安装原版界面替换模块。它只处理工作台材料槽，不会收取成品槽或拦截玩家主动丢弃的物品。

## 异常取料怎样处理

使用[配方填入](/docs/vanilla/recipe-book)从仓库取材料时，系统保存材料转移记录。中断后，能够确认尚未交付的材料会尝试退回仓库；无法确认是否已经放入工作台或熔炉的记录会保留待管理员核对，不自动补发。

| 状态 | 管理员查看时的含义 |
| --- | --- |
| `HELD` | 材料已从仓库扣除，尚未进入交付阶段 |
| `RETURNED` | 材料已退回仓库 |
| `APPLYING` | 正在交付，不能据此判断玩家是否已经收到 |
| `APPLIED` | 已放入容器，但仍需结合重启后的实际库存确认 |
| `REVIEW` | 需要人工核对，不自动补发 |
| `CONFIRMED` | 管理员已确认结案，记录保留 |

重启或重载后，遗留的 `APPLYING`、`APPLIED` 记录会转为 `REVIEW`，正常重启也可能出现。**待核对不等于物品已经丢失，请先查实际库存，再决定是否补偿。**

## 管理员核对

以下命令需要 `arcartxsuite.warehouse.admin` 权限。离线玩家填写 UUID，在线玩家也可填写完整名称。

```text
/axs warehouse material-transfers <玩家UUID或在线名>
/axs warehouse material-evidence <玩家UUID或在线名> <凭证UUID>
/axs warehouse material-confirm <玩家UUID或在线名> <凭证UUID> confirm
```

1. 使用 `material-transfers` 查询待处理记录，列表最多显示 50 条。
2. 选定凭证 UUID，使用 `material-evidence` 导出详情。文件位于 `plugins/ArcartX-Suite/data/warehouse/material-transfer-evidence/`，包含材料、数量、目标容器和相关槽位的变化。
3. 核对玩家背包、仓库与对应容器中的实际物品。需要补偿时，由管理员另行处理，避免重复发放。
4. 处理完成后，对 `REVIEW` 记录执行 `material-confirm ... confirm` 结案。**结案命令不会发放或退回物品。**

连接同一数据库的多台服务器需要各自的 `material-transfer-server.id`，该文件位于 Warehouse 数据目录中。

## 不可用物品的手动清理

移除 Mod、缺失依赖或数据不兼容后，不能正常还原的条目会显示红色屏障。物品说明提示“手动取出将直接丢弃，不会生成物品”，该条目仍占用仓库容量。

确认不再需要这些物品后，可手动取出以清理记录：随身背包、工作台和熔炉的仓库区左键清理一组、右键清理半组；无法识别堆叠上限时，一组最多按 64 个计算。仓库主界面可输入数量或选择全部清理。只读预览不能清理，仓库权限和二级密码要求仍然生效。

**清理会永久删除对应数量的仓库记录。** 如希望取回物品，可先尝试恢复对应的 Mod 或依赖。

自动填入材料不会清理这些条目。同材质物品的附魔、属性等数据缺失未必会显示为屏障。
