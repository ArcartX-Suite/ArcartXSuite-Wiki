## 功能概述

| 功能 | 说明 |
| --- | --- |
| 多货币活期 | 支持多种货币的活期余额，存取通过货币桥接扣款/放款 |
| 定期存款 | 可配置多种定期产品，按存入金额分档计息 |
| 阶梯利率 | 每个产品支持多档利率，按金额区间匹配 |
| 权限限制 | 定期产品可设置购买权限节点 |

### 货币配置

银行展示的货币在 `bank.currencies` 节定义，这些货币 ID 必须在Suite `config.yml` 的 `currencies` 节中已定义：

```yaml
bank:
  currencies:
    - money
    - points
```

加载时，如果某货币 ID 在全局货币池中不存在，会输出告警并跳过该货币。详见 [货币配置](/docs/guide/currencies)。

### 定期存款产品配置

```yaml
bank:
  deposit-products:
    money_stable_1d:
      enabled: true
      display-name: "稳健 1 日"
      description: "低门槛短期定存。"
      currency: "money"
      duration-seconds: 86400
      min-amount: 100
      max-amount: 0
      permission: ""
      interest-tiers:
        tier_1:
          min: 100
          max: 9999
          rate: 0.01
        tier_2:
          min: 10000
          max: 99999
          rate: 0.015
        tier_3:
          min: 100000
          max: 0
          rate: 0.02
    money_vip_7d:
      enabled: true
      display-name: "贵宾 7 日"
      description: "权限专属较高收益定存。"
      currency: "money"
      duration-seconds: 604800
      min-amount: 1000
      max-amount: 0
      permission: "ArcartXSuite.warehouse.bank.vip"
      interest-tiers:
        tier_1:
          min: 1000
          max: 49999
          rate: 0.04
        tier_2:
          min: 50000
          max: 0
          rate: 0.06
```

### 产品字段说明

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enabled` | boolean | `true` | 是否启用此产品 |
| `display-name` | string | — | 产品显示名称 |
| `description` | string | `""` | 产品描述 |
| `currency` | string | `money` | 存入货币 ID |
| `duration-seconds` | long | `86400` | 定期时长（秒），最小 1 |
| `min-amount` | `BigDecimal` | `1` | 最低存入金额 |
| `max-amount` | `BigDecimal` | `0` | 最高存入金额（0 = 无上限） |
| `permission` | string | `""` | 购买所需权限（留空 = 无限制） |
| `interest-tiers` | `Map<string, InterestTier>` | — | 利率阶梯配置 |

### 利率阶梯

每个定期产品支持多档利率阶梯，按存入金额匹配对应利率：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `min` | `BigDecimal` | 此档位最低金额（含） |
| `max` | `BigDecimal` | 此档位最高金额（含），0 表示无上限 |
| `rate` | `BigDecimal` | 本产品单期利率（0.01 = 1%） |

金额在 `min` 与 `max` 之间时使用对应档位的利率，包含两端金额；`max: 0` 表示没有上限。若多个档位重叠，使用其中 `min` 最大的档位。建议配置互不重叠的区间。

> 如果产品没有有效利率阶梯，加载时会跳过该产品并输出告警。

### 利率计算示例

以"贵宾 7 日"产品为例，存入 60000 money：

| 档位 | 金额区间 | 利率 | 是否匹配 |
| --- | --- | --- | --- |
| tier_1 | 1000 ~ 49999 | 4% | 否（60000 `>` 49999） |
| tier_2 | 50000 ~ 无上限 | 6% | 是 |

匹配利率为 6%，到期后本息 = 60000 + 60000 × 0.06 = 63600 money。

### 存款流程

在银行界面选择货币，输入大于 0 且不超过钱包余额的金额，再点击存入。成功后检查钱包余额与银行余额的变化。

### 取款流程

在银行界面选择货币、填写金额并取款。金额须大于 0 且不超过银行余额。成功后核对该货币的钱包余额和银行余额，放款失败时查看提示并刷新余额。

### 购买定期

1. 在银行界面选择已启用且自己有权限使用的定期产品。
2. 确认币种、期限、最小与最大金额以及本档利率。
3. 填写本金并确认购买，核对银行余额减少的金额。
4. 在定期列表检查产品、本金和到期时间。

例如本金为 1000、单期利率为 `0.05` 时，预期利息为 50。先确认余额至少为 1000，再购买并在到期后领取。金额阶梯和期限按服务器产品配置填写。

### 领取到期定期

玩家在银行界面选择已到期的定期记录，再执行领取。本金与约定利息一起入账。未到期、已领取或不属于自己的记录不能再次领取。

领取后刷新银行余额和定期列表，核对该笔记录已经完成。发生暂时错误时，先查看到账记录和日志，再决定是否重试，避免手动重复补发。

### 本息计算

到期本息计算公式：

```
payout = principal + principal × interestRate
```

结果最多保留 8 位小数，超出部分直接舍去；末尾多余的零不显示。

## 管理员操作

管理员可通过 `/axs warehouse bank` 命令调整玩家银行余额：

```bash
# 设置余额
/axs warehouse bank <玩家> <货币ID> set <金额>

# 增加余额
/axs warehouse bank <玩家> <货币ID> add <金额>

# 扣减余额
/axs warehouse bank <玩家> <货币ID> take <金额>
```

| 模式 | 说明 |
| --- | --- |
| `set` | 直接设置余额为指定值 |
| `add` | 在当前余额基础上增加 |
| `take` | 在当前余额基础上扣减（不低于 0） |
