## 玩家命令

玩家命令绑定到 `/warehouse`（别名 `/wh`、`/axswarehouse`），需持有 `arcartxsuite.warehouse.use` 权限。

| 命令 | 说明 | 权限 |
| --- | --- | --- |
| `/warehouse` | 打开仓库主界面（等同于 `open`） | `arcartxsuite.warehouse.use` |
| `/warehouse open` | 打开仓库存取界面 | `arcartxsuite.warehouse.use` |
| `/warehouse help` | 显示帮助信息 | `arcartxsuite.warehouse.use` |
| `/warehouse showcase` | 将自己公开的仓库发到聊天 | 展示权限，默认 `arcartxsuite.warehouse.showcase` |
| `/warehouse spreview <玩家名或UUID> <仓库ID>` | 打开分享链接指向的公开仓库 | `arcartxsuite.warehouse.use` |
| `/warehouse preview <玩家名或UUID> [仓库ID]` | 管理员只读预览 | `arcartxsuite.warehouse.admin` |
| `/warehouse transfer confirm <sharedId>` | 确认接收共享仓库转让 | `arcartxsuite.warehouse.use` |
| `/warehouse transfer reject <sharedId>` | 拒绝共享仓库转让 | `arcartxsuite.warehouse.use` |

### 命令详解

**`/warehouse open`**

打开仓库存取界面。首次打开时自动初始化玩家拥有的默认仓库（`default-owned: true` 的仓库）。如果当前仓库无效，自动回退到第一个个人仓库。

**`/warehouse transfer confirm <sharedId>`**

确认接收共享仓库转让。转让发起后，目标玩家会收到通知，需在 `transfer-confirm-expire-hours`（默认 24 小时）内执行此命令确认。确认后所有权转移，原所有者变为成员。

**`/warehouse transfer reject <sharedId>`**

拒绝共享仓库转让。转让记录删除，仓库所有权不变。

## 仓库预览

| 入口 | 可以在侧栏切换的仓库 |
| --- | --- |
| 点击 `/warehouse showcase` 发出的链接，或执行 `/warehouse spreview <玩家名或UUID> <仓库ID>` | 目标已公开的个人仓库，以及由目标拥有且已公开的共享仓库 |
| 执行 `/warehouse preview <玩家名或UUID> [仓库ID]` 或 `/axs warehouse view <玩家> [仓库ID]` | 目标的全部个人仓库，以及由目标拥有的共享仓库，包含私有仓库 |

两种预览都支持翻页、搜索、分类和排序，物品存取由自己的仓库界面处理。点击「返回我的仓库」或执行 `/warehouse open` 即可退出预览。页数按当前筛选命中的物品格计算，每页格数由 `ui.page-size` 设置。

仓库所有者可以在管理界面开启或关闭公开展示。关闭公开后，本子服正在查看该仓库的公开预览会随即关闭。使用共享数据库的多个子服可启用 Warehouse 跨服同步，将撤回通知传到其他子服。翻页、刷新和切换仓库时都会重新检查可见范围。

## 管理员命令

玩家使用 `/axs warehouse <action>` 时需要 `arcartxsuite.admin` 和 `arcartxsuite.warehouse.admin` 权限。

| 命令 | 说明 |
| --- | --- |
| `/axs warehouse help` | 显示管理命令帮助 |
| `/axs warehouse status` | 查看模块运行状态 |
| `/axs warehouse open <玩家>` | 为在线玩家打开仓库 |
| `/axs warehouse info <玩家>` | 查看玩家仓库概览 |
| `/axs warehouse view <玩家> [仓库ID]` | 以只读 UI 打开玩家仓库（玩家执行时）；控制台执行则输出文本概览 |
| `/axs warehouse delete <玩家> <仓库ID> confirm` | 删除玩家指定仓库（需 confirm 确认） |
| `/axs warehouse bank <玩家> <货币ID> <set\|add\|take> <金额>` | 管理玩家银行余额 |
| `/axs warehouse export <玩家> <仓库ID> <槽位>` | 导出槽位原始物品数据 |
| `/axs warehouse material-transfers <玩家UUID或在线名>` | 查询最多 50 条待处理材料转移凭证 |
| `/axs warehouse material-evidence <玩家UUID或在线名> <凭证UUID>` | 导出完整材料转移凭证 |
| `/axs warehouse material-confirm <玩家UUID或在线名> <凭证UUID> confirm` | 人工核对后结案，仅标记、不补发 |

材料记录的核对步骤见[自动存入与材料恢复](/docs/warehouse/material-recovery)。`material-confirm` 只处理 `REVIEW` 状态，不会发放物品。

### 命令详解

**`/axs warehouse status`**

显示模块运行状态，包括：缓存玩家数、货币列表、跨服编辑锁状态、活跃共享锁数量。

**`/axs warehouse open <玩家>`**

强制为指定在线玩家打开仓库界面。目标玩家必须在线。

**`/axs warehouse info <玩家>`**

异步生成玩家仓库概览，包括个人仓库列表、共享仓库列表、银行余额、定期存款等。

**`/axs warehouse view <玩家> [仓库ID]`**

打开管理员只读预览。目标玩家可以离线，仓库 ID 可填写个人仓库或由目标拥有的共享仓库。两条管理员预览命令省略 ID 时优先打开目标第一个已有的个人仓库。目标只拥有共享仓库时，会打开其中一座。控制台执行 `/axs warehouse view` 会输出指定个人仓库的物品清单，省略 ID 时使用配置中的第一个个人仓库。

**`/axs warehouse delete <玩家> <仓库ID> confirm`**

**`/axs warehouse bank <玩家> <货币ID> <set|add|take> <金额>`**

管理玩家银行余额：
- `set`：直接设置余额为指定金额
- `add`：增加指定金额
- `take`：扣减指定金额（不低于 0）

## 权限节点表

| 权限节点 | 默认 | 说明 |
| --- | --- | --- |
| `arcartxsuite.warehouse.use` | true | 使用 `/warehouse` 命令与打开仓库 |
| `arcartxsuite.warehouse.admin` | op | 管理仓库与预览他人仓库 |
| `arcartxsuite.warehouse.showcase` | 由权限插件分配 | 发送公开展示链接，实际节点可在 `showcase.permission` 中配置 |
| `ArcartXSuite.warehouse.shared.vip` | op | 共享仓库 VIP 权限组（可配置更多共享仓库与成员上限） |
| `ArcartXSuite.warehouse.bank.vip` | op | 购买 VIP 定期存款产品的权限（示例配置中的 `money_vip_7d` 产品） |

> 仓库定义中的 `permission` 字段和定期存款产品中的 `permission` 字段可自定义权限节点，玩家需持有对应权限才能拥有该仓库或购买该产品。
