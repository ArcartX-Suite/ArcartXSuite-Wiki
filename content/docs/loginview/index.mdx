| 项目 | 说明 |
| --- | --- |
| 模块 ID | `loginview` |
| 主配置 | `plugins/ArcartX-Suite/data/loginview/config.yml` |
| 主要调整内容 | 界面文件、服务条款与登录后传送位置 |
| 重载 | `/axs reload loginview` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 选择独立登录或 AuthMe 兼容模式。
2. 调整条款文字和传送点。
3. 让测试账号重新进服。

## 检查是否配置成功

检查界面文字、注册或登录操作及登录后的落点。

功能未生效时，先检查模块状态、所用定义 ID、玩家权限及客户端安装情况，随后对照[日志与报错提示](/docs/guide/config-management)逐项检查。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| 双认证模式 | `standalone` 使用 AXS 独立账户库；`authme` 委托 AuthMe 做注册、登录、改密 |
| ArcartX UI 面板 | 客户端渲染登录/注册/改密界面，内置紧凑面板与纯色块主菜单两种 UI 风格 |
| AuthMe 桥接 | `authme` 模式下认证操作委托 AuthMe 处理，AuthMe 缺失时自动降级 |
| 密码安全策略 | 密码长度限制、最大尝试次数锁定、未登录时锁定移动/聊天/命令/交互/物品丢弃 |
| Session 持久化 | 登录后一定时间内重连或服务器重启无需重新登录，可选 IP 绑定校验 |
| QQ 绑定集成 | 微软/LittleSkin 账号可配置强制绑定 QQ 才能进入游戏，需 qqbot 模块配合 |
| 服务条款 | 登录前强制玩家查阅并同意服务器服规 |
| 登录后传送 | 登录成功后可传送至指定出生点（主城） |
| 账号类型识别 | 自动识别微软正版 / LittleSkin / 离线账号，正版玩家免密直接进入 |
