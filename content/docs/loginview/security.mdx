# 安全策略与会话管理

LoginView 模块内置完整的安全策略，涵盖密码保护、登录尝试限制、未登录行为锁定、Session 持久化与密码重置。

## 密码保护

玩家密码加盐哈希存储，不明文保存。从 AuthMe 迁移的账户可继续使用原密码登录，首次登录成功后可自动转换为新存储格式（见[认证模式与 AuthMe 迁移](/docs/loginview/auth-modes)）。

### 密码长度限制

密码长度由 `security` 节配置控制，注册和改密时统一校验：

| 配置字段 | 默认值 | 说明 |
|---|---|---|
| `security.min-password-length` | `6` | 密码最小长度 |
| `security.max-password-length` | `64` | 密码最大长度 |

## 登录尝试限制

| 配置字段 | 默认值 | 说明 |
|---|---|---|
| `security.max-attempts` | `5` | 最大密码错误尝试次数 |
| `security.kick-on-max-attempts` | `true` | 达到上限后是否踢出玩家 |

<Callout type="warn">
失败次数仅记录在内存中：玩家退出后自动清除，服务器重启后全部归零。
</Callout>

## 未登录行为锁定

未通过认证的玩家会受到以下行为限制：

| 锁定项 | 配置字段 | 默认值 | 说明 |
|---|---|---|---|
| 移动 | `security.lock-movement` | `true` | 阻止跨方块移动（同方块内视角转动允许） |
| 聊天 | `security.lock-chat` | `true` | 阻止发送聊天消息 |
| 命令 | `security.lock-commands` | `true` | 阻止执行命令，白名单前缀除外 |
| 背包点击 | - | `true` | 阻止所有背包点击 |
| 物品丢弃 | - | `true` | 阻止物品丢弃 |
| 方块交互 | - | `true` | 阻止方块/空气交互 |

### 命令白名单

未登录时仍允许执行的命令通过 `security.allow-commands-prefix` 配置（逗号分隔，忽略大小写的前缀匹配）：

```yaml
security:
  allow-commands-prefix: login,register,l,reg,AXS
```

<Callout type="info">
`allow-commands-prefix` 是前缀匹配，如配置 `login` 则 `/login`、`/loginview` 均允许。建议只放行登录相关命令。
</Callout>

## 无敌保护

未登录玩家自动获得无敌状态，防止登录期间被怪物攻击或环境伤害。登录成功、玩家退出或模块卸载时自动恢复。

<Callout type="info">
无敌状态仅在未认证期间生效。正版免密玩家打开 UI 时也会获得无敌，点击「进入服务器」后立即取消。
</Callout>

## Session 持久化

standalone 模式下，登录成功后可将认证状态保持一段时间，掉线重连或服务器重启后在有效期内免重新登录。

| 配置字段 | 默认值 | 说明 |
|---|---|---|
| `security.session-ttl-minutes` | `30` | Session 有效期（分钟），0 禁用持久化 |
| `security.session-strict-ip` | `false` | 是否要求 session 绑定 IP |

<Callout type="info">
`session-ttl-minutes: 0` 禁用 Session 持久化，每次进服都必须重新登录。适合高安全要求的服务器。
</Callout>

### 跨服 Session

多服场景下，若各服共享同一数据库，玩家在 A 服登录后切换到 B 服可免登录：

| 场景 | `session-strict-ip` | 效果 |
|---|---|---|
| 单服 / 同 IP 跨服 | `false`（推荐） | 跨服免登录正常工作 |
| 不同 IP 跨服 | `true` | 跨服免登录失效（IP 不匹配），需重新登录 |
| 不同 IP 跨服 | `false` | 跨服免登录正常工作（不校验 IP） |

<Callout type="warn">
`session-strict-ip: true` 会校验 session 建立时的 IP 与当前 IP 是否一致。若玩家使用移动网络或 NAT 环境导致出口 IP 变化，需重新登录。跨服场景推荐设为 `false`。
</Callout>

## 密码重置

`standalone` 模式下，管理员可通过命令重置玩家密码：

```bash
/axs loginview reset-password <玩家> [新密码]
```

| 参数 | 必填 | 说明 |
|---|---|---|
| 玩家 | 是 | 目标玩家名 |
| 新密码 | 否 | 新密码；省略则随机生成 |

重置成功后：该玩家的登录状态与已保存的 Session 被清除，需重新登录；若玩家在线，会收到通知并自动弹出登录界面。

## 信号与事件

登录成功后 LoginView 派发信号并发布 EventBus 事件，可供其他模块监听：

| 信号 | 触发时机 | 变量 |
|---|---|---|
| `login_success` | 密码登录成功 | `auth_mode`、`account_type`、`account_type_display` |
| `first_register` | 注册成功并自动登录 | `auth_mode`、`account_type`、`account_type_display` |
| `premium_bypass` | 正版/LittleSkin 免密进入 | `auth_mode`、`account_type`、`account_type_display` |

信号可被 [条件系统](/docs/guide/conditions) 监听，实现登录后触发任务、奖励等逻辑。EventBus 事件 `axs.loginview.login_success` 供模块间直接监听，详见 [联动](/docs/loginview/integration)。

## 安全配置示例

### 高安全配置

适用于对安全性要求较高的服务器：

```yaml
security:
  min-password-length: 8
  max-password-length: 128
  max-attempts: 3
  kick-on-max-attempts: true
  lock-movement: true
  lock-chat: true
  lock-commands: true
  allow-commands-prefix: login,register,l,reg,AXS
  rehash-migrated-password-on-login: true
  session-ttl-minutes: 0
  session-strict-ip: true
```

| 配置项 | 高安全值 | 说明 |
|---|---|---|
| `min-password-length` | `8` | 更长的最小密码要求 |
| `max-attempts` | `3` | 更严格的尝试限制 |
| `session-ttl-minutes` | `0` | 禁用 Session，每次进服都需登录 |
| `session-strict-ip` | `true` | Session 绑定 IP，防止盗用 |

### 便捷配置

适用于社区服务器，注重玩家体验：

```yaml
security:
  min-password-length: 6
  max-password-length: 64
  max-attempts: 5
  kick-on-max-attempts: true
  lock-movement: true
  lock-chat: true
  lock-commands: true
  allow-commands-prefix: login,register,l,reg,AXS
  rehash-migrated-password-on-login: true
  session-ttl-minutes: 1440
  session-strict-ip: false
```

| 配置项 | 便捷值 | 说明 |
|---|---|---|
| `session-ttl-minutes` | `1440` | 24 小时内免登录 |
| `session-strict-ip` | `false` | 不校验 IP，适应移动网络 |
