---
title: "命令与占位符"
description: "查看 LoginView 状态、打开界面并读取当前连接的认证信息。"
---

| 命令 | 用途 |
| --- | --- |
| `/axs loginview status` | 显示 LoginView 与宿主认证的职责提示 |
| `/axs loginview open <玩家>` | 为指定在线玩家打开界面 |

管理命令由 Suite 统一调度，需要 `arcartxsuite.admin`。打开界面不会修改准入状态。已准入的本地密码玩家可在界面修改密码，外部身份的密码由其提供方管理。

## PlaceholderAPI

| 占位符 | 返回内容 |
| --- | --- |
| `%axsauth_stage%` | 当前阶段，例如 `awaiting_identity`、`awaiting_requirements`、`admitted` |
| `%axsauth_admitted%` | 是否已准入 |
| `%axsauth_verified%` | 是否已验证身份 |
| `%axsauth_provider%` | 验证方式，例如 `local-password` 或 `oidc`，未知时返回 `unknown` |
| `%axsauth_registered%` | `registered`、`unregistered` 或 `unknown` |

业务规则使用 `%axsauth_admitted%` 判断玩家能否参与游戏。身份验证完成与满足全部准入要求是两个阶段。
