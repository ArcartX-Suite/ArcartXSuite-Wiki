> **付费模块**：Lottery 为付费模块，需通过 Suite 云端下发获取。模块依赖本体 Suite 运行，不可独立使用。

## 概述

- **三种投递方式**：直接发放（DIRECT）、命令执行（COMMAND）、邮件发放（MAIL）
- **待领取队列**：投递失败的物品自动入队，玩家上线自动领取
- **消耗扣除与回滚**：多资源消耗原子扣除，失败自动回滚
- **兑换商店**：积分/物品/货币兑换奖品，支持限购次数

配置字段详见 [配置](/docs/lottery/configuration)，联动详见 [联动](/docs/lottery/integration)。

## 奖品投递方式

`delivery` 决定奖品的投递方式：

| 投递方式 | 配置值 | 说明 |
|---|---|---|
| 直接发放 | `DIRECT` | 生成物品放入玩家背包 |
| 命令执行 | `COMMAND` | 执行 `commands` 列表，不发放物品 |
| 邮件发放 | `MAIL` | 发送 `mail.presets` 指定的邮件预设（需 mail 模块） |

> 投递成功后，`extra-commands` 列表中的附加命令始终执行（不论投递方式）。

### DIRECT 直接发放

物品发放兜底链：

| 步骤 | 条件 | 结果 |
|---|---|---|
| 1 | 背包有空间 | 直接放入背包 |
| 2 | 背包满，邮件可用 | 转邮件补发 |
| 3 | 背包满，邮件不可用 | 暂存待领取 |

### COMMAND 命令执行

逐条执行 `commands` 列表中的命令（以控制台身份执行）：

| 占位符 | 替换值 |
|---|---|
| `{player}` | 玩家名 |
| `{uuid}` | 玩家 UUID |
| `{amount}` | 物品数量 |
| `{item}` | 物品名称 |

> COMMAND 投递不生成物品，因此无需配置 `item.source` 与 `item.id`。

### MAIL 邮件发放

发送 `mail.presets` 指定的邮件预设 ID 列表。

| 条件 | 结果 |
|---|---|
| `mail.presets` 为空 | 失败（提示缺少 mail.presets） |
| 邮件模块未安装 | 失败 |
| 邮件发送成功 | 发放成功（奖励来自邮件预设内容） |

> MAIL 投递失败时不入队待领取队列。

## 物品生成

奖品物品按 `item.source` 生成：

| `item.source` | 生成方式 |
|---|---|
| `minecraft` | 原版物品，`item.id` 为材质名 |
| `mythicmobs` | MythicMobs 物品，`item.id` 为内部 ID |
| `neigeitems` | NeigeItems 物品，`item.id` 为内部 ID |
| `overture` | Overture 物品，`item.id` 为内部 ID |
| `mmoitems` | MMOItems 物品，`item.id` 为 `TYPE;ID` 格式 |

物品来源详情详见 [物品来源](/docs/guide/item-sources)。

## 待领取队列

投递失败的物品自动入队待领取：

| 投递失败场景 | 处理方式 |
|---|---|
| 物品可序列化 | 入队待领取 |
| COMMAND 投递失败 | 仅记录日志，不入队 |

领取时机：

- 玩家上线时自动领取（背包满则暂停，剩余记录保留）
- 手动执行 `/lottery claim` 领取

## 消耗扣除与回滚

单次抽奖可同时消耗多种资源：

| 资源类型 | `type` | 说明 |
|---|---|---|
| 货币 | `CURRENCY` | 从玩家货币余额扣除 |
| 物品 | `ITEM` | 按物品匹配器从背包移除 |
| 积分 | `POINT` | 扣除指定积分余额 |

扣除前先做全量余额预检，任一条目扣除失败时已扣除的条目自动回滚。

## 积分产出

每次抽奖按积分定义累积积分：

| 积分产出来源 | 计算方式 |
|---|---|
| `per-pull` | 每次抽取固定产出（与结果无关） |
| `rarity` | 按每个中奖物品的稀有度/星级查表累加 |

| 奖池类型 | 稀有度 key |
|---|---|
| GACHA | 星级（`3` / `4` / `5`） |
| CASE | 稀有度名称（如 `COMMON` / `RARE`） |

> 积分余额按 `id` 在所有奖池间共享，跨奖池累积。

## 兑换商店

### 兑换规则

- 商品不存在：提示兑换失败
- 已达限购上限：拒绝兑换
- 消耗扣除失败或奖励发放异常：自动回滚，不产生部分扣费

### 限购

| `limit` 值 | 说明 |
|---|---|
| `0` | 无限制 |
| `> 0` | 每人最多可兑换 `limit` 次 |

### 兑换消耗

兑换消耗与抽奖消耗写法一致，支持配置节写法与直接列表写法：

```yaml
# 配置节写法
cost:
  single:
    - type: POINT
      id: "stardust"
      amount: 10

# 直接列表写法
cost:
  - type: POINT
    id: "stardust"
    amount: 10
```

> 兑换只取 `single` 列表作为消耗条目，`ten` 列表无意义。

### 兑换奖励

兑换奖励与奖池奖品结构相同，支持全部投递方式（DIRECT / COMMAND / MAIL）：

```yaml
reward:
  name: "祈愿凭证"
  item:
    source: minecraft
    id: "minecraft:amethyst_shard"
  delivery: DIRECT
  amount: 1
```
