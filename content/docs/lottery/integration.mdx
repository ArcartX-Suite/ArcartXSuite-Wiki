# 联动

## 邮件模块联动

- **奖品 MAIL 投递**：`PoolItem.delivery = MAIL` 时，通过 `mail.presets` 指定的邮件预设发送邮件；邮件模块未安装时该投递方式返回失败
- **背包满溢出**：`DIRECT` 投递时背包满，溢出物品自动转邮件补发
- **待领取奖励**：投递失败的物品自动入队，玩家上线时重新发放（背包满再次转邮件）

## 货币联动

- **消耗扣除**：`CURRENCY` 消耗类型从玩家货币余额扣除
- **余额查询**：UI 资源栏展示当前货币余额
- **退还回滚**：扣除失败或投递失败时自动退还货币

## 物品来源

奖品与图标的 `item.source` 支持以下来源：

| `item.source` | 说明 |
|---|---|
| `minecraft` / `MINECRAFT` / `PLAIN` | 原版物品，`item.id` 为材质名（可带 `minecraft:` 前缀） |
| `mythicmobs` / `MYTHICMOBS` | MythicMobs，`item.id` 为内部 ID |
| `neigeitems` / `NEIGEITEMS` | NeigeItems，`item.id` 为内部 ID |
| `overture` / `OVERTURE` | Overture，`item.id` 为内部 ID |
| `mmoitems` / `MMOITEMS` | MMOItems，`item.id` 为 `TYPE;ID` 格式 |

物品来源详情详见 [物品来源](/docs/guide/item-sources)。

## 图形界面

模块提供三个 UI 文件（`lottery_gacha.yml`、`lottery_wish.yml`、`lottery_case.yml`），界面 ID 可在奖池配置中自定义。UI 配置写法详见 [界面](/docs/guide/multi-ui)。

## 存储模式与跨服

- **共享存储**（`storage.shared: true`）：使用本体统一数据源；多服共用同一 MySQL 时抽奖状态、积分、兑换记录实时同步（推荐多服用法）
- **独立存储**（`storage.shared: false`）：使用独立数据库，数据不互通

模块无跨服事件广播，如需跨服联动可通过本体 EventBus 或第三方插件实现。

## 数据管理

- `/axs purge <玩家>` 清理指定玩家的全部抽奖数据（抽卡状态、日志、待领取奖励、积分、兑换记录）
- `/axs migrate` 支持在 SQLite 与 MySQL 之间迁移数据

## 外部插件接口

外部插件可通过 `LotteryAccess` 公开接口查询/调整积分、执行兑换、批量开箱。详见 [Capability 指南](/docs/api/capability)。
