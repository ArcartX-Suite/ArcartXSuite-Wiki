## 概述

CASE 模式实现 CS:GO 风格的开箱抽奖：

- **稀有度加权**：按稀有度 `base-weight` 加权随机选择稀有度
- **物品加权**：选定稀有度内按物品 `weight` 加权随机选取
- **箱子物品识别**：手持匹配物品右键触发开箱 UI
- **钥匙消耗**：可选的钥匙消耗机制（`requires-key`）
- **滚动动画**：开箱结果以滚动动画展示，十连自动选最高稀有度物品定格

配置字段详见 [配置](/docs/lottery/configuration)，机制概览详见 [概览](/docs/lottery)。

## 稀有度配置

CASE 奖池的稀有度由 `case` 节的 `rarity-settings` 定义：

| 字段 | 配置路径 | 说明 |
|---|---|---|
| `color` | `rarity-settings.<name>.color` | 显示颜色代码（如 `&f`） |
| `base-weight` | `rarity-settings.<name>.base-weight` | 基础权重，必须为正数 |

### 稀有度配置示例

```yaml
case:
  rarity-settings:
    COMMON:
      color: "&f"
      base-weight: 15625
    UNCOMMON:
      color: "&b"
      base-weight: 3125
    RARE:
      color: "&9"
      base-weight: 625
    EPIC:
      color: "&5"
      base-weight: 125
    LEGENDARY:
      color: "&d"
      base-weight: 25
    MYTHIC:
      color: "&c"
      base-weight: 5
    SPECIAL:
      color: "&6"
      base-weight: 2
```

### 加载校验规则

| 校验项 | 失败处理 |
|---|---|
| 物品列表为空 | 奖池加载失败 |
| 稀有度配置为空 | 奖池加载失败 |
| `base-weight <= 0` | 奖池加载失败 |
| 稀有度无对应物品 | 记录警告并从抽取表移除该稀有度 |
| 物品 `rarity` 不匹配任何稀有度 | 记录警告，该物品无法被抽出 |

> 稀有度名称大小写不敏感，物品的 `rarity` 字段匹配时忽略大小写。

## 开箱规则

1. 按各稀有度的 `base-weight` 加权随机选择一个稀有度
2. 从该稀有度的所有物品中按 `weight` 加权随机选取一件
3. 批量开箱每次独立抽取，稀有度与物品互不影响

## 箱子物品与钥匙

### 箱子物品定义（case-item）

`case-item` 定义玩家手持触发开箱 UI 的物品：

| 字段 | 配置路径 | 说明 |
|---|---|---|
| `matcher` | `case-item.matcher` | 识别手持箱子物品的匹配器 |
| `amount` | `case-item.amount` | 单次开箱消耗的箱子数量 |
| `display-name` | `case-item.display-name` | UI 显示名称，默认 `箱子` |
| `icon` | `case-item.icon` | UI 图标 |

物品匹配器写法详见 [条件系统](/docs/guide/conditions)，图标写法详见 [图标](/docs/guide/icons)。

### 钥匙机制（requires-key）

| `requires-key` | 消耗构成 |
|---|---|
| `true` | 箱子（`case-item`）+ 钥匙（`cost` 配置） |
| `false` | 仅箱子（`case-item`） |

| 场景 | 单抽消耗 | 十连消耗 |
|---|---|---|
| 有锁（`requires-key: true`） | 1 箱子 + 1 钥匙 | 10 箱子 + 10 钥匙 |
| 无锁（`requires-key: false`） | 1 箱子 | 10 箱子 |
| 无 `case-item`（向后兼容） | `cost.single` | `cost.ten` |

### 右键触发开箱

玩家手持匹配物品右键空气或方块时直接打开对应 CASE 奖池 UI。匹配条件：

- 奖池 `enabled: true` 且 `type: CASE`
- 奖池配置了 `case-item`
- 手持物品通过 `case-item.matcher` 匹配

## 开箱状态与日志

- 每次开箱累计开箱次数并记录上次开箱时间（不参与抽奖概率，仅用于统计与占位符展示）
- 每次开箱记录日志（玩家、奖池、中奖物品、稀有度），UI 历史页最多展示 20 条
- UI 预览最多展示奖池前 45 个物品，超出物品仍参与抽奖
