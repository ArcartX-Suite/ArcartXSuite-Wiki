# 客户端 Mod（ArcartX-Suite-Tooltips）

ArcartX-Suite-Tooltips 是 Forge 1.20.1 客户端 mod，是 Tooltip 模块的数据来源与交互入口。它把 TACZ/Apotheosis 附加信息以 `axstooltip.*` Aria 全局函数形式暴露给 tip UI，并实现"支持枪械"双模式浏览界面与 lore 按键隐藏。

## 依赖

| 依赖 | 类型 | 版本 |
|---|---|---|
| Minecraft | 必需 | 1.20.1 |
| Forge | 必需 | 47.3.0+ |
| ArcartX | 必需 | 2.7.92 |
| TACZ | 可选 | 1.1.5+（1.1.7+ 启用独头弹改装检测） |
| Apotheosis | 可选 | 7.4.8+ |
| Apotheosis Modern Ragnarok | 可选 | 7.0.0+ |

## Aria 全局函数

注册命名空间 `axstooltip`，全部为无参（或带列数参数）全局函数，可在 tip yml 的 `texts`/`visible` 等属性表达式中直接调用，每帧求值实时刷新：

| 函数 | 返回 | 说明 |
|---|---|---|
| `getTaczLore()` | `List<String>` | TACZ 物品文本行（枪械属性/配件增益/弹药箱/工作台，带 `§` 颜色码） |
| `getTaczGuns()` | `List<String>` | 配件"支持枪械"的 itemJson 列表，**持有优先排序** |
| `getTaczOwnedCount()` | `number` | `getTaczGuns()` 前 N 项为背包已持有 |
| `getTaczGunNames()` | `List<String>` | 枪械显示名列表（与 guns 同序，含 `display.Name` 自定义名） |
| `hasTaczGuns()` / `getTaczGunCount()` / `getTaczGunRows(列数)` | - | 存在性/总数/行数 |
| `shiftDown()` / `showGunGrid()` / `showTaczStats()` | `boolean` | Shift 状态与网格/文本互斥显隐 |
| `getApothLore()` / `getExtraLore()` | `List<String>` | 神化行/合并行 |
| `hasTacz()` / `hasApoth()` / `hasExtra()` | `boolean` | 附加信息存在性 |
| `loreHidden()` | `boolean` | lore 隐藏开关原始状态 |
| `loreVisible()` | `boolean` | **有效显隐**：开关开启且物品带附加内容才隐藏，普通物品恒显示 |
| `toggleLore()` | `boolean` | 翻转开关，返回新状态 |
| `loreKeyName()` | `String` | lore 切换键的本地化显示名（跟随按键设置） |

### tip yml 最小示例

```yaml
tacz信息:
  type: Text
  val: tacz
  attribute:
    texts: axstooltip.getTaczLore()
    fontSize: 38
    visible: axstooltip.hasTacz()
lore:
  type: Text
  val: lore
  attribute:
    texts: var.lore列表
    visible: axstooltip.loreVisible()
```

<Callout type="info">
`loreVisible()` 是"开关 ∧ 物品有附加内容"的复合判定。要判断裸开关状态用 `loreHidden()`；`getTaczLore()` 等返回的是**字符串列表**，可直接喂 `texts`。
</Callout>

## 按键隐藏 lore（默认 V）

- 选项 → 按键绑定中可改键，`loreKeyName()` 动态反映实际键名
- **只在悬停带 TACZ/神化附加内容的物品时生效**——普通物品按 V 不翻转开关
- GUI 打开时经 `ScreenEvent.KeyPressed.Pre` 处理，输入框（JEI 搜索等）焦点时跳过
- 界面外行走时走 vanilla `KeyMapping` tick 路径

## 配件"支持枪械"浏览界面（双模式）

悬停配件按 **Shift** 打开。模式由服务端 tooltip 模块的 `gun-list.mode` 决定，进服经 `axstooltip:gunui` plugin message 推送：

| 模式 | 实现 | 特性 |
|---|---|---|
| `ax` | 服务端 `openUi(AXS:gun_list)` AX 自定义 UI | 960×720 面板、10×6 网格、72px 格子、持有绿描边、滚轮/←→/按钮翻页、悬停显枪名、ESC 关闭；数据走 `axstooltip.*` 全局函数，**枪数据不走包** |
| `mod` | 客户端本地 `GunListScreen` Forge Screen | 自适应面板（GUI 缩放 1-5）、完整原版 tooltip、ESC 返回原界面、持有绿描边、文字翻页 |
| 无模块/无推送 | 默认 `mod` | 向后安全兜底 |

### 网络通道

| 通道 | 方向 | 用途 |
|---|---|---|
| `AXS_TOOLTIP_DATA` | C→S（ArcartX 通道） | tooltip 文本+结构化数据上报 |
| `AXS_GUN_LIST` | C→S（ArcartX 通道） | ax 模式下 Shift 请求打开 UI |
| `axstooltip:gunui` | S→C（Bukkit plugin message） | 模式推送 |

### Mixin 接收

`axstooltip:gunui` 由 `GunUiModePayloadMixin` 拦截 `ClientPacketListener.handleCustomPayload` 接收——Forge `ChannelBuilder` 事件通道在该环境下实测不分发，mixin 方案与 ArcartX-Suite-Map 同构。`GunUiModeChannel` 仍注册 `ChannelBuilder` 通道用于 `minecraft:register` 通告（代理识别客户端支持）。

## 构建与分发

`gradlew build` 产出 `build/libs/ArcartX-Suite-Tooltips-<版本>.jar`——已是 **ProGuard 混淆 + ASM 字符串加密**成品（管线与 Map mod 同构：`reobfJar → obfuscateJar → stringEncryptJar → assembleProtected`）。

关键 keep 规则：`@Mod` 入口类、`mixin.**`、`GunListScreen`（SRG 覆写）整类保留；事件订阅按注解发现；其余类扁平化到 `internal` 包 + Il1O0 字典。
