# 客户端 Mod（ArcartX-Suite-Tooltips）

ArcartX-Suite-Tooltips 是 Forge 1.20.1 客户端 mod，是 Tooltip 模块的数据来源与交互入口。玩家客户端安装后，服务端 `gun_list` 枪械浏览、tip 附加信息（TACZ 属性/神化词条）、lore 按键隐藏等功能才可生效。

## 安装要求

放入客户端 `mods/` 目录，需同时满足：

| 依赖 | 类型 | 版本 |
|---|---|---|
| Minecraft | 必需 | 1.20.1 |
| Forge | 必需 | 47.3.0+ |
| ArcartX | 必需 | 2.7.92 |
| TACZ | 可选 | 1.1.5+ |
| Apotheosis | 可选 | 7.4.8+ |
| Apotheosis Modern Ragnarok | 可选 | 7.0.0+ |

<Callout type="info">
客户端未装此 mod 时服务端模块照常启动，但 tooltip 数据缓存为空、枪械浏览界面不可用。
</Callout>

## 玩家操作

| 操作 | 效果 |
|---|---|
| 悬停 TACZ 配件按 **Shift** | 打开"支持枪械"浏览界面（模式由服务端决定） |
| 悬停物品按 **V**（默认） | 隐藏/显示 lore 介绍——仅对带 TACZ/神化内容的物品生效 |
| 选项 → 按键绑定 | 可改 lore 切换键 |

## 管理员：枪械浏览界面双模式

服务端 `plugins/ArcartX-Suite/data/tooltip/ArcartXTooltip.yml`：

| `gun-list.mode` | 玩家看到的界面 |
|---|---|
| `ax` | 服务端下发的 AX 自定义 UI（`ui/gun_list.yml`，可自定义皮肤布局） |
| `mod` | 客户端本地界面（服务端只推模式，界面在客户端渲染） |

- 修改后 `axs reload tooltip` 生效，自动向全部在线玩家补推新模式
- `/axs tooltip push <玩家>` 手动重推指定玩家（排查用）
- `/axs tooltip status` 查看当前模式与推送通道

## tip UI 编写：Aria 函数

命名空间 `axstooltip`，均为全局函数，在 `texts`/`visible` 等属性表达式中直接调用，每帧求值实时刷新：

| 函数 | 返回 | 说明 |
|---|---|---|
| `getTaczLore()` | `List<String>` | TACZ 物品文本行（枪械属性/配件增益/弹药箱/工作台，带 `§` 颜色码） |
| `getTaczGuns()` | `List<String>` | 配件"支持枪械"的 itemJson 列表，**背包已持有排前** |
| `getTaczOwnedCount()` | `number` | `getTaczGuns()` 前 N 项为已持有 |
| `getTaczGunNames()` | `List<String>` | 枪械显示名（含 `display.Name` 自定义名） |
| `hasTaczGuns()` / `getTaczGunCount()` / `getTaczGunRows(列数)` | - | 存在性/总数/行数 |
| `shiftDown()` / `showGunGrid()` / `showTaczStats()` | `boolean` | Shift 状态与网格/文本互斥显隐 |
| `getApothLore()` / `getExtraLore()` | `List<String>` | 神化行/合并行 |
| `hasTacz()` / `hasApoth()` / `hasExtra()` | `boolean` | 附加信息存在性 |
| `loreHidden()` | `boolean` | lore 隐藏开关原始状态 |
| `loreVisible()` | `boolean` | **有效显隐**：开关开启且物品带附加内容才隐藏 |
| `toggleLore()` | `boolean` | 翻转开关，返回新状态 |
| `loreKeyName()` | `String` | lore 切换键的本地化显示名（跟随玩家改键） |

### tip yml 最小示例

```yaml
tacz信息:
  type: Text
  val: tacz
  attribute:
    texts: axstooltip.getTaczLore()
    fontSize: 38
    visible: axstooltip.hasTacz()
lore:
  type: Text
  val: lore
  attribute:
    texts: var.lore列表
    visible: axstooltip.loreVisible()
按键提示:
  type: Text
  attribute:
    point: ~bottom_right
    texts: "'§8按 ' + axstooltip.loreKeyName() + (axstooltip.loreVisible() ? ' 隐藏说明' : ' 显示说明')"
    fontSize: 32
```
