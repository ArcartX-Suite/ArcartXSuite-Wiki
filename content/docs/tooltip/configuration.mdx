## 先改哪些内容

先安装并确认配套客户端扩展，再用默认物品提示验证。只改说明文字时，保留匹配和布局，先改一行可见文本；需要按物品类别显示不同提示时，才复制新定义并修改匹配条件。

验证顺序为普通原版物品、自定义物品、枪械或特殊 Mod 物品。名称和图标正常后再加属性区块。完整布局可参考[物品提示示例](/docs/tooltip/tip-example)，每次只改一个控件或匹配条件，避免同时失去默认回退和专用提示。

提示展示开关与枪械界面模式。先使用默认示例完成一次测试，再按本页逐项调整。

配置位置：`plugins/ArcartX-Suite/data/tooltip/config.yml`。定义文件与子目录均相对此模块目录。本文中的 YAML 片段用于修改对应小节，请保留文件中的其他设置。

修改后执行 `/axs reload tooltip`；涉及插件安装或全局设置的变更请重启后验证。

Tooltip 模块使用两个配置文件：主配置 `config.yml`（枪械浏览 UI 模式）与消息文件 `messages.yml`（管理命令输出文本）。首次启动自动释放到 `plugins/ArcartX-Suite/data/tooltip/`。

## 主配置文件（`config.yml`）

```yaml
# Tooltip 模块配置
config-version: 1

gun-list:
  # TACZ 配件"支持枪械"浏览界面的 UI 模式（客户端按"查看支持枪械"键触发，默认 Left Shift）
  #   ax  — 服务端下发 AX 自定义 UI（ui/gun_list.yml，可自定义皮肤布局）
  #   mod — 客户端本地 Forge 界面（服务端只推模式，界面在客户端渲染）
  mode: ax
```

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `config-version` | int | `1` | 配置版本，保持原值 |
| `gun-list.mode` | string | `ax` | 枪械浏览界面风格：`ax` 使用可自定义的 ArcartX 界面，`mod` 使用客户端模组界面 |

<Callout type="info">
修改 `gun-list.mode` 后执行 `/axs reload tooltip`，再用测试账号打开枪械浏览界面确认风格。玩家需要安装对应的客户端扩展。
</Callout>

<Callout type="info">
Tooltip 模块无任何模块依赖与外部插件依赖。缓存过期时间为 60 秒（固定值）。
</Callout>

## 消息文件（`messages.yml`）

`messages.yml` 首次启动时自动释放到 `plugins/ArcartX-Suite/data/tooltip/messages.yml`，定义管理命令输出的所有文本。

### 消息键一览

| 消息键 | 说明 | 参数 |
|---|---|---|
| `prefix` | 所有消息的前缀 | 无 |
| `common.no-permission` | 无权限提示 | 无 |
| `common.player-only` | 仅玩家可执行提示 | 无 |
| `admin.status-title` | 状态命令标题 | 无 |
| `admin.status-cache-size` | 缓存玩家数 | `{0}` - 玩家数量 |
| `admin.status-ttl` | 缓存 TTL | `{0}` - TTL 秒数 |
| `admin.status-no-cache` | 缓存为空提示 | 无 |
| `admin.status-gun-ui-mode` | 枪械 UI 模式 | `{0}` - ax/mod |
| `admin.status-gun-ui-unavailable` | 枪械 UI 服务未启动 | 无 |
| `admin.push-ok` | 推送成功 | `{0}` 玩家 `{1}` 模式 |
| `admin.push-notfound` | 玩家不在线 | `{0}` 玩家名 |
| `admin.push-unavailable` | 枪械 UI 服务未启动 | 无 |
| `admin.push-usage` | push 用法 | 无 |
| `help.title` | 帮助命令标题 | 无 |
| `help.status` | status 子命令帮助 | `{0}` - 根命令标签 |
| `help.push` | push 子命令帮助 | `{0}` - 根命令标签 |

#### 消息前缀（`prefix`）

消息前缀，拼接在所有管理命令输出消息之前。

| 属性 | 值 |
|---|---|
| 默认值 | `&3◆ &6ArcartXSuite &7\| &r` |
| 使用位置 | 所有管理命令输出 |
| 颜色码 | 支持 `&` 颜色码 |

#### 权限不足提示（`common.no-permission`）

无权限时提示文本。

| 属性 | 值 |
|---|---|
| 默认值 | `&c你没有权限执行此操作。` |
| 触发场景 | 玩家无 `arcartxsuite.admin` 权限执行管理命令时 |

#### 仅限玩家使用提示（`common.player-only`）

仅玩家可执行提示文本。

| 属性 | 值 |
|---|---|
| 默认值 | `&c该命令只能由玩家执行。` |
| 触发场景 | 控制台执行仅限玩家的命令时 |

#### 状态信息标题（`admin.status-title`）

`/axs tooltip status` 命令的标题行。

| 属性 | 值 |
|---|---|
| 默认值 | `&6Tooltip 模块状态` |

#### 状态统计数量文字（`admin.status-cache-size`）

缓存玩家数显示行。

| 属性 | 值 |
|---|---|
| 默认值 | `&7缓存玩家数: &f{0}` |
| 参数 `{0}` | 当前缓存中的玩家数量 |

#### 状态统计时效文字（`admin.status-ttl`）

缓存 TTL 显示行。

| 属性 | 值 |
|---|---|
| 默认值 | `&7缓存 TTL: &f{0}秒` |
| 参数 `{0}` | 固定为 `60`（秒） |

#### 无统计数据提示（`admin.status-no-cache`）

缓存为空时的提示行。

| 属性 | 值 |
|---|---|
| 默认值 | `&7缓存为空，等待客户端 mod 发送数据` |
| 触发条件 | 缓存玩家数为 0 |

#### 帮助菜单标题（`help.title`）

`/axs tooltip help` 命令的标题行。

| 属性 | 值 |
|---|---|
| 默认值 | `&6Tooltip 管理` |

#### 状态命令帮助（`help.status`）

status 子命令的帮助说明行。

| 属性 | 值 |
|---|---|
| 默认值 | `&7{0} status&f - 查看模块状态` |
| 参数 `{0}` | 根命令标签（通常为 `/axs tooltip`） |

## 完整配置示例

以下是 `messages.yml` 的完整默认内容，可直接复制使用或按需修改颜色码与文本：

```yaml
# Tooltip 模块消息文件
# 所有消息支持 & 颜色码
# {0} 等为消息参数占位符

# 消息前缀，拼接在所有管理命令输出之前
prefix: "&3◆ &6ArcartXSuite &7| &r"

# 通用消息
common:
  no-permission: "&c你没有权限执行此操作。"
  player-only: "&c该命令只能由玩家执行。"

# 管理命令消息
admin:
  status-title: "&6Tooltip 模块状态"
  status-cache-size: "&7缓存玩家数: &f{0}"
  status-ttl: "&7缓存 TTL: &f{0}秒"
  status-no-cache: "&7缓存为空，等待客户端 mod 发送数据"
  status-gun-ui-mode: "&7枪械 UI 模式: &f{0}"
  status-gun-ui-channel: "&7模式推送通道: &f{0}"
  status-gun-ui-unavailable: "&7枪械 UI: &c服务未启动"
  push-ok: "&a已向 &f{0} &a推送枪械 UI 模式: &f{1}"
  push-notfound: "&c玩家 &f{0} &c不在线"
  push-unavailable: "&c枪械 UI 服务未启动"
  push-usage: "&c用法: /axs tooltip push <玩家>"

# 帮助命令消息
help:
  title: "&6Tooltip 管理"
  status: "&7{0} status&f - 查看模块状态"
  push: "&7{0} push <玩家>&f - 手动重推枪械 UI 模式"
```

## 配置管理

<Callout type="info">
修改配置或 `messages.yml` 后，使用 `/axs reload tooltip` 重载模块即可生效，无需重启服务器。消息文件支持 `&` 颜色码与 `{0}`、`{1}` 等位置参数。
</Callout>

## 自定义消息示例

以下示例展示如何自定义消息文本与颜色：

```yaml
prefix: "&b【Tooltip】&r "

common:
  no-permission: "&c权限不足，无法执行此操作。"
  player-only: "&e此命令仅限游戏内玩家使用。"

admin:
  status-title: "&d&lTooltip 运行状态"
  status-cache-size: "&a当前缓存玩家数: &e{0}"
  status-ttl: "&a缓存有效期: &e{0}秒"
  status-no-cache: "&7暂无缓存数据，请确保客户端已安装 ArcartX-Suite-Tooltips"

help:
  title: "&d&lTooltip 管理命令"
  status: "&a{0} status &7- 查看模块运行状态"
```

<Callout type="info">
消息文件中的 `&` 颜色码会在发送时自动转换为 `§` 颜色码。`{0}` 等位置参数由命令处理器在运行时填充。
</Callout>
