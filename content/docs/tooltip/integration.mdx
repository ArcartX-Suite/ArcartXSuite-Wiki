# 联动

Tooltip 模块通过 `TooltipDataCapable` 公开能力向其他模块提供 tooltip 数据查询服务。模块本身不消费任何其他模块能力，不发布 EventBus 事件，是纯数据提供方。

## TooltipDataCapable 公开接口

第三方模块/插件可通过 `AxsCapabilities.get(TooltipDataCapable.class)` 获取此接口，查询客户端采集的动态 tooltip 数据：

| 方法 | 返回值 | 说明 |
|---|---|---|
| `getTooltipLines(Player)` | `List<String>` | 获取玩家当前手持物品的 tooltip 文本行，无数据时返回空列表 |
| `getTooltipLines(Player, ItemStack)` | `List<String>` | 获取玩家指定物品的 tooltip 文本行，无数据时返回空列表 |
| `getStructuredData(Player)` | `String` | 获取玩家当前手持物品的结构化数据（JSON 字符串），无数据时返回 `"{}"` |
| `hasTooltipData(Player, ItemStack)` | `boolean` | 判断指定物品是否有缓存的 tooltip 数据 |
| `injectLore(ItemStack, List<String>)` | `ItemStack` | 将 tooltip 文本行注入物品 Lore（返回克隆，不改原物品） |

### 使用场景

| 使用场景 | 方法 | 说明 |
|---|---|---|
| 物品预览 | `getTooltipLines` + `injectLore` | 获取文本行并注入物品 Lore，用于 UI 展示 |
| 属性判定 | `getStructuredData` | 解析 JSON 结构化数据，获取枪械属性等数值字段 |
| 数据存在性检查 | `hasTooltipData` | 判断物品是否有 tooltip 数据，决定是否展示相关 UI |
| 聊天展示 | `getTooltipLines` + `injectLore` | 聊天物品展示时注入动态内容 |

<Callout type="info">
`getStructuredData` 返回的 JSON 字符串需消费方自行解析。常见结构化数据字段包括 TACZ 枪械的 `damage`、`armorIgnore`、`headshotMultiplier` 等，以及 Apotheosis 词缀信息，具体字段由客户端 mod 决定。
</Callout>

### 使用注意事项

- 每次需要时获取能力引用，不要在启动时缓存；Tooltip 模块未加载时返回 `null`，需做空值检查
- tooltip 数据缓存 60 秒，消费方应及时使用，不要长期持有
- 物品指纹为物品注册名（不含 NBT），同类型物品共享 tooltip 数据
- tooltip 数据由客户端 mod 采集，客户端未安装 mod 时服务端缓存为空
- `injectLore` 返回克隆物品，支持 `&` 颜色码自动转换

## 与 Chat 模块集成

Chat 模块是 Tooltip 模块的主要消费方。聊天物品展示 `[item]` 时，Chat 自动获取物品 tooltip 文本行并注入 Lore，客户端预览可看到 TACZ 枪属性、Apotheosis 词缀等动态内容。Tooltip 模块未加载时物品预览正常显示，仅缺少动态内容。

## 跨服与存储

- **不使用数据库**，数据仅存内存，不参与 `/axs purge` 与 `/axs migrate`
- **不支持跨服同步**，tooltip 数据仅存在于玩家当前所在服务器；玩家切换服务器后，客户端重新悬停物品会自动重新采集
