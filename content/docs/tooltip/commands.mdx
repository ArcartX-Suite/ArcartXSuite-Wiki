# 命令与占位符

Tooltip 模块通过 `/axs` 命令系统注册管理子命令，提供模块状态查询功能。模块不注册 PlaceholderAPI 占位符，也不提供玩家命令。

## 管理命令

| 命令 | 权限 | 参数 | 说明 |
|---|---|---|---|
| `/axs tooltip help` | `arcartxsuite.admin` | 无 | 查看可用子命令 |
| `/axs tooltip status` | `arcartxsuite.admin` | 无 | 查看模块缓存状态与枪械 UI 模式 |
| `/axs tooltip push <玩家>` | `arcartxsuite.admin` | `<玩家>` 在线玩家名 | 手动重推枪械 UI 模式 |

<Callout type="info">
无参数或未知子命令时，默认显示 `help` 内容。所有子命令均需 `arcartxsuite.admin` 权限，控制台可用。
</Callout>

### `/axs tooltip status`

查看 Tooltip 模块缓存运行状态。

**输出示例**：

```
◆ ArcartXSuite | Tooltip 模块状态
缓存玩家数: 3
缓存 TTL: 60秒
枪械 UI 模式: ax
```

**缓存为空时输出**：

```
◆ ArcartXSuite | Tooltip 模块状态
缓存玩家数: 0
缓存 TTL: 60秒
枪械 UI 模式: ax
缓存为空，等待客户端 mod 发送数据
```

### `/axs tooltip push <玩家>`

手动向指定玩家重新推送枪械 UI 模式，用于验证推送链路是否打通，无需玩家重进。

**输出示例**：

```
◆ ArcartXSuite | 已向 Steve 推送枪械 UI 模式: ax
```

## 权限

| 权限节点 | 默认 | 说明 |
|---|---|---|
| `arcartxsuite.admin` | OP | 执行 Tooltip 管理命令所需权限 |

<Callout type="info">
`arcartxsuite.admin` 是 Suite 的通用管理权限，所有模块的管理命令均使用此权限节点。
</Callout>

## Tab 补全

| 补全位置 | 补全内容 |
|---|---|
| 第 2 参数 | 子命令动作：`help`、`status`、`push` |
| 第 3 参数（`push` 时） | 在线玩家名 |

## PlaceholderAPI

Tooltip 模块**不注册** PlaceholderAPI 占位符，也不依赖 PlaceholderAPI。tooltip 数据通过模块间共享接口提供，详见 [联动](/docs/tooltip/integration)。

## 玩家命令

Tooltip 模块**不提供**玩家命令。

## 枪械浏览界面

模块注册 `AXS:gun_list` 枪械浏览界面（Menu 型，ESC 关闭）：

- `gun-list.mode: ax` 时使用 AX 自定义界面（`ui/gun_list.yml`）
- `gun-list.mode: mod` 时使用客户端本地 Forge 界面
- 模式在玩家进服时自动推送，模块 reload 后补推全部在线玩家，也可用 `push` 命令手动重推
- 客户端未收到推送时默认使用 `mod` 本地界面

<Callout type="info">
经 Bungee/Velocity 代理时，模式推送依赖代理转发插件消息通道。
</Callout>
