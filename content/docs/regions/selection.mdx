# 选区工具

> **付费模块**

Regions 模块提供完整的选区工具链，从选区点的设置、粒子可视化反馈到区域创建，覆盖区域划定全流程。

## 选区工具

### 选区工具配置

选区工具通过 `selection.wand-item` 配置，默认为木斧（`WOODEN_AXE`）：

```yaml
selection:
  wand-item: WOODEN_AXE
  max-volume: 500000
  max-regions-per-player: 20
```

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `selection.wand-item` | `Material` | `WOODEN_AXE` | 选区工具物品类型（MATERIAL 枚举名） |
| `selection.max-volume` | `long` | `500000` | 单次选区最大方块体积，范围 `1` ~ `100000000` |
| `selection.max-regions-per-player` | `int` | `20` | 每玩家最大区域数量，`0` 表示无限 |

### 获取选区工具

通过 `/rg wand` 命令获取选区工具，需要 `axs.regions.select` 权限。

## 选区点设置

### 左键设点 1 / 右键设点 2

手持选区工具操作：

| 操作 | 效果 |
|---|---|
| 左键方块 | 设置选区点 1（红色粒子柱） |
| 右键方块 | 设置选区点 2（绿色粒子柱） |

### 命令设点

| 命令 | 说明 | 权限 |
|---|---|---|
| `/rg pos1` | 设置选区点 1（当前站位） | `axs.regions.select` |
| `/rg pos2` | 设置选区点 2（当前站位） | `axs.regions.select` |

命令设点使用玩家当前站位坐标，选区工具则使用所点方块坐标。

<Callout type="info">
两个选区点必须位于同一世界。玩家退出游戏时选区自动清除。
</Callout>

## 粒子可视化

| 粒子 | 颜色 | 用途 |
|---|---|---|
| 选区点 1 粒子柱 | 红色 | 标记 pos1 位置 |
| 选区点 2 粒子柱 | 绿色 | 标记 pos2 位置 |
| 选区边框 | 青色 | 选区完成后沿 12 条棱勾勒 |
| 区域边框（自己拥有） | 黄色 | `/rg show` 开启后显示 |
| 区域边框（管理员） | 紫色 | 管理员查看所有区域 |

粒子仅对操作者本人可见，大体积选区自动限制粒子数量避免卡顿。

## 区域边框可视化

通过 `/rg show` 命令切换区域边框常驻粒子显示：

| 玩家类型 | 可见区域 | 粒子颜色 |
|---|---|---|
| 普通玩家 | 自己拥有或参与的区域 | 黄色 |
| 管理员（`axs.regions.admin`） | 所有区域 | 紫色 |

区域边框仅显示玩家附近的区域（约 48 方块视距）。

## 区域创建

通过 `/rg define <名称>` 用当前选区创建区域，校验内容：

1. 选区是否完成（两点均已设置）
2. 选区体积是否超过 `max-volume` 限制
3. 区域名称是否在同世界内重复
4. 玩家区域数量是否超过 `max-regions-per-player` 限制（`axs.regions.bypass.limit` 绕过）

创建成功后，创建者自动成为区域所有者，选区自动清除。也可通过 `/rg admin` 面板在 UI 中创建。

## 区域重定义与重命名

- `/rg redefine <名称>`：用当前选区重新划定区域范围（坐标自动归一化）
- 管理员 UI：可对区域重命名，重命名保留范围/优先级/父区域/成员/标志等全部状态

## 区域传送

通过 `/rg tp <区域>` 传送到区域中心（X/Z 中心点，Y 为最高方块上方）。
