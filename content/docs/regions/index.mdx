| 项目 | 说明 |
| --- | --- |
| 模块 ID | `regions` |
| 主配置 | `plugins/ArcartX-Suite/data/regions/config.yml` |
| 主要调整内容 | 区域标志、优先级与世界规则 |
| 重载 | `/axs reload regions` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 使用有 `axs.regions.select` 的账号，在测试区域的两个对角位置分别执行 `/rg pos1` 和 `/rg pos2`。
2. 执行 `/rg define trial_area` 创建区域，再由区域所有者执行 `/rg flag trial_area block-break deny`。
3. 用 `/rg info trial_area` 核对边界，用 `/rg flags trial_area` 查看方块破坏规则。

## 检查是否配置成功

让普通测试玩家分别在区域内外尝试破坏同一种方块。区域内应被拒绝，区域外在没有其他保护时应可正常破坏。

保护测试用没有 `axs.regions.bypass` 的普通玩家。规则无效时，先核对测试方块是否在 `trial_area` 内，再检查重叠区域的优先级。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| 选区工具 | 使用木斧左键设点 1、右键设点 2，粒子柱（红/绿）与选区边框（蓝）实时可视化 |
| 50+ 区域标志 | 覆盖战斗、方块、环境、生物、玩家、杂项六大类别，共 50 个标志 |
| 三态标志 | 每个标志支持 `ALLOW` / `DENY` / `NONE` 三态，`NONE` 表示未设置并继承父区域或全局 |
| 优先级系统 | 区域可设置优先级，高优先级区域的标志覆盖低优先级区域 |
| 父子继承 | 区域可设置父区域，未设置的标志从父区域继承，支持成环检测 |
| 全局区域 | `__global__` 作为无任何区域覆盖时的保底规则 |
| 成员/拥有者 | 支持玩家 UUID 和权限组（`g:` 前缀）两种成员类型，成员对方块/交互类标志豁免 |
| 进出提示 | 进入/离开区域时通过 Actionbar / Chat / Title 三种方式显示通知，支持自定义 greeting/farewell 文本 |
| 世界规则 | 按世界级别的限制（禁飞、禁活塞、禁交互物品），不依赖区域选区，运行时可 CRUD 并持久化 |
