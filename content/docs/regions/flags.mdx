# 标志系统

> **付费模块**

Regions 模块的标志系统是区域保护的核心。模块提供 50 个标志，覆盖战斗、方块、环境、生物、玩家、杂项六大类别，每个标志支持 `ALLOW` / `DENY` / `NONE` 三态，并支持父子继承与成员豁免。

## 三态标志模型

每个标志有三种状态，存储在 `RegionFlag.State` 枚举中：

| 状态 | 别名 | 说明 |
|---|---|---|
| `ALLOW` | `true`、`yes` | 显式允许操作 |
| `DENY` | `false`、`no` | 显式拒绝操作 |
| `NONE` | - | 未设置，继承父区域或全局规则 |

`NONE` 是默认状态，表示该区域未对此标志做出决策。查询时会沿父链向上继承；若所有区域均为 `NONE`，则该位置无保护。

命令中设置标志时，`allow` / `true` / `yes` 均视为允许，`deny` / `false` / `no` 均视为拒绝（不区分大小写），其他值视为 `NONE`（移除标志）。

## 标志判定规则

当玩家在某坐标执行操作时，按以下规则判定标志：

1. 取该坐标的所有覆盖区域，按优先级从高到低逐个检查
2. 区域自身设置了标志 → 采用其值（ALLOW/DENY）
3. 区域未设置（NONE）→ 沿父区域链向上继承；父链全部未设置 → 检查下一个低优先级区域
4. 所有区域均为 NONE → 无保护（允许操作）
5. 玩家拥有 `axs.regions.bypass` 权限 → 一律允许
6. 标志为 DENY 且属成员豁免类时，区域成员自动豁免

## 成员豁免

部分标志对区域成员（含所有者）自动豁免。当标志查询结果为 `DENY` 时，若该标志属于成员豁免类且玩家是区域成员，则返回 `ALLOW`。

### 成员豁免标志列表

| 标志 | 类别 | 说明 |
|---|---|---|
| `block-break` | BLOCK | 方块破坏 |
| `block-place` | BLOCK | 方块放置 |
| `use` | BLOCK | 右键交互 |
| `chest-access` | BLOCK | 容器访问 |
| `vehicle-destroy` | BLOCK | 破坏矿车/船 |
| `vehicle-place` | BLOCK | 放置矿车/船 |
| `item-drop` | PLAYER | 丢弃物品 |
| `item-pickup` | PLAYER | 拾取物品 |
| `ride` | PLAYER | 骑乘实体 |
| `sleep` | PLAYER | 使用床 |

### 成员判定

成员判定支持玩家和权限组两种方式。玩家权限组通过 `axs.regions.group.<name>` 权限节点识别，拥有该节点的玩家视为对应组的成员。

## 管理员绕过

拥有 `axs.regions.bypass` 权限的玩家跳过所有区域保护检查。此权限为全局绕过，影响所有标志类型，不区分区域。

## 标志附加数据

部分标志支持附加数据（自定义文本）。当前使用附加数据的标志：

| 标志 | 数据内容 | 设置方式 |
|---|---|---|
| `greeting` | 进入区域的自定义欢迎文本 | `/rg flag <区域> greeting allow &6欢迎来到出生点！` |
| `farewell` | 离开区域的自定义告别文本 | `/rg flag <区域> farewell allow &c再见！` |

附加数据随标志一起保存，设置后长期有效。

## 标志设置与移除

### 命令方式

```bash
# 设置标志为允许
/rg flag spawn pvp allow

# 设置标志为拒绝
/rg flag spawn block-break deny

# 设置带附加数据的标志
/rg flag spawn greeting allow &6欢迎来到出生点！

# 移除标志（恢复为 NONE，继承父区域）
/rg removeflag spawn pvp

# 查看区域所有已设置标志
/rg flags spawn
```

### UI 方式

管理员通过 `/rg admin` 打开管理面板，在区域编辑页可查看全部 50 个标志的当前状态并直接修改。

## 优先级与继承

### 优先级机制

同一坐标可被多个区域覆盖。高优先级区域的标志先被检查。若高优先级区域设置了该标志（非 `NONE`），则直接采用其值，不再检查低优先级区域。

### 父子继承

区域可设置父区域（须同世界），未设置的标志从父区域继承，沿父链向上查找直到找到非 `NONE` 的值或到顶。设置父区域时自动检测继承环，若沿父链回到自身则拒绝设置。

### 继承示例

```
区域层级：
  __global__ (priority=0)
    └→ town (priority=10, pvp=deny)
        └→ spawn (priority=20, pvp=none, block-break=deny)

查询 spawn 区域的 pvp 标志：
  spawn.pvp = NONE → 继承父区域 town
  town.pvp = DENY → 返回 DENY

查询 spawn 区域的 block-break 标志：
  spawn.block-break = DENY → 直接返回 DENY（不继承）

查询 spawn 区域的 mob-spawning 标志：
  spawn.mob-spawning = NONE → 继承 town
  town.mob-spawning = NONE → 继承 __global__
  __global__.mob-spawning = NONE → 返回 NONE（无保护）
```
