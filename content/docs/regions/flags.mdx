# 标志系统

> **付费模块**

Regions 模块的标志系统是区域保护的核心。模块提供 50 个标志，覆盖战斗、方块、环境、生物、玩家、杂项六大类别，每个标志支持 `ALLOW` / `DENY` / `NONE` 三态，并支持父子继承与成员豁免。

## 三态标志模型

每个标志有三种状态，存储在 `RegionFlag.State` 枚举中：

| 状态 | 别名 | 说明 |
|---|---|---|
| `ALLOW` | `true`、`yes` | 显式允许操作 |
| `DENY` | `false`、`no` | 显式拒绝操作 |
| `NONE` | - | 未设置，继承父区域或全局规则 |

`NONE` 是默认状态，表示该区域未对此标志做出决策。查询时会沿父链向上继承；若所有区域均为 `NONE`，则该位置无保护。

### 状态解析

状态值通过 `RegionFlag.State.fromString()` 解析，不区分大小写：

```java
public static State fromString(String s) {
    if (s == null) return NONE;
    return switch (s.toLowerCase(Locale.ROOT)) {
        case "allow", "true", "yes" -> ALLOW;
        case "deny", "false", "no" -> DENY;
        default -> NONE;
    };
}
```

命令中设置标志时，`allow` / `true` / `yes` 均视为允许，`deny` / `false` / `no` 均视为拒绝，其他值视为 `NONE`（移除标志）。

## 标志查询流程

当玩家在某坐标执行操作时，`RegionManager` 按以下流程查询标志状态：

```
1. 获取该坐标的所有区域（按优先级降序排列）
   └→ 使用空间索引定位目标点所在 cell
   └→ 遍历 cell 内候选区域，精确 contains 校验
   └→ 按优先级降序排序

2. 遍历区域列表，对每个区域解析标志：
   ├→ 区域自身设置了该标志 → 返回其值（ALLOW/DENY）
   └→ 区域未设置（NONE）→ 沿父链向上继承
       └→ 父区域设置了 → 返回父区域值
       └→ 父区域也未设置 → 继续向上
       └→ 到顶仍为 NONE → 检查下一个同坐标区域

3. 所有区域均为 NONE → 返回 NONE（无保护）

4. 玩家相关标志额外检查：
   ├→ 玩家拥有 axs.regions.bypass 权限 → 直接返回 ALLOW
   ├→ 标志为 DENY 且是成员豁免类标志 → 检查玩家是否为区域成员
   └→ 成员豁免类标志：BLOCK_BREAK, BLOCK_PLACE, USE, CHEST_ACCESS,
       VEHICLE_DESTROY, VEHICLE_PLACE, ITEM_DROP, ITEM_PICKUP, RIDE, SLEEP
```

### 两种查询方法

| 方法 | 签名 | 说明 |
|---|---|---|
| `queryFlag` | `(world, x, y, z, flag)` → `State` | 纯坐标查询，不考虑玩家身份，用于环境/生物类标志 |
| `queryFlagForPlayer` | `(loc, flag, player)` → `State` | 带玩家上下文查询，检查管理员绕过与成员豁免 |

### 标志继承解析

`resolveFlag` 方法实现递归继承，沿父链向上查找：

```java
private RegionFlag.State resolveFlag(Region region, RegionFlag flag) {
    RegionFlag.State state = region.getFlag(flag);
    if (state != RegionFlag.State.NONE) return state;
    // 继承父区域
    if (region.parentId() != null) {
        Region parent = getRegion(region.parentId(), region.world());
        if (parent != null) return resolveFlag(parent, flag);
    }
    return RegionFlag.State.NONE;
}
```

父链最多遍历 64 层（由 `wouldCreateCycle` 的 guard 上限保证无无限循环）。

## 成员豁免

部分标志对区域成员（含所有者）自动豁免。当标志查询结果为 `DENY` 时，若该标志属于成员豁免类且玩家是区域成员，则返回 `ALLOW`。

### 成员豁免标志列表

| 标志 | 类别 | 说明 |
|---|---|---|
| `block-break` | BLOCK | 方块破坏 |
| `block-place` | BLOCK | 方块放置 |
| `use` | BLOCK | 右键交互 |
| `chest-access` | BLOCK | 容器访问 |
| `vehicle-destroy` | BLOCK | 破坏矿车/船 |
| `vehicle-place` | BLOCK | 放置矿车/船 |
| `item-drop` | PLAYER | 丢弃物品 |
| `item-pickup` | PLAYER | 拾取物品 |
| `ride` | PLAYER | 骑乘实体 |
| `sleep` | PLAYER | 使用床 |

### 成员判定

成员判定通过 `Region.hasAccess()` 方法，支持玩家 UUID 和权限组两种方式：

```java
public boolean hasAccess(UUID uuid, Set<String> playerGroups) {
    if (isOwner(uuid) || members.contains(uuid)) return true;
    if (playerGroups != null) {
        for (String group : playerGroups) {
            if (ownerGroups.contains(group) || memberGroups.contains(group)) return true;
        }
    }
    return false;
}
```

玩家权限组通过 `axs.regions.group.<name>` 权限节点识别：

```java
private Set<String> getPlayerGroups(Player player) {
    Set<String> groups = new HashSet<>();
    for (var perm : player.getEffectivePermissions()) {
        String p = perm.getPermission();
        if (p.startsWith("axs.regions.group.") && perm.getValue()) {
            groups.add(p.substring("axs.regions.group.".length()));
        }
    }
    return groups;
}
```

## 管理员绕过

拥有 `axs.regions.bypass` 权限的玩家在 `queryFlagForPlayer` 中直接返回 `ALLOW`，跳过所有区域保护检查：

```java
if (player.hasPermission("axs.regions.bypass")) return RegionFlag.State.ALLOW;
```

此权限为全局绕过，影响所有标志类型，不区分区域。

## 标志附加数据

部分标志支持附加数据（`flagData`），通过 `Region.setFlagData()` 存储。当前使用附加数据的标志：

| 标志 | 数据内容 | 设置方式 |
|---|---|---|
| `greeting` | 进入区域的自定义欢迎文本 | `/rg flag <区域> greeting allow &6欢迎来到出生点！` |
| `farewell` | 离开区域的自定义告别文本 | `/rg flag <区域> farewell allow &c再见！` |

附加数据存储在 `axs_rg_flags` 表的 `data` 列（`TEXT` 类型），保存时序列化为字符串。

## 标志设置与移除

### 命令方式

```bash
# 设置标志为允许
/rg flag spawn pvp allow

# 设置标志为拒绝
/rg flag spawn block-break deny

# 设置带附加数据的标志
/rg flag spawn greeting allow &6欢迎来到出生点！

# 移除标志（恢复为 NONE，继承父区域）
/rg removeflag spawn pvp

# 查看区域所有已设置标志
/rg flags spawn
```

### UI 方式

管理员通过 `/rg admin` 打开管理面板，在区域编辑页可查看全部 50 个标志的当前状态，并通过 `set_flag` / `remove_flag` 动作修改标志。UI 推送的标志列表包含 `key`、`desc`、`category`、`state` 四个字段。

### 编程方式

```java
Region region = regionManager.getRegion("spawn", "world");
// 设置标志
region.setFlag(RegionFlag.PVP, RegionFlag.State.DENY);
// 设置附加数据
region.setFlagData(RegionFlag.GREETING, "&6欢迎来到出生点！");
// 移除标志
region.setFlag(RegionFlag.PVP, RegionFlag.State.NONE);
// 持久化
regionManager.saveRegion(region);
```

## 优先级与继承

### 优先级机制

同一坐标可被多个区域覆盖。查询时按优先级降序遍历，高优先级区域的标志先被检查。若高优先级区域设置了该标志（非 `NONE`），则直接返回其值，不再检查低优先级区域。

```java
public List<Region> getRegionsAt(String world, int x, int y, int z) {
    // ... 空间索引查询候选区域 ...
    result.sort(Comparator.comparingInt(Region::priority).reversed());
    return result;
}
```

### 父子继承

区域可设置父区域（须同世界），未设置的标志从父区域继承。继承通过 `resolveFlag` 递归实现，沿父链向上查找直到找到非 `NONE` 的值或到顶。

设置父区域时自动检测继承环：

```java
private boolean wouldCreateCycle(Region region, Region newParent) {
    Region cursor = newParent;
    int guard = 0;
    while (cursor != null && guard < 64) {
        if (cursor == region) return true;
        if (cursor.parentId() == null) return false;
        cursor = manager.getRegion(cursor.parentId(), cursor.world());
        guard++;
    }
    return false;
}
```

### 继承示例

```
区域层级：
  __global__ (priority=0)
    └→ town (priority=10, pvp=deny)
        └→ spawn (priority=20, pvp=none, block-break=deny)

查询 spawn 区域的 pvp 标志：
  spawn.pvp = NONE → 继承父区域 town
  town.pvp = DENY → 返回 DENY

查询 spawn 区域的 block-break 标志：
  spawn.block-break = DENY → 直接返回 DENY（不继承）

查询 spawn 区域的 mob-spawning 标志：
  spawn.mob-spawning = NONE → 继承 town
  town.mob-spawning = NONE → 继承 __global__
  __global__.mob-spawning = NONE → 返回 NONE（无保护）
```

## 容器类型识别

`chest-access` 标志通过 `isContainer()` 方法识别容器方块：

```java
private boolean isContainer(Material type) {
    return type == Material.CHEST || type == Material.TRAPPED_CHEST
        || type == Material.BARREL || type == Material.HOPPER
        || type == Material.DROPPER || type == Material.DISPENSER
        || type == Material.SHULKER_BOX || type.name().contains("SHULKER_BOX")
        || type == Material.FURNACE || type == Material.BLAST_FURNACE || type == Material.SMOKER
        || type == Material.BREWING_STAND;
}
```

支持的容器类型：箱子、陷阱箱、木桶、漏斗、投掷器、发射器、各色潜影盒、熔炉、高炉、烟熏炉、酿造台。
