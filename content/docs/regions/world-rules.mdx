# 世界规则

> **付费模块**

世界规则提供独立于区域系统的世界级限制。与区域标志不同，世界规则不依赖区域选区，而是按世界名直接生效，覆盖飞行、活塞、物品交互三类限制。世界规则可通过管理员 UI 在线修改，修改自动保存到主配置文件。

## 概述

世界规则与区域标志是两套独立的保护机制，各有适用场景：

| 特性 | 区域标志 | 世界规则 |
|---|---|---|
| 依赖选区 | 是，需要划定区域范围 | 否，按世界名直接生效 |
| 粒度 | 区域级（精确坐标范围） | 世界级（整个世界） |
| 三态系统 | `ALLOW` / `DENY` / `NONE` | 开关式（启用/禁用） |
| 继承 | 支持父子继承 | 不支持继承 |
| 成员豁免 | 支持 | 不支持（仅权限绕过） |
| 管理方式 | 命令 + UI | UI 面板 + 配置文件 |
| 持久化 | 数据库 | 主配置文件（`config.yml`） |

## 规则类型

### 禁飞世界

在指定世界中禁止玩家飞行。进入禁飞世界时自动取消飞行状态，阻止飞行切换。

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `world-rules.no-fly-worlds` | `list` | `["world_pvp"]` | 禁止飞行的世界名列表 |
| `world-rules.no-fly-action` | `string` | `cancel` | 进入禁飞世界的处理方式 |
| `world-rules.no-fly-message` | `string` | `&c此世界禁止飞行。` | 禁飞提示消息（支持 `&` 颜色码） |

### 禁活塞世界

在指定世界中阻止活塞推动（含活塞伸出与收回）。

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `world-rules.no-piston-worlds` | `list` | `[]` | 禁止活塞推动的世界名列表 |

### 禁交互物品

在指定世界中禁止玩家与特定物品/方块交互。配置为世界名到 MATERIAL 列表的映射。

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `world-rules.disabled-interactions` | `map` | `{}` | 按世界配置禁止交互的物品/方块类型 |

```yaml
world-rules:
  disabled-interactions:
    world_spawn:
      - ENDER_CHEST
      - ANVIL
    world_creative:
      - CRAFTING_TABLE
```

## 绕过权限

| 权限节点 | 默认 | 绕过的规则 | 说明 |
|---|---|---|---|
| `axs.essentials.fly.bypass` | op | 禁飞世界 | 在禁飞世界中仍可飞行 |
| `axs.essentials.interact.bypass` | op | 禁交互物品 | 可与禁交互物品交互 |
| - | - | 禁活塞世界 | 无绕过权限，活塞限制不可绕过 |

<Callout type="info">
世界规则的绕过权限使用 `axs.essentials.*` 前缀，由 Essentials 模块提供（Essentials 为 Regions 的软依赖）。
</Callout>

## 运行时管理

世界规则通过管理员面板（`/rg admin`）的 `world_rules` 页面在线管理：

- 切换各世界的禁飞 / 禁活塞状态
- 按世界增删禁交互物品
- 修改自动保存，无需手动编辑配置文件或执行重载命令

## 配置示例

### 最小配置

```yaml
world-rules:
  no-fly-worlds: []
  no-fly-action: cancel
  no-fly-message: "&c此世界禁止飞行。"
  no-piston-worlds: []
  disabled-interactions: {}
```

### 完整配置

```yaml
world-rules:
  no-fly-worlds:
    - "world_pvp"
    - "world_nether"
  no-fly-action: cancel
  no-fly-message: "&c此世界禁止飞行。"
  no-piston-worlds:
    - "world_spawn"
  disabled-interactions:
    world_spawn:
      - ENDER_CHEST
      - ANVIL
      - CRAFTING_TABLE
    world_creative:
      - ENCHANTING_TABLE
```

## 与区域标志的协作

世界规则与区域标志可以同时生效，互不冲突：

| 场景 | 世界规则 | 区域标志 | 效果 |
|---|---|---|---|
| 禁飞世界中的飞行区域 | 禁飞 | `fly` = `allow` | 世界规则优先，禁止飞行 |
| 禁活塞世界中的活塞区域 | 禁活塞 | `pistons` = `allow` | 世界规则优先，禁止活塞 |
| 禁交互世界中的交互区域 | 禁交互 | `use` = `allow` | 世界规则优先，禁止交互 |

<Callout type="warn">
世界规则的限制优先于区域标志。若需要在特定区域内允许被世界规则禁止的操作，需通过绕过权限（`axs.essentials.fly.bypass` 等）实现。
</Callout>
