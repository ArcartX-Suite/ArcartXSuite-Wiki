# Suite

import Link from 'next/link';

Suite 是面向 ArcartX 客户端 MOD 生态的 Minecraft 服务器插件套件：一个插件覆盖 30 个功能领域，模块可按需启用，统一使用 ArcartX UI。

---

## 功能概览

- 统一管理 AttributePlus / CraneAttribute / MythicLib / Symphony 等属性桥接
- MythicMobs / NeigeItems / MMOItems 等物品来源桥接
- Vault / PlayerPoints 等经济桥接
- 内置跨服传输（Redis + Proxy）、按键绑定服务、聊天签名绕过、账号类型识别等基础功能

---

## 核心特性

### 模块化
全部 30 个模块支持热加载 / 热卸载，`config.yml` 一键开关，按需启用。

### 开放 API
提供公开 API（`axs-api`），支持开发第三方模块扩展功能，详见 [开发者指南](../developer/)。

### 跨模块联动
模块间零配置联动。事件包、称号授予、邮件派发、聊天卡片、QQ 推送等能力可自由组合。

### ArcartX UI 原生
所有模块统一使用 ArcartX 客户端 UI 渲染，实现游戏级沉浸式交互体验。

### 智能配置体检
自动检测配置结构差异、类型错误、字段迁移，一键修复。

### 跨服同步
支持 Redis + Proxy 双后端跨服传输，Market 拍卖行、OnlineRewards 签到、Mail 邮件、Tab 列表等模块可跨服务器无缝同步。

---

## 环境要求

- **Java** 17+
- **Minecraft** 1.20.1+（Spigot / Paper / Mohist / Arclight）
- **ArcartX** 客户端 MOD
