Suite 可让称号、道具等功能使用属性插件、持续药水效果及兼容环境中的模组实体属性。它们不是同一种加成，需要分别配置和验证。

## 区分加成来源

| 类型 | 功能 | 使用前确认 |
| --- | --- | --- |
| 属性插件加成 | 攻击、暴击等由属性插件定义的数值 | 对应插件成功启用，属性键存在，主配置允许使用该来源 |
| 持续药水效果 | 装备期间持续提供速度、急迫等效果 | 目标模块支持该效果，`potion-aura.enabled` 开启 |
| 模组实体属性 | 使用兼容混合服务端中模组提供的属性 | 模组与属性都存在，`mod-attributes.enabled` 开启 |

主配置 `attribute-bridges` 分别控制 AttributePlus、CraneAttribute、MythicLib、Symphony。开关不会安装插件或自动创建属性，具体属性名和单位由所用插件定义。

## 哪些模块实际使用

| 模块 | 实际用途 | 配置与限制 |
| --- | --- | --- |
| [Title](/docs/title) | 装备、收藏及套装属性；装备称号的持续药水；符合条件的模组属性加成 | 属性插件加成、药水和模组属性分别配置；不是改一行描述就全部生效 |
| [Prop](/docs/prop) | 道具使用时应用定时属性、药水、生命、饥饿或经验等效果 | 使用自己的 `effects` 类型与 `Duration`；不会自动读取称号字段，也不是本体光环刷新规则 |
| [Abyss](/docs/abyss) | 副本脚本、Buff 等效果；副本属性修饰 | `apply_potion` 与 `apply_attribute` 是不同动作；当前 `apply_attribute` 使用 Symphony，不能推断安装任意属性插件都能替代 |
| [CombatEffect](/docs/combateffect) | 读取属性插件提供的伤害、治疗等事件，用于显示与触发 | 主要是消费战斗结果，不是给所有玩家增加一组基础属性 |
| [EntityTracker](/docs/entitytracker) | 读取伤害事件并进行 Boss 追踪与统计 | 与伤害来源、怪物和追踪设置相关，不是称号或道具加成的另一份配置 |

本体提供了通用能力，但只有对应模块实际调用的功能才受它影响。特别是 `potion-aura` 不能当作“控制所有模块药水”的总开关。

## 示例：称号提供持续药水

在一个已经有效的称号定义中增加：

```yaml
display-effects:
  speed: 1
```

表示装备该称号期间提供一级速度效果。当前按已装备且可访问的各组称号汇总，不只是聊天里选中的主展示称号。此处等级从 `1` 开始，不要把命令中可能使用的零起始等级照搬。具体位置见[称号定义](/docs/title/title-definitions)。

本体主配置控制持续效果的总体表现：

```yaml
potion-aura:
  enabled: true
  refresh-interval-ticks: 60
  effect-duration-ticks: 200
  particles: false
  icon: true
```

默认约每三秒刷新一次十秒效果。效果时长应大于刷新间隔，卸下来源后可能需要等待剩余时长结束。`particles` 与 `icon` 分别控制粒子和图标，不决定加成数值。

主配置修改执行 `/axs reload all`，称号定义修改执行 `/axs reload title`。两处都修改时可统一重载全部模块，再装备、卸下测试。

## 展示属性与收藏属性

称号的 `display-attributes` 在装备时使用，`collection-attributes` 在拥有且满足称号状态条件时使用。仅编辑 `display-attribute-lines` 等展示文字，不会自动得到同名数值加成。

隐藏称号不等于回收称号，收藏属性是否仍生效，应按[称号状态规则](/docs/title/player-state)检查。测试时分别记录未拥有、已拥有未装备、已装备与过期状态，避免把几种来源相加后的结果误认为单项配置值。

快捷道具的效果类型与触发方式另有格式，不能把称号的 `display-effects` 直接放到道具配置。应从[道具功能配置](/docs/prop/configuration)选择所需效果。

## 道具与副本的定时效果

Prop 的药水写在道具 `effects` 中，例如：

```yaml
Duration: 30
effects:
  - "potion|speed:1"
```

表示使用该道具后提供 30 秒一级速度。`Duration` 的大小写要保留，当前读取的不是小写 `duration`。属性插件效果另有 `ap`、`ml` / `mythiclib`、`sy` / `symphony` 等类型，需按对应插件格式填写，不能把它们当作药水名称。

副本脚本中则是动作行，例如：

```text
apply_potion @trigger SPEED 30 1
```

表示对触发玩家施加 30 秒一级速度；需要在副本脚本的有效动作位置使用。副本 Buff、脚本动作与称号持续效果的结束条件不同，副本效果见[脚本与动作](/docs/abyss/scripting)。

## 模组属性与枪械兼容

模组属性仅在相应服务端环境中有意义，属性 ID 必须为实际存在的注册名称。普通插件服务端不会因为开启开关就支持 Forge 属性。

称号的 `permanent-display-bonuses` 当前只对**永久拥有且已装备**的有效称号汇总，不是拥有一个限时称号也能得到永久模组加成。“永久”是此类配置的生效条件，不表示卸下称号后加成仍然保留。

`tacz-compat` 用于识别 TACZ 枪械伤害，以便相关战斗和追踪功能正确统计；它不是全局伤害倍率。修改此兼容设置需重启，具体字段见[本体安装与配置](/docs/guide/first-run#属性插件与模组兼容)。

## 无效果时怎样检查

| 现象 | 检查方法 |
| --- | --- |
| 界面描述变化但数值没变 | 是否只改了展示文字，属性键和提供插件是否正确 |
| 装备称号没有药水 | 称号是否实际装备、效果名与等级是否有效、本体持续效果开关是否开启 |
| 卸下后效果短暂存在 | 等待已施加效果到期，再判断是否仍有其他来源 |
| 插件属性报未注册 | 先在属性插件中核对名称与配置，不要通过修改描述行解决 |
| 多种加成后结果不符 | 先逐一关闭测试来源，区分装备、收藏、套装及其他插件的效果 |

日志中的来源不可用、效果名无效等提示见[日志与报错提示](/docs/guide/config-management)。
