## 开始前

先按发行版提供的部署说明完成群组服基础配置，确认各子服已安装所需插件。这里只说明模块功能的使用开关。

## 按模块开启

需要支持跨服的模块，在其功能配置中启用对应开关。例如支持以下格式的模块：

```yaml
cross-server:
  enabled: true
```

Chat 还需要为指定频道开启 `cross-server: true`；Tab、公告、邮件等功能以各模块配置页为准。不同模块的可同步内容并不相同，不要将一个模块的设置直接复制到其他模块。

## 验证步骤

1. 分别在两台子服检查模块已加载。
2. 确认双方启用的是同一项跨服功能。
3. 在子服 A 发送测试消息或执行测试业务。
4. 在子服 B 确认收到对应结果，且内容、数量符合预期。

跨服功能未生效时，先确认普通单服功能可用，再检查发行版部署设置与双方模块开关。
