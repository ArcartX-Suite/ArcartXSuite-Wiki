# 货币系统

ArcartX-Suite 内置统一货币桥接层，所有涉及经济的模块（Warehouse、Mail、Map、Market、OnlineRewards 等）共享同一组货币定义。你只需在 `config.yml` 顶部的 `currencies` 节配置一次，全局生效。

## 基本结构

```yaml
currencies:
  <货币ID>:
    enabled: true
    provider: "<提供者类型>"
    display-name: "显示名称"
    scale: 2
    rounding: "DOWN"
    # 以下三项仅 command / placeholder-command / custom 类型需要
    balance-placeholder: ""
    withdraw-command: ""
    deposit-command: ""
```

### 通用字段说明

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enabled` | boolean | `true` | 设为 false 则跳过该货币 |
| `provider` | string | `"vault"` | 提供者类型 |
| `display-name` | string | 货币 ID | 显示给玩家的名称 |
| `scale` | int | `2` | 小数精度位数。0 = 整数，2 = 保留两位小数 |
| `rounding` | string | `DOWN` | 舍入策略，支持 HALF_UP 等标准 RoundingMode 名称 |
| `balance-placeholder` | string | — | PAPI 占位符，返回纯数字余额（command 类型必填） |
| `withdraw-command` | string | — | 扣款时执行的控制台命令（command 类型必填） |
| `deposit-command` | string | — | 入账时执行的控制台命令（command 类型必填） |

> `scale` 是标准小数位字段；为兼容旧配置，parser 仍会在缺少 `scale` 时读取 `precision`。

## 支持的 Provider 类型

| Provider | 前置插件 | 适用场景 |
|----------|----------|----------|
| `vault` | Vault + 经济插件 | 最通用，适配 CMI / EssentialsX 等 Vault 经济 |
| `playerpoints` | PlayerPoints | 整数点券系统 |
| `xconomy` | XConomy | 直连 XConomy 原生 API |
| `rondo` | Rondo | ArcartX 生态多货币插件 |
| `command` | PlaceholderAPI | 通过控制台命令 + PAPI 占位符桥接任意经济 |
| `placeholder-command` | PlaceholderAPI | 同 command，别名 |
| `custom` | PlaceholderAPI | 同 command，别名 |

> `command`、`placeholder-command`、`custom` 三个名称完全等价，内部使用相同的桥接实现。

## Provider 详解

### vault — Vault 经济

需要服务端安装 Vault 插件以及至少一个注册了 Vault Economy 服务的经济插件。

```yaml
currencies:
  money:
    enabled: true
    provider: "vault"
    display-name: "金币"
    scale: 2
    rounding: "DOWN"
```

一个服务端只能注册一个 Vault Economy 服务。如果需要多种货币，请使用 `rondo` 或 `command` 类型。

### playerpoints — PlayerPoints 点券

适用于基于整数点数的经济系统。建议设置 `scale: 0`。

```yaml
currencies:
  points:
    enabled: true
    provider: "playerpoints"
    display-name: "点券"
    scale: 0
    rounding: "DOWN"
```

### xconomy — XConomy 原生经济

直接调用 XConomy 原生 `XConomyAPI`，不经过 Vault。余额查询、充值和扣款全程使用 `BigDecimal`。

```yaml
currencies:
  money:
    enabled: true
    provider: "xconomy"
    display-name: "金币"
    scale: 2
    rounding: "DOWN"
```

### rondo — Rondo 多货币

Rondo 原生支持多种货币 ID。ArcartX-Suite 会将配置中的货币 ID 直接传递给 Rondo API。

```yaml
currencies:
  money:
    enabled: true
    provider: "rondo"
    display-name: "金币"
    scale: 2
    rounding: "DOWN"
  points:
    enabled: true
    provider: "rondo"
    display-name: "点券"
    scale: 0
    rounding: "DOWN"
```

> ArcartX-Suite 中的货币 ID（即 `currencies:` 下的键名）会直接作为 Rondo 的 `currencyId` 参数传递，请确保两边 ID 完全一致。

### command — 命令桥接

最灵活的类型。通过 PAPI 占位符读取余额，通过控制台命令执行扣款和入账。

```yaml
currencies:
  gems:
    enabled: true
    provider: "command"
    display-name: "宝石"
    scale: 0
    rounding: "DOWN"
    balance-placeholder: "%economy_balance_gems%"
    withdraw-command: "esc take gems %player% %amount%"
    deposit-command: "esc give gems %player% %amount%"
```

`balance-placeholder`、`withdraw-command`、`deposit-command` 三项必须全部填写，否则该货币桥接将标记为不可用。

#### 命令模板变量

| 变量 | 替换为 | 示例 |
|------|--------|------|
| `%player%` | 玩家名 | `Steve` |
| `%uuid%` | 玩家 UUID | `069a79f4-...` |
| `%amount%` | 操作金额（经过精度处理） | `100`、`99.5` |

命令不需要加 `/` 前缀（加了也会自动去除），以控制台身份执行。

#### 常见经济插件示例

Economy：

```yaml
currencies:
  gems:
    enabled: true
    provider: "command"
    display-name: "宝石"
    scale: 0
    rounding: "DOWN"
    balance-placeholder: "%economy_balance_gems%"
    withdraw-command: "eco take gems %player% %amount% gems"
    deposit-command: "eco give gems %player% %amount% gems"
```

CoinsEngine：

```yaml
currencies:
  coins:
    enabled: true
    provider: "command"
    display-name: "硬币"
    scale: 0
    rounding: "DOWN"
    balance-placeholder: "%coinsengine_balance_coins%"
    withdraw-command: "coinsengine take %player% coins %amount%"
    deposit-command: "coinsengine give %player% coins %amount%"
```

## 完整配置示例

```yaml
currencies:
  # 主货币 — Vault
  money:
    enabled: true
    provider: "vault"
    display-name: "金币"
    scale: 2
    rounding: "DOWN"
  # 点券 — PlayerPoints
  points:
    enabled: true
    provider: "playerpoints"
    display-name: "点券"
    scale: 0
    rounding: "DOWN"
  # 宝石 — 命令桥接
  gems:
    enabled: true
    provider: "command"
    display-name: "宝石"
    scale: 0
    rounding: "DOWN"
    balance-placeholder: "%economy_balance_gems%"
    withdraw-command: "eco take gems %player% %amount% gems"
    deposit-command: "eco give gems %player% %amount% gems"
```

## 模块局部货币

部分模块（如 Warehouse、Map、Market）在自身配置中也支持 `currencies` 节。模块中定义的货币会合并到全局池中，但不覆盖已有的同名货币。全局 `config.yml` 中的货币定义优先。

## 货币变动事件

`CurrencyBridgeManager` 在每次 `withdraw` / `deposit` 成功后，自动通过 `EventBusCapability` 分发货币变动事件。

| 事件主题 | 触发时机 |
|---------|---------|
| `axs.currency.spent` | 扣款（withdraw）成功时 |
| `axs.currency.earned` | 入账（deposit）成功时 |

Payload 字段：

| 字段 | 说明 |
|------|------|
| `currency_id` | 货币 ID |
| `amount` | 变动金额 |
| `action` | `"withdraw"` 或 `"deposit"` |
| `balance_after` | 变动后余额 |

该机制对所有货币提供者自动生效。模块（如 BattlePass）可通过 `event-topic` 订阅这些事件来追踪消费/收入。

## 状态检查

使用 `/axs status` 命令可以查看当前已注册的货币数量：

```
ArcartXSuite 状态:
 - 货币桥接: 已注册 3 种货币
```

如果某个货币的 provider 不可用（如 Vault 未安装），该货币的所有操作将返回失败结果，不会导致崩溃。

## 故障排除

| 现象 | 排查方向 |
| --- | --- |
| 货币不可用，提示"桥接不可用" | 确认前置插件已安装、provider 拼写正确 |
| Vault 提示未注册 | 安装一个 Vault 经济插件（如 CMI、EssentialsX） |
| PlayerPoints 余额始终为 0 | 将 `scale` 设为 `0`（整数点数） |
| command 类型扣款失败 | 在控制台手动执行扣款命令确认可用，检查命令格式（不带 `/`） |
| `balance-placeholder` 返回非数字 | 确保占位符返回纯数字，不含货币符号 |
