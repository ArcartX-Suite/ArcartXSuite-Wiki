# 命令速查

本页列出 ArcartX-Suite 全部可用命令及其用法。`&lt;参数>` 表示必填，`[参数]` 表示选填，`A|B` 表示二选一。

## 管理命令

主入口：`/axs`（别名 `/ArcartX-Suite`），需要权限 `arcartxsuite.admin`（默认 OP）。

### 全局管理

| 命令 | 说明 |
| --- | --- |
| `/axs` 或 `/axs status` | 查看全部模块运行状态 |
| `/axs help` | 查看帮助及已加载模块列表 |
| `/axs reload all` | 重载本体配置 + 全部模块 |
| `/axs reload &lt;模块名>` | 仅重载指定模块 |
| `/axs load &lt;模块名>` | 热加载新模块（从 `modules/` 扫描） |
| `/axs unload &lt;模块名>` | 热卸载模块（释放 ClassLoader） |
| `/axs diagnostic` | 生成运行环境诊断报告到 `diagnostics/` 目录 |
| `/axs purge &lt;玩家名\|all> [模块ID\|all]` | 仅控制台。清除玩家模块数据，需 10 秒内重复确认 |
| `/axs migrate &lt;模块ID\|all> &lt;sqlite-to-mysql\|mysql-to-sqlite> [overwrite]` | 仅控制台。跨源数据库一键迁移 |

### 智能配置体检

| 命令 | 说明 |
|--------|------|
| `/axs config status` | 查看当前会话诊断概况 |
| `/axs config diagnose [ownerId\|all]` | 重新运行诊断 |
| `/axs config preview &lt;ownerId\|all>` | 控制台输出 issue 详情 |
| `/axs config apply &lt;ownerId\|all> [--force]` | 应用自动修复提案 |
| `/axs config rollback &lt;ownerId\|all> [--to &lt;timestamp>]` | 还原备份 |

### 云端模块管理

| 命令 | 说明 |
| --- | --- |
| `/axs sync` | 从云端同步授权模块列表并加载新授权的模块 |
| `/axs update &lt;模块ID\|all>` | 从云端强制更新模块到最新版本并热加载 |

### 多方认证管理

| 命令 | 说明 |
| --- | --- |
| `/axs auth status` | 查看 authlib-injector 加载状态与混合代理连通性 |
| `/axs auth setup [api-url]` | 一键下载 authlib-injector 并生成启动脚本 |
| `/axs auth update` | 手动更新最新版 authlib-injector |
| `/axs auth check` | 检测 authlib-injector 最新版本并输出提示 |

### 统一二级密码

| 命令 | 权限 | 说明 |
| --- | --- | --- |
| `/axs password set &lt;新密码> [旧密码]` | `arcartxsuite.password` | 设置二级密码 |
| `/axs password unlock &lt;密码>` | `arcartxsuite.password` | 解锁二级密码 |
| `/axs password clear &lt;密码\|玩家名>` | `arcartxsuite.password` / `arcartxsuite.admin` | 清除自己或指定玩家的密码 |

## 模块管理命令

以下命令均以 `/axs &lt;模块名>` 为前缀，仅管理员可用。每个模块都自带 `status` 子命令。

### EntityTracker

| 命令 | 说明 |
| --- | --- |
| `/axs entitytracker sessions [mobId]` | 列出当前正在追踪的 Boss 会话 |
| `/axs entitytracker rank &lt;实体UUID> [页码]` | 查看指定 Boss 的实时伤害排行榜 |
| `/axs entitytracker settlements [页码]` | 分页查看历史结算记录 |
| `/axs entitytracker settlement &lt;结算ID> [页码]` | 查看某次结算的详细排名 |
| `/axs entitytracker reissue &lt;结算ID> &lt;名次> [玩家]` | 补发奖励 |

### EventPacket

| 命令 | 说明 |
| --- | --- |
