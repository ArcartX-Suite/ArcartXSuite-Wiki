命令在游戏中带 `/` 输入；在服务器控制台通常省略开头的 `/`。`<参数>` 为必填，`[参数]` 为可选，不要输入尖括号或方括号本身。

## 日常管理

| 命令 | 用途 |
| --- | --- |
| `/axs help` | 查看帮助 |
| `/axs status` | 查看模块加载状态 |
| `/axs reload <模块ID>` | 重载单个模块配置 |
| `/axs reload all` | 重载全局配置与模块 |
| `/axs sync` | 同步已装备模块 |
| `/axs update <模块ID>` | 更新指定模块，操作前先备份并阅读发行说明 |

管理操作需要 `arcartxsuite.admin` 权限。普通玩家的功能权限见各模块的「命令与权限」页。

## 配置检查

| 命令 | 用途 |
| --- | --- |
| `/axs config diagnose <模块ID>` | 检查配置 |
| `/axs config preview <模块ID>` | 查看建议 |
| `/axs config apply <模块ID>` | 应用已确认的修复建议 |
| `/axs config rollback <模块ID>` | 恢复配置备份 |

## 查找某个功能的命令

进入[模块目录](/docs)，选择模块后打开「命令与权限」。玩家入口例如 `/menu open example`、`/warehouse open` 和 `/onlinerewards open`，以模块实际配置为准。
