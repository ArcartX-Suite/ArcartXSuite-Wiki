---
title: "PlaceholderAPI 占位符"
description: "查找各模块可用于文字展示的占位符，以及解析失败时的排查方式。"
---

占位符是放在文字中的变量。例如 `%axsfishing_level%` 会被替换为当前玩家的钓鱼等级，可用于支持 PlaceholderAPI 的菜单、聊天、计分板等显示位置。

命令配置中的 `{player}` 由 Suite 对应字段填入玩家名。下表的百分号占位符由 PlaceholderAPI 解析，填入命令时也需要该字段明确支持 PAPI。参见[配置写法](/docs/guide/config-syntax)。

## 第一次使用

1. 安装 PlaceholderAPI 并重启服务器。
2. 启用需要查询的 Suite 模块，使用 `/axs status` 确认模块已经加载。Suite 自带的占位符由对应模块注册，无需从 eCloud 另行下载。
3. 使用在线玩家测试。例如在游戏内输入下方命令，确认返回实际数字后，再把占位符填入目标插件支持 PAPI 的文字字段。

```text
/papi parse me %axsfishing_level%
/papi parse me %axsmail_unread_count%
```

控制台测试时，将 `me` 换成在线玩家名称。以下字段按所属模块分组，未启用的模块不提供对应变量。

## 写法与显示示例

保留两侧的 `%` 和完整前缀。包含 `<分类ID>`、`<组ID>` 等标记的写法是模板，需要替换为自己配置中的实际 ID，不保留尖括号。

```text
钓鱼等级：%axsfishing_level%
鱼类图鉴：%axsfishing_collection%
未读邮件：%axsmail_unread_count%
战令等级：%axsbattlepass_level%
```

例如，额外背包分类 ID 为 `materials` 时，使用 `%axsvanillabackpack_used_materials%`。具体填在哪个配置字段，由显示文字的目标插件决定；并非所有文本字段都会自动解析 PAPI。

返回类型为“布尔”的字段输出 `true` 或 `false`，不会自动转换成“是 / 否”。时间、百分比等字段是否已经格式化，以表内说明为准。

## 挂机奖励

用于展示玩家挂机状态与奖励进度，需启用 [挂机奖励模块](/docs/afkreward)。

| 占位符 | 返回内容 |
| --- | --- |
| `%axsafkreward_type%` | 挂机类型 |
| `%axsafkreward_status%` | 挂机中 / 未挂机 |
| `%axsafkreward_area%` | 当前挂机区域名称 |
| `%axsafkreward_time%` | 当前挂机时长，已格式化 |
| `%axsafkreward_session_time%` | 本次会话挂机时长，已格式化 |
| `%axsafkreward_session_rewards%` | 本次会话获得的奖励次数 |
| `%axsafkreward_daily_seconds%` | 今日挂机总秒数 |
| `%axsafkreward_total_time%` | 累计挂机时长，已格式化 |
| `%axsafkreward_total%` | 累计奖励次数 |
| `%axsafkreward_multiplier%` | 当前奖励倍率 |
| `%axsafkreward_next%` | 距离下次奖励的剩余秒数 |

## 无法解析时怎么检查

| 现象 | 检查方式 |
| --- | --- |
| 原样显示 `%...%` | 先执行 `/papi parse`；检查 PlaceholderAPI 是否安装、前缀拼写和对应模块是否已加载 |
| 命令可以解析，菜单或计分板仍原样显示 | 检查目标插件该字段是否支持 PAPI，以及是否需要启用其占位符解析选项 |
| 返回空文字 | 使用在线玩家测试，并确认玩家当前具有对应状态，例如已经进入挂机区域、装备称号或进入副本 |
| 返回 `0` 或 `false` | 这些可能是正常结果；先在游戏中产生对应数据，再重新解析 |
| 带 ID 的字段无结果 | 将模板中的尖括号内容替换为配置 ID，检查 ID 是否存在，不要使用中文显示名称代替 |
| 数字没有随状态变化 | 比较 `/papi parse` 的结果；若命令已变化而界面未变化，检查目标插件的刷新间隔 |
| 彩色文本显示异常 | 检查目标插件支持的颜色格式；PAPI 解析成功不代表目标插件一定支持该颜色格式 |

安装或调整插件后，优先完整重启服务器，再用同一在线玩家重新测试。不要直接把空值认定为模块故障，也不要给已经格式化的时间和百分比重复追加单位。
