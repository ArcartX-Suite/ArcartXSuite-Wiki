# PlaceholderAPI 占位符

本页列出 ArcartX-Suite 对外输出的全部 PlaceholderAPI 占位符。

> 前置条件：服务器需安装 PlaceholderAPI 插件，ArcartX-Suite 会在启动时自动注册占位符。

## 占位符总览

ArcartX-Suite 共有 16 个模块对外输出 PAPI 占位符：

| 模块 | 前缀 | 说明 |
| --- | --- | --- |
| AfkReward | `%axsafkreward_*%` | 区域挂机状态、时长、奖励次数 |
| BattlePass | `%axsbattlepass_*%` | 战令等级、XP、通行证层级 |
| EntityTracker | `%axsentitytracker_*%` | Boss 追踪、伤害排行、结算数据 |
| Essentials | `%axsess_*%` | AFK、隐身、飞行、昵称等玩家状态 |
| Title | `%axstitle_*%` | 称号前缀/后缀、装备状态、属性加成 |
| RGB | `%axsrgb_*%` | 动态渐变彩色文本渲染（必装 PAPI） |
| OnlineRewards | `%axsonlinerewards_*%` | 在线时长、签到状态、排行榜 |
| Mail | `%axsmail_*%` | 邮箱未读数、可领取数 |
| Chat | `%axschat_*%` | 聊天频道、禁言状态 |
| LoginView | `%axsloginview_*%` | 账号来源识别 |
| Warehouse | `%axswarehouse_*%` | 仓库容量、银行余额 |
| Market | `%axsmarket_*%` | 拍卖数量、商店数、Redis 状态 |
| QQBot | `%axsqqbot_*%` | OneBot 连接状态、QQ 绑定信息 |
| Tab | `%axstab_*%` | Tab 在线列表变量 |
| Fishing | `%axsfishing_*%` | 钓鱼等级、经验、捕获数 |
| Lottery | `%axslottery_*%` | 保底计数、开箱次数、命运点 |

## AfkReward 占位符

前缀：`%axsafkreward_&lt;字段>%`

| 占位符 | 返回值 | 说明 |
| --- | --- | --- |
| `%axsafkreward_type%` | 文本 | 挂机类型：区域挂机 / 原地挂机 / 未挂机 |
| `%axsafkreward_status%` | 文本 | 挂机状态：挂机中 / 未挂机 |
| `%axsafkreward_mode%` | 文本 | 挂机模式名称 |
| `%axsafkreward_area%` | 文本 | 当前所在区域名称 |
| `%axsafkreward_time%` | 文本 | 当前挂机时长（格式化） |
| `%axsafkreward_multiplier%` | 数字 | 当前倍率 |
| `%axsafkreward_session_rewards%` | 数字 | 本次会话已获得奖励数 |
| `%axsafkreward_daily_seconds%` | 数字 | 今日已挂机总秒数 |
| `%axsafkreward_total_time%` | 文本 | 累计总挂机时长 |
| `%axsafkreward_total%` | 数字 | 累计获得奖励总次数 |
| `%axsafkreward_players%` | 数字 | 当前区域同时挂机人数 |
| `%axsafkreward_next%` | 数字 | 距离下次奖励的剩余秒数 |
| `%axsafkreward_top_&lt;名次>_name%` | 文本 | 排行榜指定名次玩家名 |
| `%axsafkreward_top_&lt;名次>_time%` | 文本 | 排行榜指定名次总时长 |

## EntityTracker 占位符

前缀：`%axsentitytracker_&lt;字段>%`

### 全局信息

| 占位符 | 返回值 | 说明 |
| --- | --- | --- |
| `%axsentitytracker_sort_mode%` | 文本 | 当前 Boss 排序模式 |
| `%axsentitytracker_max_visible_bars%` | 数字 | 最大同时显示 Boss 血条数 |
| `%axsentitytracker_active_session_count%` | 数字 | 当前活跃 Boss 战斗会话数 |

### 玩家视野中的 Boss

| 占位符 | 说明 |
| --- | --- |
| `%axsentitytracker_current_&lt;字段>%` | 视野中第一个 Boss 的信息 |
| `%axsentitytracker_slot_&lt;N>_&lt;字段>%` | 第 N 个 Boss 的信息 |
| `%axsentitytracker_boss_count%` | 该玩家视野中的 Boss 数量 |

常用字段：`display_name`、`health_percent`、`mob_id`、`viewer_rank`、`viewer_damage`、`top_&lt;排名>_name`、`top_&lt;排名>_damage`

### 最近结算

| 占位符 | 说明 |
| --- | --- |
| `%axsentitytracker_last_rank%` | 最近结算中的排名 |
| `%axsentitytracker_last_damage%` | 造成的伤害值 |
| `%axsentitytracker_last_boss_name%` | 被击杀的 Boss 名称 |

## 反向消费 PAPI

部分模块会读取其他插件的 PAPI 占位符作为数据来源，无需额外配置：

| 模块 | 配置字段 | 用途 |
| --- | --- | --- |
| Tab | `tabs.&lt;id>.pack` / `sort-papi-key` | 渲染自定义行并按占位符值排序 |
| EventPacket | `rules.&lt;id>.placeholder` / `conditions` | 监控占位符值变化或条件判断 |
| Mail | `currencies.&lt;id>.balance-placeholder` | 读取玩家货币余额 |
| EntityTracker | `bosses.&lt;id>.title-format` | Boss 名称格式中嵌入占位符 |
