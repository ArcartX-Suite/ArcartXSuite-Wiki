区域范围与选区工具是两件事：有的模块从配置读取多边形，有的模块提供游戏内选点，有的使用独立的两点工具。相同形状不代表共享创建命令或保存文件。下面按实际模块列出入口。

## 选择哪种操作

| 模块与用途 | 范围与维度 | 实际配置或入口 |
| --- | --- | --- |
| Fishing：水域判定 | 世界 + X、Z 多边形，至少三个顶点 | `waters/water-<ID>.yml` 的 `world`、`pos`；也支持 `/axs fishing water create <ID>` 后保存 |
| AfkReward：挂机区域判定 | 世界 + X、Z 多边形，至少三个顶点 | 模块数据目录的 `area-<ID>.yml`，填写 `world`、`pos`；没有同名的钓鱼选区命令 |
| Map：地图预点亮与锚点点亮范围 | 所属世界配置中的 X、Z 多边形 | `worlds/<世界>.yml` 的 `preload.regions[].points` 与锚点 `light.region.points`；通过配置填写 |
| Regions：区域规则范围 | 同一世界两个角点组成三维长方体，包含高度 | `/rg wand`，或 `/rg pos1`、`/rg pos2`，再定义区域 |
| Abyss：场景快照与设计对象 | 场景模板使用两个角点；设计对象按所选对象类型标记范围 | `/axs abyss region pos1`、`pos2`、`save`，或副本设计界面；与 Regions 的选区独立 |

这里的“区域”不表示相同业务。地图点亮不会创建挂机区域或区域规则；副本场景快照也不会自动成为钓鱼水域。上表中的路径均相对于对应模块的数据目录。

## 多边形工具设置

本体主配置 `plugins/ArcartX-Suite/config.yml` 可设置多边形工具物品，未配置时默认木棍：

```yaml
selection:
  wand-item: STICK
```

该片段是本体设置，不是 Regions 自己的 `selection` 配置。修改后执行 `/axs reload all`。仅手持木棍不会自动进入选区，必须先通过使用该功能的模块开始选区。

## 示例：创建钓鱼水域

需启用 Fishing，由有管理权限的玩家在游戏中执行：

```text
/axs fishing water create lake_demo
```

手持配置的工具，沿水域边缘按顺序操作：

| 操作 | 效果 |
| --- | --- |
| 左键方块 | 添加该方块位置的 X、Z 顶点 |
| 右键方块 | 闭合多边形，至少需要三个点 |
| Shift + 右键方块 | 撤销最后一个顶点 |

所有顶点必须在同一世界。沿边界顺序选点，避免来回交叉。玩家退出会清除临时选区，应在退出前完成保存。

闭合后执行：

```text
/axs fishing water save lake_demo
```

生成文件 `plugins/ArcartX-Suite/data/fishing/waters/water-lake_demo.yml`。它记录世界和边界，默认鱼类与宝藏列表仍为空，需要按[水域配置](/docs/fishing/pools)补充实际鱼种 ID，再执行：

```text
/axs fishing water reload
```

保存时使用尚未占用的 ID；修改已有水域前先备份文件。保存边界与创建完整鱼池是两步，不要只看到“已保存”就认为水域已有可捕获鱼类。

## 直接配置挂机区域

AfkReward 从 `area-<ID>.yml` 读取区域，不会自动读取已经创建的 Fishing 水域。可以在已有有效区域模板中修改：

```yaml
world: world
pos:
  - "0,0"
  - "20,0"
  - "20,20"
  - "0,20"
```

`pos` 的每一项为 `"x,z"`，不是 X、Y、Z，也不是地图使用的数组写法。挂机区域还必须保留有效的 `teleport` 设置；其世界需要已加载。这里只展示边界片段，不能用它替换整份区域文件。奖励、人数限制与传送点见[挂机区域](/docs/afkreward/afk-areas)。

## 地图区域不是选区工具

Map 的预点亮范围采用另一种结构，在对应世界文件中填写：

```yaml
preload:
  regions:
    - points:
        - [0, 0]
        - [20, 0]
        - [20, 20]
        - [0, 20]
```

锚点自身的点亮范围写在该锚点的 `light.region.points` 中。两者都描述地图探索显示范围，不会生成传送锚点、创建 Regions 区域或复制方块。完整位置见[地图世界配置](/docs/map/worlds)。

## 两点选区的区别

Regions 默认使用木斧，左键设点 1、右键设点 2，通过 `/rg define <名称>` 创建区域；它不使用多边形的“右键闭合”操作。权限、体积限制和边框显示见[Regions 选区工具](/docs/regions/selection)。

副本场景快照使用以下独立入口，由玩家在游戏中标记脚下的两个角点：

```text
/axs abyss region pos1
/axs abyss region pos2
/axs abyss region sel
/axs abyss region save <副本ID> <模板名>
```

这类保存涉及场景方块快照，不只是平面的顶点列表；范围和体积需按实际用途控制。设计界面的对象标记按当前对象模式操作，不能将所有设计对象都当成同一种多边形。参阅[副本命令](/docs/abyss/commands)。

## 检查与常见问题

| 现象 | 检查与处理 |
| --- | --- |
| 点击没有选点提示 | 是否先开始选区、主手物品是否匹配、当前是否在正确模块的操作流程 |
| 提示至少三个点 | 多边形顶点不够，继续添加再闭合 |
| 提示不在同一世界 | 回到开始选区的世界，或重新开始选区 |
| 保存时没有已闭合选区 | 先右键方块闭合，退出后需要重新选区 |
| 水域文件存在但钓不到目标鱼 | 检查鱼类列表、鱼种 ID、世界、玩家等级与水域边界，而不只检查选区工具 |
