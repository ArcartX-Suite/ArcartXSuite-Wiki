RGB 模块为纯计算型模块，无玩家命令，仅提供管理员重载命令和 PlaceholderAPI 占位符输出。

## 管理员命令

RGB 模块没有注册 `/axs rgb` 子命令处理器，管理操作通过Suite主命令 `/axs` 执行，需要 `arcartxsuite.admin` 权限（默认 OP）。

| 命令 | 说明 | 权限 |
|---|---|---|
| `/axs reload rgb` | 热重载主配置和所有条目文件 | `arcartxsuite.admin` |
| `/axs status` | 查看全部模块运行状态（含 RGB） | `arcartxsuite.admin` |

### 重载配置（reload）

热重载主配置 `config.yml` 和 `entries/` 目录下的所有条目文件。重载后立即生效，无需重启服务器。

```
/axs reload rgb
```

重载流程：

```
读取 config.yml → 解析 settings 和 entries-directory
  → 扫描 entries 目录下所有 *.yml 文件
  → 按文件名排序依次加载
  → 每个文件的根键作为条目 ID（不区分大小写）
  → 解析条目字段（text、gradient-colors、shine 等）
  → 替换内存中的配置和条目映射
```

<Callout type="info">
修改条目文件后只需执行 `/axs reload rgb` 即可生效。新增、删除、修改条目均支持热重载。
</Callout>

### 查看运行状态（status）

RGB 模块不提供独立的 `/axs rgb status` 子命令。查看模块运行状态请使用Suite命令：

```
/axs status
```

输出中 `rgb` 行显示该模块的启用/未启用状态。

## 权限节点

| 权限节点 | 说明 | 默认 |
|---|---|---|
| `arcartxsuite.admin` | Suite管理命令权限（`/axs reload rgb`、`/axs status`） | OP |

<Callout type="info">
RGB 模块无玩家权限节点。所有玩家均可通过 PlaceholderAPI 使用 `%axsrgb_<entryId>%` 占位符，渲染结果取决于条目配置，不涉及权限校验。
</Callout>

## UI 文本中使用

RGB 渲染结果可直接用于任何支持 PlaceholderAPI 的 UI 文本场景。在 ArcartX UI（Aria）中，通过 [图标](/docs/guide/icons) 的文本字段引用占位符即可显示渐变文本。

### 在 UI 图标中使用

在 UI 图标的 `display-name` 或 `lore` 字段中使用 `%axsrgb_<entryId>%`：

```yaml
# UI 图标定义
icon:
  display-name: "%axsrgb_shop_title%"
  lore:
    - "%axsrgb_shop_description%"
```

<Callout type="info">
RGB 渲染输出的颜色码为 `§#RRGGBB` 格式，需 ArcartX 客户端模组识别。在 UI 中使用时，确保玩家已安装 ArcartX 客户端，否则颜色码会显示为原始文本。
</Callout>

### 在条件判定中使用

RGB 占位符返回的是带颜色码的文本，**不建议**直接用于 [条件系统](/docs/guide/conditions) 的数值比较。如需获取条目状态用于条件判定，应使用其他模块的状态占位符。

### 在物品来源中使用

RGB 占位符可用于 [物品来源](/docs/guide/item-sources) 的名称/Lore 渲染，为生成的物品添加渐变色文本：

```yaml
# 物品来源定义
item:
  type: vanilla
  material: DIAMOND
  display-name: "%axsrgb_legendary_item%"
  lore:
    - "%axsrgb_legendary_lore%"
```
