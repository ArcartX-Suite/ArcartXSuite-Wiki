| 项目 | 说明 |
| --- | --- |
| 模块 ID | `rgb` |
| 主配置 | `plugins/ArcartX-Suite/data/rgb/config.yml` |
| 主要调整内容 | entries/ 中的文字、颜色与动画间隔 |
| 重载 | `/axs reload rgb` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。本模块还需要安装 `PlaceholderAPI`。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 编辑默认文字条目。
2. 将该条目的占位符放进支持 PlaceholderAPI 的文本。
3. 在游戏内查看颜色效果。

## 检查是否配置成功

将默认条目的 text 改为服务器名称，检查引用处是否显示新文字。

界面直接显示 `%axsrgb_welcome%` 时，先用 `/papi parse me %axsrgb_welcome%` 核对占位符是否解析。能解析出文字却没有渐变时，检查引用该值的文本组件是否支持对应颜色格式。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| 逐字渐变 | 文本按字符（字符）分配颜色梯度，支持两色到任意多色渐变（如红 → 黄 → 蓝） |
| 动态扫光 | 在渐变基础上叠加移动的高亮光带，可配置扫光颜色、宽度和强度 |
| 动画帧切换 | 每隔 `switch-interval-ticks` tick 切换到下一帧，形成动态流光效果；设为 `0` 则显示静态渐变 |
| PAPI 嵌套 | `text` 字段先按目标玩家解析 PlaceholderAPI（如 `%player_name%`），再叠加 RGB 渐变 |
| 多条目管理 | `entries/` 目录下每个 YAML 文件可包含多个条目，根键即为条目 ID，按文件名排序加载 |
| 递归引用检测 | 自动检测条目间的递归 PAPI 引用并中止渲染，防止死循环 |
| 文本长度截断 | 渲染文本最大 1024 字符，超长自动截断，防止恶意超长输入拖慢渲染 |
| 颜色格式兼容 | 支持 `#RRGGBB`、`§#RRGGBB`、`RRGGBB` 三种颜色输入格式 |
| 条目热重载 | 通过 `/axs reload rgb` 可热重载条目配置，无需重启服务器 |
