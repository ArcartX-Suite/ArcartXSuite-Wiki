# 渲染效果说明

> **付费模块**

本页说明 RGB 渐变条目的渲染行为，帮助管理员准确配置 `gradient-colors`、`shine`、`switch-interval-ticks` 等字段。完整字段表见 [配置](/docs/rgb/configuration)。

## 渐变效果

- 渐变按字符逐个取色：首字符取调色板首色、尾字符取末色，中间字符在相邻两色之间平滑过渡
- 字符数以实际显示字符为准——emoji 与中文均算一个字符，渐变颜色能正确分配到每个字符
- 调色板多于 2 色时，颜色沿文本顺序依次过渡
- 单字符文本固定取调色板首色；单色调色板全文同色

## 扫光效果（shine）

`shine: true` 时在渐变颜色之上叠加一层移动的高亮光带，形成"光从左扫到右"的效果。

| 配置 | 效果 |
|---|---|
| `shine: false` | 无扫光 |
| `shine: true` + `switch-interval-ticks: 0` | 静态高亮停在文本中间 |
| `shine: true` + `switch-interval-ticks > 0` | 扫光从左到右循环掠过 |

- `shine-width`：光带宽度（字符数），越大光带覆盖范围越宽
- `shine-strength`：光带强度（0~1），越大亮部越接近扫光色
- `shine-color`：光带颜色，默认白色 `#FFFFFF`

## 动画速度（switch-interval-ticks）

| 值 | 效果 |
|---|---|
| `0` | 静态，渐变与扫光均不移动 |
| `1` | 每 50ms 一帧，最快（可能闪烁） |
| `2` | 每 100ms 一帧，推荐，流畅 |
| `3` | 每 150ms 一帧，适中 |
| `10` | 每 500ms 一帧，慢速 |

动画同时驱动两个维度：调色板整体滚动（颜色位置循环移动）与扫光移动，两者周期不同，形成不重复的视觉效果。

## 客户端要求

渲染输出为 `§#RRGGBB` 颜色码，由 ArcartX 客户端模组解析。未安装客户端的玩家会看到原始颜色码文本（如 `§#FF7A18`），功能不受影响但无颜色效果。
