| 项目 | 说明 |
| --- | --- |
| 模块 ID | `onlinerewards` |
| 主配置 | `plugins/ArcartX-Suite/data/onlinerewards/config.yml` |
| 主要调整内容 | sign-in.yml 签到奖励、rewards.yml 时长奖励 |
| 重载 | `/axs reload onlinerewards` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。本模块还需要安装 `PlaceholderAPI`。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 修改一个默认奖励。
2. 执行 `/axs reload onlinerewards`。
3. 执行 `/onlinerewards open`。

## 检查是否配置成功

用测试账号签到或达到一个奖励条件，检查奖励内容。

奖励列表有测试档位却无法领取时，用 `/onlinerewards status` 核对当天累计时长，并查看是否已领取该档。先使用[短阶段奖励示例](/docs/onlinerewards/time-rewards#从一个短阶段开始测试)验证一次实际发放。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| 四维在线时长统计 | 今日 / 本周 / 本月 / 总在线分钟数，每分钟 tick 累计 |
| 在线阶段奖励 | 按当日累计在线分钟数分阶段触发，支持命令、邮件预设、物品奖励 |
| 每日签到 | 每日签到领取基础奖励，支持进服提醒 |
| 连续签到里程碑 | 连续签到天数"恰好等于"指定天数时触发额外奖励 |
| 累计签到里程碑 | 累计签到天数"恰好等于"指定天数时触发额外奖励 |
| 每月指定日期奖励 | 每月特定日期签到触发额外奖励 |
| 节日签到奖励 | 指定月日签到触发节日奖励 |
| 补签卡 | 消耗补签卡补签本月今天之前未签到的日期 |
| 权限组加成 | 拥有指定权限的玩家签到时额外发放一组奖励 |
