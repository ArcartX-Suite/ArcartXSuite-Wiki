## 配置文件

主配置 `config.yml`（配置版本 2）：

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `debug.enabled` | boolean | `false` | 是否输出调试日志 |
| `ui.panel-ui-id` | string | `AXS:menu_panel` | 面板布局 UI 的 ID |
| `ui.esc-ui-id` | string | `AXS:menu_esc` | ESC 布局 UI 的 ID |
| `ui.packet-id` | string | `AXS_MENU` | 客户端通信包标识符 |
| `ui.register-ui-on-enable` | boolean | `true` | 启动时是否自动注册 UI |
| `ui.overwrite-ui-files` | boolean | `false` | 是否强制覆盖用户已修改的 UI 文件 |
| `client.esc-menu-id` | string | `esc_main` | ESC 暂停界面绑定的默认菜单 ID（layout 为 esc 的菜单定义） |
| `settings.menus-directory` | string | `menus` | 菜单定义文件目录（相对模块数据目录） |
| `settings.default-layout` | string | `panel` | 默认布局模式（panel / esc） |
| `settings.columns` | int | `2` | 默认每行按钮列数 |
| `settings.buttons-per-page` | int | `12` | 每页最大按钮数量 |
| `settings.click-cooldown-ms` | int | `300` | 按钮点击冷却时间（毫秒） |
| `settings.close-on-action` | boolean | `true` | 点击按钮执行动作后是否自动关闭菜单 |
| `settings.notify-open-failed` | boolean | `true` | 打开菜单失败时是否向玩家发送提示 |
| `settings.item-binds` | list | 见下 | 全局物品绑定（跨菜单） |

菜单定义文件位于 `menus/` 目录，每个 `.yml` 文件定义一个或多个菜单。菜单级字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | 菜单唯一标识，用于 `open:` 引用与命令注册 |
| `title` | string | 是 | 菜单标题，支持颜色代码与 MiniMessage |
| `layout` | string | 是 | 布局模式：`panel` / `esc` |
| `columns` | int | 是 | 每行按钮列数 |
| `buttons-per-page` | int | 是 | 每页最大按钮数量 |
| `permission` | string | 否 | 打开菜单所需权限，留空无限制 |
| `match-esc` | boolean | 否 | 仅 esc 布局，是否拦截 ESC 键替代原版暂停界面 |
| `open-requirements` | list | 否 | 打开前置条件（PlaceholderAPI 表达式或 `aria:` 脚本） |
| `open-actions` | list | 否 | 打开菜单时执行的动作 |
| `close-actions` | list | 否 | 关闭菜单时执行的动作 |
| `commands` | list | 否 | 注册为游戏命令的别名列表 |
| `command-regex` | list | 否 | 命令正则匹配列表 |
| `item-binds` | list | 否 | 物品绑定列表 |
| `pages` | list | 是 | 页面定义列表 |
| `footer-buttons` | map | 否 | esc 布局专属，底部固定按钮 |

按钮字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `text` | string | 是 | 按钮显示文字 |
| `order` | int | 是 | 排列顺序（从 0 开始，越小越靠前） |
| `permission` | string | 否 | 按钮级权限，无权限的玩家看不到此按钮 |
| `icon` | map | 否 | 按钮图标配置（仅 panel/esc 有效） |
| `use-conditions` | list | 否 | 按钮显示条件，不满足时可显示 `deny-message` |
| `requirements` | list | 否 | 按钮硬性前置条件，不满足时按钮完全隐藏 |
| `deny-message` | string | 否 | `use-conditions` 不满足时的提示消息 |
| `deny-actions` | list | 否 | `use-conditions` 不满足时执行的动作 |
| `actions` | list | 是 | 点击按钮执行的动作列表 |

动作类型（`actions` / `open-actions` / `close-actions` 中使用）：

| 动作关键字 | 说明 |
| --- | --- |
| `command: <命令>` | 以玩家身份执行命令 |
| `chat: <消息>` | 以玩家身份发送聊天消息（`/` 开头为命令） |
| `connect: <服务器名>` | 通过 BungeeCord Plugin Messaging 切换子服 |
| `console: <命令>` | 以控制台身份执行命令 |
| `op: <命令>` | 以玩家身份临时给予 OP 执行，用完自动收回 |
| `message: <消息>` | 向玩家发送聊天消息（支持颜色代码） |
| `sound: <音效名>\|<音量>\|<音调>` | 播放音效 |
| `close` | 关闭当前菜单 |
| `open: <菜单id>` | 打开另一个菜单 |
| `page: <页面id>` | 切换到同菜单内的另一页 |
| `signal: <名称>` | 触发 EventPacket command-signal 信号 |
| `signal: <名称>\|键=值` | 触发信号并传递变量 |
| `aria: <脚本>` | 执行 Aria 脚本（注入 AXS player 门面到 `global.` 命名空间） |
| `js: <脚本>` | 执行 JavaScript（注入 player 门面与 Bukkit，需 classpath 有 JS 引擎） |
| `delay: <tick>` | 延迟 N tick 后执行后续动作（1 tick = 50ms） |

图标 `icon` 支持的来源：

| 来源 | 字段 | 说明 |
| --- | --- | --- |
| 原版物品 | `material` | Minecraft 物品 ID |
| 物品库 | `source` + `id` | `neigeitems` / `mythicmobs` / `overture` |
| MMOItems | `source: mmoitems` + `mmo-type` + `mmo-id` | 需类型与 ID 两段定位 |
| ArcartX 贴图 | `texture` / `texture-url` / `nbt` | 写入 NBT 渲染自定义贴图 |
| 直接 NBT | `json` | 直接提供物品 NBT JSON |

## 全屏功能导航与悬停详情（1.5.0）

内置 `AXS:menu_panel` 已改为全屏导航：左侧功能列表，右侧通高详情面板。`panel` 与 `full` 仍使用该 UI ID，`esc` 界面不变。内置新版采用单列宽幅条目；`columns` 仍保留在数据包中，供 ESC 或自定义 UI 使用，不再控制内置全屏列表的列数。

鼠标停留在功能上后切换详情，离开后保留当前详情；点击左侧功能才执行动作。禁用功能仍可预览，但不会发送执行请求。长说明独立滚动，页脚较多时支持横向滚动。刷新按按钮 ID 保留预览，切换页面时重置滚动位置。

按钮及 `footer-buttons` 均可添加可选的 `details`：

| 字段 | 类型 | 默认值 / 行为 |
| --- | --- | --- |
| `details.summary` | string | `浏览功能详情`，列表与详情区的一句话介绍 |
| `details.category` | string | `功能导航`，详情区顶部的分类标签 |
| `details.accent` | string | `#D6BE8F`，主题色，必须为 `#RRGGBB`；无效值记录警告并回退 |
| `details.artwork` | string | 空，独立详情展示图资源路径；不为空时替代右侧物品图标，建议使用约 2.3:1 的图片 |
| `details.description` | string / string[] | `选择此功能，继续你的旅程。`；支持多行文本和段落列表 |
| `details.requirements` | string / string[] | 空，仅用于展示使用说明，不参与权限、条件或费用判断 |
| `details.action-hint` | string | `点击左侧功能进入`，可用时的操作提示 |
| `details.disabled-reason` | string | 空；禁用时优先显示此值，否则使用 `deny-message`，均未配置则显示通用提示 |

简介、分类、说明、使用说明、操作提示和禁用原因支持既有占位符解析。长说明在服务端解析占位符后折行，客户端以独立行展示。标题和简介为单行展示，建议使用简短文案，完整内容放入 `description`。主题色和图片路径不作为脚本执行。

```yaml
warehouse:
  text: "&f仓库系统"
  order: 0
  icon:
    material: CHEST
  details:
    summary: "为每一次冒险，留出新的空间"
    category: "物资管理 / STORAGE"
    accent: "#D6BE8F"
    artwork: ""
    description:
      - "把旅途中的收获妥善收藏，让背包轻装上阵。"
      - "在仓库中浏览、整理和存取你的物品。"
    requirements:
      - "可用仓库与容量以仓库界面为准。"
    action-hint: "点击左侧功能，打开仓库"
    disabled-reason: ""
  actions:
    - "close"
    - "delay: 10"
    - "command: warehouse open"
```

此次新增可选字段，不需要迁移菜单配置，主配置版本仍为 `2`。没有 `details` 的旧按钮使用默认介绍；动作、权限与写操作令牌校验保持不变。新增详情数据随 `init/update` 一起发送，悬停不发起服务端请求，也不下发动作脚本或条件表达式。

升级需同时更新 menu 模块与 UI 资源。`ui.overwrite-ui-files: false` 时，已修改的服务器 UI 不会被强制覆盖；请先备份、比较并更新对应 UI 文件，再执行 `/axs reload menu`。已有 `menus/` 文件不会自动覆盖，示例详情需按需加入。模块二进制通过 GitHub CI 构建、云端下发，不在本地构建 JAR。

## 配置示例

以下为 `menus/example.yml` 的精简示例，演示面板布局、多页、按钮动作与物品库图标：

```yaml
id: example
title: "&f&l服务器菜单"
layout: panel
columns: 4
buttons-per-page: 64
permission: ""
open-requirements: []
open-actions:
  - "message: &a欢迎打开示例菜单！"
close-actions: []
commands:
  - "examplemenu"
command-regex:
  - "example(?:menu)?"
item-binds:
  - material: COMPASS
    name-contains: "功能菜单"
    action: RIGHT_CLICK
pages:
  - id: main
    title: "&f功能"
    buttons:
      warehouse:
        text: "&f仓库系统"
        order: 0
        permission: "arcartxsuite.warehouse.use"
        icon:
          material: CHEST
          name: "&f仓库"
        actions:
          - "close"
          - "delay: 10"
          - "command: warehouse open"
      rewards:
        text: "&f在线奖励"
        order: 2
        use-conditions:
          - "%player_level% >= 5"
        deny-message: "&c需要达到 5 级才能领取在线奖励"
        actions:
          - "close"
          - "delay: 10"
          - "command: onlinerewards open"
      teleport:
        text: "&f传送菜单"
        order: 5
        actions:
          - "open: teleport"
      next_page:
        text: "&f更多功能 »"
        order: 7
        actions:
          - "page: page2"
  - id: page2
    title: "&f更多"
    buttons:
      script_demo:
        text: "&f脚本动作示例"
        order: 2
        use-conditions:
          - "aria: global.player.getLevel() >= 30 && global.player.hasPermission('menu.vip')"
        deny-message: "&c需要 30 级且拥有 menu.vip 权限"
        actions:
          - "aria: if (global.player.hasPermission('rank.mvp')) { global.player.command('warp mvp') } elif (global.player.papiNumber('%vault_eco_balance%') >= 1000) { global.player.console('eco take %player_name% 1000'); global.player.command('warp vip') } else { global.player.msg('&c权限/余额不足') }"
          - "close"
---
id: teleport
title: "&f&l传送"
layout: panel
columns: 2
buttons-per-page: 6
pages:
  - id: main
    title: "&f传送点"
    buttons:
      spawn:
        text: "&f出生点"
        order: 0
        icon:
          material: COMPASS
          name: "&a出生点"
        actions:
          - "close"
          - "delay: 10"
          - "command: spawn"
```

```yaml
id: esc_main

```
