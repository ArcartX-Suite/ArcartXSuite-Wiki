| 模块 ID | `menu` |

| 主要调整内容 | menus/ 菜单、按钮图标、说明与点击动作 |
| 重载 | `/axs reload menu` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 按[单按钮示例](/docs/menu/configuration#从一个可验证的按钮开始)建立 `plugins/ArcartX-Suite/data/menu/menus/trial_menu.yml`。
2. 管理员执行 `/axs reload menu`，让具有 `arcartxsuite.menu.use` 的测试玩家执行 `/menu open trial_menu`。
3. 先点无条件的测试按钮，再比较两名等级分别低于和达到示例要求的玩家。

## 检查是否配置成功

检查按钮文字、点击动作、翻页和关闭。

`/menu open trial_menu` 提示菜单不存在时，核对文件在 `menus/` 且根级 `id` 为 `trial_menu`。菜单可开但按钮呈禁用状态时，检查 `use-conditions` 和玩家实际等级。见[单按钮示例](/docs/menu/configuration#从一个可验证的按钮开始)。

## 可以配置的功能

- 配置驱动菜单：一个 `.yml` 文件可包含多个菜单（用 `---` 分隔），每个菜单支持多页分页
- 两种布局模式：`panel`（居中弹出面板，适合功能菜单/商店）与 `esc`（左侧滑出，专用于替换暂停界面）
- 按钮动作系统：支持命令、聊天、跨服切换、控制台命令、消息、音效、打开/关闭菜单、翻页、信号分发、Aria/JS 脚本、延迟等动作
- 条件与权限：菜单级 `permission` 与 `open-requirements`，按钮级 `use-conditions`/`requirements`，支持 PlaceholderAPI 表达式与 Aria 脚本条件
- 命令绑定：菜单可注册为游戏命令（含中文别名与正则匹配），输入命令即打开
- 物品绑定：将菜单绑定到背包物品，右键/左键/潜行点击触发
- ESC 界面替换：`match-esc: true` 的菜单会拦截 ESC 键并替代原版暂停界面，支持底部固定按钮（如游戏选项、退出游戏）
- 图标系统：支持原版材质、CustomModelData、头颅材质、皮革颜色、物品库（NeigeItems/MythicMobs/Overture/MMOItems）、ArcartX 自定义贴图（url NBT）、直接 NBT JSON
- 自定义 UI：菜单可引用自定义 UI 文件，启动时自动注册
