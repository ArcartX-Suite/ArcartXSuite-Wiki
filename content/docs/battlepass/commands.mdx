## 玩家命令

玩家命令通过 `/bp`、`/battlepass` 或 `/axsbp` 触发，仅限玩家执行。

| 命令 | 别名 | 权限 | 说明 |
|---|---|---|---|
| `/bp` | `/bp open` | 无 | 打开战令主界面 |
| `/bp open` | — | 无 | 打开战令主界面 |
| `/bp tasks` | — | 无 | 打开任务列表界面 |
| `/bp rewards` | — | 无 | 打开奖励列表界面 |
| `/bp claim <等级>` | — | 无 | 领取指定等级的奖励 |
| `/bp help` | — | 无 | 显示玩家命令帮助 |

> 无参数执行 `/bp` 等同于 `/bp open`。未知子命令也会自动打开主界面。

### claim 领取说明

`/bp claim <等级>` 会领取指定等级下当前可领的全部档位奖励：

| 结果 | 消息 |
|---|---|
| 成功 | `成功领取等级 {等级} 的奖励！` |
| 等级未达到 | `尚未达到该等级。` |
| 已领取过 | `该等级奖励已领取。` |
| 无可领奖励 | `该等级没有可领取的奖励。` |

### Tab 补全

第一参数支持补全：`open` / `tasks` / `rewards` / `claim` / `help`。

## 管理员命令

管理员命令通过 `/axs battlepass <子命令>` 触发，控制台和玩家均可执行。

| 命令 | 说明 |
|---|---|
| `/axs battlepass help` | 显示管理命令帮助 |
| `/axs battlepass status` | 查看模块状态（赛季、活跃玩家数、跨服、奖励数） |
| `/axs battlepass season` | 查看当前赛季信息（ID、名称、等级上限、起止日期、结算状态） |
| `/axs battlepass reset <玩家>` | 重置指定玩家的战令进度 |
| `/axs battlepass unlock <玩家> <premium\|deluxe>` | 解锁指定玩家的战令档位 |
| `/axs battlepass addexp <玩家> <数量>` | 增加玩家战令经验（自动升级） |
| `/axs battlepass setexp <玩家> <数量>` | 设置玩家当前等级内经验（不触发升级） |
| `/axs battlepass removeexp <玩家> <数量>` | 扣除玩家经验（可能降级） |
| `/axs battlepass setlevel <玩家> <等级>` | 设置玩家等级（经验清零） |
| `/axs battlepass settle` | 手动结算当前赛季 |

### Tab 补全

| 参数位置 | 补全内容 |
|---|---|
| 第 2 参数 | 子命令名（`help` / `status` / `reset` / `season` / `unlock` / `addexp` / `setexp` / `removeexp` / `setlevel` / `settle`） |
| 第 3 参数 | 在线玩家名（`reset` / `unlock` / `addexp` / `setexp` / `removeexp` / `setlevel` 子命令） |
| 第 4 参数 | `unlock` 子命令补全 `premium` / `deluxe` |

#### status 查看模块状态

显示当前赛季 ID、活跃玩家数、跨服同步状态、奖励配置数量。

#### season 查看赛季信息

显示赛季 ID、名称、最大等级、起止日期、结算状态。

#### reset 重置玩家进度

重置指定玩家在当前赛季的全部战令数据（等级、经验、任务进度、奖励领取记录）。玩家必须在线。

#### unlock 解锁档位

解锁指定玩家的 PREMIUM 或 DELUXE 档位。档位升级是单向的，如果玩家已拥有更高档位则提示已解锁。

#### addexp 增加经验

增加指定玩家的战令经验，自动触发升级。数量必须为正整数。

#### setexp 设置经验

设置玩家当前等级内的经验值，不触发升级。超出当前等级所需经验的部分截断。数量必须 ≥ 0。

#### removeexp 扣除经验

扣除玩家经验，可能导致降级。从 1 级开始逐级累加确定新等级和新级内经验。数量必须为正整数。

#### setlevel 设置等级

直接设置玩家等级，经验清零。等级不能超过 `season.max-level`。等级必须 ≥ 1。

#### settle 手动结算

异步执行当前赛季结算。结算流程：
1. 发放所有玩家未领取的等级奖励
2. 按等级阈值发放赛季结算奖励
3. 标记赛季已结算

> 已结算的赛季不会重复结算。如需重新结算，需先清除 `bp_season_settlement` 表中的记录。

## 权限节点

BattlePass 模块的命令权限设计：

| 权限节点 | 说明 | 默认 |
|---|---|---|
| `/bp` 系列命令 | 玩家命令，无权限限制 | 所有玩家可用 |
| `/axs battlepass` 系列命令 | 管理命令，通过 `/axs` 总命令权限控制 | 管理员可用 |

> 玩家命令（`/bp` / `/battlepass`）不需要任何权限节点。管理命令通过 ArcartXSuite 的 `/axs` 命令权限体系控制，通常需要 OP 或管理员权限。
