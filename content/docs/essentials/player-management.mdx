# 玩家管理

Essentials 提供一组玩家状态管理与便捷操作功能。

## 状态切换

### 飞行（Fly）

`/fly` 切换飞行开关。关闭飞行时根据游戏模式恢复默认（创造/旁观保留飞行）。可对目标玩家操作并通知执行者。

### 无敌（God）

`/god` 切换无敌状态，开启后玩家不受任何伤害。

### 治疗 / 饱食

- `/heal` 恢复生命值至上限并清除着火状态（兼容修改过最大生命值的 RPG 服务器）
- `/feed` 恢复饥饿值与饱和度

### 游戏模式与速度

- `/gamemode` 切换游戏模式
- `/speed <0-10>` 设置飞行或行走速度，超出范围自动限幅

## 隐身（Vanish）

`/vanish` 切换隐身状态，隐身玩家对其他玩家不可见，拥有 `axs.essentials.vanish.see` 权限者仍可见。

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `player.vanish-hide-join-message` | `true` | 隐身玩家加入时隐藏加入消息 |
| `player.vanish-hide-quit-message` | `true` | 隐身玩家退出时隐藏退出消息 |

> 后入服的玩家同样看不到隐身者。隐身状态变化会触发 Tab 列表刷新。

## AFK 挂机

| 方式 | 说明 |
|------|------|
| `/essentials afk` | 手动切换 AFK 状态并广播 |
| 自动检测 | 每 10 秒检查一次，空闲超过 `afk-timeout` 自动标记 AFK 并广播 |

- `afk-kick-timeout > 0` 时，空闲超过 `afk-timeout + afk-kick-timeout` 自动踢出（`axs.essentials.afk.exempt` 豁免）
- 玩家移动时自动退出 AFK 并广播
- `afk-timeout` 为 0 禁用自动检测；`afk-kick-timeout` 为 0 不踢人

## 返回栈（/back）

传送前自动记录位置，`/back` 返回最近位置，栈深度由 `teleport.back-stack-size`（默认 5）控制，超出丢弃最旧记录。详见 [传送系统](/docs/essentials/teleport)。

## 物品与容器

| 命令 | 功能 |
|------|------|
| `/repair` | 修复主手物品耐久 |
| `/hat` | 主手物品戴到头上 |
| `/enderchest [玩家]` | 打开自己或目标玩家的末影箱 |
| `/workbench` | 打开工作台 |
| `/anvil` | 打开铁砧 |
| `/trash` | 打开 54 格垃圾桶容器 |

## 背包查看（/invsee）

`/invsee <玩家>` 查看并实时修改其他在线玩家的背包：以 36 格界面展示主背包（前 27 格）与快捷栏（后 9 格），支持拾取、放置、Shift 移动、数字键交换等常规背包操作，改动直接同步到目标玩家。目标下线时界面自动关闭。

## PlaceholderAPI 占位符

模块注册 `axsessentials` 前缀的 PAPI 占位符：

| 占位符 | 返回值 |
|--------|--------|
| `%axsessentials_afk%` | `true` / `false` |
| `%axsessentials_afk_symbol%` | `&7[AFK]` 或空 |
| `%axsessentials_vanish%` | `true` / `false` |
| `%axsessentials_vanish_symbol%` | `&b[V]` 或空 |
| `%axsessentials_flying%` | `true` / `false` |
| `%axsessentials_god%` | `true` / `false` |
| `%axsessentials_nick%` | 玩家显示名 |

## UI 菜单

玩家工具菜单（`/essentials menu`）首页展示飞行/无敌/AFK 状态、速度与坐标；管理员面板（`/essentials admin`）可对在线玩家执行治疗、喂食、飞行、无敌等操作。
