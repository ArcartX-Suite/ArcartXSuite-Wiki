## 命令体系

Essentials 模块的所有功能通过 `/essentials <action>` 或缩写 `/ess <action>` 访问。同时支持在配置中定义命令简写别名（`command-aliases` 节），将独立顶层命令（如 `/fly`）转发到对应的 `/essentials <action>` 子命令。

| 命令格式 | 说明 |
|----------|------|
| `/essentials <action> [参数...]` | 标准命令格式 |
| `/ess <action> [参数...]` | 缩写别名，等价于 `/essentials` |
| `/<别名> [参数...]` | 配置中定义的简写别名（如 `/fly`、`/home`），自动转发 |

## PlaceholderAPI 占位符

模块注册了 `axsessentials` 标识符的 PlaceholderAPI 扩展，支持以下占位符：

| 占位符 | 返回值 | 说明 |
|--------|--------|------|
| `%axsessentials_afk%` | `true` / `false` | 是否处于 AFK 状态 |
| `%axsessentials_afk_symbol%` | `&7[AFK]` 或空 | AFK 标记符号（可用于 Tab 列表） |
| `%axsessentials_vanish%` | `true` / `false` | 是否处于隐身状态 |
| `%axsessentials_vanish_symbol%` | `&b[V]` 或空 | 隐身标记符号 |
| `%axsessentials_flying%` | `true` / `false` | 是否正在飞行 |
| `%axsessentials_god%` | `true` / `false` | 是否处于无敌模式 |
| `%axsessentials_nick%` | 昵称文本 | 玩家自定义昵称（未设置则返回玩家名） |

> 占位符需要安装 PlaceholderAPI 插件才能生效。模块启动时自动注册，卸载时自动注销。

## UI Packet 详解

模块通过 PacketBridge 与 ArcartX 客户端 UI 交互。服务端通过 `sendPacket` 推送数据，客户端通过 `Packet.send` 发送操作指令。

### 玩家工具菜单（`AXS_ESS_MENU`）

**打开命令**：`/essentials menu`

**服务端推送字段**（`init` handler）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `page` | `string` | 当前页面（`home` / `homes` / `warps` / `tpa` / `settings`） |
| `packetId` | `string` | 固定为 `AXS_ESS_MENU`，客户端回包使用 |
| `playerName` | `string` | 玩家名称 |
| `isFlying` | `string` | 是否飞行（`true` / `false`） |
| `isGod` | `string` | 是否无敌 |
| `isAfk` | `string` | 是否挂机 |
| `flySpeed` | `string` | 飞行速度（格式 `X.X`） |
| `walkSpeed` | `string` | 行走速度 |
| `location` | `string` | 当前位置（世界名 + 坐标） |
| `homes` | `list<map>` | 家列表（每项含 `name`、`world`、`coords`） |
| `homeCount` | `string` | 家数量 |
| `warps` | `list<string>` | 传送点名称列表 |
| `warpCount` | `string` | 传送点数量 |
| `onlinePlayers` | `list<string>` | 在线玩家名称列表（排除自己，用于 TPA） |
| `replantEnabled` | `string` | 自动补种是否开启 |
| `autotoolEnabled` | `string` | 自动工具是否开启 |

**客户端操作指令**（`Packet.send('AXS_ESS_MENU', action, ...)`）：

| Action | 参数 | 说明 |
|--------|------|------|
| `navigate` | `<page>` | 切换页面 |
| `refresh` | `<page>` | 刷新当前页面数据 |
| `teleport_home` | `<name>` | 传送到指定家 |
| `delete_home` | `<name>` | 删除指定家 |
| `set_home` | `<name>` | 设置家 |
| `teleport_warp` | `<name>` | 传送到传送点 |
| `send_tpa` | `<player> [here]` | 发送 TPA 请求（`here` 为 tpahere） |
| `accept_tpa` | — | 接受 TPA |
| `deny_tpa` | — | 拒绝 TPA |
| `toggle_replant` | — | 切换自动补种 |
| `toggle_autotool` | — | 切换自动工具 |
| `sort` | — | 整理背包 |

### 管理员后台（`AXS_ESS_ADMIN`）

**打开命令**：`/essentials admin`（需要 `axs.essentials.admin` 权限）

**服务端推送字段**（`init` handler）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `page` | `string` | 当前页面（`players` / `bans` / `mutes` / `warps` / `world`） |
| `packetId` | `string` | 固定为 `AXS_ESS_ADMIN` |
| `players` | `list<map>` | 在线玩家列表（含 `name`、`health`、`isFlying`、`isGod`、`world`） |
| `playerCount` | `string` | 在线玩家数量 |
| `warps` | `list<string>` | 传送点名称列表 |
| `bans` | `list<map>` | 封禁列表（含 `uuid`、`name`、`reason`、`operator`、`permanent`） |
| `banCount` | `string` | 封禁数量 |
| `chatAvailable` | `string` | Chat 模块是否可用 |
| `mutes` | `list<map>` | 禁言列表（含 `uuid`、`name`、`reason`、`operator`、`permanent`） |
| `muteCount` | `string` | 禁言数量 |
| `worldName` | `string` | 当前世界名称 |
| `worldTime` | `string` | 当前世界时间（tick） |
| `worldWeather` | `string` | 当前天气（`clear` / `rain` / `thunder`） |

**客户端操作指令**（`Packet.send('AXS_ESS_ADMIN', action, ...)`）：

| Action | 参数 | 所需权限 | 说明 |
|--------|------|----------|------|
| `refresh` | `<page>` | — | 刷新页面数据 |
| `navigate` | `<page>` | — | 切换页面 |
| `heal` | `<player>` | `axs.essentials.heal` | 治疗玩家 |
| `feed` | `<player>` | `axs.essentials.feed` | 喂食玩家 |
| `fly` | `<player>` | `axs.essentials.fly` | 切换玩家飞行 |
| `god` | `<player>` | `axs.essentials.god` | 切换玩家无敌 |
| `teleport_to` | `<player>` | `axs.essentials.teleport` | 传送到玩家 |
| `teleport_here` | `<player>` | `axs.essentials.teleport` | 将玩家传送到你 |
| `mute` | `<player> [reason]` | `axs.essentials.mute` | 禁言玩家 |
| `unmute` | `<player>` | `axs.essentials.unmute` | 解除禁言 |
| `kick` | `<player> [reason]` | `axs.essentials.kick` | 踢出玩家 |
| `ban` | `<player> [reason]` | `axs.essentials.ban` | 封禁玩家 |
| `unban` | `<uuid>` | `axs.essentials.unban` | 解除封禁（需 UUID） |
| `set_time` | `<day\|night\|noon\|midnight\|tick>` | — | 设置世界时间 |
| `set_weather` | `<clear\|rain\|thunder>` | — | 设置世界天气 |
| `set_warp` | `<name>` | — | 设置传送点 |
| `del_warp` | `<name>` | — | 删除传送点 |
| `set_spawn` | — | — | 设置出生点 |

> UI Packet 的频率控制由框架路由层（`ClientPacketRouter` + `PacketGuard`）统一处理，Packet Handler 内部不再重复检查。
