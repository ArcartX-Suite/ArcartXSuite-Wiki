## 功能概述

安全管理包含封禁、禁言、踢出、警告与强制执行。禁言数据由 Chat 模块存储，封禁与警告记录持久化到数据库。所有管理命令均要求对应的 `axs.essentials.*` 权限。

| 功能 | 命令 | 权限 |
|------|------|------|
| 永久封禁 | `ban` | `axs.essentials.ban` |
| 临时封禁 | `tempban` | `axs.essentials.ban` |
| 解除封禁 | `unban` | `axs.essentials.unban` |
| 永久/临时禁言 | `mute` / `tempmute` | `axs.essentials.mute` |
| 解除禁言 | `unmute` | `axs.essentials.unmute` |
| 踢出 | `kick` | `axs.essentials.kick` |
| 警告 | `warn` | `axs.essentials.warn` |
| 强制执行 | `sudo` | `axs.essentials.sudo` |
| 背包查看 | `inv` | `axs.essentials.inv` |

## 封禁系统

### 永久封禁（ban）

`/essentials ban <玩家> [原因]` 对在线玩家执行永久封禁：记录玩家 IP、写入封禁记录、踢出玩家（使用 `moderation.ban-message` 模板），并全服广播。

### 临时封禁（tempban）

```yaml
# 命令格式
/essentials tempban <玩家> <时长> [原因]

# 时长格式
1d   # 1 天
2h   # 2 小时
30m  # 30 分钟
45s  # 45 秒
3600 # 纯数字按秒处理
```

时长无法解析时按 1 小时处理。

### 解除封禁（unban）

`/essentials unban <玩家>` 删除封禁记录。命令仅对在线玩家生效，离线玩家需通过管理员面板的 unban 操作（按 UUID 解除）。

> 封禁记录写入数据库，但**不拦截离线封禁玩家的加入**。如需加入时拦截，需配合宿主或代理层的封禁门扩展开发。

## 禁言系统

禁言功能由 Chat 模块提供，Essentials 本身不存储禁言数据：

- `mute` 永久禁言；`tempmute` 临时禁言；`unmute` 解除禁言
- Chat 模块未加载时命令提示禁言不可用，管理面板禁言标签页显示「Chat 模块未加载」

## 踢出（kick）

`/essentials kick <玩家> [原因]` 踢出在线玩家，使用 `moderation.kick-message` 模板并全服广播。原因缺省为"无"。

## 警告与自动封禁（warn）

`/essentials warn <玩家> [原因]` 记录一次警告并全服广播，然后检查自动封禁阈值：

```yaml
moderation:
  # 达到 5 次警告自动永久封禁（0 = 不自动封禁）
  max-warnings-before-ban: 5
  # 警告 30 天后过期，不计入自动封禁判定（0 = 永不过期）
  warning-expire-days: 30
```

- 有效警告数仅统计 `warning-expire-days` 内的警告
- 达到阈值时自动封禁玩家（操作者显示为"系统"）并踢出

> 警告过期仅影响自动封禁判定，历史警告记录不会被删除。

## 强制执行（sudo）

`/essentials sudo <玩家> <命令>` 强制目标玩家执行命令，命令以 `/` 开头时自动去除前缀：

```yaml
/essentials sudo Steve /spawn
/essentials sudo Steve say hello
```

## 背包查看（inv）

`/essentials inv <玩家>` 打开目标玩家背包界面，支持实时双向同步修改，详见 [玩家管理](/docs/essentials/player-management)。

> 仅对在线玩家生效，且需要执行者为玩家。

## 时长格式

临时封禁与临时禁言共用时长格式：

| 后缀 | 单位 | 示例 |
|------|------|------|
| `d` | 天 | `7d` = 7 天 |
| `h` | 小时 | `2h` = 2 小时 |
| `m` | 分钟 | `30m` = 30 分钟 |
| `s` | 秒 | `45s` = 45 秒 |
| 无后缀 | 秒 | `3600` = 3600 秒 |

> 解析失败时回退为 1 小时。

## 管理员面板

管理员面板（`/essentials admin`）提供安全管理的可视化操作，均要求 `axs.essentials.admin` 权限，并二次校验对应功能权限：

| 页面 | 操作 | 所需权限 |
|------|------|----------|
| 玩家列表 | 踢出 | `axs.essentials.kick` |
| 封禁列表 | 封禁 / 解除（按 UUID） | `axs.essentials.ban` / `axs.essentials.unban` |
| 禁言列表 | 禁言 / 解除 | `axs.essentials.mute` / `axs.essentials.unmute` |

> 更多关于 UI 配置文件编写与图标显示，请参考 [图标配置](/docs/guide/icons)。
