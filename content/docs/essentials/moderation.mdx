## 功能概述

安全管理包含封禁、禁言、踢出、警告与强制执行。禁言由 Chat 模块管理。下表使用 `/ess` 入口，操作者需要 `axs.essentials.menu` 和对应操作权限。

| 中文功能 | 命令示例 | 所需权限 |
| --- | --- | --- |
| 永久封禁 | `/ess ban Steve 违反规则` | `axs.essentials.ban` |
| 临时封禁 | `/ess tempban Steve 1d 违反规则` | `axs.essentials.ban` |
| 解除封禁 | `/ess unban Steve` | `axs.essentials.unban` |
| 永久/临时禁言 | `/ess tempmute Steve 30m 请停止刷屏` | `axs.essentials.mute` |
| 解除禁言 | `/ess unmute Steve` | `axs.essentials.unmute` |
| 踢出 | `/ess kick Steve 请重新连接` | `axs.essentials.kick` |
| 警告 | `/ess warn Steve 请遵守聊天规则` | `axs.essentials.warn` |
| 强制执行 | `/ess sudo Steve help` | `axs.essentials.sudo` |
| 背包查看 | `/ess inv Steve` | `axs.essentials.inv` |

### 永久封禁（ban）

`/ess ban <玩家> [原因]` 记录永久封禁，踢出在线玩家并广播。踢出界面使用 `moderation.ban-message`。开启 `moderation.record-ban-ip` 时会同时记录在线玩家 IP。

### 临时封禁（tempban）

例如 `/ess tempban Steve 30m 刷屏` 为在线测试玩家登记 30 分钟封禁并踢出。其他单位见[时长格式](#时长格式)。

### 解除封禁（unban）

`/ess unban <玩家>` 删除封禁记录。命令仅对在线玩家生效，离线玩家需通过管理员面板的 unban 操作（按 UUID 解除）。

这组命令记录封禁并处理当前在线连接。需要拦截玩家再次连接时，由服务器的封禁准入功能处理。

## 禁言系统

禁言功能由 Chat 模块提供，Essentials 本身不存储禁言数据：

- `mute` 永久禁言；`tempmute` 临时禁言；`unmute` 解除禁言
- Chat 模块未加载时命令提示禁言不可用，管理面板禁言标签页显示「Chat 模块未加载」

## 踢出（kick）

`/ess kick <玩家> [原因]` 踢出在线玩家，使用 `moderation.kick-message` 模板并全服广播。原因缺省为"无"。

## 警告与自动封禁（warn）

`/ess warn <玩家> [原因]` 记录一次警告并全服广播，然后检查自动封禁阈值：

```yaml
moderation:
  # 达到 5 次警告自动永久封禁（0 = 不自动封禁）
  max-warnings-before-ban: 5
  # 警告 30 天后过期，不计入自动封禁判定（0 = 永不过期）
  warning-expire-days: 30
```

- 有效警告数仅统计 `warning-expire-days` 内的警告
- 达到阈值时自动封禁玩家（操作者显示为"系统"）并踢出

> 警告过期仅影响自动封禁判定，历史警告记录不会被删除。

## 强制执行（sudo）

`/ess sudo <玩家> <命令>` 强制目标玩家执行命令，命令以 `/` 开头时自动去除前缀：

```text
/ess sudo Steve /spawn
/ess sudo Steve say hello
```

## 背包查看（inv）

`/ess inv <玩家>` 打开目标玩家背包界面，支持实时双向同步修改，详见 [玩家管理](/docs/essentials/player-management)。

> 仅对在线玩家生效，且需要执行者为玩家。

## 时长格式

临时封禁与临时禁言共用时长格式：

| 后缀 | 单位 | 示例 |
|------|------|------|
| `d` | 天 | `7d` = 7 天 |
| `h` | 小时 | `2h` = 2 小时 |
| `m` | 分钟 | `30m` = 30 分钟 |
| `s` | 秒 | `45s` = 45 秒 |
| 无后缀 | 秒 | `3600` = 3600 秒 |

> 解析失败时回退为 1 小时。

## 管理员面板

管理员面板（`/ess admin`）提供安全管理的可视化操作，均要求 `axs.essentials.admin` 权限，并二次校验对应功能权限：

| 页面 | 操作 | 所需权限 |
|------|------|----------|
| 玩家列表 | 踢出 | `axs.essentials.kick` |
| 封禁列表 | 封禁 / 解除（按 UUID） | `axs.essentials.ban` / `axs.essentials.unban` |
| 禁言列表 | 禁言 / 解除 | `axs.essentials.mute` / `axs.essentials.unmute` |

> 更多关于 UI 配置文件编写与图标显示，请参考 [图标配置](/docs/guide/icons)。
