## 模块简介

Essentials 是 Suite 的基础工具模块，提供服务器日常运营所需的全部常用功能：玩家状态管理（飞行、无敌、治疗、饱食、速度、隐身、AFK）、传送系统（家、传送点、出生点、TPA、返回、坐标传送）、世界控制（时间、天气）、安全管理（封禁、禁言、踢出、警告、强制执行）、交互动作（坐下、躺下）以及背包操作（一键砍树、自动补种、背包整理、自动工具切换）。

模块通过 `EssentialsModule` 主类统一管理生命周期，内部拆分为四个独立服务层（`PlayerManagementService`、`TeleportService`、`TreeCapitatorService`、`InventoryActionsService`），各服务职责清晰、可独立启停。数据持久化由 `EssentialsRepository` 统一处理，支持 SQLite 与 MySQL 双方言，并兼容本体共享存储与模块自建存储两种模式。

模块同时提供两个 ArcartX UI 界面：玩家工具菜单（`/essentials menu`）与管理员后台面板（`/essentials admin`），通过 PacketBridge 实现服务端与客户端的双向数据交互。

## 核心机制

### 服务架构

Essentials 模块内部由四个独立服务层组成，各服务在 `startService()` 阶段按顺序初始化，在 `stopService()` 阶段按逆序关闭：

| 服务 | 职责 | 事件监听 |
|------|------|----------|
| `PlayerManagementService` | 飞行、无敌、治疗、饱食、游戏模式、速度、隐身、AFK、返回栈、修复、帽子、容器、背包查看 | `PlayerMoveEvent`、`PlayerQuitEvent`、`EntityDamageEvent`、`InventoryClickEvent` 等 |
| `TeleportService` | 家、传送点、出生点、TPA、返回、坐标传送、延迟传送 | `PlayerMoveEvent`、`PlayerQuitEvent` |
| `TreeCapitatorService` | 一键砍树连锁破坏 | `BlockBreakEvent` |
| `InventoryActionsService` | 自动补种、背包整理、自动工具切换 | `BlockBreakEvent`、`PlayerInteractEvent` |

### 存储模式

模块支持两种存储模式，通过 `storage.shared` 配置项控制：

- **共享模式**（`shared: true`，默认推荐）：复用本体 `config.yml` 的 `storage` 节配置，模块只需指定表前缀（`axs_ess_`），连接池由本体统一管控，性能最优。
- **自建模式**（`shared: false`）：模块自建独立 HikariCP 连接池，支持 SQLite 或 MySQL，适合需要独立数据库的场景。

### 命令分发

所有功能通过 `/essentials <action>` 或 `/ess <action>` 命令访问。同时支持在配置中定义命令简写别名（`command-aliases` 节），将独立顶层命令（如 `/fly`）转发到对应的 `/essentials <action>` 子命令。命令分发由 `EssentialsCommandDelegate` 统一处理，包含权限校验、参数校验与 Tab 补全。

### UI 交互

模块注册两个 ArcartX UI 界面，通过 `PacketBridge` 实现服务端推送与客户端回包：

| UI | 打开命令 | Packet ID | 说明 |
|----|----------|-----------|------|
| 玩家工具菜单 | `/essentials menu` | `AXS_ESS_MENU` | 首页 / 家 / 传送点 / TPA / 设置 |
| 管理员后台 | `/essentials admin` | `AXS_ESS_ADMIN` | 玩家 / 封禁 / 禁言 / 传送点 / 世界 |

UI 配置文件位于模块资源目录 `arcartx/ui/` 下，模块启动时自动导出到数据目录并注册。客户端通过 `Packet.send(packetId, action, ...)` 发送操作指令，服务端 `ClientPacketHandler` 接收并处理后推送更新数据。

### 跨模块能力

模块注册以下 Capability 供其他模块查询：

| Capability | 说明 |
|------------|------|
| `EssentialsQueryable` | 查询玩家 AFK / 隐身 / 禁言 / 昵称 / 飞行 / 无敌状态 |
| `PlayerDataPurgeable` | 清除指定玩家或全部玩家数据 |
| `DatabaseMigratable` | 数据库跨源迁移 |

同时通过 `getCapability` 延迟获取其他模块能力：

| Capability | 来源 | 用途 |
|------------|------|------|
| `TabRefreshable` | Tab 模块 | AFK / 隐身状态变化时刷新 Tab 列表 |
| `ChatMutable` | Chat 模块 | 禁言 / 解禁玩家，查询禁言列表 |
