| 项目 | 说明 |
| --- | --- |
| 模块 ID | `essentials` |
| 主配置 | `plugins/ArcartX-Suite/data/essentials/config.yml` |
| 主要调整内容 | 传送预热、家数量、命令别名与功能开关 |
| 重载 | `/axs reload essentials` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。本模块还需要安装 `PlaceholderAPI`。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 选择需要的工具。
2. 按命令页授予相应权限。
3. 使用 `/ess help` 查看入口。

## 检查是否配置成功

先测试设置家与回家，再开放其他功能。

家点能设置却没有完成传送时，先在预热期间保持静止并检查游戏内提示。若顶层命令由其他插件接管，用 `/ess home` 指定 Suite 入口，再核对[家点命令权限](/docs/essentials/commands)。

## 可以配置的功能

| 分类 | 功能 | 说明 |
|------|------|------|
| 玩家管理 | 飞行 / 无敌 | 切换飞行与无敌模式，支持对其他玩家操作 |
| 玩家管理 | 治疗 / 饱食 | 恢复生命值与饥饿值，清除着火状态 |
| 玩家管理 | 速度控制 | 设置飞行 / 行走速度（1-10） |
| 玩家管理 | 游戏模式 | 切换生存 / 创造 / 冒险 / 旁观模式 |
| 玩家管理 | 隐身 | Vanish 隐身，对无权限玩家隐藏，可选隐藏进出服消息 |
| 玩家管理 | AFK 挂机 | 自动检测挂机，可选超时踢出，支持手动切换 |
| 玩家管理 | 昵称 | 设置 / 重置自定义昵称，持久化存储 |
| 玩家管理 | 物品修复 | 修复主手物品耐久度 |
| 玩家管理 | 戴帽 | 将主手物品戴到头盔槽 |
