# Essentials 基础指令集

## 模块简介

Essentials 是 Suite 的基础工具模块，提供服务器日常运营所需的全部常用功能：玩家状态管理（飞行、无敌、治疗、饱食、速度、隐身、AFK）、传送系统（家、传送点、出生点、TPA、返回、坐标传送）、世界控制（时间、天气）、安全管理（封禁、禁言、踢出、警告、强制执行）、交互动作（坐下、躺下）以及背包操作（一键砍树、自动补种、背包整理、自动工具切换）。

数据持久化支持 SQLite 与 MySQL，兼容本体共享存储与模块自建存储两种模式。

模块同时提供两个 ArcartX UI 界面：玩家工具菜单（`/essentials menu`）与管理员后台面板（`/essentials admin`）。

| 属性 | 值 |
|---|---|
| 模块 ID | `essentials` |
| 版本 | 1.4.5 |
| 配置文件 | `config.yml`、`messages.yml` |
| 命令入口 | 玩家 `/ess`（51 个子命令）+ `command-aliases` 注册的顶层别名（默认 47 个） |
| 外部依赖 | PlaceholderAPI（必需）；Multiverse-Core（可选，世界别名解析） |
| 模块依赖 | 无 |
| 对外能力 | `EssentialsQueryable`（隐身/飞行/上帝/AFK 等状态查询）、`PlayerDataPurgeable`、`DatabaseMigratable` |
| PAPI 前缀 | `%axsessentials_*%` |

## 核心机制

### 存储模式

模块支持两种存储模式，通过 `storage.shared` 配置项控制：

- **共享模式**（`shared: true`，默认推荐）：复用本体 `config.yml` 的 `storage` 节配置，性能最优。
- **自建模式**（`shared: false`）：自建独立数据库连接，支持 SQLite 或 MySQL，适合需要独立数据库的场景。

### 命令

所有功能通过 `/essentials <action>` 或 `/ess <action>` 命令访问。支持在 `command-aliases` 节定义顶层命令别名（如 `/fly`），转发到对应的子命令。

### UI 界面

| UI | 打开命令 | 说明 |
|----|----------|------|
| 玩家工具菜单 | `/essentials menu` | 首页 / 家 / 传送点 / TPA / 设置 |
| 管理员后台 | `/essentials admin` | 玩家 / 封禁 / 禁言 / 传送点 / 世界 |

### 跨模块联动

- AFK / 隐身状态变化时自动刷新 Tab 列表（需 Tab 模块）
- 禁言 / 解禁功能使用 Chat 模块能力（需 Chat 模块）
- 其他模块可查询玩家 AFK / 隐身 / 禁言 / 昵称 / 飞行 / 无敌状态
- `/axs purge` 支持按 UUID 或全量清理玩家数据；`/axs migrate` 支持跨源迁移
