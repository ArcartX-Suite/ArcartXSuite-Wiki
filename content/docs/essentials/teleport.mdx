# 传送系统

Essentials 传送系统提供家（home）、传送点（warp）、出生点（spawn）、玩家间传送请求（TPA）、`/back` 返回、延迟传送与安全传送。

## 家（Home）

每个玩家可设置多个家，数量受 `teleport.max-homes` 限制（默认 3）。

- `/sethome <名称>` 设置或更新家（超出上限提示）
- `/delhome <名称>` 删除家
- `/home <名称>` 传送到家
- 家名称不区分大小写，同名家被覆盖

### 权限覆盖上限

通过 `axs.essentials.homes.<数字>` 权限节点可覆盖 `max-homes`，取玩家拥有的最高值作为实际上限。

> 例如配置 `max-homes: 3`，玩家拥有 `axs.essentials.homes.10` 权限时上限提升为 10。仅对新增家生效，更新已有家不检查上限。

## 传送点（Warp）

传送点是全服共享的公共传送点：

- 使用需要 `axs.essentials.warp` 权限
- `/setwarp`、`/delwarp` 分别需要 `axs.essentials.setwarp` / `axs.essentials.delwarp` 权限
- 传送点名称不区分大小写，同名被覆盖

## 出生点（Spawn）

`/setspawn` 以管理员当前位置设置服务器出生点；`/spawn` 传送到出生点，未设置时传送到世界默认出生点。

## TPA 请求

| 命令 | 传送方向 |
|------|----------|
| `/tpa <玩家>` | 请求者传送到目标 |
| `/tpahere <玩家>` | 目标传送到请求者 |

- `/tpaccept` 接受请求并执行延迟传送；`/tpdeny` 拒绝并通知双方
- 请求在 `tpa-timeout`（默认 60 秒）后过期并通知发送者
- 每个目标玩家同一时刻只保留一个待处理请求，新请求覆盖旧请求；请求者下线时请求自动清理

## 延迟传送与预热

除 `/tp` 外，所有传送命令默认经过预热（`teleport.teleport-delay`，默认 3 秒）：

| 条件 | 行为 |
|------|------|
| `teleport-delay <= 0` | 即时传送 |
| 拥有 `axs.essentials.teleport.bypass-delay` | 跳过预热，即时传送 |
| 预热期间移动 | 取消传送并提示（`cancel-on-move: false` 时禁用移动取消） |

## 安全传送

`teleport.safe-teleport: true` 时，若目标位置是固体方块，自动向上搜索（最多 10 格）可站立的空位再传送；找不到时按原坐标传送。

## 返回栈（/back）

每次实际传送前自动记录当前位置，`/back` 返回最近一次传送前的位置。栈深度由 `teleport.back-stack-size`（默认 5）控制，连续传送可多级返回。

## 直接传送

| 命令 | 功能 |
|------|------|
| `/top` | 传送到当前坐标最高方块上方（走预热） |
| `/tp <玩家> [目标]` | 传送到玩家，或传送玩家到目标（即时传送，不走预热） |
| `/tppos <x> <y> <z>` | 传送到指定坐标（走预热） |

## UI 菜单

玩家工具菜单（`/essentials menu`）提供家列表、传送点、TPA 页面；管理员面板（`/essentials admin`）提供传送到玩家/传送玩家到自己、设置传送点与出生点等操作。

## 配置项汇总

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `teleport.tpa-timeout` | `60` | TPA 请求过期时间（秒，最小 10） |
| `teleport.teleport-delay` | `3` | 传送预热延迟（秒，0=即时） |
| `teleport.cancel-on-move` | `true` | 预热期间移动是否取消 |
| `teleport.max-homes` | `3` | 每玩家家数量上限（可被权限覆盖） |
| `teleport.back-stack-size` | `5` | `/back` 返回栈最大深度 |
| `teleport.safe-teleport` | `true` | 是否启用安全传送 |
