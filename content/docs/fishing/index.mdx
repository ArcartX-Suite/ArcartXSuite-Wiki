| 重载 | `/axs reload fishing` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。本模块还需要安装 `PlaceholderAPI`。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 先保留默认鱼类和鱼竿。
2. 设置测试水域。
3. 执行 `/fishing` 查看界面，再尝试钓鱼。

## 检查是否配置成功

完成一次小游戏，确认获得鱼类并更新图鉴。

能抛竿却不进入小游戏时，先检查浮标是否落在已启用的水域内，再核对测试鱼竿与该水域的匹配要求。能完成小游戏却没有奖励时，检查水域引用的鱼池、鱼种与发放设置。

## 可以配置的功能

| 功能 | 说明 |
| --- | --- |
| 星露谷风格小游戏 | 绿条物理（重力/点击力/阻尼/反弹）、鱼行为模式（7 种）、多阶段行为、逃离机制、连续命中加成 |
| 多水域生态 | 通过多边形选区定义水域，每个水域有独立的鱼类池、宝藏池、难度修正公式、等级限制与饵料倍率 |
| 鱼类定义 | 稀有度（4 级）、尺寸范围、售价、经验、季节/天气/时段限制、行为模式、多阶段行为、条件掉落、出现条件 |
| 宝藏系统 | 独立宝藏池，支持原版/MythicMobs/NeigeItems/Overture/MMOItems 物品 |
| 饵料系统 | 鱼类吸引倍率、宝藏概率加成、鱼竿耐久加成、饵料队列管理、默认饵料自动使用 |
| 鱼竿系统 | 宝藏概率加成、绿条高度加成、小游戏时长加成、经验倍率、等级限制、ItemMatcher 物品识别 |
| 天赋树 | 赛季天赋点（每级 1 点），点亮节点获得钓鱼加成（30+ 种效果类型） |
| 赛季系统 | 赛季等级与经验成长曲线（ARIA 表达式自定义），赛季结束时重置等级/经验/天赋，永久数据保留 |
| 疲惫值系统 | 每钓一条鱼增加疲惫值，影响钓鱼效率分段（4 档），高疲惫值可触发特殊鱼类 |
