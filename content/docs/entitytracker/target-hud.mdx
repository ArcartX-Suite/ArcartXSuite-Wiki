# 攻击目标 HUD

> **付费模块**（消费额度满 ¥150 获得授权）

攻击目标 HUD 是 EntityTracker 的独立功能，**不依赖 MythicMobs**。玩家攻击任意生物时，在超时时间内向攻击者显示目标实体的血量、类型、距离等信息。即使未安装 MythicMobs 也可独立运行。

## 追踪触发

玩家攻击生物时触发追踪：近战攻击直接判定，投射物解析实际射击者，属性插件伤害事件同样计入。

> 攻击者不是玩家、已下线、已死亡、或攻击的是自己时不触发。

## 过滤机制

### 黑名单过滤

通过 `attack-target.settings.blacklist` 排除特定实体不显示目标 HUD：

```yaml
attack-target:
  settings:
    blacklist:
      mythic-mob-ids:
        - "TrainingDummy"    # MythicMob ID 黑名单（大小写不敏感）
        - "DecorativeBoss"
      entity-types:
        - "ARMOR_STAND"       # 实体类型黑名单
        - "PLAYER"            # 不显示玩家目标
```

| 黑名单类型 | 配置字段 | 匹配方式 |
|---|---|---|
| MythicMob ID | `mythic-mob-ids` | 大小写不敏感 |
| EntityType | `entity-types` | 大小写不敏感 |

### Boss 联动过滤

当 `attack-target.settings.entitytracker-link.ignore-configured-bosses` 为 `true`（默认）时，已被 Boss 追踪的 Boss 不显示目标 HUD，避免两个 HUD 同时显示同一实体：

```yaml
attack-target:
  settings:
    entitytracker-link:
      ignore-configured-bosses: true
```

## 刷新与超时

HUD 按 `refresh-interval-ticks` 周期刷新。以下情况关闭目标 HUD：

| 触发条件 | 说明 |
|---|---|
| 超时 | 超过 `target-timeout-ms`（默认 3000ms，最小 250ms）未再次攻击 |
| 目标死亡/无效 | 目标实体不再有效 |
| 目标超出距离 | 距离超过 `max-view-distance`（默认 48 格） |
| 过滤命中 | 目标被黑名单/Boss 联动过滤 |
| 玩家退出/死亡 | 自动清除追踪 |

每次攻击目标会刷新超时计时，持续攻击期间 HUD 保持显示。

## 显示条件

目标 HUD 显示需同时满足：攻击者在线且未死亡、目标存活、同一世界、未超时、距离在 `max-view-distance` 内。

## 显示模板

`title-format` 和 `subtitle-format` 支持 `{}` 包裹的占位符和 `&` 颜色代码：

```yaml
attack-target:
  settings:
    title-format: "&c{display_name}"
    subtitle-format: "&7{entity_type_name} &8| &c{health}/{max_health} &8| &f{distance_text}"
```

### 可用占位符

| 占位符 | 说明 |
|---|---|
| `{display_name}` | 目标显示名称 |
| `{health}` / `{health_text}` | 当前血量（文本） |
| `{max_health}` / `{max_health_text}` | 最大血量（文本） |
| `{health_percent}` / `{health_percent_text}` | 血量百分比 |
| `{progress}` / `{progress_text}` | 血量进度（0-1） |
| `{distance}` / `{distance_text}` | 距离 |
| `{entity_uuid}` | 目标实体 UUID |
| `{entity_type}` | 实体类型标识 |
| `{entity_type_name}` | 实体类型显示名称 |
| `{mythic_mob_id}` | MythicMob ID |
| `{is_player_target}` | 目标是否为玩家 |
| `{world}` | 所在世界 |
| `{x}` / `{y}` / `{z}` | 坐标 |
| `{last_hit_ago_ms}` | 距上次攻击的毫秒数 |
| `{timeout_ms}` | 超时毫秒数 |

> 模板支持 `\n` 换行符。

## UI 可用字段

目标 HUD UI 文件可直接绑定以下字段：

```yaml
title: "&c骷髅"
subtitle: "&7SKELETON &8| &c20/20 &8| &f15m"
health: 20.0
maxHealth: 20.0
healthText: "20"
maxHealthText: "20"
healthPercent: 100.0
healthPercentText: "100"
progress: 1.0
distance: 15
distanceText: "15m"
displayName: "骷髅"
entityUuid: "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
world: "world"
x: 100
y: 64
z: 200
entityType: "SKELETON"
entityTypeName: "骷髅"
mythicMobId: ""
isPlayerTarget: false
lastHitAgoMs: 500
timeoutMs: 3000
```

> 支持多 UI ID 同时发包，在配置中将 `target-ui-id` 设为列表即可。

## 调试模式

```yaml
attack-target:
  settings:
    debug: true
```

开启后输出发包详细日志，仅影响日志输出。生产环境建议关闭。
