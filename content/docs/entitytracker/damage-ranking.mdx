# 伤害排名与结算奖励

> **付费模块**（消费额度满 ¥150 获得授权）

EntityTracker 的伤害排名系统在 Boss 生命周期内实时追踪玩家伤害，在 Boss 死亡时按排名发放即时奖励，并支持按周/月周期发放排行榜定时奖励。奖励动作支持物品、命令、消息、邮件、信号五种类型，变量替换后还会经过 PlaceholderAPI 二次解析。

## 伤害排名追踪

Boss 存活期间实时记录两类数据：玩家对 Boss 造成的伤害、Boss 对玩家造成的伤害。排名按伤害降序，受 `max-entries` 限制。

## 伤害门槛

`damage-ranking.min-damage` 控制玩家伤害是否足以参与排名：

| 模式 | 配置示例 | 判断逻辑 |
|---|---|---|
| 百分比（默认） | `"1%"` | 伤害 ≥ Boss **最大血量** × 百分比 |
| 绝对值 | `"1000"` | 伤害 ≥ 固定值 |
| 任意 | 留空或无法解析 | 任何伤害均可参与 |

> 百分比门槛基于 Boss 最大血量计算，而非当前血量。留空默认 1%。

## 死亡结算

Boss 死亡时执行一次结算：生成结算记录（含各名次玩家、伤害、承受伤害、是否达标），按名次发放即时奖励，并跨服同步。结算记录保留最近 100 条供管理命令查询。

## 即时奖励

即时奖励在 Boss 死亡结算时发放，通过 Boss 配置文件的 `damage-ranking.rewards` 配置：

```yaml
damage-ranking:
  rewards:
    enabled: false          # 是否启用即时奖励
    ranks:                  # 名次到奖励的映射
      1:
        actions:
          - type: item
            source: neige
            id: "legendary_sword"
            amount: 1
          - type: command
            command: "points give {player} 100"
          - type: message
            target: "player"
            text: "&6你在 {boss_display_name} 伤害排名第 {rank} 名，获得奖励。"
      2:
        actions:
          - type: command
            command: "points give {player} 50"
```

> 即时奖励只在 Boss 死亡结算时发放。Boss 重载、消失或服务器停机不会触发。

## 排行榜定时奖励

排行榜定时奖励独立于即时死亡结算，按周/月周期发放，通过 Boss 配置文件的 `damage-ranking.ranking-rewards` 配置：

```yaml
damage-ranking:
  ranking-rewards:
    weekly:                 # 周奖励
      enabled: false
      ranks:
        1:
          actions:
            - type: command
              command: "points give {player} 100"
            - type: message
              target: "broadcast"
              text: "&6&l恭喜 {player} 获得本周 {boss_display_name} 伤害冠军！"
    monthly:                # 月奖励
      enabled: false
      ranks:
        1:
          actions:
            - type: command
              command: "points give {player} 500"
```

### 调度配置

全局调度设置在主配置文件的 `new-features.ranking-rewards.schedule` 中：

```yaml
new-features:
  ranking-rewards:
    schedule:
      weekly:
        enabled: true
        day-of-week: "MONDAY"    # MONDAY ~ SUNDAY
        hour: 0
        minute: 0
      monthly:
        enabled: true
        day-of-month: 1
        hour: 0
        minute: 0
    timezone: "Asia/Shanghai"
    reward-settings:
      auto-distribute: true
      max-retry-count: 3
      retry-interval-minutes: 30
      broadcast-rewards: true
      detailed-logging: true
```

| 调度字段 | 说明 |
|---|---|
| `weekly.enabled` | 是否启用周奖励调度 |
| `weekly.day-of-week` | 周奖励执行日（`MONDAY` ~ `SUNDAY`） |
| `weekly.hour` / `weekly.minute` | 执行时间 |
| `monthly.enabled` | 是否启用月奖励调度 |
| `monthly.day-of-month` | 月奖励执行日（1-31） |
| `monthly.hour` / `monthly.minute` | 执行时间 |
| `timezone` | 时区（默认 `Asia/Shanghai`） |

| 发放字段 | 默认值 | 说明 |
|---|---|---|
| `auto-distribute` | `true` | 是否自动发放奖励 |
| `max-retry-count` | `3` | 发放失败重试次数 |
| `retry-interval-minutes` | `30` | 重试间隔（分钟） |
| `broadcast-rewards` | `true` | 是否广播奖励发放结果 |
| `detailed-logging` | `true` | 是否记录详细日志 |

> 定时奖励的排行数据从数据库中的玩家最高伤害记录查询，而非实时伤害追踪。

## 奖励动作类型

| 类型 | 配置值 | 必填字段 | 说明 |
|---|---|---|---|
| 物品 | `item` | `source`、`id`、`amount` | 发放物品 |
| 命令 | `command` | `command` | 以控制台身份执行命令 |
| 消息 | `message` | `target`、`text` | 发送消息到指定目标 |
| 邮件 | `mail` | `text` 或 `preset-id` | 发送邮件（需 Mail 模块） |
| 信号 | `signal` | `signal` | 派发信号供其他系统监听 |

### 物品奖励

```yaml
- type: item
  source: neige           # minecraft / mythic / neige / overture / mmoitems
  id: "legendary_sword"    # 物品来源 ID
  amount: 1                # 数量（至少 1）
  nbt: "{Custom:1b}"      # 自定义 NBT（仅 minecraft 源有效，可选）
```

> 物品发放：放入背包 → 背包满转邮件 → 无邮件则掉落。物品来源详见 [物品来源](/docs/guide/item-sources)。

### 命令奖励

```yaml
- type: command
  command: "points give {player} 100"
```

以控制台身份执行，支持变量替换和 PlaceholderAPI 二次解析。

### 消息奖励

```yaml
- type: message
  target: "player"       # player / broadcast / console
  text: "&6你在 {boss_display_name} 伤害排名第 {rank} 名。"
```

| `target` 值 | 说明 |
|---|---|
| `player` | 发送给获奖玩家 |
| `broadcast` | 全服广播 |
| `console` | 输出到控制台 |

### 邮件奖励

```yaml
- type: mail
  text: "&6您在 {boss_display_name} 伤害排名第 {rank} 名，获得奖励。"
  # 或使用预设
  preset-id: "boss_reward_template"
```

> 需 Mail 模块可用，否则邮件动作被跳过。

### 信号奖励

```yaml
- type: signal
  signal: "boss_kill_reward"
```

派发信号供其他系统（如 EventPacket）监听处理。

## 变量替换

奖励动作中的 `command`、`text` 等字段先做内置变量替换，再经 PlaceholderAPI 二次解析（可用 `%vault_eco_balance%` 等）。

| 变量 | 说明 |
|---|---|
| `{player}` / `{player_name}` / `{player_uuid}` / `{player_display_name}` | 获奖玩家信息 |
| `{boss_id}` / `{boss_display_name}` / `{entity_uuid}` | Boss 信息 |
| `{rank}` / `{rank_text}` | 排名 |
| `{damage}` / `{damage_percent}` / `{taken_damage}` | 伤害数据 |
| `{total_damage}` / `{participant_count}` / `{tracked_player_count}` | 统计数据 |
| `{top_N_name}` / `{top_N_damage}` / `{top_N_damage_percent}` / `{top_N_taken_damage}` | 排行榜字段（N = 1 ~ max-entries） |

## 奖励补发

`/axs entitytracker reissue <settlementId> <rank> [玩家名]` 可补发指定结算中指定名次的奖励：

```bash
# 补发结算 ID 为 5 的第 1 名奖励
/axs entitytracker reissue 5 1

# 补发给指定玩家
/axs entitytracker reissue 5 1 Steve
```

## 结算占位符

以 `last_` 为前缀的 PAPI 占位符返回玩家最近一次 Boss 死亡结算的数据：

| 占位符 | 说明 |
|---|---|
| `%axsentitytracker_last_settlement_id%` | 结算 ID |
| `%axsentitytracker_last_boss_id%` | Boss MythicMob ID |
| `%axsentitytracker_last_boss_display_name%` | Boss 显示名称 |
| `%axsentitytracker_last_participant_count%` | 参与人数 |
| `%axsentitytracker_last_total_damage%` | 总伤害 |
| `%axsentitytracker_last_rank%` | 玩家排名 |
| `%axsentitytracker_last_rank_text%` | 玩家排名文本 |
| `%axsentitytracker_last_damage%` | 玩家伤害 |
| `%axsentitytracker_last_damage_percent%` | 玩家伤害百分比 |
| `%axsentitytracker_last_taken_damage%` | 玩家承受伤害 |
| `%axsentitytracker_last_rewarded%` | 玩家是否已领奖 |
| `%axsentitytracker_last_top_1_name%` | 结算第 1 名玩家名 |
| `%axsentitytracker_last_top_1_damage%` | 结算第 1 名伤害值 |
