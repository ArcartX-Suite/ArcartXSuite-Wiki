所有命令通过Suite统一命令入口 `/axs` 执行，模块命令 ID 为 `entitytracker`。

## 管理员命令

Boss 追踪管理命令（需 MythicMobs 已安装且 BossTrackerService 已启动）：

| 命令 | 说明 |
|---|---|
| `/axs entitytracker help` | 显示帮助信息 |
| `/axs entitytracker status` | 查看模块运行状态（活跃会话数、观察者数、历史结算数） |
| `/axs entitytracker sessions [mobId]` | 列出当前活跃的 Boss 会话，可按 MythicMob ID 筛选 |
| `/axs entitytracker rank <entityUuid> [页码]` | 查看指定 Boss 会话的实时伤害排名 |
| `/axs entitytracker settlements [页码]` | 列出历史结算记录 |
| `/axs entitytracker settlement <settlementId> [页码]` | 查看指定结算记录的详情（含各名次奖励发放状态） |
| `/axs entitytracker reissue <settlementId> <rank> [玩家名]` | 补发指定结算中指定名次的奖励 |

排行榜奖励管理命令（需 `new-features.ranking-rewards` 已配置且数据库可用）：

| 命令 | 说明 |
|---|---|
| `/axs entitytracker rewards help` | 显示排行榜奖励帮助 |
| `/axs entitytracker rewards manage` | 打开奖励管理 UI 界面（需玩家执行） |
| `/axs entitytracker rewards history` | 打开奖励发放历史 UI 界面（需玩家执行） |
| `/axs entitytracker rewards distribute <weekly\|monthly>` | 手动触发周/月奖励发放 |
| `/axs entitytracker rewards status` | 查看调度器状态（下次执行时间、任务运行状态） |
| `/axs entitytracker rewards reload` | 重新加载排行榜奖励调度配置（重读模块配置文件并刷新调度计划） |

## 权限节点

| 权限节点 | 说明 | 默认 |
|---|---|---|
| `entitytracker.rewards.admin` | 排行榜奖励管理命令权限（`rewards` 子命令组） | OP |

> Boss 追踪管理命令（`status`、`sessions`、`rank` 等）通过 `/axs entitytracker` 执行，权限由Suite统一管理（通常需要 OP 或Suite管理员权限）。排行榜奖励命令（`/axs entitytracker rewards *`）独立检查 `entitytracker.rewards.admin` 权限。
