# 联动

## EventBus 事件

EntityTracker 模块通过宿主 EventBus 发布以下事件主题，供其他模块订阅：

| 主题 | 触发时机 | 说明 |
|---|---|---|
| `axs.entitytracker.boss_kill` | Boss 死亡结算完成 | 发布 Boss 击杀事件，包含 Boss ID、显示名、参与者、伤害数据、结算记录等 |

其他模块（如 BattlePass、QuestGPS 等）可通过 EventBus 订阅 `axs.entitytracker.boss_kill` 主题，将 Boss 击杀作为任务条件或战令任务触发源。

事件条件配置详见 [条件系统](/docs/guide/conditions)。

## Capability 注册

EntityTracker 在宿主 Capability 注册表中注册以下能力：

### BossTrackerQueryable（公开）

活跃 Boss 会话查询能力（`@PublicCapability`），外部插件经 `AxsCapabilities.get(BossTrackerQueryable.class)` 获取；EntityTracker 未启用时返回 `null`。

| 方法 | 说明 |
|---|---|
| `isTrackedBoss(entityUuid)` | 实体是否为被追踪的配置 Boss |
| `activeSessionCount()` | 当前活跃 Boss 会话数 |
| `activeViewerCount()` | 正在观看 Boss 面板的玩家总数 |
| `activeSessions(mobIdFilter)` | 活跃会话列表；`mobIdFilter` 为 MythicMob id 过滤，`null` 不过滤 |

### 数据清理与迁移

- `/axs purge` 支持按 UUID 或全量清理玩家数据（最高伤害记录、DKP、奖励记录等）
- `/axs migrate` 支持切换数据库时无缝迁移 EntityTracker 数据

## 邮件联动

EntityTracker 在以下场景使用 Mail 模块的邮件功能：

- **奖励发放**：物品奖励背包满时通过邮件发送
- **离线奖励**：排行榜定时奖励发放时，离线玩家通过邮件接收

若 Mail 模块不可用，物品奖励降级为掉落地面。

## 跨服同步

### 跨服 Boss 排行

当 `cross-server.enabled` 和 `new-features.cross-server-ranking.enabled` 均为 `true` 时启用跨服 Boss 排行。

- Boss 死亡结算后写入本地玩家最高伤害记录；若伤害为历史最高，向其他子服广播并合并
- 跨服通道由宿主 `config.yml` 的 `cross-server` 节配置（Redis / Proxy 双后端）

### 跨服击杀记录

Boss 击杀记录同样跨服广播：Boss 死亡时记录击杀信息（参与者、掉落物、位置等），其他子服合并至本地记录。

## 与其他模块/插件联动

### MythicMobs / MythicBukkit（外部依赖）

- Boss 追踪依赖 MythicMobs 的生成/死亡/消失事件
- Mohist 混合端上事件可能延迟触发，`sort-mode: hybrid` 时自动启动补扫机制

### 属性插件

安装以下属性插件时，其伤害事件自动计入 Boss 伤害排名：

| 属性插件 |
|---|
| AttributePlus |
| Crane |
| MythicLib |
| Symphony |

### TACZ 枪械模组

TACZ 枪械伤害同样计入 Boss 伤害排名。

### Mail 模块

- 物品奖励背包满时自动转邮件
- 离线玩家通过邮件接收排行榜奖励
- 奖励配置中 `type: mail` 的动作直接通过邮件发送

### 物品奖励发放

所有物品奖励发放统一执行：放入背包 → 背包满转邮件 → 无邮件则掉落地面。

物品来源支持 `minecraft` / `mythic` / `neige` / `overture` / `mmoitems`，详见 [物品来源](/docs/guide/item-sources)。

### PlaceholderAPI

奖励动作中的变量替换完成后会再经 PlaceholderAPI 解析，支持在奖励命令和消息中使用其他插件的占位符（如 `%vault_eco_balance%`）。

### 存储共享

| 模式 | 配置 | 说明 |
|---|---|---|
| 共享存储（推荐） | `storage.shared: true` | 复用宿主统一数据源 |
| 独立存储 | `storage.shared: false` | 自建独立连接，支持 SQLite 或 MySQL |

存储配置与迁移详见宿主存储文档。
