# 掉落分配与跨服排行

> **付费模块**（消费额度满 ¥150 获得授权）

EntityTracker 在 Boss 伤害排名的基础上扩展了三大进阶功能：Boss 掉落记录、掉落分配（DKP / ROLL / 优先级 / 手动）和跨服 Boss 排行。这些功能需要数据库支持，通过 `new-features` 配置节统一管理。

## 功能开关与依赖

三个新功能通过 `new-features` 配置节独立开关，均需要数据库支持：

```yaml
new-features:
  drop-recording:
    enabled: true       # Boss 掉落记录
  drop-allocation:
    enabled: true       # 掉落分配
  cross-server-ranking:
    enabled: false      # 跨服 Boss 排行
```

| 功能 | 配置节 | 依赖条件 |
|---|---|---|
| 掉落记录 | `drop-recording` | 数据库可用 |
| 掉落分配 | `drop-allocation` | 数据库可用 |
| 跨服排行 | `cross-server-ranking` | 数据库可用 + 跨服通道启用 |

> 数据库不可用时所有新功能不会启用。

## Boss 掉落记录

Boss 死亡时记录击杀信息和掉落物品，支持统计分析和自动清理。

### 配置

```yaml
new-features:
  drop-recording:
    enabled: true
    retention-days: 30              # 数据保留天数，超过自动清理（最小 1）
    enable-statistics: true         # 是否启用掉落统计
    statistics-update-interval: 300 # 统计更新间隔秒数（最小 30）
```

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | `boolean` | `true` | 是否启用掉落记录 |
| `retention-days` | `int` | `30` | 数据保留天数，超过此天数的记录自动清理 |
| `enable-statistics` | `boolean` | `true` | 是否启用掉落统计 |
| `statistics-update-interval` | `int` | `300` | 统计更新间隔（秒） |

### 记录内容

每次 Boss 死亡时记录：Boss ID 与显示名、击杀时间、参与者列表（UUID、名称、伤害）、掉落物品列表、总伤害、击杀位置、服务器节点。

### EventBus 事件

Boss 死亡结算完成时发布 `axs.entitytracker.boss_kill` 主题，包含 Boss ID、显示名、参与者、伤害数据、结算记录等，供其他模块订阅。

> 事件条件配置详见 [条件系统](/docs/guide/conditions)。

## 掉落分配系统

### 分配模式

通过 `default-mode` 配置掉落分配模式：

| 模式 | 配置值 | 说明 | 获胜逻辑 |
|---|---|---|---|
| ROLL | `roll` | 随机分配 | 每个参与者随机一个值，最大者获胜 |
| DKP | `dkp` | 积分竞拍 | DKP 积分最高者获胜 |
| 优先级 | `priority` | 职业/品质优先 | 按职业优先级排序，最优先者获胜 |
| 手动 | `manual` | 手动分配 | 仅记录掉落，不自动分配 |

Boss 死亡后按结算记录中的达标玩家构建参与者列表，（DKP 启用时先发放积分），再对每个掉落物品按 `default-mode` 分配、记录结果、发放物品并广播。

### ROLL 模式

```yaml
new-features:
  drop-allocation:
    default-mode: "roll"
    roll:
      enabled: true
      timeout-seconds: 30     # ROLL 超时时间（秒，最小 5）
      roll-range: "1-100"     # ROLL 数值范围
      allow-pass: true         # 是否允许放弃
```

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | `boolean` | `true` | 是否启用 ROLL 模式 |
| `timeout-seconds` | `int` | `30` | ROLL 超时时间（秒） |
| `roll-range` | `String` | `"1-100"` | ROLL 数值范围（`min-max` 格式） |
| `allow-pass` | `boolean` | `true` | 是否允许放弃（pass） |

每个参与者随机生成一个 `[rollMin, rollMax]` 范围内的整数，最大者获胜。所有参与者的 ROLL 值均记录在数据库中可查。

### DKP 模式

```yaml
new-features:
  drop-allocation:
    default-mode: "dkp"
    dkp:
      enabled: true
      base-earn-points: 10       # Boss 击杀基础积分
      rank-bonus-points:          # 伤害排名额外积分
        1: 20
        2: 15
        3: 10
        4: 5
        5: 3
```

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | `boolean` | `true` | 是否启用 DKP 模式 |
| `base-earn-points` | `int` | `10` | Boss 击杀基础积分 |
| `rank-bonus-points` | `Map<int, int>` | `{1: 20, 2: 15, ...}` | 伤害排名额外积分 |

DKP 分配逻辑：

1. **积分发放**：每次 Boss 击杀后，所有达标参与者获得 `base-earn-points + rank-bonus-points[rank]` 积分
2. **物品分配**：DKP 积分最高的参与者获得掉落物品
3. **积分记录**：积分变动持久化到数据库

### 优先级模式

```yaml
new-features:
  drop-allocation:
    default-mode: "priority"
    priority:
      enabled: true
      class-priority:           # 职业优先级（数值越小越优先）
        tank: 1
        healer: 2
        dps: 3
      quality-priority:        # 装备品质优先级
        legendary: 1
        epic: 2
        rare: 3
        common: 4
```

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | `boolean` | `true` | 是否启用优先级模式 |
| `class-priority` | `Map<String, int>` | `{tank: 1, healer: 2, dps: 3}` | 职业优先级 |
| `quality-priority` | `Map<String, int>` | `{legendary: 1, ...}` | 装备品质优先级 |

按 `class-priority` 中的职业优先级排序参与者，优先级数值最小者获胜。

### 手动模式

```yaml
new-features:
  drop-allocation:
    default-mode: "manual"
```

仅记录掉落物品，不自动分配，由管理员手动处理。

### 物品发放

物品发放按以下优先级执行：放入背包 → 背包满转邮件 → 邮件不可用时掉落地面。

> 物品来源支持 `minecraft` / `mythic` / `neige` / `overture` / `mmoitems`，详见 [物品来源](/docs/guide/item-sources)。

## 跨服 Boss 排行

### 启用条件

| 条件 | 配置位置 | 说明 |
|---|---|---|
| 跨服通道启用 | 宿主 `config.yml` 的 `cross-server` 节 | Redis / Proxy 连接配置 |
| 模块跨服开关 | `cross-server.enabled` | 模块级跨服通道开关 |
| 排行功能启用 | `new-features.cross-server-ranking.enabled` | 排行功能开关 |

```yaml
# 模块配置
cross-server:
  enabled: true

new-features:
  cross-server-ranking:
    enabled: true
    update-interval: 60
    ranking-types:
      - "best_damage"
      - "boss_damage"
      - "kills"
      - "participate"
      - "server"
    max-entries: 50
```

### 排行类型

| 类型 | 说明 |
|---|---|
| `best_damage` | 玩家 Boss 最高伤害记录 |
| `boss_damage` | Boss 伤害排行 |
| `kills` | Boss 击杀次数排行 |
| `participate` | 参与度排行 |
| `server` | 服务器维度排行 |

### 同步行为

- Boss 死亡结算后写入本地玩家最高伤害记录；若伤害为该玩家历史最高，向其他子服广播并合并
- Boss 击杀记录同样跨服广播，其他服合并至本地记录
- 排行榜缓存按 `update-interval`（秒，最小 15）刷新，最多保留 `max-entries` 条

## 存储配置

EntityTracker 支持两种存储模式：

```yaml
storage:
  shared: true    # 共享存储模式（推荐），复用本体数据源
```

| 模式 | 配置 | 说明 |
|---|---|---|
| 共享存储（推荐） | `storage.shared: true` | 复用宿主统一数据源 |
| 独立存储 | `storage.shared: false` | 自建独立连接，支持 SQLite 或 MySQL |

> 推荐使用 `shared: true`（默认值）。存储配置与迁移详见宿主存储文档。
