| 项目 | 说明 |
| --- | --- |
| 模块 ID | `entitytracker` |
| 主配置 | `plugins/ArcartX-Suite/data/entitytracker/config.yml` |
| 主要调整内容 | bosses/ 目标定义、显示模板和排名奖励 |
| 重载 | `/axs reload entitytracker` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。本模块还需要安装 `PlaceholderAPI`。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 准备一个 MythicMobs 测试 Boss。
2. 为其配置追踪条目。
3. 攻击该目标。

## 检查是否配置成功

检查目标面板、伤害排名及击杀结算。

普通目标面板出现但 Boss 排名未启动时，核对 `bosses/` 中的定义与召出的 MythicMobs 怪物标识，再检查其[追踪与排名配置](/docs/entitytracker/boss-tracking)。用两名玩家造成不同伤害验证排名。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| Boss 追踪 HUD | 实时显示 Boss 血量、距离、存活时间、目标信息，支持多 Boss 同时显示（上限可配置） |
| 实时伤害排行 | 追踪并显示每个 Boss 的伤害排行榜，支持伤害门槛过滤 |
| 死亡结算 | Boss 死亡时按伤害排名发放奖励（物品/命令/消息/邮件/信号） |
| 排行榜定时奖励 | 按周/月调度发放排行榜奖励，独立于即时死亡结算 |
| 攻击目标 HUD | 显示玩家最近攻击的实体信息（血量、类型、距离），支持黑名单与 Boss 联动过滤 |
| Boss 定义 | 通过 `bosses/` 目录为每个 MythicMob 独立配置追踪参数、显示格式、排名与奖励 |
| 多种排序模式 | 生成顺序、距离优先、血量百分比、配置优先级、混合排序 |
| 聊天卡片 | Boss 生成/死亡/消失时发送 ArcartX 聊天卡片（需配置卡片模板 ID） |
| 掉落记录系统 | 记录 Boss 掉落物品，支持统计与自动清理 |
