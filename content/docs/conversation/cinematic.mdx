---
title: "电影序列"
description: "按顺序编排传送、镜头移动、字幕、音效与 NPC 动画，制作过场演出。"
---

电影序列用于为玩家播放一段有顺序的过场演出。你可以组合镜头移动、标题、声音和 NPC 动作；动作名称仍填写英文 `type` 值，下面用中文解释每种动作的用途。

## 第一次播放

1. 在 `plugins/ArcartX-Suite/data/conversation/config.yml` 中确认 `cinematic.enabled: true`。
2. 在模块的 `cinematics/` 目录新建 `intro.yml`，放入下文「序列定义」中的示例。
3. 执行 `/axs reload conversation`，再用 `/axs conversation cinematic list` 确认出现 `intro`。
4. 在游戏中执行 `/axs conversation cinematic play intro`。控制台播放时需追加玩家名。
5. 用 `/axs conversation cinematic stop` 停止自己正在播放的序列。先检查标题、等待时长和结束后的状态，再增加其他动作。

## 播放行为

- 播放前自动记录玩家状态（游戏模式、速度、位置等），播放结束 / 玩家退出 / 强制停止时恢复
- 每个动作执行完毕后按 `delay-after-ms` 等待，再执行下一个动作；`wait` 动作本身不做任何操作，只等待
- 播放时自动显示 letterbox 黑边（UI ID 由 `ui.letterbox-ui-id` 配置，支持字符串或列表），结束自动隐藏

## 序列定义

- 每个文件可包含 `cinematic.cinematics` 或顶层 `cinematics` 节
- 文件按文件名排序加载，后加载文件中同 ID 的序列覆盖先前的
- 解析失败的序列被跳过，不影响其他序列

```yaml
cinematic:
  cinematics:
    intro:
      name: "开场动画"
      actions:
        - type: lock_movement
          locked: true
          delay-after-ms: 0
        - type: title
          title: "&6第一章"
          subtitle: "&7新的开始"
          fade-in: 10
          stay: 60
          fade-out: 10
          delay-after-ms: 2000
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 序列显示名（默认取序列 ID） |
| `actions` | list | 动作列表，按顺序执行 |

## 动作类型

| 类型 | 说明 | 关键字段 |
| --- | --- | --- |
| `teleport` | 传送玩家到指定坐标 | `world`, `x`, `y`, `z`, `yaw`, `pitch` |
| `camera_path` | 沿路径平滑插值传送（模拟摄像机移动） | `world`, `duration-ms`, `ticks-per-frame`, `points` |
| `title` | 显示原版标题 / 副标题 | `title`, `subtitle`, `fade-in`, `stay`, `fade-out` |
| `action_bar` | 显示 Action Bar 消息 | `message` |
| `wait` | 纯等待 | — |
| `sound` | 播放原版音效 | `sound`, `volume`, `pitch`, `at-player` |
| `game_mode` | 切换游戏模式 | `mode`（`SURVIVAL` / `CREATIVE` / `ADVENTURE` / `SPECTATOR`） |
| `npc_animation` | 对 Adyeshach NPC 播放动画 | `npc`, `animation`, `speed`, `transition-time`, `keep-time` |
| `npc_model` | 对 Adyeshach NPC 设置模型 | `npc`, `model`, `scale` |
| `message` | 发送聊天消息 | `message` |
| `command` | 执行命令 | `command`, `as-console`（`{player}` 替换为玩家名） |
| `speed` | 设置行走 / 飞行速度 | `walk-speed`, `fly-speed` |
| `lock_movement` | 锁定 / 解锁玩家移动 | `locked` |
| `subtitle` | 播放 Announcer 字幕组 | `group-id`（需 Announcer 模块） |
| `arcartx_sound` | 播放 ArcartX 资源包自定义音效 | `resource-path`, `category`, `at-player`, `pitch` |

> `delay-after-ms` 是每个动作执行**完毕后**的等待毫秒数，而非执行前的延迟。

### 传送玩家（teleport）

将玩家传送到指定世界与坐标，适合设置过场的起点或切换场景。先在测试区域检查落点和朝向。

```yaml
- type: teleport
  world: world
  x: 100.5
  y: 70
  z: 200.5
  yaw: 90
  pitch: 0
  delay-after-ms: 500
```

`world` 找不到时回退到玩家当前世界。`yaw` / `pitch` 可选，默认 0。

### 镜头移动路径（camera_path）

让玩家视角沿多个坐标点移动，形成镜头推进、环绕等过场效果。总播放时长由 `duration-ms` 控制。

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `world` | string | `world` | 世界名 |
| `duration-ms` | long | `3000` | 总时长（毫秒），最小 50 |
| `ticks-per-frame` | int | `2` | 每帧间隔（tick），最小 1 |
| `points` | list | — | 路径点列表，至少 2 个点 |

每个路径点支持 `x` / `y` / `z` / `yaw`（可选）/ `pitch`（可选）。相邻点间线性插值。

```yaml
- type: camera_path
  world: world
  duration-ms: 5000
  ticks-per-frame: 2
  points:
    - { x: 100, y: 70, z: 200, yaw: 0, pitch: 30 }
    - { x: 110, y: 75, z: 210, yaw: 45, pitch: 20 }
    - { x: 120, y: 80, z: 220, yaw: 90, pitch: 10 }
  delay-after-ms: 1000
```

### 主标题与副标题（title）

在屏幕中央显示主标题与副标题，适合章节名称或剧情提示。淡入、停留和淡出的单位都是 tick。

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title` | string | `""` | 主标题 |
| `subtitle` | string | `""` | 副标题 |
| `fade-in` | int | `10` | 淡入时间（tick） |
| `stay` | int | `60` | 停留时间（tick） |
| `fade-out` | int | `10` | 淡出时间（tick） |

### 播放音效（sound）

在玩家当前位置或指定坐标播放音效。先填写音效名称，再调整音量与音调。

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `sound` | string | — | 音效名（原版枚举名或自定义音效名） |
| `world` | string | `world` | 世界名（`at-player: false` 时使用） |
| `x` / `y` / `z` | double | `0` | 坐标（`at-player: false` 时使用） |
| `volume` | float | `1.0` | 音量 |
| `pitch` | float | `1.0` | 音调 |
| `at-player` | boolean | `true` | 是否在玩家位置播放 |

### 切换游戏模式（game_mode）

在演出期间切换玩家的游戏模式，例如使用旁观模式观看场景。演出停止或结束后恢复播放前的状态。

```yaml
- type: game_mode
  mode: SPECTATOR
  delay-after-ms: 0
```

`mode` 无法解析时默认 `SPECTATOR`。

### 播放 NPC 动画（npc_animation）

让指定 Adyeshach NPC 播放一次动画。NPC 名称和动画名称必须与服务器已有配置一致。

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `npc` | string | — | NPC 名称 |
| `animation` | string | — | 动画名称 |
| `speed` | double | `1.0` | 播放速度 |
| `transition-time` | int | `5` | 过渡时间（毫秒） |
| `keep-time` | long | `-1` | 持续时间（毫秒），`-1` 表示播放完整 |

> 需 Adyeshach。NPC 未找到时动作静默跳过。

### 设置 NPC 模型（npc_model）

修改指定 Adyeshach NPC 的显示模型和缩放。先准备模型资源，再填写 NPC 名称与模型 ID。

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `npc` | string | — | NPC 名称 |
| `model` | string | — | 模型 ID |
| `scale` | double | `1.0` | 缩放比例 |

### 执行命令（command）

在动作执行到此处时运行一条命令，可选择控制台或玩家身份；命令中不填写开头的斜杠。

```yaml
- type: command
  command: "say 电影序列开始！"
  as-console: true
  delay-after-ms: 1000
```

`as-console: true` 以控制台身份执行，`false` 以玩家身份执行。`{player}` 替换为玩家名。

### 调整移动速度（speed）

调整演出期间玩家的行走或飞行速度。未填写的速度项保持不变，结束后按序列恢复规则处理。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `walk-speed` | float | 行走速度（0.0 ~ 1.0），可选 |
| `fly-speed` | float | 飞行速度（0.0 ~ 1.0），可选 |

### 锁定与恢复移动（lock_movement）

控制玩家在演出期间能否自行移动。使用 `locked: true` 锁定，使用 `false` 恢复移动。

```yaml
- type: lock_movement
  locked: true
  delay-after-ms: 0
```

锁定时行走 / 飞行速度设为 0，解锁时恢复默认值。

### 播放字幕组（subtitle）

播放 Announcer 中已配置的字幕组，适合显示对白或旁白；`group-id` 必须对应实际字幕组。

```yaml
- type: subtitle
  group-id: intro_subtitle
  delay-after-ms: 3000
```

播放 Announcer 字幕组（打字机效果），需 Announcer 模块；未安装时动作自动跳过。

### 播放自定义音效（arcartx_sound）

播放 ArcartX 资源包中的自定义声音。填写资源路径，并确认客户端已获得对应声音文件。

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `resource-path` | string | — | 资源路径（必填） |
| `category` | string | `master` | 音效分类 |
| `world` | string | `world` | 世界名（`at-player: false` 时使用） |
| `x` / `y` / `z` | double | `0` | 坐标 |
| `dist-or-roll` | int | `16` | 距离 / 滚动参数 |
| `pitch` | double | `1.0` | 音调 |
| `keep-time-ms` | int | `5000` | 持续时间（毫秒） |
| `at-player` | boolean | `true` | 是否在玩家位置播放 |

### 快捷栏提示（action_bar）

在快捷栏上方显示一条短提示，适合显示目标或演出提醒。

```yaml
- type: action_bar
  message: "请留意前方的 NPC"
  delay-after-ms: 1500
```

### 等待后续动作（wait）

不改变玩家状态，只等待 `delay-after-ms` 指定的毫秒数后继续下一条动作。

```yaml
- type: wait
  delay-after-ms: 2000
```

### 聊天栏消息（message）

向观看演出的玩家发送聊天文字，适合补充剧情说明。

```yaml
- type: message
  message: "&7新的旅程即将开始。"
  delay-after-ms: 1000
```

## 玩家状态恢复

播放前自动记录：游戏模式、行走 / 飞行速度、飞行状态、位置。播放结束 / 玩家退出 / 强制停止时全部恢复。

## 调试

启用 `debug.enabled: true` 后输出播放过程日志（开始播放、每个动作执行、停止、完成）。
