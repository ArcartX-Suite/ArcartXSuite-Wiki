# 电影序列

> **付费模块**

电影序列（Cinematic）是 Conversation 模块内置的过场动画回放功能，可编排一系列动作（传送、摄像机移动、标题、音效、NPC 动画、字幕等）按顺序对玩家播放。播放时自动显示 letterbox 黑边 UI 营造沉浸感，结束后恢复玩家状态。

## 播放行为

- 通过 `/axs conversation cinematic play <序列ID>` 播放；同一玩家同一时间只能播放一个序列
- 播放前自动记录玩家状态（游戏模式、速度、位置等），播放结束 / 玩家退出 / 强制停止时恢复
- 每个动作执行完毕后按 `delay-after-ms` 等待，再执行下一个动作；`wait` 动作本身不做任何操作，只等待
- 播放时自动显示 letterbox 黑边（UI ID 由 `ui.letterbox-ui-id` 配置，支持字符串或列表），结束自动隐藏

## 序列定义

序列定义文件存放于 `data/conversation/cinematics/*.yml`，模块启动 / 重载时加载：

- 每个文件可包含 `cinematic.cinematics` 或顶层 `cinematics` 节
- 文件按文件名排序加载，后加载文件中同 ID 的序列覆盖先前的
- 解析失败的序列被跳过，不影响其他序列

```yaml
cinematic:
  cinematics:
    intro:
      name: "开场动画"
      actions:
        - type: lock_movement
          locked: true
          delay-after-ms: 0
        - type: title
          title: "&6第一章"
          subtitle: "&7新的开始"
          fade-in: 10
          stay: 60
          fade-out: 10
          delay-after-ms: 2000
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 序列显示名（默认取序列 ID） |
| `actions` | list | 动作列表，按顺序执行 |

## 动作类型

| 类型 | 说明 | 关键字段 |
| --- | --- | --- |
| `teleport` | 传送玩家到指定坐标 | `world`, `x`, `y`, `z`, `yaw`, `pitch` |
| `camera_path` | 沿路径平滑插值传送（模拟摄像机移动） | `world`, `duration-ms`, `ticks-per-frame`, `points` |
| `title` | 显示原版标题 / 副标题 | `title`, `subtitle`, `fade-in`, `stay`, `fade-out` |
| `action_bar` | 显示 Action Bar 消息 | `message` |
| `wait` | 纯等待 | — |
| `sound` | 播放原版音效 | `sound`, `volume`, `pitch`, `at-player` |
| `game_mode` | 切换游戏模式 | `mode`（`SURVIVAL` / `CREATIVE` / `ADVENTURE` / `SPECTATOR`） |
| `npc_animation` | 对 Adyeshach NPC 播放动画 | `npc`, `animation`, `speed`, `transition-time`, `keep-time` |
| `npc_model` | 对 Adyeshach NPC 设置模型 | `npc`, `model`, `scale` |
| `message` | 发送聊天消息 | `message` |
| `command` | 执行命令 | `command`, `as-console`（`{player}` 替换为玩家名） |
| `speed` | 设置行走 / 飞行速度 | `walk-speed`, `fly-speed` |
| `lock_movement` | 锁定 / 解锁玩家移动 | `locked` |
| `subtitle` | 播放 Announcer 字幕组 | `group-id`（需 Announcer 模块） |
| `ui_packet` | 发送包到 ArcartX 客户端 UI | `ui-id`, `handler`, `payload` |
| `arcartx_sound` | 播放 ArcartX 资源包自定义音效 | `resource-path`, `category`, `at-player`, `pitch` |

> `delay-after-ms` 是每个动作执行**完毕后**的等待毫秒数，而非执行前的延迟。

## 动作详解

### teleport

```yaml
- type: teleport
  world: world
  x: 100.5
  y: 70
  z: 200.5
  yaw: 90
  pitch: 0
  delay-after-ms: 500
```

`world` 找不到时回退到玩家当前世界。`yaw` / `pitch` 可选，默认 0。

### camera_path

沿路径点平滑移动视角。

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `world` | string | `world` | 世界名 |
| `duration-ms` | long | `3000` | 总时长（毫秒），最小 50 |
| `ticks-per-frame` | int | `2` | 每帧间隔（tick），最小 1 |
| `points` | list | — | 路径点列表，至少 2 个点 |

每个路径点支持 `x` / `y` / `z` / `yaw`（可选）/ `pitch`（可选）。相邻点间线性插值。

```yaml
- type: camera_path
  world: world
  duration-ms: 5000
  ticks-per-frame: 2
  points:
    - { x: 100, y: 70, z: 200, yaw: 0, pitch: 30 }
    - { x: 110, y: 75, z: 210, yaw: 45, pitch: 20 }
    - { x: 120, y: 80, z: 220, yaw: 90, pitch: 10 }
  delay-after-ms: 1000
```

### title

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title` | string | `""` | 主标题 |
| `subtitle` | string | `""` | 副标题 |
| `fade-in` | int | `10` | 淡入时间（tick） |
| `stay` | int | `60` | 停留时间（tick） |
| `fade-out` | int | `10` | 淡出时间（tick） |

### sound

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `sound` | string | — | 音效名（原版枚举名或自定义音效名） |
| `world` | string | `world` | 世界名（`at-player: false` 时使用） |
| `x` / `y` / `z` | double | `0` | 坐标（`at-player: false` 时使用） |
| `volume` | float | `1.0` | 音量 |
| `pitch` | float | `1.0` | 音调 |
| `at-player` | boolean | `true` | 是否在玩家位置播放 |

### game_mode

```yaml
- type: game_mode
  mode: SPECTATOR
  delay-after-ms: 0
```

`mode` 无法解析时默认 `SPECTATOR`。

### npc_animation

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `npc` | string | — | NPC 名称 |
| `animation` | string | — | 动画名称 |
| `speed` | double | `1.0` | 播放速度 |
| `transition-time` | int | `5` | 过渡时间（毫秒） |
| `keep-time` | long | `-1` | 持续时间（毫秒），`-1` 表示播放完整 |

> 需 Adyeshach。NPC 未找到时动作静默跳过。

### npc_model

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `npc` | string | — | NPC 名称 |
| `model` | string | — | 模型 ID |
| `scale` | double | `1.0` | 缩放比例 |

### command

```yaml
- type: command
  command: "say 电影序列开始！"
  as-console: true
  delay-after-ms: 1000
```

`as-console: true` 以控制台身份执行，`false` 以玩家身份执行。`{player}` 替换为玩家名。

### speed

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `walk-speed` | float | 行走速度（0.0 ~ 1.0），可选 |
| `fly-speed` | float | 飞行速度（0.0 ~ 1.0），可选 |

### lock_movement

```yaml
- type: lock_movement
  locked: true
  delay-after-ms: 0
```

锁定时行走 / 飞行速度设为 0，解锁时恢复默认值。

### subtitle

```yaml
- type: subtitle
  group-id: intro_subtitle
  delay-after-ms: 3000
```

播放 Announcer 字幕组（打字机效果），需 Announcer 模块；未安装时动作自动跳过。

### ui_packet

发送包到 ArcartX 客户端 UI。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `ui-id` | string | 目标 UI ID |
| `handler` | string | UI 包处理器名 |
| `payload` | map | 任意键值对载荷 |

```yaml
- type: ui_packet
  ui-id: AXS:custom_hud
  handler: show_title
  payload:
    text: "过场动画"
    color: gold
  delay-after-ms: 2000
```

### arcartx_sound

播放 ArcartX 资源包自定义音效。

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `resource-path` | string | — | 资源路径（必填） |
| `category` | string | `master` | 音效分类 |
| `world` | string | `world` | 世界名（`at-player: false` 时使用） |
| `x` / `y` / `z` | double | `0` | 坐标 |
| `dist-or-roll` | int | `16` | 距离 / 滚动参数 |
| `pitch` | double | `1.0` | 音调 |
| `keep-time-ms` | int | `5000` | 持续时间（毫秒） |
| `at-player` | boolean | `true` | 是否在玩家位置播放 |

## 玩家状态恢复

播放前自动记录：游戏模式、行走 / 飞行速度、飞行状态、位置。播放结束 / 玩家退出 / 强制停止时全部恢复。

## 调试

启用 `debug.enabled: true` 后输出播放过程日志（开始播放、每个动作执行、停止、完成）。
