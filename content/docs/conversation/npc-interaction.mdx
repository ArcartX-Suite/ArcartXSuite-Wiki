# NPC 交互与选择器

> **付费模块**

Conversation 模块周期性扫描玩家附近可交互的 NPC，通过选择器 HUD 展示候选列表，玩家使用按键选择并触发对话。同时支持 NPC 外观自动配置，在玩家看见 NPC 时自动应用模型与动画。

## 前置条件

交互增强功能需要以下条件全部满足，否则功能降级（选择器仍可用鼠标点击，快捷键不可用）：

| 条件 | 缺失时表现 |
| --- | --- |
| `interaction.enabled: true` | 配置关闭时功能停用 |
| 选择器 UI 已注册 | `selector UI` 未就绪时降级 |
| Adyeshach 插件可用 | NPC 桥接不可用时降级 |
| Chemdah 插件已安装 | 对话打开器不可用时降级 |

> `/axs conversation status` 可查看当前降级原因。

## 附近 NPC 扫描

模块周期性扫描每个在线玩家附近的 Adyeshach NPC（周期由 `interaction.scan-period-ticks` 控制，默认 10 tick），筛选出有 Chemdah 对话可触发的 NPC 加入选择器候选列表。

- 玩家正在对话中选择器自动关闭
- NPC 离开范围后选择器保持一小段时间再关闭（`interaction.selector-sticky-ms`，默认 1500ms），防止短暂越界时频繁闪烁

## 选择器操作

选择器 HUD 展示附近可对话 NPC 列表（显示名与距离），当前选中项居中高亮：

| 操作 | 按键/方式 |
| --- | --- |
| 向上导航 | `AXS_NAVIGATE_PREV` 按键或滚轮 |
| 向下导航 | `AXS_NAVIGATE_NEXT` 按键或滚轮 |
| 确认打开对话 | `AXS_INTERACT` 按键或点击 |

> 导航为环绕式——到达列表末尾后回到开头。`AXS_INTERACT` 优先级高于拾取模块，确保对话中不会误触拾取。

## 防抖与冷却

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `interaction.open-cooldown-ms` | `350` | 两次打开对话的最小间隔 |
| `interaction.suppress-reopen-ms` | `500` | 回复确认后抑制选择器重新打开的时长 |
| `interaction.selector-sticky-ms` | `1500` | NPC 离开范围后选择器保持显示的延迟 |

## NPC 外观自动配置

`npc-appearances` 配置节定义 NPC 名称到模型与动画的映射，模块启动 / 重载时自动应用：

```yaml
npc-appearances:
  - npc: "村长老王"
    model: npc_village_elder
    scale: 1.0
    state: idle
    animation: idle_loop
```

### 动画模式

| 模式 | 配置方式 | 说明 |
| --- | --- | --- |
| 持久默认状态 | 填 `state` + `animation`，不填 `animation-speed` | NPC 进入视野时保持持久动画 |
| 一次性播放 | 填 `animation` + `animation-speed`（`> 0`） | 播放一次动画，`state` 被忽略 |

### 应用时机

- 玩家进入 NPC 视野时立即应用模型与动画
- 玩家客户端 MOD 初始化完成后自动补发
- 模块启动时对尚未加载的 NPC 自动重试（最多 30 次），仍未找到的 NPC 输出警告日志

> NPC 名称匹配不区分大小写，NPC 的 displayName、customName、Adyeshach ID 均可匹配。

## 状态清理

玩家退出服务器或 Chemdah 对话结束时，该玩家的对话 UI、选择器 UI 与选择器状态自动清理；离线玩家的残留状态在扫描周期中自动移除。
