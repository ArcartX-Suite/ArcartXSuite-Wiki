## 对话显示

- Chemdah 对话开始时自动打开对话 UI，显示 NPC 名称与对话正文
- 对话内容更新（进入下一句）时 UI 自动刷新，当前选中的回复项保持不变
- 对话 UI 打开时附近的 NPC 选择器自动关闭

## 回复交互

| 操作 | 方式 |
| --- | --- |
| 选中回复 | 点击回复项，或键盘数字键 1-9 |
| 确认回复 | 点击已选中的回复 |
| 取消对话 | ESC 或关闭按钮 |

回复类型行为：

| 回复类型 | 行为 |
| --- | --- |
| `talk` | 选中后仅更新 UI，需再次确认才触发 |
| `close` | 关闭对话 |
| 其他 | 正常执行 |

底部提示文字：存在可选回复时显示 `点击选项或按数字键 1-9 发送`，无可选回复时显示 `当前没有可选回复`。

## 防抖与抑制

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `interaction.reply-debounce-ms` | `250` | 两次回复确认的最小间隔，间隔内的确认被丢弃 |
| `interaction.suppress-reopen-ms` | `500` | 回复后抑制选择器重新打开的时长 |

## 关闭行为

- 玩家退出、Chemdah 会话结束、或客户端关闭 UI（ESC）时对话状态自动清理
- UI 端先关闭时不会重复发送关闭包；对话关闭后如满足条件选择器自动恢复
