| 项目 | 说明 |
| --- | --- |
| 模块 ID | `conversation` |
| 主配置 | `plugins/ArcartX-Suite/data/conversation/config.yml` |
| 主要调整内容 | 对话界面、NPC 交互距离与电影序列 |
| 重载 | `/axs reload conversation` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。本模块还需要安装 `Chemdah`、`Adyeshach`。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 按[Chemdah 对话与任务接入](/docs/guide/chemdah-setup)配置主题、NPC 绑定和对话。
2. 确认 Adyeshach 中对应 NPC 已存在。
3. 重载 Chemdah 与 Conversation，再与 NPC 交互。

## 检查是否配置成功

检查文本、回复选择、关闭与再次打开。

与 NPC 交互后没有 Suite 对话时，先确认 NPC 绑定的是目标 Chemdah 对话。若出现了另一种界面，核对 Chemdah 主题与 Suite 的 `theme.name` 是否一致，见[对话主题设置](/docs/guide/chemdah-setup)。

## 可以配置的功能

| 特性 | 说明 |
| --- | --- |
| Adyeshach NPC 联动 | 自动为指定 Adyeshach NPC 设置 ArcartX 模型与动画，支持持久默认状态和一次性播放两种模式 |
| 附近 NPC 扫描 | 周期性扫描附近可交互 NPC，通过选择器 HUD 展示候选列表与距离 |
| 电影序列 | 编排一系列动作（传送、摄像机移动、标题、音效、NPC 动画等）按顺序播放，支持 15 种内置动作类型 |
| Letterbox 黑边 | 电影序列播放时自动显示 letterbox 黑边 UI，隐藏原版与自定义 HUD 营造沉浸感 |
| 多 UI 支持 | 对话 UI、选择器 UI、letterbox UI 均支持字符串或列表格式，可同时向多个 UI 发包 |
| NPC 外观自动配置 | 启动 / 重载时自动为指定 NPC 设置模型和动画，支持重试机制 |
| 玩家状态快照 | 电影序列播放前捕获玩家游戏模式、速度、位置，结束后自动恢复 |
