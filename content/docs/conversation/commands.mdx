title: "NPC 对话命令与权限"
description: "NPC 对话可用命令、参数填写方式和权限要求。"
---

这些管理命令需要 `arcartxsuite.admin` 权限。参数中的 NPC 名称、模型 ID 和电影序列 ID 必须先在对应配置中存在；`<参数>` 为必填，`[参数]` 为选填。

### 通用命令

| 命令 | 权限 | 说明 |
| --- | --- | --- |
| `/axs conversation help` | `arcartxsuite.admin` | 查看可用子命令 |
| `/axs conversation status` | `arcartxsuite.admin` | 查看模块运行状态 |
| `/axs reload conversation` | `arcartxsuite.admin` | 重载 Conversation 模块 |

### Adyeshach NPC 命令

| 命令 | 权限 | 说明 |
| --- | --- | --- |
| `/axs conversation adyeshach setModel <名称> <modelID> <scale>` | `arcartxsuite.admin` | 为指定 NPC 设置 ArcartX 模型与缩放 |
| `/axs conversation adyeshach setAnimation <名称> <state> <animName>` | `arcartxsuite.admin` | 为指定 NPC 设置持久默认动画状态 |
| `/axs conversation adyeshach playAnimation <名称> <动画名> <速度> [过渡ms] [持续ms]` | `arcartxsuite.admin` | 为指定 NPC 一次性播放动画 |

> `playAnimation` 的 `过渡ms` 默认 5，`持续ms` 默认 -1（播放完整动画）。速度必须为正数。

### 电影序列命令

| 命令 | 权限 | 说明 |
| --- | --- | --- |
| `/axs conversation cinematic play <序列ID> [玩家名]` | `arcartxsuite.admin` | 播放指定电影序列（控制台执行需指定玩家名） |
| `/axs conversation cinematic stop` | `arcartxsuite.admin` | 停止自己当前播放的电影序列 |
| `/axs conversation cinematic list` | `arcartxsuite.admin` | 列出所有已定义的电影序列 |
| `/axs conversation cinematic preview <序列ID>` | `arcartxsuite.admin` | 为自己开启彩排，可暂停、定位、单步或循环 |

彩排操作与完整序列示例见[电影序列与场景彩排](/docs/conversation/cinematic)。

### status 命令输出

| 状态项 | 说明 |
| --- | --- |
| 交互增强 | 是否启用附近 NPC 扫描与快捷键交互 |
| NPC 桥接 | Adyeshach NPC 桥接是否就绪 |
| 按键事件 | Suite按键事件是否就绪 |
| Selector UI | 选择器 UI 是否就绪 |
| 对话中 | 当前活跃对话数量 |
| 电影序列播放中 | 当前正在播放的电影序列数量 |
