全局配置位于 `plugins/ArcartX-Suite/data/questgps/config.yml`。**具体任务写在 Chemdah 文件中**，最小例子见[Chemdah 任务配置](/docs/questgps/chemdah-mapping)。

模块会生成 `data/questgps/examples/chemdah-quest.yml` 供参考。需要使用这个示例时，将其复制到 Chemdah 的 `core/quest/` 目录并修改真实世界和目标；示例文件本身不会自动创建任务。

## 第一次需要修改什么

先保留默认全局配置，确认 Chemdah 任务能出现在菜单。需要改界面或整服导航样式时再调整本页；单任务排序、名称覆盖和奖励预览放在该任务的[展示小节](/docs/questgps/chemdah-mapping#在任务中添加-axs-view)。

修改全局设置后执行 `/axs reload questgps`。只改 Chemdah 任务文件时执行 Chemdah 重载，QuestGPS 会自动刷新。

## 界面与日志

| 字段 | 默认值 | 用途 |
| --- | --- | --- |
| `debug.enabled` | `false` | 输出模块诊断日志 |
| `ui.menu-ui-id` | `AXS:questgps_menu` | 任务菜单，可使用 ID 或 ID 列表 |
| `ui.guide-ui-id` | `AXS:questgps_guide` | 任务指引 HUD，可使用 ID 或列表 |
| `ui.register-ui-on-enable` | `true` | 模块启用或重载时注册界面 |
| `ui.overwrite-ui-files` | `false` | 是否覆盖已存在的默认界面文件 |

多个界面的规范写法见[多界面配置](/docs/guide/multi-ui)。

## 分类样式

分类自动识别 Chemdah 的 `meta.type`，无需为每个分类重复登记。`categories` 仅用于按需覆盖同 ID 分类的名称和顺序：

```yaml
categories:
  daily:
    display-name: "日常委托"
    sort-order: 20
```

未命中具体分类时，`category.fallback` 控制是否进入“未分类”，包含 `enabled`、`id`、`display-name`、`sort-order`。默认开启，ID 为 `uncategorized`。

## 导航基础设置

明确填写的任务展示目的地优先，否则使用 Chemdah 原生追踪；没有坐标时不伪造目的地。全局参数控制是否显示以及刷新与到达表现。

| 字段 | 默认值 | 用途 |
| --- | --- | --- |
| `navigation.enabled` | `true` | 是否启用导航 |
| `navigation.remove-on-finish` | `true` | 任务结束时清理对应导航 |
| `navigation.refresh-ticks` | `10` | 目标刷新周期，单位 tick |
| `navigation.world-hint-interval` | `30` | 异世界目标提示间隔，单位秒 |
| `navigation.finish-range` | `0` | 到达触发半径，`0` 不启用 |
| `navigation.finish-commands` | `[]` | 到达时执行的控制台命令 |
| `navigation.finish-rearm-buffer` | `3` | 再次触发到达前需离开的缓冲范围 |
| `navigation.waypoint.enabled` | `true` | 是否显示屏幕路标 |
| `navigation.waypoint.style-id` | `default` | 使用的 ArcartX 路标样式 |
| `navigation.waypoint.title-template` | 空文本 | 路标标题模板，不填时显示目标名称 |

## 路径标记

`navigation.model-marker` 使用 Adyeshach 模型，`navigation.texture-marker` 使用 ArcartX 贴图。两者可分别开启，默认关闭；资源 ID 必须真实存在。

| 小节 | 常用字段 |
| --- | --- |
| 模型标记 | `enabled`、`model-id`、`scale`、`default-state`、`animation`、`y-offset` |
| 贴图标记 | `enabled`、`texture`、`width`、`height`、`facing`、`glowing`、`y-offset`、`pitch`、`life-time` |
| 两者各自的路径参数 | `path-interval`、`path-max-markers`、`path-update-ticks`、`path-max-distance`、`path-reshow-buffer`、`path-max-iterations` |

上表字段中的 `enabled` 为开关，`scale` 为缩放，`y-offset` 为高度偏移，`path-interval` 为路径点间隔，`path-max-markers` 为标记数上限。`model-id` 和 `texture` 填服务器已准备的模型或贴图 ID。

具体资源与动态目标用法见[导航系统](/docs/questgps/navigation)。先测试屏幕路标，确认坐标正确，再开启路径标记。

例如只启用模型路径时，在原 `navigation.model-marker` 小节修改以下字段。`guide_arrow` 是示例模型 ID，须替换为实际资源。

```yaml
navigation:
  model-marker:
    enabled: true       # 开启模型路径标记
    model-id: guide_arrow
    scale: 1.0          # 模型缩放
    y-offset: 0.3       # 位置向上偏移
```

## 可选主线门禁

`gate.required-mainline-quest-ids` 为空时关闭门禁。需要新手流程限制时，填写须完成的 Chemdah 任务 ID，再选择要限制的入口。

| 字段 | 用途 |
| --- | --- |
| `gate.required-mainline-quest-ids` | 必须完成的任务 ID 列表 |
| `gate.blocked-categories` | 未完成时锁定的分类 ID |
| `gate.blocked-command-prefixes` | 要限制的命令前缀，不带 `/` |
| `gate.blocked-module-entries` | 已支持门禁的模块入口 ID |
| `gate.blocked-event-rule-ids` | 未满足要求时不触发的 EventPacket 规则 |
| `gate.deny-message` | 拦截提示文字 |
| `gate.deny-chat-card` / `gate.deny-subtitle` | 按需使用的卡片或字幕组 ID |

完整例子见[主线门禁](/docs/questgps/gate)。玩家任务数据仍由 Chemdah 保存，QuestGPS 只读取状态，不单独配置任务数据库。
