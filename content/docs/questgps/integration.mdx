# 联动

## EventBus 事件

QuestGPS 在任务完成时通过 `EventBusCapability` 发布事件主题，供其他模块订阅。

| 主题 | 触发时机 | Payload |
|---|---|---|
| `axs.questgps.quest_completed` | Chemdah 任务完成 | `quest_id` = 任务 ID, `quest_name` = 任务显示名 |

> 其他模块（如 BattlePass）可通过 EventBus 订阅此主题，将任务完成作为战令任务的完成条件。

## Capability 注册

QuestGPS 注册以下 Capability，供其他模块跨模块调用：

### QuestGpsNavigable

任务导航能力接口，供 EventPacket 等模块调用。

| 方法 | 参数 | 说明 |
|---|---|---|
| `offerQuest` | `Player`, `String questId`, `boolean openMenu` | 向玩家推送任务，可选自动打开菜单 |
| `acceptQuest` | `Player`, `String questId` | 让玩家接受指定任务 |
| `openMenu` | `Player` | 为玩家打开任务导航菜单 |
| `trackQuest` | `Player`, `String questId` | 追踪任务级导航（与其他追踪并行登记，不覆盖已有目标） |
| `trackTask` | `Player`, `String questId`, `String taskId` | 追踪子任务级导航（与其他追踪并行登记） |
| `eventRuleLocked` | `Player`, `String ruleId` | 检查 EventPacket 事件规则是否被主线门禁锁定 |
| `moduleEntryLocked` | `Player`, `String moduleEntryId` | 检查其他模块入口是否被主线门禁锁定 |

#### 调用示例

```java
// 获取 QuestGpsNavigable 能力
QuestGpsNavigable questGps = getCapability(QuestGpsNavigable.class);
if (questGps != null) {
    // 向玩家推送任务并自动打开菜单
    questGps.offerQuest(player, "example_mainline_quest", true);

    // 检查模块入口是否被门禁锁定
    if (questGps.moduleEntryLocked(player, "market")) {
        player.sendMessage("请先完成主线任务");
        return;
    }
}
```

### 信号派发

任务生命周期事件（`triggered`/`accepted`/`abandoned`/`completed`/`track-changed`）向 EventPacket 派发自定义信号，信号携带 `quest_id` 参数。EventPacket 规则匹配信号后执行 actions（发称号/发邮件/派命令等），规则中可用 `{quest_id}` 占位符区分具体任务。

## 跨服同步

`categories` 段支持跨服配置同步，其他配置段（`ui`、`navigation`、`gate`、`database` 等）各服独立加载。

## 数据存储

当 `database.enabled: true` 时，QuestGPS 为 Chemdah 免费版提供 MySQL 存储支持，连接参数沿用 Chemdah `config.yml` 的 `database.source.SQL` 配置。

## 与其他模块联动

### EventPacket

| 联动方式 | 说明 |
|---|---|
| 信号桥接 | 任务生命周期事件向 EventPacket 派发自定义信号，EventPacket 规则匹配信号后执行动作 |
| 门禁检查 | EventPacket 在触发规则前检查是否被主线门禁锁定，未过关则跳过规则 |
| 信号携带参数 | 信号携带 `quest_id` 参数，EventPacket 规则中可用 `{quest_id}` 占位符区分具体任务 |

### Map 模块

| 联动方式 | 说明 |
|---|---|
| 目标同步 | 进行中任务自动同步为地图目标标记（来源 `questgps`），Chemdah 坐标变化时跟随更新 |
| 导航回调 | 地图面板"导航"→ 任务追踪，"取消"→ 停止追踪（标记保留） |
| 导航互斥 | 一方开始导航时另一方的导航自动停止 |
| 打开地图 | UI 的 `open_map` 操作打开地图菜单并选中目标 |

> Map 模块不存在时导航功能正常运行，仅跳过地图目标同步。详见 [导航系统](/docs/questgps/navigation)。

### Announcer

| 联动方式 | 说明 |
|---|---|
| 门禁字幕 | 主线门禁拦截时，若 `gate.deny-subtitle` 非空则播放字幕组 |

### Chat

| 联动方式 | 说明 |
|---|---|
| 门禁聊天卡片 | 主线门禁拦截时，若 `gate.deny-chat-card` 非空则发送聊天卡片 |

### Title

| 联动方式 | 说明 |
|---|---|
| 称号奖励预览 | 奖励类型为 `title` 时，查询称号的显示名、品质与描述用于 UI 预览 |

### Adyeshach

| 联动方式 | 说明 |
|---|---|
| 导航标记模型 | 使用 ArcartX 模型渲染客户端导航标记与路径标记 |

> Adyeshach 不存在时模型导航提示自动关闭，路标导航与贴图导航提示不受影响。

### ArcartX Waypoint

| 联动方式 | 说明 |
|---|---|
| 路标导航 | 在客户端显示方向指引路标 |
| 样式解析 | 路标样式 ID 优先使用任务/子任务配置的 `style-id`，回退到全局 `navigation.waypoint.style-id` |

> ArcartX Waypoint 不存在时路标导航不可用。

### Chemdah

| 联动方式 | 说明 |
|---|---|
| 任务模板读取 | 读取任务名称、描述、目标等元数据 |
| 玩家档案 | 读取任务状态（可接取/进行中/已完成） |
| 任务接取/放弃 | 执行任务接取与放弃操作 |
| 任务追踪 | 启动/停止任务追踪，解析动态导航坐标 |
| MySQL 存储 | `database.enabled: true` 时为 Chemdah 免费版提供 MySQL 存储 |

> Chemdah 是硬依赖，不存在时模块无法启动。
