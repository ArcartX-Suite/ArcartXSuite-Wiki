| 项目 | 说明 |
| --- | --- |
| 模块 ID | `questgps` |
| 主配置 | `plugins/ArcartX-Suite/data/questgps/config.yml` |
| 主要调整内容 | Chemdah 任务文件、可选展示小节与全局导航样式 |
| 重载 | `/axs reload questgps` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。本模块还需要安装 `Chemdah`。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 按[Chemdah 接入教程](/docs/guide/chemdah-setup)准备任务，并使用[Chemdah 任务配置](/docs/questgps/chemdah-mapping)设置展示。
2. 配置对应任务的展示与目标位置。
3. 执行 `/questgps open`。

## 检查是否配置成功

接取一个任务，检查追踪目标及导航方向。

菜单能打开但找不到测试任务时，先在 Chemdah 中确认该玩家已接取任务。任务可见但没路标时，检查当前目标的世界和坐标，按[任务文件示例](/docs/questgps/chemdah-mapping#从任务文件开始)分别核对任务和目标。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| Chemdah 任务桥接 | 读取 Chemdah 任务模板与玩家档案，在 ArcartX UI 中展示任务列表、目标进度与状态 |
| 动态分类菜单 | 自动识别 Chemdah `meta.type`，需要时只覆盖分类名称与顺序 |
| 自动读取任务 | 直接展示已加载的 Chemdah 任务，无需再写一份 Suite 任务配置 |
| 三态分页 | 可接取（AVAILABLE）、进行中（ACTIVE）、已完成（COMPLETED）三个页面，自动按任务状态分桶 |
| 任务接取/放弃 | 通过 UI Packet 触发 Chemdah 任务接取/放弃，支持 `allow-abandon` 开关控制是否允许放弃 |
| 任务追踪 | 追踪任务级或子任务级目标，同步到 ArcartX waypoint 路标导航和 Map 模块第三方插件注册路径点 |
| 多目标追踪 | 玩家可同时追踪多个任务/子目标（追踪态/到达判定并行）；屏幕路标与路径标记链只跟随"最新激活且同世界"的主目标 |
| 路标导航 | 通过 ArcartX waypoint 系统创建路标，在客户端显示方向指引；标题支持模板化（`{label}`/`{quest}`/`{objective}`/`{distance}` 等占位符） |
| NPC 动态目标 | 导航点可绑定 Adyeshach NPC 名/ID，坐标随 NPC 实时移动 |
