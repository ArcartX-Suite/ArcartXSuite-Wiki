---
title: "导航系统"
description: "设置任务导航坐标、路标、模型或贴图路径提示。"
---

通常在 Chemdah 任务或目标的 `addon.track.center` 填写目的地即可。QuestGPS 自动使用原生追踪位置，提供屏幕路标、路径标记与任务指引。

## 导航坐标来源

Chemdah 的固定坐标示例：

```yaml
addon:
  track:
    center: "world 100 64 100"
    name: "讨伐区域"
```

NPC 动态目标可写 `center: "adyeshach guide_demo"`。放在任务还是具体目标中，按 Chemdah 的追踪逻辑选择；完整任务见[Chemdah 任务配置](/docs/questgps/chemdah-mapping)。

如果需要 QuestGPS 专用目的地，在同一任务或目标的 `addon.axs-view.navigation` 中直接填写 `world`、`x`、`y`、`z`，也可填写有效 NPC。明确填写的展示目的地优先，未填写时使用原生追踪。

## 全局表现设置

在 `ArcartXQuestGPS.yml` 中调整 `navigation` 的开启、刷新周期、路标样式和路径标记。具体字段见[功能配置](/docs/questgps/configuration#导航基础设置)。任务坐标仍写在 Chemdah 文件中。

## 任务级与目标级

任务的 `addon.axs-view.navigation` 可补充整个任务的目的地；目标的同名小节可补充该目标目的地。坐标直接放入小节，不额外套层。全局或任务导航关闭时不建立该任务导航。

## 多目标追踪与单路标语义

| 层 | 行为 |
|---|---|
| 追踪态 | 并行：多个任务/子目标可同时登记，各自独立做位置解析与到达判定 |
| 屏幕路标 | 仅主目标；取消主目标后其余同世界目标自动接管 |
| 路径标记链 | 仅主目标——屏幕上始终只有一条路线 |
| 指引 HUD | 并行展示：最多展示 3 张追踪卡片，仅主目标渲染导航坐标 |
| 地图标记 | 并行展示：所有追踪中任务的地图标记显示"导航中"，可按目标单独取消 |

> 动态目标（Chemdah tracker / NPC）即使不是主目标，其坐标仍随 `refresh-ticks` 周期解析并同步到地图标记。

### 到达判定滞回与命令钩子

- `finish-range > 0` 时玩家进入半径触发**一次**到达回调与 `finish-commands`（控制台执行，支持 `{player}`/`{world}`/`{x}`/`{y}`/`{z}` 占位）
- 触发后须离开 `finish-range + finish-rearm-buffer` 才重新武装——防止边界抖动重复执行
- **到达不取消导航**：导航保持到玩家显式取消或任务完成（`remove-on-finish`）
- 任务级与子目标级导航点可用 `finish-range`/`finish-commands` 覆盖全局配置

### NPC 动态目标

导航点配置 `npc: "<Adyeshach NPC 名/ID>"` 时，目标坐标实时跟随 NPC 移动；`world` 可留空。NPC 不存在时该轮不显示路标。

### 跨世界处理与传送点

- 目标世界与玩家不同时：路标与路径标记被抑制，按 `world-hint-interval` 节流提示「任务目标位于其他世界」
- 导航点配置 `teleport` 段后，任务面板显示「传送并追踪」按钮：先传送到该点，再开始追踪
- 子目标未声明 `teleport` 时回退任务级 `addon.axs-view.navigation.teleport`

## 导航路径提示

路径导航有两种互补的可视化方式，可同时启用或只开其一：

- **模型导航提示**（`navigation.model-marker`）：Adyeshach 模型路径标记，仅追踪玩家可见。需 Adyeshach。
- **贴图导航提示**（`navigation.texture-marker`）：沿路径向玩家单人下发贴图箭头，无需实体。

### 模型导航提示配置

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `navigation.model-marker.enabled` | `boolean` | `true` | 是否启用模型导航提示 |
| `navigation.model-marker.model-id` | `String` | `"nav_beacon"` | ArcartX 模型 ID |
| `navigation.model-marker.scale` | `double` | `1.0` | 模型缩放比例 |
| `navigation.model-marker.default-state` | `String` | `"idle"` | 模型默认状态名称 |
| `navigation.model-marker.animation` | `String` | `"rotate"` | 循环播放的动画名称 |
| `navigation.model-marker.y-offset` | `double` | `2.0` | 模型相对导航目标的 Y 轴偏移 |

> 需 Adyeshach 插件，不存在时该功能自动关闭，路标与贴图导航不受影响。

### 贴图导航提示配置

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `navigation.texture-marker.enabled` | `boolean` | `false` | 是否启用贴图路径提示（需资源包中存在对应贴图） |
| `navigation.texture-marker.texture` | `String` | `"nav_arrow"` | 贴图资源 ID |
| `navigation.texture-marker.width` / `height` | `double` | `100` | 贴图渲染宽/高 |
| `navigation.texture-marker.facing` | `boolean` | `false` | `true` 始终面向玩家；`false` 按 pitch/yaw 定向（贴地箭头） |
| `navigation.texture-marker.glowing` | `boolean` | `true` | 是否泛光 |
| `navigation.texture-marker.y-offset` | `double` | `0.1` | 贴图相对路径点的 Y 轴偏移 |
| `navigation.texture-marker.pitch` | `double` | `90` | 俯仰角（贴地渲染 90） |
| `navigation.texture-marker.orient-to-path` | `boolean` | `true` | 朝向下一个路径点 |
| `navigation.texture-marker.life-time` | `int` | `-1` | 贴图存活时长（-1 = 永续直到移除） |
| `navigation.texture-marker.pulse.*` | — | — | 循环缩放脉冲：`enabled`/`from`/`to`/`duration`/`stagger` |

### 路径寻路参数

两种渲染方式各自带一组同语义的 `path-*` 参数（互不影响）：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `navigation.<renderer>.path-interval` | `double` | `3.0` | 路径点间距（方块数） |
| `navigation.<renderer>.path-max-markers` | `int` | `20` | 路径点最大数量（超出后截断远端） |
| `navigation.<renderer>.path-update-ticks` | `int` | `10` | 路径更新间隔（tick） |
| `navigation.<renderer>.path-max-distance` | `double` | `64.0` | 路径最大渲染距离 |
| `navigation.<renderer>.path-reshow-buffer` | `double` | `8.0` | 超距隐藏后须回到 `path-max-distance - 本值` 以内才重新显示 |
| `navigation.<renderer>.path-max-iterations` | `int` | `2000` | 寻路最大迭代次数（100-50000，越大越精确但越耗时） |

> `<renderer>` 为 `model-marker` 或 `texture-marker`。

## 指引 HUD

追踪任务时，QuestGPS 会在屏幕左上角常驻显示追踪卡片列表与主目标导航坐标。最多展示 3 张卡片，按激活顺序排列，主目标在最后。

### HUD 可用字段

| 字段 | 说明 |
|---|---|
| `active` | HUD 是否激活显示 |
| `trackedCount` | 追踪中的目标总数 |
| `quests` | 追踪卡片字典（最多 3 张，字段见下） |
| `questCount` | 卡片条数 |
| `questName` / `hasNav` / `navWorld` / `navX` / `navY` / `navZ` | 主目标名称与导航点（兼容字段） |

`quests` 单卡片字段：`questId` / `taskId` / `mode`（`QUEST`/`TASK`）/ `name` / `label` / `progressText` / `taskText` / `taskDesc` / `hasNav` / `navWorld` / `navText`。

## Map 模块目标同步

QuestGPS 与 Map 模块双向联动——地图负责展示与转发点击，导航执行仍在 QuestGPS：

- 所有进行中任务作为第三方路径点同步到地图（`source = questgps`），追踪中的任务显示"导航中"
- 玩家在地图面板点击「导航」→ QuestGPS 开始任务/子任务追踪；点击「取消」→ 停止追踪（标记保留）
- Chemdah tracker 动态坐标变化时地图标记自动跟随
- 任务接受/完成/失败、玩家进服时自动重新同步

## 导航完整配置示例

```yaml
navigation:
  enabled: true
  remove-on-finish: true
  mode: hybrid
  refresh-ticks: 10
  world-hint-interval: 30
  finish-range: 0
  finish-commands: []
  finish-rearm-buffer: 3.0
  waypoint:
    enabled: true
    style-id: "default"
    title-template: ""
  model-marker:
    enabled: true
    model-id: "waypoint"
    scale: 1.0
    default-state: "idle"
    animation: "rotate"
    y-offset: 0.0
    path-interval: 3.0
    path-max-markers: 20
    path-update-ticks: 10
    path-max-distance: 64
    path-reshow-buffer: 8
    path-max-iterations: 2000
  texture-marker:
    enabled: false
    texture: "nav_arrow"
    width: 100
    height: 100
    facing: false
    glowing: true
    y-offset: 0.1
    pitch: 90
    orient-to-path: true
    life-time: -1
    pulse:
      enabled: true
      from: 0.8
      to: 1.2
      duration: 20
      stagger: 2
    path-interval: 3.0
    path-max-markers: 20
    path-update-ticks: 10
    path-max-distance: 64
    path-reshow-buffer: 8
    path-max-iterations: 2000
```

### 任务级导航配置

以下是已有 Chemdah 任务的局部片段，保留其原有目标与完成行为，只合并展示设置。

```yaml
example_mainline_quest:
  addon:
    axs-view:
      navigation:
        enabled: true
        world: "world"
        x: 0
        y: 80
        z: 0
        title: "初入岛屿"
        style-id: "default"
        map-label: "主线目标"
        # npc: "长老"              # 可选：动态 NPC 目的地
        # finish-range: 3
        # finish-commands:
        #   - "say {player} 到达了目标"
```

### 子任务级导航配置

```yaml
example_mainline_quest:
  task:
    kills:
      addon:
        axs-view:
          sort-order: 10
          navigation:
            world: "world"
            x: 12
            y: 80
            z: -8
            title: "目标位置"
            style-id: "default"
            map-label: "任务目标"
```

> 明确配置的展示目的地优先于原生追踪。目标和任务分别配置所需位置；任务级导航会优先考虑当前目标的展示目的地。

## 依赖关系

| 依赖 | 类型 | 不可用时的影响 |
|---|---|---|
| ArcartX Waypoint | 硬依赖 | 导航功能不可用 |
| Adyeshach | 软依赖 | 模型导航标记关闭，路标导航正常 |
| Chemdah Tracker API | 软依赖 | 仅使用明确配置的展示目的地 |
| Map 模块 | 软依赖 | 跳过地图目标同步，导航正常 |

> 导航运行时就绪状态可通过 `/axs questgps status` 查看。
