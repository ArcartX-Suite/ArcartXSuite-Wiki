# 效果系统

> **付费模块**
>
> Prop 模块属于 Suite 付费模块，需在宿主 `config.yml` 中开启 `modules.prop.enabled` 并完成授权后生效。

效果系统是 Prop 模块的核心能力。每个道具定义中的 `effects` 列表以 `type|payload` 格式编写，模块按行解析并分类执行。效果分为两大类：

- **即时效果**：命令、消息、饱食度、生命值、经验、百分比生命、药水——使用后立即生效
- **属性效果**：AttributePlus、MythicLib、Symphony——聚合后批量提交，在 `Duration` 秒后自动移除

## 效果类型一览

| 类型标识 | 格式 | 分类 | 说明 |
|----------|------|------|------|
| `cmd` | `cmd\|<命令>` | 即时 | 以控制台身份执行命令，支持 `{player}` 变量 |
| `msg` | `msg\|<消息>` | 即时 | 给玩家发送消息，支持 `&` 颜色码和 `{player}` 变量 |
| `food` | `food\|<数量>` | 即时 | 恢复饱食度，上限 20 |
| `health` | `health\|<数量>` | 即时 | 恢复生命值，上限为玩家最大生命值 |
| `exp` | `exp\|<数量>` | 即时 | 增加经验值 |
| `healthPercent` | `healthPercent\|<百分比>` | 即时 | 按最大生命值百分比恢复生命值 |
| `potion` | `potion\|<效果>:<等级>` | 即时 | 附加药水效果，持续 `Duration` 秒 |
| `ap` | `ap\|<属性>:<值>` | 属性 | 附加 AttributePlus 属性词条 |
| `ml` | `ml\|<属性>:<值>` | 属性 | 附加 MythicLib 临时属性 modifier |
| `mythiclib` | `mythiclib\|<属性>:<值>` | 属性 | 同 `ml`，完整前缀写法 |
| `sy` | `sy\|<属性>:<值>` | 属性 | 附加 Symphony 属性修改 |
| `symphony` | `symphony\|<属性>:<值>` | 属性 | 同 `sy`，完整前缀写法，支持百分比 |

> 类型标识不区分大小写，解析时会转为小写后匹配。格式无效的行会被跳过，调试模式下会输出警告日志。

## 生效方式

- **即时效果**逐行执行
- **属性效果**先聚合再一次性提交给对应属性插件——同属性多行值会累加

## 即时效果详解

### 命令（`cmd`）

以控制台身份执行任意 Bukkit 命令。`{player}` 占位符替换为玩家名（经安全校验）。

```yaml
effects:
  - "cmd|say {player} 使用了治疗药水"
  - "cmd|give {player} diamond 1"
  - "cmd|lp user {player} parent add vip"
```

> 玩家名安全校验会过滤非法字符，确保 `{player}` 替换后不会产生命令注入风险。

### 消息（`msg`）

向玩家发送消息，支持 `&` 颜色码和 `{player}` 变量替换。

```yaml
effects:
  - "msg|&a你获得了力量加成！"
  - "msg|&6{player} &e感受到了神圣的庇护"
```

### 饱食度（`food`）

恢复玩家饱食度，数值会与当前饱食度相加，上限为 20。负数表示减少饱食度。

```yaml
effects:
  - "food|10"   # 恢复 10 点饱食度
  - "food|-5"   # 减少 5 点饱食度
```

### 生命值（`health`）

恢复玩家生命值，数值与当前生命值相加，上限为玩家最大生命值（兼容属性插件修改的最大生命值）。负数表示扣血。

```yaml
effects:
  - "health|10"   # 恢复 10 点生命值
  - "health|-5"   # 扣除 5 点生命值
```

### 经验（`exp`）

增加玩家经验值，负数表示减少经验。

```yaml
effects:
  - "exp|100"   # 增加 100 点经验
```

### 百分比生命（`healthPercent`）

按玩家最大生命值的百分比恢复生命值。

```yaml
effects:
  - "healthPercent|10"   # 恢复最大生命值的 10%
  - "healthPercent|50"   # 恢复最大生命值的 50%
```

> 无法获取最大生命值属性时跳过执行（不报错）。

### 药水（`potion`）

附加药水效果，格式为 `<效果名>:<等级>`。持续时间由道具的 `Duration` 字段决定（秒）。等级从 0 开始（0 = I 级，1 = II 级）。

```yaml
Duration: 30

effects:
  - "potion|SPEED:2"           # 速度 III，持续 30 秒
  - "potion|REGENERATION:1"     # 生命恢复 II，持续 30 秒
  - "potion|STRENGTH:0"         # 力量 I，持续 30 秒
  - "potion|JUMP_BOOST:1"       # 跳跃提升 II，持续 30 秒
```

#### 药水效果名兼容映射

Minecraft 1.20.2 重命名了部分药水效果名。Prop 模块内置旧名 → 新名映射，配置中可继续使用旧名：

| 旧名（1.20.1 及以下） | 新名（1.20.2+） |
|----------------------|-----------------|
| `SLOW` | `SLOWNESS` |
| `FAST_DIGGING` | `HASTE` |
| `SLOW_DIGGING` | `MINING_FATIGUE` |
| `INCREASE_DAMAGE` | `STRENGTH` |
| `JUMP` | `JUMP_BOOST` |
| `CONFUSION` | `NAUSEA` |
| `HEAL` | `INSTANT_HEAL` |
| `HARM` | `INSTANT_DAMAGE` |
| `DAMAGE_RESISTANCE` | `RESISTANCE` |

> 两个版本名都支持，无需根据服务器版本修改配置。

## 属性效果详解

属性效果通过宿主属性桥接对接三个属性插件。对应插件未安装或未启用桥接时，效果静默跳过（调试模式有日志）。

### AttributePlus（`ap`）

属性行列表（如 `物理伤害:10`）作为来源添加到玩家属性数据中，持续 `Duration` 秒后自动移除。

```yaml
name: "力量卷轴"
Duration: 30

effects:
  - "ap|物理伤害:10"
  - "ap|暴击伤害:5"
  - "ap|移动速度:2"
```

> 来源 ID 由道具显示名生成。多个道具若显示名处理结果相同，会共享同一个来源 ID，后添加的覆盖前者。

### MythicLib（`ml` / `mythiclib`）

附加 MythicLib 临时 modifier，持续 `Duration` 秒后自动关闭。**同属性多行的值会累加**。

```yaml
# ArcartXProp.yml
mythiclib:
  source-prefix: "AXS_PROP"

# 道具定义
name: "力量卷轴"
Duration: 30

effects:
  - "ml|ATTACK_DAMAGE:5"
  - "mythiclib|critical_damage:8"
  - "ml|ATTACK_DAMAGE:3"   # 同属性多行，值会累加为 8
```

> 仅处理已注册的 MythicLib 属性，未注册的属性记录警告并跳过。
>
> `source-prefix` 在 `config.yml` 的 `mythiclib.source-prefix` 中配置，默认 `AXS_PROP`。

### Symphony（`sy` / `symphony`）

附加 Symphony 属性修改，持续 `Duration` 秒后自动移除并重算。payload 以 `%` 结尾时为百分比修饰。

```yaml
name: "力量卷轴"
Duration: 30

effects:
  - "sy|ATTACK_DAMAGE:5"        # 数值修饰
  - "symphony|ATTACK_SPEED:10%" # 百分比修饰
```

> 玩家下线时自动清除全部活跃属性并重新计算。

## 持续时间与下线清理

- 属性效果的持续时间由道具的 `Duration` 字段控制（秒），到期自动移除
- `Duration: 0` 时立即移除
- 玩家退出服务器时，全部活跃临时属性自动清除；重新上线需再次使用道具才能获得加成

## 效果组合示例

### 综合增益道具

```yaml
name: "神圣祝福"
coolDownGroup: "祝福冷却组"
coolDownTime: 120
Duration: 60
remove: true
hand: false
key: true
permission: "arcartxsuite.prop.blessing"

conditions:
  - "%player_level% >= 20"
  - "%player_health% > 0"

effects:
  # 即时效果
  - "msg|&6你获得了神圣祝福！"
  - "cmd|say {player} 获得了神圣祝福"
  - "health|20"
  - "food|10"
  - "exp|500"
  # 药水效果（持续 60 秒）
  - "potion|REGENERATION:2"
  - "potion|DAMAGE_RESISTANCE:1"
  # 属性效果（持续 60 秒）
  - "ap|物理伤害:15"
  - "ap|魔法防御:10"
  - "ml|ATTACK_DAMAGE:10"
  - "ml|MOVEMENT_SPEED:5"
  - "sy|ATTACK_SPEED:15%"
  - "symphony|LUCK:5"
```

### 纯药水道具

```yaml
name: "隐身药水"
coolDownGroup: "药水冷却组"
coolDownTime: 30
Duration: 15
remove: true
hand: true
key: true
permission: ""

conditions: []

effects:
  - "potion|INVISIBILITY:0"
  - "potion|SPEED:1"
  - "msg|&7你进入了隐身状态"
```

### 纯命令道具

```yaml
name: "传送卷轴"
coolDownGroup: "传送冷却组"
coolDownTime: 60
Duration: 0
remove: true
hand: false
key: true
permission: "arcartxsuite.prop.teleport"

conditions:
  - "%player_world% != world_nether"

effects:
  - "cmd|spawn {player}"
  - "msg|&a你已被传送回主城"
```

## 调试与排错

启用 `config.yml` 中的 `settings.debug: true` 后，效果执行过程中会输出以下调试日志：

| 日志内容 | 触发条件 |
|----------|----------|
| `ArcartXProp 检测到未知效果类型: <行>` | 效果行的 type 不在 10 种已知类型中 |
| `Prop MythicLib 效果格式无效，已跳过: <行>` | MythicLib 效果行解析失败（格式错误或数值无法解析） |
| `Prop Symphony 效果格式无效，已跳过: <行>` | Symphony 效果行解析失败 |
| `Prop MythicLib 属性未注册，已跳过: <statId>` | MythicLib 属性 ID 未在插件中注册（仅警告一次） |
| `ArcartXProp AP 效果已跳过 -> hooked=false` | AttributePlus 未挂钩，AP 效果被跳过 |
| `ArcartXProp MythicLib 效果已跳过 -> hooked=false` | MythicLib 未挂钩，效果被跳过 |
| `ArcartXProp Symphony 效果已跳过 -> hooked=false` | Symphony 未挂钩，效果被跳过 |

> 属性插件未安装或未在宿主 `config.yml` 的 `attribute-bridges` 中启用时，对应属性效果会被静默跳过。调试模式下会输出跳过日志，帮助排查属性效果不生效的问题。
