Prop 的按键用于触发道具槽位中的物品。先确认 Prop 已启用、玩家已安装匹配的 ArcartX 客户端，再设置槽位与道具。地图、对话等本体按键见[通用按键绑定](/docs/guide/keybinds)。

## 配置按键与槽位

文件位于 `plugins/ArcartX-Suite/data/prop/key.yml`：

```yaml
category: "我的服务器 - 快捷道具"
keys:
  治疗键:
    defaultKey: "Z"
    slot: Slot1
  增益键:
    defaultKey: "X"
    slot: Slot2
```

| 字段 | 功能 |
| --- | --- |
| `category` | 客户端按键分类显示名称 |
| `keys` 下的条目名称 | 按键名称，使用清楚且不重复的文字 |
| `defaultKey` | 默认键位，例如 `Z`、`X`、`C` |
| `slot` | 对应道具槽位，例如 `Slot1`，需与实际槽位一致 |

修改后执行 `/axs reload prop`，重新进入服务器，在客户端按键设置中检查分类、实际按键与冲突。玩家可以自行改键，服务端配置的默认值不是每个玩家当前使用的值。

## 第一次测试

1. 在[道具配置](/docs/prop/configuration)中选择一个可用道具，确认允许按键使用。
2. 将该道具放入绑定的槽位，例如 `Slot1`。
3. 检查玩家拥有使用权限，满足条件，且该道具不在冷却中。
4. 按绑定键，确认效果发生；若配置消耗物品，同时核对槽位数量变化。
5. 再次按键，检查冷却提示和结束后的可用状态。

只配置 `key.yml` 不会自动把道具放进槽位，也不会让未配置按键使用方式的物品变成技能。

## 按键模式与手持模式

| 模式 | 操作对象 | 使用入口 |
| --- | --- | --- |
| 按键使用 | 配置所指的道具槽位 | 按槽位绑定键 |
| 手持使用 | 玩家主手物品 | 按道具允许的手持交互方式 |

同一道具是否支持两种方式由定义决定。测试时不要把主手持有与额外槽位放入视为同一种状态。

## 共享冷却

道具的 `coolDownGroup` 决定哪些道具共用冷却，`coolDownTime` 以秒填写。例如分别在两个道具定义中设置：

```yaml
coolDownGroup: "药水冷却组"
coolDownTime: 30
```

使用其中一个后，另一个也会受到同组冷却影响。想让两个道具独立使用，应使用不同的冷却组名称。未填写分组时可能回退默认组，出现多个道具一起冷却时，先检查这一项。

冷却提示在模块 `language.yml` 中配置，例如：

```yaml
COOL_DOWN: "&c{item} 仍在冷却，还需等待 {remaining_seconds} 秒"
```

`{item}` 是道具名，`{remaining_seconds}` 是剩余冷却秒数。这里只修改提示文字，不改变实际冷却时间。

## 无法使用时检查

| 现象 | 优先检查 |
| --- | --- |
| 客户端没有对应按键 | 模块状态、ArcartX 版本、`key.yml` 格式与重载结果 |
| 按键无效果 | 实际绑定、冲突、槽位名称、物品是否在该槽位 |
| 提示无法按键使用 | 道具是否允许此使用方式 |
| 提示无权限或条件不满足 | 对应道具的权限与条件，而不只是管理权限 |
| 多个道具同时冷却 | 是否使用相同 `coolDownGroup` 或都回退默认组 |
| 只有提示文字变化 | 是否只编辑了语言文件，尚未修改效果或冷却配置 |

未知效果、属性未注册和按键异常的处理见[日志与报错提示](/docs/guide/config-management)。
