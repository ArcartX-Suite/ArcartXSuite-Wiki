| 项目 | 说明 |
| --- | --- |
| 模块 ID | `prop` |
| 主配置 | `plugins/ArcartX-Suite/data/prop/config.yml` |
| 主要调整内容 | props/ 道具效果、key.yml 按键与槽位设置 |
| 重载 | `/axs reload prop` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 选择一个默认道具。
2. 手持测试物品执行 `/axs prop set <道具ID>`。
3. 按配置按键使用。

## 检查是否配置成功

检查道具效果、消耗和冷却提示。

按键无反应时，检查 `key.yml` 中绑定的槽位、物品是否在对应槽内，以及物品是否已绑定道具 ID。道具有提示却无效果时，从[按键测试](/docs/prop/keybinds#第一次测试)检查冷却、权限和使用条件。

## 可以配置的功能

| 特性 | 说明 |
|------|------|
| 客户端按键绑定 | 通过 ArcartX 客户端按键系统将道具槽位绑定到键盘按键，按下即触发使用 |
| 手持右键使用 | 将任意物品绑定为指定道具后，玩家手持右键即可触发 |
| 多槽位支持 | 支持配置多个快捷道具槽位（Slot1/Slot2/Slot3...），每个槽位独立绑定按键 |
| 冷却组 | 同一冷却组内的多个道具共享冷却时间，避免重复使用 |
| 物品消耗 | 使用后可选消耗一个物品（`remove: true`）或保留物品（`remove: false`） |
| 权限控制 | 每个道具可配置使用权限节点，留空表示无限制 |
| 使用条件 | 支持 PlaceholderAPI 条件判断（等级、余额、世界、职业等），全部满足才可使用 |
| 自动触发 | 服务端定时轮询快捷槽道具，独立的触发条件（`auto.conditions`）满足时自动使用，支持每道具检查间隔与成功提示开关 |
| 效果系统 | 支持 10 种效果类型：命令、消息、饱食度、生命值、经验、百分比生命、药水、AttributePlus、MythicLib、Symphony |
