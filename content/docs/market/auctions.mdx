Market 的拍卖系统包含 **拍卖行**（竞价交易）和 **玩家商店**（固定价格交易）两个子系统，两者独立运作。

## 界面使用流程

### 拍卖大厅 → 单件拍品竞价厅

拍品卡上的“查看拍品实录”或“参与竞价”会进入独立竞价厅，也可以执行 `/market lot <拍品ID>` 直达。返回大厅会保留原来的分类、关键词与页码。

竞价厅分为三个区域：

- **拍品展示**：卖家、整组数量、起拍价、真实物品预览与物品说明；悬浮物品可查看原有提示。
- **竞价实录**：当前最高价、领先者、剩余时间、出价次数、独立竞价者人数、关注人数，以及最近 20 次有效出价。触发过延时的记录会显示实际延长秒数，结束后显示正式结算事件。
- **你的竞拍**：是否领先、是否被超价、是否得标、可用余额、当前押金、自己参与过的最高出价，以及只属于你的款项/物品交付进度。

页面人数来自真实出价及关注记录，不表示在线围观人数；不会制造虚拟出价或虚拟参与者。竞价记录和报价一起提交，失败出价不进入实录。截止倒计时仅作显示，正式落槌以服务端结算状态为准。

“最低有效价”“再加一档”“再加两档”只生成服务端报价，仍须确认；自定义金额同样先报价再确认，不会自动竞价。你的出价仍可在确认前被其他玩家超越，服务端将重新检查。

竞价厅约每两秒同步一次数据，收到本服或跨服的竞价变化也会请求更新；同步暂不可用时会提示，保留旧内容供查看，暂停新的出价入口。已打开的确认报价如遇到出价、截止时间或拍卖状态变化，会失效并要求重新报价。

大厅新增“即将结束”和“我的竞拍”：前者按实际截止时间排序，后者包含自己参与过的拍卖及已结束结果。命令分别为 `/market ending`、`/market bids`。“我的关注”仍可查看关注拍品的最终状态。

新竞价厅使用 `ui.auction-room-ui-id`（默认 `AXS:market_auction_room`），其界面文件随模块导出为 `ui/market_auction_room.yml`。自定义 ID 时应与其他市场页面保持不同。

### 自定义出价与真实竞价状态

拍卖卡片区分起拍价、当前出价、领先者、剩余时间和结算状态。无人出价时显示“暂无出价”；到期后显示等待结算，成交、流拍、下架则各自显示最终状态，不再提供出价按钮。列表和已打开的报价会定期读取最新状态。

进入竞价厅后，点击“自定义金额并确认”可输入金额，按回车或点“更新报价”；也可以选择“最低有效出价”。报价显示最低金额、当前领先者、已冻结金额、本次追加扣款和实际截止时间。修改金额后必须重新报价并确认，系统不会自动替你抬价。

首次出价可等于起拍价；后续最低出价为 `当前最高价 + max(当前最高价 × 比例加价, 固定加价)`，向上取到货币支持的精度。报价后仍可能被其他玩家抢先出价，服务端会重新检查，失败不会自动加价。

出价者之前未领先时，扣除本次完整出价；被他人超价后，原押金进入退款队列。如果你本来就在领先，再次出价只扣新旧金额的差额，不会重复冻结全额。退款和物品交付可在交易流水中追踪。

### 关注商品和提醒

点击星标关注或取消关注，每位玩家最多关注 100 件商品。“我的关注”分类可搜索和查看关注商品，也保留已结束拍卖的状态。

默认提醒被超价者、成交卖家和得标买家，并告知关注者商品的成交、流拍或取消结果。通知先保存，离线玩家上线后接收。`auction.notifications.watch-bids` 可额外开启每次出价提醒，默认关闭以减少打扰。被超价提醒的位置使用 `outbid-notify: chat/actionbar/title`。

### 可选临近结束延时

```yaml
auction:
  allow-cancel-with-bids: false
  end-protection:
    enabled: true
    window-seconds: 120
    extend-seconds: 120
    max-extension-seconds: 1800
  notifications:
    outbid: true
    settlement: true
    watch-bids: false
```

延时默认关闭。以上示例表示：剩余不超过 120 秒时有有效出价，将截止时间调整为“不早于当前截止时间、出价处理时间后 120 秒”，但最多比原截止时间延后 1800 秒。达到累计上限后不会无限延长。无效、失败或未确认的报价不触发延时。

截止时间与出价一起提交；结算重新读取最新挂单，避免延时后仍按旧时间结算。多服市场必须共享数据库，跨服拍卖消息只通知界面缓存更新，不重复执行竞价。

统一上架页面 `/market sellui` 可以选择交易模式、背包物品、价格、货币和时长。可选模式与时长受对应功能配置限制；从玩家商店进入上架页时默认选中玩家商店模式。

拍卖出价会先显示本次金额并提醒出价时扣款；确认后提交。拍卖与玩家商店下架均需确认。玩家商店价格是整组商品的总价，购买确认会显示数量与金额，小数价格会保留显示。

竞价、购买、下架后保留当前分类、搜索及页码；玩家商店也保留卖家筛选。左侧按钮可在“我的商品”与全部卖家之间切换，自己的商品显示下架入口。列表刷新按钮会请求最新数据。

玩家商店左侧的卖家列表可独立翻页；选中卖家后搜索会在该卖家的商品中查找。切换为全部卖家后，相同关键词会搜索整个玩家市场。

交易失败后操作按钮会恢复，已输入的上架表单不因失败而清空；成交与退还情况可在 `/market history` 查看。

## 拍卖行

拍卖行是玩家间的纯竞价交易系统。卖家上架物品设定起拍价，买家竞价，到期后价高者得。

### 拍卖配置结构

拍卖行配置位于 `config.yml` 的 `auction` 节，详见 [配置 - 拍卖行配置](/docs/market/configuration#拍卖行配置-auction)。

### 上架流程

1. 玩家通过 `/market sell <起拍价> [时长] [货币]` 命令或上架 UI 上架物品
2. 服务端校验：
   - 起拍价在 `min-price` ~ `max-price` 范围内
   - 时长在 `min-duration-seconds` ~ `max-duration-seconds` 范围内
   - 留言长度不超过 `message-max-length`
   - 留言通过敏感词过滤（ContentModerator）
   - 货币在 `currencies` 列表中且可用
3. 检查上架数量限制（`max-listings-per-player`）
4. 检查物品黑名单（ItemMatcher）
5. 校验手持物品一致性（防止客户端伪造物品/数量导致复制）
6. **先扣除背包物品**（占有），避免"先入库后扣除"异常时物品复制
7. 扣除上架费（如有，先验余额）
8. 序列化物品（Overture 物品优先使用原生序列化，其余使用 Bukkit Base64）
10. 自动分类（按 NBT/PDC 路径匹配 categories）
11. 入库 → 失效 Redis 缓存 → 跨服广播

<Callout type="info" title="物品安全">
上架时使用物品副本，防止与主手物品引用别名。入库失败会自动退费 + 归还物品。
</Callout>

### 竞价流程

1. 玩家在 UI 输入金额并获取报价，再确认出价
2. 校验：
   - 物品处于 ACTIVE 状态且未过期
   - 出价者不能是卖家本人
   - 出价 ≥ 最低出价
3. 按当前是否领先扣除全额或差额，原子检查挂单状态、旧出价及截止时间
4. 写入有效出价及可能的延时；被超价者押金进入退款队列
5. 持久保存提醒，记录竞价历史并刷新列表

### 最低出价计算

```
最低出价 = 当前最高价 + max(当前最高价 × min-bid-increment-ratio, min-bid-increment-absolute)
```

| 场景 | 当前最高价 | ratio | absolute | 最低出价 |
|---|---|---|---|---|
| 首次出价 | 起拍价 100 | - | - | 100（等于起拍价） |
| 第二次出价 | 100 | 0.05 | 10 | 110（max(105, 110)） |
| 高价出价 | 10000 | 0.05 | 10 | 10500（max(10500, 10010)） |

#### 有人竞价（SOLD）

2. 计算税费：`税 = 成交价 × 有效税率`
3. 有效税率取匹配权限中的最低最终税率，未匹配时使用基础税率；离线玩家通过 LuckPerms 查询权限
4. 卖家收款 = `成交价 - 税`（安全发放，离线入待发放队列）
5. 买家得物品（安全发放：在线放入背包，背包满转邮件，离线入待发放队列）
6. 记录交易历史（类型 `BID_WIN`）

#### 无人竞价（EXPIRED）

2. 退还物品给卖家（安全发放）
3. 保存流拍提醒，离线卖家上线后接收
4. 记录交易历史（类型 `EXPIRED`）


### 取消上架

卖家可取消自己尚未到期且无人有效出价的物品。默认 `allow-cancel-with-bids: false`，禁止卖家撤回已经有人出价的拍卖；只有显式开启该选项才允许退还押金后取消：

2. 如有竞价者，退还押金（安全发放）
3. 返还物品给卖家（安全发放）
4. 记录交易历史（类型 `CANCELLED`）

管理员可通过 `/axs market remove <ID>` 强制下架，流程类似但记录类型为 `ADMIN_CANCELLED`。

### 手续费配置

| 配置项 | 说明 |
|---|---|
| `listing-fee` | 上架手续费（固定金额，上架时立即扣除，无论是否成交） |
| `listing-fee-currency` | 手续费货币类型 |
| `transaction-tax-rate` | 成交税率（从卖家最终收入中扣除） |
| `transaction-tax-currency` | 税费货币类型 |
| `tax-discount` | 权限节点 → 最终税率，取匹配的最低税率 |

#### 税率计算示例

```
基础税率 = 5%
VIP 减免 = 2%（权限 axsmarket.vip）
MVP 减免 = 1%（权限 axsmarket.mvp）

VIP 玩家有效税率 = 5% - 2% = 3%
MVP 玩家有效税率 = 5% - 1% = 4%
同时拥有 VIP + MVP = 5% - max(2%, 1%) = 3%
```

### 分类系统

拍卖行通过 NBT/PDC 路径自动分类物品。分类用于 UI 筛选功能。

```yaml
auction:
  categories:
    weapon:
      display-name: "&c武器"
      priority: 10
      nbt:
        path: "pdc:arcartx:item_category"
        values: ["weapon"]
    other:
      display-name: "&7其他"
      priority: 9999
      default: true
```

分类匹配逻辑：
1. 按优先级（`priority` 升序）遍历所有分类
2. 读取物品 PDC 中 `path` 指定的键值
3. 若值匹配 `values` 列表中的任一项，归属此分类
4. 未匹配任何分类时归入 `default: true` 的分类

### 拼音搜索

- "钻石剑" → 拼音 `zuan shi jian`，首字母 `z s j`
- 多音字遍历所有读音
- 搜索时同时匹配物品名称、拼音、首字母

## 玩家商店

玩家商店允许玩家以固定价格上架物品，其他玩家可直接购买（无竞价机制）。与拍卖行独立运作。

### 与拍卖行的区别

| 对比项 | 拍卖行 | 玩家商店 |
|---|---|---|
| 交易方式 | 竞价 | 固定价格直接购买 |
| 价格机制 | 起拍价 + 竞价加价 | 固定价格 |
| 最长上架时长 | 7 天 | 30 天 |
| 默认上架时长 | 24 小时 | 7 天 |
| 每人上架上限 | 10 件 | 20 件 |

### 购买流程

1. 买家通过 UI 浏览/搜索玩家商店商品
3. 扣买家钱
4. 计算税费：`税 = 价格 × 有效税率`
5. 给卖家打钱（`收入 = 价格 - 税`）
6. 给买家物品
7. 记录交易历史
8. 通知在线卖家
9. 失效缓存 → 跨服广播

### 下架流程

卖家可下架自己的商品，流程与拍卖行取消上架类似：状态校验 → 返还物品 → 记录历史。

### 卖家浏览

玩家商店 UI 支持按卖家浏览：显示所有有在售商品的卖家列表（UUID + 名称 + 在售数量），点击进入该卖家的商品页面。

## 跨服竞价

拍卖行和玩家商店均支持跨服同步。启用 `cross-server.enabled: true` 后：

| 同步内容 | 说明 |
|---|---|
| 上架创建 / 取消 | 各服失效本地缓存 |
| 竞价 | 各服同步最新竞价 |
| 玩家商店上架 / 购买 / 下架 | 各服失效缓存 |
| 限购更新 | 各服同步限购记录 |
| 动态商品 | 各服同步动态商品状态 |


### 通过命令上架

```
/market sell 1000 86400 money
```

将手持物品以起拍价 1000、时长 86400 秒（24 小时）、货币 money 上架到拍卖行。

### 通过 UI 上架

1. 执行 `/market` 打开拍卖行 UI
2. 点击上架按钮打开上架 UI
3. 选择背包中的物品
4. 输入起拍价、时长、货币、留言
5. 确认上架

### 竞价

在拍卖行 UI 中点击物品，输入出价金额。系统会自动计算最低出价并提示。

### 搜索

```
/market search 钻石剑
```

打开拍卖行 UI 并搜索"钻石剑"（同时匹配物品名、拼音 `zuan shi jian`、首字母 `z s j`）。

### 查看我的上架

```
/market my
```

打开拍卖行 UI 并筛选显示自己的上架物品。

### 取消上架

```
/market cancel 42
```

取消上架 ID 为 42 的物品（退还竞价押金 + 返还物品）。

### 玩家商店上架

通过统一上架 UI（`/market sell` 或 UI 按钮），选择 `pshop` 模式上架。物品以固定价格上架到玩家商店，其他玩家可直接购买。
