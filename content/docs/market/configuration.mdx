## 先改哪些内容

shops/ 商品、回收价格、交易货币与拍卖规则。先使用默认示例完成一次测试，再按本页逐项调整。

配置位置：`plugins/ArcartX-Suite/data/market/config.yml`。定义文件与子目录均相对此模块目录。本文中的 YAML 片段用于修改对应小节，请保留文件中的其他设置。

修改后执行 `/axs reload market`；涉及插件安装或全局设置的变更请重启后验证。

Market 模块的配置文件位于 `plugins/ArcartX-Suite/data/market/config.yml`。修改后执行 `/axs reload market` 即可生效（商店/回收配置热重载，主配置需重启）。

### settings 全局设置

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `settings.debug` | boolean | `false` | 调试模式，输出详细日志 |
| `settings.scheduler-interval-ticks` | long | `200` | 定时任务间隔（tick，20 tick = 1 秒），用于检查到期上架、结算竞价、刷新限时商品 |

| 字段 | 类型 | 默认值 | 说明 |

## 拍卖行配置 (auction)

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `auction.enabled` | boolean | `true` | 是否启用拍卖行 |
| `auction.currencies` | list | `[{id: money, name: 金币}]` | 允许的货币列表 |
| `auction.default-currency` | string | `money` | 默认货币 |
| `auction.min-price` | double | `1` | 起拍价最低值 |
| `auction.max-price` | double | `1000000000` | 起拍价最高值 |
| `auction.message-max-length` | int | `50` | 留言最大字符数 |
| `auction.min-duration-seconds` | long | `3600` | 最短上架时长（1 小时） |
| `auction.max-duration-seconds` | long | `604800` | 最长上架时长（7 天） |
| `auction.default-duration-seconds` | long | `86400` | 默认上架时长（24 小时） |
| `auction.max-listings-per-player` | int | `10` | 每人最多同时上架数量 |
| `auction.min-bid-increment-ratio` | double | `0.05` | 竞价加价比例（5%） |
| `auction.min-bid-increment-absolute` | double | `10` | 竞价加价绝对值 |
| `auction.listing-fee` | double | `0` | 上架手续费（固定金额） |
| `auction.listing-fee-currency` | string | `money` | 手续费货币类型 |
| `auction.transaction-tax-rate` | double | `0.05` | 成交税率（5%） |
| `auction.transaction-tax-currency` | string | `money` | 税费货币类型 |
| `auction.tax-discount` | map | - | VIP 税率减免（权限节点 → 减免值） |
| `auction.expired-return-method` | string | `mail` | 到期退回方式：`mail` / `inventory` |
| `auction.outbid-notify` | string | `chat` | 被超越通知方式：`chat` / `actionbar` / `title` |

### 竞价加价规则

新出价必须满足：

```
新出价 ≥ max(当前最高价 × (1 + min-bid-increment-ratio), 当前最高价 + min-bid-increment-absolute)
```

例如：当前最高价 100，ratio=0.05，absolute=10 → 新出价至少 110（取 max(105, 110)）。

### 物品黑名单 (auction.blacklist)

黑名单使用统一的 ItemMatcher 规则，满足任意一条即拦截。详见 [物品匹配器](/docs/guide/conditions)。

| 字段 | 类型 | 说明 |
|---|---|---|
| `material-ids` | list | 禁止的原版材质 ID（Bukkit Material 枚举名） |
| `mythic-item-ids` | list | 禁止的 MythicMobs 物品 ID |
| `neige-item-ids` | list | 禁止的 NeigeItems 物品 ID |
| `overture-item-ids` | list | 禁止的 Overture 物品 ID |
| `kinds` | list | 禁止的物品类别（`mythic`/`neige`/`vanilla`） |
| `name-contains` | list | 物品名称包含此字符串则禁止 |
| `lore-contains` | list | 物品 Lore 包含此字符串则禁止 |
| `name-regex` | list | 物品名称匹配正则则禁止 |
| `lore-regex` | list | 物品 Lore 匹配正则则禁止 |
| `nbt-keys` | list | 物品存在此 NBT/PDC 键则禁止 |
| `nbt-values` | map | NBT/PDC 键值匹配则禁止 |

### 拍卖行分类 (auction.categories)

分类用于拍卖行界面的筛选功能，通过检查物品的 NBT/PDC 数据判定归属。

| 字段 | 类型 | 说明 |
|---|---|---|
| `display-name` | string | 分类在 UI 中显示的名称 |
| `priority` | int | 排序优先级，数字越小越靠前 |
| `nbt.path` | string | 检查的 NBT/PDC 路径（格式 `pdc:namespace:key`） |
| `nbt.values` | list | 值匹配列表，任一匹配即归属此分类 |
| `default` | boolean | 是否为默认分类（未匹配其他分类时归入） |

## 系统商店配置 (shop)

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `shop.enabled` | boolean | `true` | 是否启用系统商店 |

### 动态商品策略 (shop.dynamic)

| 字段 | 类型 | 说明 |
|---|---|---|
| `shop.dynamic.enabled` | boolean | 是否启用动态商品策略 |
| `shop.dynamic.strategies` | section | 策略配置节，每个键为策略唯一键 |

每个策略支持三种类型：

| 类型 | 说明 |
|---|---|
| `random-refresh` | 随机刷新（神秘商人）：从候选池按权重随机抽选 N 个商品上架 |
| `price-float` | 价格浮动：按 random-walk 或 supply-demand 模式动态调价 |
| `scheduled-swap` | 定时换货：按多个商品集轮换上架 |

详见 [商店系统 - 动态价格策略](/docs/market/shops#动态价格策略)。

## 商店与回收配置示例

以下为原配置中两个功能小节的修改片段。先在全局货币中配置 `money`，再准备对应的商品与回收定义：

```yaml
shop:
  enabled: true
  shops-directory: shops
  refresh-interval-ticks: 6000
  default-currency: money
recycle:
  enabled: true
  recycle-directory: recycle
  default-currency: money
  batch-recycle-enabled: true
  batch-confirm: true
```

重载后执行 `/market shop`，用测试账号完成一次购买和回收，核对货币余额与物品数量。
