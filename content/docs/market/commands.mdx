## 玩家命令

玩家入口 `/market` 及别名 `/mk`、`/ah`、`/axsmarket` 都需要 `arcartxsuite.market.use`。该节点默认向玩家开放。下表列出各子命令在这个基础权限之外的条件。

| 命令 | 说明 | 附加条件 |
|---|---|---|
| `/market` | 打开拍卖行主界面 | — |
| `/market help` | 显示帮助信息 | — |
| `/market shop` | 打开系统商店列表 | — |
| `/market shop <商店ID>` | 打开指定系统商店 | 商店 `permission` 字段 |
| `/market auction` | 打开拍卖行界面 | — |
| `/market ah` | 打开拍卖行界面（别名） | — |
| `/market lot <拍品ID>` | 打开单件拍品的独立竞价厅 | — |
| `/market bids` | 查看自己参与过的拍卖与最终状态 | — |
| `/market ending` | 按截止时间查看即将结束的拍卖 | — |
| `/market pshop` | 打开玩家店铺目录，可浏览及收藏店铺 | — |
| `/market playershop` | 打开玩家店铺目录（别名） | — |
| `/market pshop mine` | 打开自己的独立店铺 | — |
| `/market pshop edit` | 编辑自己的店名、简介、图标和公告 | 仅本人资料 |
| `/market pshop market` | 浏览所有玩家的商品 | — |
| `/market store [店主UUID]` | 访问独立店铺；省略时进入自己的店铺 | — |
| `/market sell <起拍价> [时长秒] [货币]` | 上架手持物品到拍卖行 | — |
| `/market list <起拍价> [时长秒] [货币]` | 上架手持物品（别名） | — |
| `/market sellui` | 打开统一上架界面，可选择拍卖或玩家商店 | — |
| `/market recycle` | 打开回收界面 | — |
| `/market recycle protect` | 管理个人自动回收、材质排除与收藏同款保护 | — |
| `/market recycle all` | 批量回收；开启确认时先进入回收界面 | `recycle.batch-recycle-enabled` 已启用 |
| `/market history` | 查看拍卖、玩家商店、系统商店、回收的统一交易历史 | — |
| `/market my [auction\|pshop]` | 查看自己的拍卖或玩家商店挂单 | — |
| `/market search <关键词>` | 搜索拍卖行物品 | — |
| `/market cancel <上架ID> [auction\|pshop]` | 取消指定类型的挂单，默认拍卖 | 仅可取消自己的挂单 |

#### 上架手持商品（`/market sell`）

将手持物品上架到拍卖行。

```
/market sell <起拍价> [时长秒] [货币]
```

| 参数 | 必填 | 说明 |
|---|---|---|
| 起拍价 | 是 | 起拍价格，需在 `min-price` ~ `max-price` 范围内 |
| 时长秒 | 否 | 上架时长（秒），默认使用 `default-duration-seconds` |
| 货币 | 否 | 默认使用 `auction.default-currency` |

示例：
```
/market sell 1000              # 起拍价 1000，默认时长，money 货币
/market sell 500 3600 points    # 起拍价 500，1 小时，points 货币
```

#### 搜索拍卖商品（`/market search`）

搜索拍卖行物品，支持中文名称、拼音、首字母匹配。

```
/market search <关键词>
```

示例：
```
/market search 钻石剑          # 按中文名称搜索
/market search zuan shi jian   # 按拼音搜索
/market search zs j            # 按首字母搜索
```

## 管理员命令

### 管理员交易管理面板

玩家可通过交易历史页的「交易管理」打开面板，需要 `arcartxsuite.market.admin`。用 `/axs market trades` 打开时还需 `arcartxsuite.admin`。控制台可使用下方的流水命令。

面板按玩家、物品、创建时间、交易类型及状态查询，提供待发放、失败与待核对入口，以及记录详情和关联流水。业务历史、单条操作完成和最终交付的含义不同，应结合整笔交易判断。

完整的筛选填写方式、时间格式、状态解释及纠纷查询示例见[交易管理与异常查询](/docs/market/trade-management)。个人自动回收、材质排除及收藏同款的操作见[玩家回收保护](/docs/market/recycle-protection)。

### 交易流水与异常核对

```text
/axs market ledger [页码] [all|PREPARED|READY|RUNNING|REVIEW|DONE|FAILED] [玩家UUID]
/axs market resolve <流水ID> <delivered|cancel|retry-confirmed> <核对说明>
```

流水页码从 0 开始，每页 10 条，显示操作编号、父交易编号、业务类型、玩家、金额、引用和处理说明。四类交易都有业务流水，扣款、入账和持久交付使用独立子记录。

| 状态 | 含义 |
|---|---|
| `PREPARED` | 交付快照已保存，尚未确认扣款或收取物品等前置条件 |
| `READY` | 可安全执行的待交付任务，上线后自动消费 |
| `RUNNING` | 业务或外部调用正在处理 |
| `REVIEW` | 处理曾中断、结果不确定，需要核对 |
| `DONE` | 本条记录完成；仍需结合父交易及子任务判断整笔交易进度 |
| `FAILED` | 业务或外部接口明确返回失败；可能另有退款子任务 |

进程失去心跳超过约两分钟后，遗留任务会进入恢复处理。能够确认已扣款的系统商店奖励快照会激活；已经入库的 `READY` 交付会继续执行。结果不明的扣款、物品或指令发放不会自动重放，而是保留为 `REVIEW`。

只对 `REVIEW` 记录使用核对命令：`delivered` 表示已核实该操作完成；`cancel` 表示关闭该记录；`retry-confirmed` 仅适用于物品、货币或指令交付，表示**已核实交付义务成立且尚未执行**，重新放入待交付队列。核对命令本身会记录操作者和说明。不要仅凭余额差额判断，或在结果未知时反复补发。

旧待发放队列会在模块初始化时迁入新队列；原数据损坏或发放结果未知时保留记录，不会直接丢弃。

下表的 `/axs market` 命令同时需要 `arcartxsuite.admin` 和 `arcartxsuite.market.admin`。NPC 兑换有单独的[命令与权限](#npc-兑换命令)。

| 命令 | 说明 | 权限 |
|---|---|---|
| `/axs market help` | 显示管理帮助 | `arcartxsuite.market.admin` |
| `/axs market trades` | 打开交易管理面板（仅玩家） | `arcartxsuite.market.admin` |
| `/axs market status` | 查看模块运行状态 | `arcartxsuite.market.admin` |
| `/axs market clear-expired` | 同时处理拍卖与玩家商店的到期挂单 | `arcartxsuite.market.admin` |
| `/axs market remove <auction\|pshop> <上架ID>` | 强制下架对应类型挂单并退还；旧写法 `remove <ID>` 仍表示拍卖 | `arcartxsuite.market.admin` |
| `/axs market open <auction\|pshop\|shop\|recycle\|history\|sell> [商店ID]` | 打开对应业务界面；仅玩家执行，商店 ID 只用于 shop | `arcartxsuite.market.admin` |
| `/axs market edit [商店ID]` | 打开系统商店编辑 UI（仅玩家可执行；省略 ID 时打开商店选择界面） | `arcartxsuite.market.admin` |

### 清理过期商品（clear-expired）

手动触发到期物品处理，返回处理的条目数。正常情况下定时任务会自动处理，此命令用于手动触发。

### 移除指定商品（remove）

拍卖和玩家商店的 ID 分开编号，请显式指定类型，避免选错挂单。拍卖下架会退还竞价押金和卖家物品；玩家商店下架会退还卖家物品。两者都会写入交易历史。

系统商店通过 `/axs market edit [商店ID]` 编辑；回收表位于模块目录 `recycle/`，修改后执行 `/axs reload market`。`status` 同时列出四类功能的启用状态、两类挂单数量、系统商店数量及回收条目数量。

## 权限节点

| 权限节点 | 说明 | 默认 |
|---|---|---|
| `arcartxsuite.market.use` | 使用 `/market` 和玩家别名 | true |
| `arcartxsuite.market.admin` | 管理员命令权限 | OP |
| `arcartxsuite.market.exchange.admin` | 编辑 NPC 兑换所、查看凭证与结案 | OP |
| `axsmarket.autorecycle` | 拾取自动回收权限；仍需服务器允许及个人开关开启 | 无 |
| `axsmarket.vip` | 拍卖行/玩家商店 VIP 税率减免 | 无 |
| `axsmarket.mvp` | 拍卖行/玩家商店 MVP 税率减免 | 无 |
| `axsmarket.recycle.vip` | 回收价格 VIP 加成 | 无 |
| `axsmarket.recycle.mvp` | 回收价格 MVP 加成 | 无 |
| `axsmarket.shop.legendary` | 系统商店商品购买权限（按商品配置） | 无 |
| `axsmarket.shop.vip` | 系统商店商品购买权限（按商品配置） | 无 |

<Callout type="info">
权限节点在配置文件中自定义。`tax-discount` 和 `price-multiplier` 的键名即为权限节点，`discount` 的键名也是权限节点。你可以根据需要修改为任意权限节点。
</Callout>

## NPC 兑换命令

启用 Market 的 `exchange.enabled` 并绑定 Adyeshach NPC 后，普通玩家可右键交互，也可以在 NPC 同一世界、距离 8 格以内执行 `/axs market exchange open <兑换所ID>`。兑换所与兑换条目的 `permission` 字段分别控制使用权限。

| 命令 | 用途 |
| --- | --- |
| `/axs market exchange edit [兑换所ID]` | 玩家管理员打开兑换所编辑器 |
| `/axs market exchange ledger [玩家UUID]` | 查看待核对的兑换凭证 |
| `/axs market exchange evidence <凭证UUID>` | 导出指定凭证的核对资料 |
| `/axs market exchange confirm <凭证UUID> confirm` | 核对扣款与发放后登记结案 |

这四项管理命令使用 `arcartxsuite.market.exchange.admin`。结案只登记核对结果。
