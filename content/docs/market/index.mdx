| 主配置 | `plugins/ArcartX-Suite/data/market/config.yml` |
| 主要调整内容 | shops/ 商品、回收价格、交易货币与拍卖规则 |
| 重载 | `/axs reload market` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。本模块还需要安装 `PlaceholderAPI`。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 确认货币可用。
2. 编辑一个默认商品。
3. 执行 `/market shop`。

玩家可通过 `/market recycle protect` 先设置回收保护，再在 `/market recycle` 中查看可回收物品。管理员使用 `/axs market trades` 查询四类交易的业务历史和处理流水。

## 检查是否配置成功

用测试账号购买一个商品，检查扣款与物品数量。

功能未生效时，先检查模块状态、所用定义 ID、玩家权限及客户端安装情况，随后对照[日志与报错提示](/docs/guide/config-management)逐项检查。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| 拍卖行 | 玩家间纯竞价交易，支持分类筛选、拼音搜索、竞价加价规则、手续费与税率 |
| 玩家商店 | 独立店铺、店名/简介/图标/公告、店铺收藏；商品以固定价格整组出售，保留跨店商品市场 |
| 统一历史 | 拍卖、玩家商店、系统商店购买与回收记录按时间分页展示 |
| 系统商店 | 管理员通过 YAML 文件定义商店，支持多物品来源（原版/MythicMobs/NeigeItems/Overture/MMOItems） |
| 回收商店 | 玩家将物品出售给系统，支持单件、批量和拾取自动回收，收益进入持久入账队列 |
| 玩家回收保护 | 个人自动回收开关、材质排除、收藏同款；三种回收方式共同遵守保护规则 |
| 管理员交易管理 | 按玩家、物品、创建时间、交易类型查询，查看待发放、失败和需核对记录及关联流水 |
| 动态价格 | 系统商店支持三种动态策略：价格浮动、随机刷新（神秘商人）、定时换货 |
| VIP 税率减免 | 按权限节点配置不同税率减免，离线玩家通过 LuckPerms 查询权限 |
| 回收价格倍率 | 按权限组设置回收价格加成（如 VIP 1.2 倍、MVP 1.5 倍） |
| 物品黑名单 | 按材质/物品库 ID/名称/Lore/NBT 键拦截不可交易物品 |
| 分类系统 | 按 NBT/PDC 路径自动分类拍卖行物品，支持自定义分类与优先级 |
