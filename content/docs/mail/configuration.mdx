## 先改哪些内容

presets/ 邮件预设、附件、有效期与清理设置。先使用默认示例完成一次测试，再按本页逐项调整。

配置位置：`plugins/ArcartX-Suite/data/mail/config.yml`。定义文件与子目录均相对此模块目录。本文中的 YAML 片段用于修改对应小节，请保留文件中的其他设置。

修改后执行 `/axs reload mail`；涉及插件安装或全局设置的变更请重启后验证。

## 配置文件概览

Mail 模块的配置文件位于 `data/mail/config.yml`，预设邮件位于 `data/mail/presets/` 目录。执行 `/axs reload mail` 可热重载配置和预设。

配置文件的 `config-version` 当前为 `3`，使用自动生成的值。

### 基础设置（settings）

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `settings.debug` | boolean | `false` | 是否输出 Mail 模块调试日志 |

### 跨服功能（cross-server）

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `cross-server.enabled` | boolean | `false` | 是否启用跨服邮件刷新通知；连接参数见Suite `config.yml` 的 `cross-server` 节 |

### 界面显示（ui）

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `ui.register-ui-on-enable` | boolean | `true` | 模块启用时是否自动注册 UI 配置文件 |
| `ui.overwrite-ui-files` | boolean | `false` | 是否覆盖已有的同名 UI 文件（false 则保留自定义修改） |
| `ui.compose-inventory-title` | String | `AXS Mail Compose` | 玩家打开写信背包时显示的标题 |
| `ui.inbox-preview-max-chars` | int | `40` | 收件箱列表预览文字的最大字符数（超过则截断并追加 `...`） |
| `ui.notify-char-width-full` | int | `31` | 通知卡片全角字符占位宽度 |
| `ui.notify-char-width-half` | int | `18` | 通知卡片半角字符占位宽度 |
| `ui.notify-max-line-width` | int | `750` | 通知卡片文字区最大宽度（超过此值换行） |

### 玩家写信与发送（player-send）

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `player-send.enabled` | boolean | `true` | 玩家写信功能总开关 |
| `player-send.require-permission` | boolean | `true` | 是否要求 `arcartxsuite.mail.send` 权限 |
| `player-send.cooldown-seconds` | int | `120` | 发信冷却（秒），0 表示不冷却 |
| `player-send.base-fee` | double | `0.0` | 每封邮件固定手续费 |
| `player-send.item-fee` | double | `0.0` | 每个物品附件额外手续费 |
| `player-send.fee-currency` | String | `money` | 手续费货币 ID（需在 currencies 中存在） |
| `player-send.attachment-tax-rates` | Map | — | 各货币附件税率映射（key 为货币 ID，value 为税率 0.0~1.0） |
| `player-send.allow-self-send` | boolean | `false` | 是否允许给自己发信 |
| `player-send.allow-offline-send` | boolean | `true` | 是否允许向离线玩家发信 |
| `player-send.allow-vault-attachment` | boolean | `true` | 是否允许附带 Vault 金币 |
| `player-send.max-attachments` | int | `6` | 玩家写信可放入的物品附件槽数量上限（1~64） |
| `player-send.subject-max-length` | int | `48` | 邮件标题最大长度 |
| `player-send.body-max-length` | int | `400` | 邮件正文最大长度 |
| `player-send.vault-default-icon` | Icon | — | 玩家发送的 Vault 货币附件在收件箱 UI 中展示的默认图标 |

> **`vault-default-icon`** 配置与 menu 模块的 icon 配置一致，支持 `material` / `custom-model-data` / `texture` / `texture-url` / `name` / `lore` / `source` / `id` / `nbt` / `glow` / `skull-texture` / `color` 等字段。留空或不配置时使用默认纸片图标。

> **手续费计算**：总手续费 = `base-fee` + `item-fee` × 物品附件数量。货币附件税费 = 附件金额 × `attachment-tax-rates` 中对应货币的税率。发送时需同时支付手续费和货币附件金额（含税费）。

### 内容管理（moderation）

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `moderation.blocked-words` | List | 见下方示例 | 命中时禁止发送的敏感词列表（小写匹配） |
| `moderation.blocked-patterns` | List | 见下方示例 | 屏蔽正则表达式列表（邮件标题/正文命中则禁止发送，大小写不敏感） |
| `moderation.blocked-materials` | List | `BEDROCK`, `COMMAND_BLOCK`, `BARRIER` | 屏蔽物品材质列表（附件物品命中则禁止发送，大写匹配） |
| `moderation.blocked-lore-patterns` | List | （空） | 屏蔽 Lore 正则表达式列表（附件物品 Lore 命中则禁止发送） |
| `moderation.blocked-displayname-patterns` | List | （空） | 屏蔽物品自定义名称正则列表（附件物品 displayName 命中则禁止发送，大小写不敏感） |
| `moderation.blocked-nbt-keys` | List | （空） | 屏蔽 NBT/PDC 键列表（附件物品存在任一指定键则禁止发送，匹配键名或完整键 namespace:key） |
| `moderation.blocked-nbt-values` | Map | （空） | 屏蔽 NBT/PDC 键值对（键为 PDC 键名，值为期望的字符串/数值，支持数值比较和字符串比较） |

### 过期与清理（retention）

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `retention.cleanup-interval-ticks` | long | `1200` | 自动清理周期（tick，最小 20） |
| `retention.default-expire-after-days` | int | `15` | 默认邮件过期天数（最小 1） |
| `retention.claimed-retention-days` | int | `7` | 已领取邮件保留天数（超过后物理删除） |
| `retention.deleted-retention-days` | int | `7` | 已删除邮件保留天数（超过后物理删除） |
| `retention.allow-delete-with-unclaimed-attachments` | boolean | `false` | 是否允许在仍有未领取附件时删除邮件 |

## 邮件预设配置

预设邮件位于 `data/mail/presets/` 目录，每个 `.yml` 文件定义一个预设。详见 [邮件预设](/docs/mail/presets) 页面。

## 邮件附件配置

邮件附件分为三种类型（`MailAttachmentType` 枚举）：

| 附件类型 | 枚举值 | 配置字段 | 说明 |
|---|---|---|---|
| 物品附件 | `ITEM` | `item-attachments` | 序列化为 Base64 存储完整 NBT/附魔/自定义模型数据 |
| Vault 货币 | `VAULT` | `currency-attachments`（currency 为 `money`） | 走 Vault 经济桥接 |

### 物品附件

物品附件支持两种配置方式：

1. **`item-data`**（推荐）：完整 Base64 物品数据，保留 customModelData/附魔/PDC/自定义 NBT 等全部字段。管理员 UI 保存预设时自动生成。
2. **`source` + `id`**：按配置生成物品，支持以下来源：

| source 值 | 物品库 | id 格式 |
|---|---|---|
| `minecraft` | 原版物品 | 材质名（如 `APPLE`、`DIAMOND`） |
| `mythic` | MythicMobs | MythicMobs 内部物品名 |
| `neige` | NeigeItems | NeigeItems 物品 ID |
| `overture` | Overture | Overture 物品 ID |
| `mmoitems` | MMOItems | `类型ID;物品ID`（如 `SWORD;LEGENDARY_SWORD`） |

物品附件还支持 `name`（自定义名称）、`lore`（自定义描述）、`custom-model-data`、`nbt` 等属性，详见 [物品来源](/docs/guide/item-sources)。

### 货币附件

货币附件配置在 `currency-attachments` 列表中，每个条目包含：

| 字段 | 类型 | 说明 |
|---|---|---|
| `amount` | double | 货币数量（必须 `>` 0） |
| `description` | String | 附件展示描述（可选，默认为 `货币ID 数量`） |
| `icon` | Icon | 货币附件展示图标（可选，与 menu 模块 IconDefinition 一致） |

### 领取命令

`claim-commands` 列表定义玩家领取邮件时额外执行的命令，支持 `{player}` 等变量：

```yaml
claim-commands:
  - "tell {player} 你领取了奖励。"
  - "lp user {player} permission set vip.reward true"
```

## 邮件过期/清理配置

邮件过期和清理由 `retention` 节控制，定时任务按 `cleanup-interval-ticks` 周期执行：

1. **过期标记**：将 `status` 为 `UNREAD`/`READ` 且 `expires_at <= 当前时间` 的邮件标记为 `EXPIRED`
2. **物理删除**：删除超过保留天数的 `CLAIMED`/`DELETED`/`EXPIRED` 邮件及其附件记录
3. **CDK 清理**：删除已过期的 CDK 定义及其领取记录
