## 玩家命令

玩家命令绑定到 `/mail`（别名 `/axsmail`），需要 `arcartxsuite.mail.use` 权限。

| 命令 | 权限 | 说明 |
|---|---|---|
| `/mail` 或 `/mail open` | `arcartxsuite.mail.use` | 打开收件箱 UI |
| `/mail compose` | `arcartxsuite.mail.use` | 打开写信界面 |
| `/mail claimall` | `arcartxsuite.mail.use` | 一键领取所有可领取邮件的附件 |
| `/mail deleteall` | `arcartxsuite.mail.use` | 一键删除所有可删除邮件 |
| `/mail cdk <兑换码>` | `arcartxsuite.mail.use` | 兑换 CDK |

> **CDK 兑换权限**：当 `cdk.require-permission` 设为 `true` 时，CDK 兑换还需 `arcartxsuite.mail.cdk` 权限。

> **写信权限**：当 `player-send.require-permission` 设为 `true` 时，写信还需 `arcartxsuite.mail.send` 权限。

## 管理员命令

管理员命令通过Suite统一命令系统调度，前缀为 `/axs mail`，需要 `arcartxsuite.admin` 权限。

### 通用子命令

| 命令 | 说明 |
|---|---|
| `/axs mail help` | 查看所有可用子命令 |
| `/axs mail status` | 查看邮件模块状态（预设数、跨服通道、写信会话数） |
| `/axs mail open <玩家>` | 为指定在线玩家打开收件箱 |
| `/axs mail admin` | 打开管理 UI（预设编辑器） |

### 预设邮件子命令

| 命令 | 说明 |
|---|---|
| `/axs mail preset list` | 列出所有已加载的预设（显示 ID、显示名、附件数、命令数） |
| `/axs mail preset send <预设ID> <目标> [force-bypass]` | 派发预设邮件 |
| `/axs mail preset send confirm` | 确认上一次发起的多人派发请求 |
| `/axs mail preset info <预设ID>` | 查看预设详情（启用状态、显示名、标题、正文、过期、附件数、命令数、条件数、CDK 数） |
| `/axs mail preset delete <预设ID>` | 删除预设（从内存和 YAML 文件） |
| `/axs mail preset reload` | 重新从磁盘加载全部预设 |

#### preset send 参数说明

| 参数 | 说明 |
|---|---|
| `<预设ID>` | 预设 ID（不区分大小写） |
| `<目标>` | 玩家名、`all-online`（所有在线玩家）或 `all-registered`（所有注册玩家） |
| `[force-bypass]` | 可选，跳过多人派发二次确认（仅对 `all-online`/`all-registered` 生效） |

> **多人派发确认流程**：当目标为 `all-online` 或 `all-registered` 时，系统会提示在 30 秒内执行 `/axs mail preset send confirm` 完成确认。附加 `force-bypass` 可直接派发，跳过确认。

### CDK 子命令

| 命令 | 说明 |
|---|---|
| `/axs mail cdk create <预设ID> <code\|auto> <最大领取数> <有效期>` | 创建 CDK |
| `/axs mail cdk info <兑换码>` | 查看 CDK 详情（关联预设、领取次数、过期时间、启用状态） |
| `/axs mail cdk list [页码]` | 分页列出所有 CDK（每页 10 条） |
| `/axs mail cdk delete <兑换码>` | 删除 CDK |

#### cdk create 参数说明

| 参数 | 说明 |
|---|---|
| `<预设ID>` | 关联的预设邮件 ID |
| `<code\|auto>` | CDK 兑换码（自定义或 `auto` 自动生成） |
| `<最大领取数>` | 全局共享最大领取次数（所有玩家共用） |
| `<有效期>` | 有效期格式：`permanent`（永久）、`<N>s`（秒）、`<N>m`（分）、`<N>h`（时）、`<N>d`（天），默认 7 天 |

示例：

```
/axs mail cdk create starter WELCOME2026 100 30d
/axs mail cdk create summer-event auto 50 7d
/axs mail cdk create starter PERMANENT_CODE 999 permanent
```

## 权限节点

| 权限 | 默认 | 说明 |
|---|---|---|
| `arcartxsuite.mail.use` | true | 使用邮件系统（收件箱、写信、CDK 兑换） |
| `arcartxsuite.mail.send` | true | 玩家写信权限（`player-send.require-permission: true` 时检查） |
| `arcartxsuite.mail.cdk` | op | CDK 兑换权限（需 `cdk.require-permission: true`） |
| `arcartxsuite.admin` | op | 管理员命令和管理 UI 权限 |
