title: "账号绑定与白名单"
description: "通过宿主认证绑定 QQ，使用独立的群内白名单管理命令。"
---

QQBot 接收群内绑定请求并展示绑定结果。账号与 QQ 的绑定事实由宿主认证运行时管理，中心模式下存于中心。每个账号和 QQ 在同一 Realm 内各只能有一条绑定。

1. 在已接入的群里发送 `#绑定 <游戏名>`，以实际 `binding.bind-prefix` 为准。目标账号需要已经创建。
2. 玩家先验证游戏身份，再在 LoginView 的绑定步骤输入验证码。已经准入的玩家也可以通过 `/qqbot bind <验证码>` 或绑定面板确认。
3. 验证码有效期为 300 秒，只能由目标账号确认一次。用 `/qqbot info` 或绑定面板查看结果。

需要将 QQ 绑定设为准入要求时，standalone 配置 `requirements.qq-binding: true`，中心模式配置 Realm 的 `requireBinding: true`。中心节点需要相应的 `binding-read` 和 `binding-write` 权限。解绑由认证权威处理，原准入状态会重新评估。[认证配置](/docs/loginview/configuration)

## 群内白名单

群管理或群主可在启用白名单管理后显式执行下列命令。命令前缀和执行模板由 `whitelist` 配置。认证绑定流程与 Minecraft 白名单命令分别执行。

| 指令 | 用途 |
| --- | --- |
| `#白名单添加 <玩家名或QQ号>` | 添加白名单，QQ 号通过绑定记录解析 |
| `#白名单移除 <玩家名或QQ号>` | 移除白名单 |
| `#白名单列表` | 查看白名单 |

## 游戏内面板

`/qqbot ui` 打开绑定中心，`/qqbot admin` 打开管理后台。验证码从 QQ 群发起，绑定中心可查看状态及完成确认。消息通知 HUD 和其他界面配置见[QQBot 配置](/docs/qqbot/configuration)。
