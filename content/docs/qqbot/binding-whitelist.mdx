title: "账号绑定与白名单"
description: "群内申请验证码，验证游戏身份后确认绑定，独立维护白名单。"
---

实际绑定由宿主认证权威管理，中心模式下保存在中心。Realm 内每个账号和 QQ 各只能有一条绑定。

## 绑定

1. 目标账号已创建，机器人已连接。
2. 群内 #绑定 你的游戏名，保存验证码。
3. 目标账号先完成游戏身份验证。等待准入时在 LoginView 绑定步骤输入；已准入时 /qqbot bind 验证码，或 /qqbot 面板输入确认。
4. 验证码固定 300 秒，仅目标账号确认一次；过期后重新申请。
5. /qqbot info、面板或群内 #查绑 查看结果。

面板不生成验证码，确认结果由服务端返回。旧绑定数量、方式、期限配置已移除，不能通过 QQBot 放宽认证约束。

## 解绑与准入

游戏内 /qqbot unbind 先查看确认提示，再 /qqbot unbind confirm；面板同样需要二次确认。群内 #解绑 发起当前 QQ 解绑。宿主认证处理解绑并重新评估准入。

需要把绑定设为准入要求：standalone 配置 requirements.qq-binding: true；中心配置 Realm requireBinding: true，并给节点相应 binding-read/binding-write 权限。见[认证配置](/docs/loginview/configuration)。

## 独立白名单

绑定不自动添加 Minecraft 白名单，解绑也不自动移除。whitelist 启用后，还需 admin.enabled:true 且 QQ 在 admin.qq-list 可信名单内，才可使用下列命令。QQ群管/群主身份不自动授权。需要白名单管理时可保持 admin.remote-console-enabled:false，单独关闭 #cmd。

| 指令 | 作用 |
| --- | --- |
| #白名单添加 玩家名或QQ号 | 添加，QQ 号需解析到绑定账号 |
| #白名单移除 玩家名或QQ号 | 移除 |
| #白名单列表 | 查看 |

默认模板为 whitelist add {name} 和 whitelist remove {name}；使用其他插件时换成真实控制台命令。Minecraft 白名单不能替代宿主身份验证。

/qqbot admin 提供绑定记录搜索、分页及二次确认解绑。面板权限与执行任意控制台命令权限分别授予。旧 QQBot 数据库中的绑定副本不作为当前认证事实。
