# QQBot 配置文件详解

QQBot 模块的配置文件为 `ArcartXQQBot.yml`，位于 `plugins/ArcartX-Suite/modules/qqbot/` 目录下。修改后执行 `/axs qqbot reload` 重载生效。

## 主配置字段总览

| 配置节 | 说明 |
|---|---|
| `settings` | 全局设置（调试日志、服务器标识） |
| `onebot` | OneBot 11 WebSocket 连接配置 |
| `groups` | 监听的 QQ 群列表 |
| `binding` | QQ-游戏账号绑定配置 |
| `whitelist` | 白名单管理配置 |
| `admin` | 管理员远程控制配置 |
| `command-prefix` | 群指令前缀 |
| `custom-commands` | 自定义群指令 |
| `signin` | 签到积分系统配置 |
| `prizes` | 积分兑换奖品列表 |
| `monitor` | 服务器监控告警配置 |
| `scheduled-messages` | 定时消息列表 |
| `broadcast` | 击杀/死亡播报配置 |
| `market-broadcast` | 大额交易播报配置 |
| `welcome` | 入群欢迎配置 |
| `auto-reply` | 关键词自动回复配置 |
| `announce` | 群公告广播配置 |
| `moderation` | 群管理 moderation 配置 |
| `at-to-game` | @ 提示配置 |
| `blacklist` | 黑名单配置 |
| `storage` | 数据存储配置 |
| `ui` | UI 界面配置 |
| `messages` | 消息文本模板 |

## 全局设置 (settings)

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `debug` | boolean | `false` | 是否输出调试日志（OneBot 事件、聊天事件等） |
| `server-id` | string | `"survival"` | 服务器标识，多服时区分消息来源 |

## OneBot 连接配置 (onebot)

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `ws-url` | string | `"ws://127.0.0.1:3001"` | OneBot 正向 WebSocket 地址 |
| `access-token` | string | `""` | 鉴权 token（留空表示不鉴权） |
| `reconnect-interval-seconds` | int | `10` | 断线重连间隔（秒） |
| `heartbeat-interval-seconds` | int | `30` | 心跳间隔（秒，服务端主动推送，此参数保留兼容） |

### SnowLuma 子配置 (onebot.snowluma)

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `mode` | string | `"native"` | 运行模式：`native`（本地子进程）/ `docker`（Docker 容器） |
| `dir` | string | `"snowluma"` | SnowLuma 安装目录（相对于服务端根目录，仅 native 模式） |
| `auto-start` | boolean | `false` | 模块启动时自动启动 SnowLuma |

### Docker 模式配置 (onebot.snowluma.docker)

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `container-name` | string | `"snowluma"` | Docker 容器名称 |
| `image` | string | `"motricseven7/snowluma:latest"` | Docker 镜像 |
| `webui-port` | int | `5099` | 宿主机 WebUI 端口映射 |
| `ws-port` | int | `3001` | 宿主机 WebSocket 端口映射 |
| `http-port` | int | `3000` | 宿主机 HTTP 端口映射 |
| `auto-install` | boolean | `false` | 模块启动时若容器不存在则自动安装 |

## 群配置 (groups)

`groups` 是一个列表，每个元素代表一个监听的 QQ 群：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `group-id` | long | — | QQ 群号（必填） |
| `sync-mode` | string | `"both"` | 消息同步模式：`both` / `game-to-qq` / `qq-to-game` / `none` |
| `game-to-qq` | string | `"[MC] {player}: {message}"` | 游戏消息转发到 QQ 群的格式 |
| `qq-to-game` | string | `"&7[QQ] &f{nick}: &7{message}"` | QQ 群消息转发到游戏内的格式 |
| `commands-enabled` | boolean | `true` | 是否允许群成员执行指令 |
| `join-message` | string | `"[MC] {player} 加入了服务器"` | 玩家进服通知（留空则不推送） |
| `quit-message` | string | `"[MC] {player} 离开了服务器"` | 玩家退服通知（留空则不推送） |

### 消息格式占位符

| 占位符 | 说明 | 适用场景 |
|---|---|---|
| `{player}` | 玩家名 | game-to-qq、join-message、quit-message |
| `{display_name}` | 玩家显示名 | game-to-qq |
| `{message}` | 消息内容 | game-to-qq、qq-to-game |
| `{nick}` | 群名片/昵称 | qq-to-game |
| `{qq}` | QQ 号 | qq-to-game |
| `{group}` | 群号 | qq-to-game |
| `{server}` | 服务器标识 | game-to-qq |
| `{online}` | 在线人数 | join-message、quit-message |
| `{max}` | 最大人数 | join-message、quit-message |

## 管理员远程控制 (admin)

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | boolean | `false` | 是否启用管理员远程控制 |
| `qq-list` | list(long) | — | 管理员 QQ 号列表 |
| `command-prefix` | string | `"#cmd"` | 管理员指令前缀 |
| `allowed-commands` | list(string) | — | 允许执行的命令白名单（命令名，不含参数；留空表示允许全部） |

> **安全警告**：管理员远程控制等同于控制台权限。请仅添加完全信任的 QQ 号，并配置 `allowed-commands` 限制可执行命令范围。

## 自定义群指令 (custom-commands)

`custom-commands` 是一个映射表，键为指令名称，值为指令配置：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `permission` | int | `0` | 权限等级：`0`=普通群员，`1`=群管理/群主 |
| `type` | string | `"builtin"` | 命令类型：`builtin` / `server-command` / `papi-query` |
| `builtin-id` | string | — | 内置命令标识（仅 `builtin` 类型） |
| `command` | string | — | 服务器命令模板（仅 `server-command` 类型） |
| `usage` | string | — | 用法说明 |
| `placeholders` | list(string) | — | PAPI 占位符列表（仅 `papi-query` 类型） |
| `format` | string | — | 输出格式模板（仅 `papi-query` 类型） |

### 内置命令 (builtin-id)

| builtin-id | 说明 |
|---|---|
| `online-list` | 查在线玩家列表（含 AFK/隐身/无敌标签） |
| `server-status` | 查服务器状态（版本/在线/TPS/内存/实体/区块） |
| `points-leaderboard` | 积分排行榜 Top10 |

### papi-query 类型说明

`papi-query` 类型用于查询在线玩家的 PAPI 占位符值。`placeholders` 列表中的占位符按顺序替换到 `format` 中的 `{0}`、`{1}`、`{2}`... 位置，`{name}` 替换为玩家名。

## 签到积分系统 (signin)

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | boolean | `true` | 是否启用签到积分系统 |
| `base-points` | int | `10` | 每日签到基础积分（范围 0-100000） |
| `streak-bonus` | int | `2` | 每多连续签到 1 天额外增加的积分（范围 0-100000） |
| `max-streak-bonus` | int | `50` | 连续签到加成上限（范围 0-1000000） |
| `sign-prefix` | string | `"#签到"` | 签到指令 |
| `aliases` | list(string) | — | 签到别名列表 |
| `shop-prefix` | string | `"#商店"` | 兑换商店指令 |
| `redeem-prefix` | string | `"#兑换"` | 兑换指令前缀 |
| `points-query-prefix` | string | `"#积分"` | 积分查询指令 |
| `transfer-prefix` | string | `"#转账"` | 积分转账指令 |
| `red-packet-prefix` | string | `"#红包"` | 发红包指令 |
| `grab-red-packet-prefix` | string | `"#抢红包"` | 抢红包指令 |
| `activity-prefix` | string | `"#活跃排行"` | 活跃度排行指令 |

### 积分计算公式

```
签到积分 = base-points + min((连续天数 - 1) * streak-bonus, max-streak-bonus)
```

## 积分兑换奖品 (prizes)

`prizes` 是一个列表，每个元素代表一个可兑换的奖品：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `id` | string | — | 奖品 ID（唯一，兑换时使用） |
| `name` | string | — | 奖品名称 |
| `cost` | int | — | 兑换所需积分 |
| `mail.presets` | list(string) | — | 邮件预设 ID 列表（对应 Mail 模块中的预设） |
| `description` | string | — | 奖品描述 |
| `limit-per-day` | int | `0` | 每日兑换上限（0=不限） |
| `require-bind` | boolean | — | 是否需要先绑定游戏账号 |
| `discount-rate` | double | `1.0` | 折扣比例（0.8=8折），1.0 或省略表示不折扣 |
| `discount-until` | long | `0` | 折扣截止 unix 时间戳（毫秒），0=无折扣 |

> 兑换奖品通过 `MailDispatchable` Capability 调用 Mail 模块发送邮件预设。若邮件发放失败，积分自动退还。

## 服务器监控告警 (monitor)

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | boolean | `false` | 是否启用监控告警 |
| `tps-threshold` | double | `15.0` | TPS 低于此值触发告警（范围 0.0-20.0） |
| `memory-threshold-percent` | int | `90` | 内存占用百分比超过此值触发告警（范围 1-100） |
| `check-interval-seconds` | int | `60` | 检测间隔（秒，范围 5-86400） |
| `cooldown-seconds` | int | `300` | 同类告警冷却（秒），避免刷屏 |
| `alarm-groups` | list(long) | `[]` | 接收告警的群号列表（留空=推送到所有已配置群） |
| `tps-alarm-format` | string | — | TPS 告警格式 |
| `memory-alarm-format` | string | — | 内存告警格式 |

### 告警格式占位符

| 占位符 | 说明 | 适用 |
|---|---|---|
| `{tps}` | 当前 TPS（1分钟） | tps-alarm-format |
| `{threshold}` | TPS 阈值 | tps-alarm-format |
| `{used}` | 已用内存（MB） | memory-alarm-format |
| `{max}` | 最大内存（MB） | memory-alarm-format |
| `{percent}` | 内存占用百分比 | memory-alarm-format |

## 黑名单 (blacklist)

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|

| `qq-list` | list(long) | — | 配置静态黑名单 QQ 号列表 |

## 数据存储配置 (storage)

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `shared` | boolean | `true` | 是否使用共享存储模式 |

### 共享模式 (shared: true)

共享存储模式复用本体统一数据源（`plugins/ArcartX-Suite/config.yml` 的 `storage` 节），无需配置连接参数，性能较好，**推荐使用**。

### 自建模式 (shared: false)

自建模式下模块自行创建独立 HikariCP 连接池，支持 SQLite 与 MySQL：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `mode` | string | `"sqlite"` | 存储模式：`sqlite` 或 `mysql` |
| `sqlite.file` | string | `"qqbot.db"` | SQLite 文件名（相对模块数据目录） |
| `mysql.host` | string | `"127.0.0.1"` | MySQL 主机地址 |
| `mysql.port` | int | `3306` | MySQL 端口 |
| `mysql.database` | string | `"arcartxsuite"` | MySQL 数据库名 |
| `mysql.username` | string | `"root"` | MySQL 用户名 |
| `mysql.password` | string | `""` | MySQL 密码 |
| `mysql.table-prefix` | string | `"axs_qqbot_"` | MySQL 表名前缀 |
| `pool-size` | int | `4` | 连接池大小（SQLite 建议 1） |

> UI 文件名（`qqbot_bind.yml` 等）为代码常量，不可在此配置。UI 编辑请参考 [UI 指南](/docs/guide/icons)。

## 消息文本 (messages)

`messages` 节定义各场景的消息模板，支持 `&` 颜色码和占位符变量。以下为常用消息项：

| 消息键 | 默认值 | 说明 |
|---|---|---|
| `prefix` | `"&8[&bQQBot&8] &7"` | 消息前缀 |
| `bind-code-sent` | — | 验证码发送提示（群内），占位符 `{code}` `{expire}` |
| `bind-success` | — | 绑定成功提示（群内），占位符 `{qq}` `{name}` |
| `bind-success-game` | — | 绑定成功提示（游戏内），占位符 `{qq}` `{name}` |
| `unbind-success` | — | 解绑成功提示（群内），占位符 `{name}` |
| `unbind-success-game` | — | 解绑成功提示（游戏内），占位符 `{qq}` |
| `signin-success` | — | 签到成功提示，占位符 `{points}` `{streak}` `{balance}` |
| `signin-already` | — | 重复签到提示，占位符 `{streak}` `{balance}` |
| `points-query` | — | 积分查询结果，占位符 `{balance}` `{earned}` `{spent}` |
| `redeem-success` | — | 兑换成功提示，占位符 `{name}` `{player}` `{cost}` `{balance}` |
| `bot-connected` | — | 机器人连接成功提示 |
| `bot-disconnected` | — | 机器人断开提示 |

## 配置版本迁移

模块支持配置版本自动迁移。当前配置版本为 4，历史迁移记录：

| 迁移 | 说明 |
|---|---|
| 1 → 2 | 初始迁移 |
| 2 → 3 | 结构调整 |
| 3 → 4 | `storage.mode` 重命名为 `storage.shared`，值从 `sqlite`/`mysql` 映射为 `true`/`false` |

模块启动时自动检测 `config-version` 并执行必要的迁移操作，无需手动干预。
