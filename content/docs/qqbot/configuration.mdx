## 先改哪些内容

OneBot 连接、群号、消息模板与签到奖励。先使用默认示例完成一次测试，再按本页逐项调整。

配置位置：`plugins/ArcartX-Suite/data/qqbot/config.yml`。定义文件与子目录均相对此模块目录。本文中的 YAML 片段用于修改对应小节，请保留文件中的其他设置。

修改后执行 `/axs reload qqbot`；涉及插件安装或全局设置的变更请重启后验证。

QQBot 模块的配置文件为 `config.yml`，位于 `plugins/ArcartX-Suite/data/qqbot/` 目录下。修改后执行 `/axs reload qqbot` 重载生效。

## 群配置 (groups)

`groups` 是一个列表，每个元素代表一个监听的 QQ 群：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `group-id` | long | — | QQ 群号（必填） |
| `sync-mode` | string | `"both"` | 消息同步模式：`both` / `game-to-qq` / `qq-to-game` / `none` |
| `game-to-qq` | string | `"[MC] {player}: {message}"` | 游戏消息转发到 QQ 群的格式 |
| `qq-to-game` | string | `"&7[QQ] &f{nick}: &7{message}"` | QQ 群消息转发到游戏内的格式 |
| `commands-enabled` | boolean | `true` | 是否允许群成员执行指令 |
| `join-message` | string | `"[MC] {player} 加入了服务器"` | 玩家进服通知（留空则不推送） |
| `quit-message` | string | `"[MC] {player} 离开了服务器"` | 玩家退服通知（留空则不推送） |

### 消息格式占位符

| 占位符 | 说明 | 适用场景 |
|---|---|---|
| `{player}` | 玩家名 | game-to-qq、join-message、quit-message |
| `{display_name}` | 玩家显示名 | game-to-qq |
| `{message}` | 消息内容 | game-to-qq、qq-to-game |
| `{nick}` | 群名片/昵称 | qq-to-game |
| `{qq}` | QQ 号 | qq-to-game |
| `{group}` | 群号 | qq-to-game |
| `{server}` | 服务器标识 | game-to-qq |
| `{online}` | 在线人数 | join-message、quit-message |
| `{max}` | 最大人数 | join-message、quit-message |

## 签到积分系统 (signin)

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | boolean | `true` | 是否启用签到积分系统 |
| `base-points` | int | `10` | 每日签到基础积分（范围 0-100000） |
| `streak-bonus` | int | `2` | 每多连续签到 1 天额外增加的积分（范围 0-100000） |
| `max-streak-bonus` | int | `50` | 连续签到加成上限（范围 0-1000000） |
| `sign-prefix` | string | `"#签到"` | 签到指令 |
| `aliases` | list(string) | — | 签到别名列表 |
| `shop-prefix` | string | `"#商店"` | 兑换商店指令 |
| `redeem-prefix` | string | `"#兑换"` | 兑换指令前缀 |
| `points-query-prefix` | string | `"#积分"` | 积分查询指令 |
| `transfer-prefix` | string | `"#转账"` | 积分转账指令 |
| `red-packet-prefix` | string | `"#红包"` | 发红包指令 |
| `grab-red-packet-prefix` | string | `"#抢红包"` | 抢红包指令 |
| `activity-prefix` | string | `"#活跃排行"` | 活跃度排行指令 |

### 积分计算公式

```
签到积分 = base-points + min((连续天数 - 1) * streak-bonus, max-streak-bonus)
```

## 黑名单 (blacklist)

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|

## 消息文本 (messages)

`messages` 节定义各场景的消息模板，支持 `&` 颜色码和占位符变量。以下为常用消息项：

| 消息键 | 默认值 | 说明 |
|---|---|---|
| `prefix` | `"&8[&bQQBot&8] &7"` | 消息前缀 |
| `bind-code-sent` | — | 验证码发送提示（群内），占位符 `{code}` `{expire}` |
| `bind-success` | — | 绑定成功提示（群内），占位符 `{qq}` `{name}` |
| `bind-success-game` | — | 绑定成功提示（游戏内），占位符 `{qq}` `{name}` |
| `unbind-success` | — | 解绑成功提示（群内），占位符 `{name}` |
| `unbind-success-game` | — | 解绑成功提示（游戏内），占位符 `{qq}` |
| `signin-success` | — | 签到成功提示，占位符 `{points}` `{streak}` `{balance}` |
| `signin-already` | — | 重复签到提示，占位符 `{streak}` `{balance}` |
| `points-query` | — | 积分查询结果，占位符 `{balance}` `{earned}` `{spent}` |
| `redeem-success` | — | 兑换成功提示，占位符 `{name}` `{player}` `{cost}` `{balance}` |
| `bot-connected` | — | 机器人连接成功提示 |
| `bot-disconnected` | — | 机器人断开提示 |

## 群消息配置示例

在原配置的 `groups` 列表中添加或修改测试群。将示例群号替换为实际群号：

```yaml
groups:
  - group-id: 123456789
    sync-mode: both
    game-to-qq: "[MC] {player}: {message}"
    qq-to-game: "&7[QQ] &f{nick}: &7{message}"
    commands-enabled: true
    join-message: "[MC] {player} 加入了服务器"
    quit-message: "[MC] {player} 离开了服务器"
```

此片段只调整群消息展示，OneBot 连接信息仍填写在原配置对应小节中。重载后从群和游戏分别发送消息，确认双向同步。
