## 游戏内入口

| 命令 | 作用 |
| --- | --- |
| /qqbot 或 /qqbot ui | 打开绑定与群消息中心 |
| /qqbot help | 查看帮助 |
| /qqbot bind 验证码 | 已验证身份的目标账号确认绑定 |
| /qqbot unbind | 显示解绑确认提示 |
| /qqbot unbind confirm | 确认解绑，由宿主重新评估准入 |
| /qqbot info | 查看绑定 |
| /qqbot send 消息 | 发到允许游戏到 QQ 的配置群 |
| /qqbot at QQ号 消息 | 向可发送群提及该 QQ，另有权限和冷却 |
| /qqbot admin | 打开管理面板 |

玩家发送需要已准入、有权限，并满足绑定要求、长度、冷却和每群预算。面板显示服务端发送结果，不会在结果未知时自动重发。

## 权限

| 权限 | 默认 | 作用 |
| --- | --- | --- |
| arcartxsuite.qqbot.use | true | 玩家基本入口 |
| arcartxsuite.qqbot.send | true | 普通发群 |
| arcartxsuite.qqbot.at | OP | 提及 QQ，独立 10 秒冷却 |
| arcartxsuite.qqbot.admin | OP | 管理面板和管理操作 |
| arcartxsuite.qqbot.console | OP | 高权限控制台执行入口 |

面板管理权限不会自动赋予任意控制台执行能力。群内游戏管理要求 admin.enabled:true、命中 admin.qq-list 可信名单，以及对应功能开关；QQ群管/群主角色不自动授权。Minecraft 权限节点与 QQ 名单分别设置。

## 服务器管理

| 命令 | 作用 |
| --- | --- |
| /axs qqbot status | 连接、群和功能状态 |
| /axs qqbot send all或群号 消息 | 明确发到配置群并等待动作回执 |
| /axs qqbot lookup 玩家名或QQ号 | 查询绑定 |
| /axs qqbot blacklist add或remove QQ号 | 动态黑名单 |
| /axs qqbot blacklist list | 静态及动态黑名单 |
| /axs reload qqbot | 重载模块 |

结果未知时先查看群及实现端日志。重载会取消旧启动任务、等待托管清理后启动新实例；external 不停止外部服务。

## 兑换复核

| 命令 | 作用 |
| --- | --- |
| /axs qqbot redemptions list [1–100] | 列出待检查订单 |
| /axs qqbot redemptions get 兑换ID | 查看订单和逐项邮件状态 |
| /axs qqbot redemptions resolve 兑换ID delivered confirm 备注 | 核对并补齐所有邮件后保留扣款结案 |
| /axs qqbot redemptions resolve 兑换ID not-delivered confirm 备注 | 独立核实全部未发后申请退款 |

备注为 4–500 字。任何邮件项已确认 SENT 时，不允许直接全单退款；需先人工核对部分发放情况。不要把超时直接当成全部未发。

## SnowLuma 托管命令

均使用 /axs qqbot snowluma 子命令：

| 子命令 | 作用 |
| --- | --- |
| install | native 下载完整包；docker 拉取镜像并重建已有托管容器，保留数据卷 |
| start / stop | 仅启动/停止归属验证通过的托管对象 |
| status | 模式、归属、安装和状态 |
| logs | Docker 最近日志；含初始登录信息，仅管理员使用 |
| password | 查询启动日志中的 WebUI 初始密码；改密后旧值失效 |
| password reset | 重置 WebUI 密码。Docker 自动重启，native 模式需随后执行 `start` |
| check-update | 查询上游版本；固定镜像 tag 不会自动改成另一个 tag |

external 模式不管理进程。目录/容器名称相同不代表本模块拥有它。[安装教程](/docs/qqbot)说明 SSH 转发、NTQQ 和 token。

## QQ 群命令

仅在配置群和功能开启时有效，前缀可配置。

| 指令 | 作用 |
| --- | --- |
| #帮助 | 列出可用指令 |
| #绑定 游戏名 / #解绑 / #查绑 [游戏名] | 绑定、解绑和查询 |
| #签到、#打卡、#积分 | 每日签到与余额 |
| #商店、#兑换 奖品ID | 查看奖品和兑换 |
| #转账 QQ号 积分 | 积分转账 |
| #红包 总积分 份数 / #抢红包 红包ID | 发红包和领取 |
| #活跃排行 / #积分榜 | 活跃度或余额排行 |
| #白名单添加、#白名单移除、#白名单列表 | 管理总开关开启、命中可信名单，且 whitelist 开启 |
| #公告 内容、#踢 玩家 [原因]、#封禁 玩家 [原因] | 管理总开关开启、命中可信名单，且对应功能开启 |
| #发邮件 玩家名 预设ID | 管理总开关开启且命中可信名单，调用真实邮件预设 |
| #黑名单添加、#黑名单移除、#黑名单列表 | 管理总开关开启、命中可信名单，且 blacklist 开启 |
| #cmd 固定允许的命令 | 命中可信名单，且 admin.enabled、admin.remote-console-enabled 均为 true |

custom-commands 的 builtin/papi-query 在 permission=0 时允许普通群员，>0 要求 admin.enabled:true 且命中可信名单。自定义 server-command 无论 permission 如何配置，都强制检查总开关和可信名单，只应配置具体业务模板。

需要具体群管理时设置 admin.enabled:true 并填写自己的可信 QQ，仍保持 admin.remote-console-enabled:false，即可关闭 #cmd。admin.enabled:false 会关闭全部可信 QQ 游戏管理入口。普通群管/群主即使 role=admin/owner，也不会自动获得这些权限。

## 占位符查询（PlaceholderAPI）

| 占位符 | 返回 |
| --- | --- |
| %axsqqbot_connected% | true/false |
| %axsqqbot_connected_display% | 已连接/未连接 |
| %axsqqbot_bound_qq% | 玩家绑定 QQ 或空 |
| %axsqqbot_is_bound% | true/false |
| %axsqqbot_bound_name% | 绑定名称或空 |
| %axsqqbot_group_count% | 配置群数 |
