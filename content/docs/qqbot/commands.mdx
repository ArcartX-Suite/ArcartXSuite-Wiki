# QQBot 命令与占位符

QQBot 模块提供游戏内命令和 QQ 群内指令两套命令体系，以及 PlaceholderAPI 占位符。

## 游戏内命令

玩家在游戏内使用 `/qqbot <子命令>` 执行操作。仅允许玩家执行（控制台执行会提示仅玩家可用）。

### 玩家命令

| 命令 | 用法 | 说明 |
|---|---|---|
| `/qqbot` | `/qqbot` | 显示帮助信息 |
| `/qqbot help` | `/qqbot help` | 显示帮助信息 |
| `/qqbot bind` | `/qqbot bind <验证码>` | 使用验证码绑定 QQ 账号 |
| `/qqbot unbind` | `/qqbot unbind` | 解除 QQ 绑定 |
| `/qqbot info` | `/qqbot info` | 查看当前绑定信息 |
| `/qqbot ui` | `/qqbot ui` | 打开绑定中心 UI 面板 |
| `/qqbot admin` | `/qqbot admin` | 打开管理后台 UI 面板（需管理员权限） |
| `/qqbot at` | `/qqbot at <QQ号> <消息>` | 通过 QQ 群向指定 QQ 号发送 @ 消息 |

### 玩家命令详解

#### `/qqbot bind <验证码>`

使用在 QQ 群内通过 `#绑定 <游戏名>` 获取的验证码完成绑定。

- 验证码为 6 位数字，有效期由 `binding.code-expire-seconds` 控制（默认 300 秒）
- 绑定成功后自动加白名单（若 `whitelist.auto-add-on-bind` 启用）
- 验证码与玩家名必须匹配，否则提示"该验证码不是为你生成的"

#### `/qqbot unbind`

解除当前玩家的 QQ 绑定。

- 解绑成功后自动移除白名单（若 `whitelist.auto-remove-on-unbind` 启用）
- 未绑定时提示"你尚未绑定QQ"

#### `/qqbot at <QQ号> <消息>`

向所有已配置群发送一条带 @ 标记的消息，格式为 `[MC] <玩家名> @QQ <QQ号>: <消息>`。

- QQ 号必须为有效数字
- 消息发送到所有已配置群

## 管理员命令

管理员通过 `/axs qqbot <子命令>` 执行管理操作。这些命令通过 `ModuleCommandHandler` 注册到 `/axs` 命令体系中。

### 管理员子命令

| 命令 | 用法 | 说明 |
|---|---|---|
| `/axs qqbot help` | `/axs qqbot help` | 显示管理帮助 |
| `/axs qqbot status` | `/axs qqbot status` | 查看机器人运行状态 |
| `/axs qqbot send` | `/axs qqbot send <all\|群号> <消息>` | 向指定群或所有群发送消息 |
| `/axs qqbot lookup` | `/axs qqbot lookup <玩家名\|QQ号>` | 查询绑定记录 |
| `/axs qqbot snowluma` | `/axs qqbot snowluma <子命令>` | SnowLuma 进程管理 |
| `/axs qqbot blacklist` | `/axs qqbot blacklist <add\|remove\|list> [QQ]` | 黑名单管理 |

### 管理员命令详解

#### `/axs qqbot status`

查看机器人运行状态，包括：

- 连接状态（已连接/未连接）
- 监听群数
- 存储模式
- 绑定功能状态（启用/禁用）
- 白名单状态（启用/禁用）

#### `/axs qqbot send <all|群号> <消息>`

向指定群或所有群发送消息。

- `all` — 发送到所有已配置群
- `<群号>` — 发送到指定群号（必须是已配置的群）

#### `/axs qqbot lookup <玩家名|QQ号>`

查询绑定记录，支持按玩家名或 QQ 号查询：

- 输入纯数字时按 QQ 号查询，返回绑定的玩家名
- 输入非纯数字时按玩家名查询，返回绑定的 QQ 号

#### `/axs qqbot snowluma <子命令>`

SnowLuma 进程/容器管理：

| 子命令 | 说明 |
|---|---|
| `start` | 启动 SnowLuma |
| `stop` | 停止 SnowLuma |
| `status` | 查看 SnowLuma 状态 |
| `install` | 下载安装/部署 SnowLuma（异步执行） |
| `logs` | 查看最近日志（仅 Docker 模式） |
| `check-update` | 检查是否有新版本（异步执行） |

#### `/axs qqbot blacklist <add|remove|list> [QQ]`

黑名单管理（操作数据库动态黑名单）：

| 子命令 | 用法 | 说明 |
|---|---|---|
| `add` | `blacklist add <QQ号>` | 将指定 QQ 加入黑名单 |
| `remove` | `blacklist remove <QQ号>` | 将指定 QQ 移出黑名单 |
| `list` | `blacklist list` | 查看黑名单列表（含配置静态 + 数据库动态） |

## 权限节点

|---|---|---|
| `arcartxsuite.qqbot.admin` | 允许使用管理后台 UI 和 `/qqbot admin` 命令 | OP |

### 自定义指令

自定义指令在 `custom-commands` 配置节中定义，支持三种类型：

#### builtin 类型

内置功能指令，通过 `builtin-id` 指定：

```yaml
custom-commands:
  查在线:
    permission: 0
    type: "builtin"
    builtin-id: "online-list"
```

| builtin-id | 说明 |
|---|---|
| `online-list` | 在线玩家列表（含 AFK/隐身/无敌标签，需 EssentialsQueryable） |
| `server-status` | 服务器状态（版本/在线/TPS/内存/实体/区块） |
| `points-leaderboard` | 积分排行榜 Top10 |

#### server-command 类型

在服务器控制台执行命令，`{args}` 替换为指令后的所有参数：

```yaml
custom-commands:
  执行命令:
    permission: 1
    type: "server-command"
    command: "{args}"
```

#### papi-query 类型

查询在线玩家的 PAPI 占位符值，`placeholders` 列表按顺序替换到 `format` 中的 `{0}`、`{1}`... 位置：

```yaml
custom-commands:
  查玩家:
    permission: 0
    type: "papi-query"
    usage: "#查玩家 [玩家名]"
    placeholders:
      - "%player_level%"
      - "%vault_eco_balance%"
      - "%player_health%"
      - "%player_food_level%"
    format: "玩家: {name}\n等级: {0}\n金币: {1}\n生命: {2}\n饥饿: {3}"
```

- 不指定玩家名时，自动通过 QQ 绑定关系解析玩家名
- 玩家不在线时提示"找不到玩家"

## PlaceholderAPI 占位符

QQBot 模块向 PlaceholderAPI 注册了 `axsqqbot` 标识符的占位符：

| 占位符 | 返回值 | 说明 |
|---|---|---|
| `%axsqqbot_connected%` | `true` / `false` | 机器人是否已连接 |
| `%axsqqbot_connected_display%` | `已连接` / `未连接` | 机器人连接状态（中文显示） |
| `%axsqqbot_bound_qq%` | QQ 号 / 空 | 当前玩家绑定的 QQ 号 |
| `%axsqqbot_is_bound%` | `true` / `false` | 当前玩家是否已绑定 QQ |
| `%axsqqbot_bound_name%` | 玩家名 / 空 | 当前玩家绑定的游戏名 |
| `%axsqqbot_group_count%` | 数字 | 已配置的监听群数量 |

### 占位符使用示例

```yaml
# 在计分板中显示 QQ 绑定状态
绑定状态: %axsqqbot_is_bound%
QQ号码: %axsqqbot_bound_qq%
机器人: %axsqqbot_connected_display%

# 在 Tab 列表中显示
Tab标题: "QQ群服互联 - %axsqqbot_group_count% 个群"
```

## 命令权限体系总结

QQ 群内指令的权限分为以下层级：

| 权限层级 | 说明 | 适用指令 |
|---|---|---|
| 全员（permission: 0） | 所有群成员可用 | 绑定/解绑/查绑、签到积分、自定义指令（permission=0） |
| 群管理/群主 | OneBot sender.role 为 admin 或 owner | 白名单管理、公告、踢人/封禁、黑名单管理 |
| 配置管理员 | `admin.qq-list` 中的 QQ 号 | `#cmd` 控制台命令、所有群管理指令 |
| 自定义指令（permission: 1） | 仅 `admin.qq-list` 中的 QQ 号可用 | `custom-commands` 中 permission=1 的指令 |

> 群管理/群主权限通过 OneBot 协议的 `sender.role` 字段判断（`admin` 或 `owner`）。配置管理员权限通过 `admin.qq-list` 判断。两者满足其一即可执行群管理类指令。
