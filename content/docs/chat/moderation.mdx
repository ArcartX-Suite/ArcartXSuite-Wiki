Chat 模块提供完整的管理与审核工具链，包括禁言管理、社交监听、忽略列表、内容审核、发言冷却与重复检测，以及强制接管模式。

## 禁言系统

禁言系统允许管理员禁止指定玩家在聊天中发言，支持临时禁言（按时长）与永久禁言，禁言记录持久化到数据库。

### 禁言命令

| 命令 | 说明 | 权限 |
|---|---|---|
| `/axs chat mute <玩家> <时长> [原因]` | 禁言指定玩家 | `arcartxsuite.admin` |
| `/axs chat unmute <玩家>` | 解除指定玩家的禁言 | `arcartxsuite.admin` |

时长格式为 `<数字><单位>`，单位支持 `s`（秒）、`m`（分）、`h`（时）、`d`（天），或 `permanent` 永久禁言：

```text
/axs chat mute Steve 30m 刷屏
/axs chat mute Steve 7d 广告
/axs chat mute Steve permanent 恶意行为
```

| 输入 | 解析结果 |
|---|---|
| `permanent` | 永久禁言 |
| `30s` / `30m` / `12h` / `7d` | 对应时长后过期 |
| 非法格式 | 默认 1 天后过期 |

<Callout type="warn">
无法解析的时长格式不会报错，而是默认禁言 1 天。请确保时长格式正确。
</Callout>

### 禁言效果

- 被禁言玩家发言时会收到系统提示（聊天卡片或文本消息），显示剩余时间与原因
- 禁言记录包含操作者、原因与过期时间，过期后自动解除
- 其他模块（如 Essentials）可委托 Chat 执行禁言/解禁与查询

## 社交监听

社交监听（SocialSpy）允许管理员查看全服私聊内容，使用 `spy-format` 模板渲染。

### 玩家命令

| 命令 | 说明 | 权限 |
|---|---|---|
| `/chat socialspy` | 切换社交监听 | `arcartxsuite.chat.socialspy` |
| `/chat socialspy on` | 开启社交监听 | `arcartxsuite.chat.socialspy` |
| `/chat socialspy off` | 关闭社交监听 | `arcartxsuite.chat.socialspy` |

### 管理员命令

具备 `arcartxsuite.admin` 的管理员可设置其他玩家的社交监听开关。

```text
/axs chat spy Steve on
/axs chat spy Steve off
```

被操作的玩家会收到通知消息，告知其社交监听已被管理员变更。

<Callout type="info">
监听者不会收到自己参与的私聊的重复提示。监听消息使用 `spy-format` 模板渲染（如 `&5[监听 {player_name} -> {target_name}] &r{message}`），与私聊双方看到的格式不同。
</Callout>

## 忽略列表

玩家可忽略指定玩家的消息。忽略关系双向生效：你忽略的人发消息你收不到，你给被忽略的人发消息也会被拦截。

| 命令 | 说明 | 权限 |
|---|---|---|
| `/chat ignore <玩家>` | 忽略指定玩家 | `arcartxsuite.chat.use` |
| `/chat unignore <玩家>` | 取消忽略指定玩家 | `arcartxsuite.chat.use` |

忽略对频道消息、私聊与跨服私聊均生效。忽略列表持久化存储，玩家下次登录自动生效。

## 内容审核

消息会经过敏感词过滤。命中屏蔽词时消息被拦截，发送者收到系统提示。
