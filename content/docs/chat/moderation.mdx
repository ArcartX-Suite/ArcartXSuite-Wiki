# 管理与审核

> **付费模块**

Chat 模块提供完整的管理与审核工具链，包括禁言管理、社交监听、忽略列表、内容审核、发言冷却与重复检测，以及强制接管模式。

## 禁言系统

禁言系统允许管理员禁止指定玩家在聊天中发言，支持临时禁言（按时长）与永久禁言，禁言记录持久化到数据库。

### 禁言命令

| 命令 | 说明 | 权限 |
|---|---|---|
| `/axs chat mute <玩家> <时长> [原因]` | 禁言指定玩家 | `ArcartXSuite.chat.mute` |
| `/axs chat unmute <玩家>` | 解除指定玩家的禁言 | `ArcartXSuite.chat.mute` |

时长格式为 `<数字><单位>`，单位支持 `s`（秒）、`m`（分）、`h`（时）、`d`（天），或 `permanent` 永久禁言：

```yaml
/axs chat mute Steve 30m 刷屏        # 禁言 30 分钟，原因"刷屏"
/axs chat mute Steve 7d 广告         # 禁言 7 天，原因"广告"
/axs chat mute Steve permanent 恶意行为  # 永久禁言
```

| 输入 | 解析结果 |
|---|---|
| `permanent` | 永久禁言 |
| `30s` / `30m` / `12h` / `7d` | 对应时长后过期 |
| 非法格式 | 默认 1 天后过期 |

<Callout type="warn">
无法解析的时长格式不会报错，而是默认禁言 1 天。请确保时长格式正确。
</Callout>

### 禁言效果

- 被禁言玩家发言时会收到系统提示（聊天卡片或文本消息），显示剩余时间与原因
- 禁言记录包含操作者、原因与过期时间，过期后自动解除
- 其他模块（如 Essentials）可委托 Chat 执行禁言/解禁与查询

## 社交监听

社交监听（SocialSpy）允许管理员查看全服私聊内容，使用 `spy-format` 模板渲染。

### 玩家命令

| 命令 | 说明 | 权限 |
|---|---|---|
| `/chat socialspy` | 切换社交监听 | `arcartxsuite.chat.socialspy` |
| `/chat socialspy on` | 开启社交监听 | `arcartxsuite.chat.socialspy` |
| `/chat socialspy off` | 关闭社交监听 | `arcartxsuite.chat.socialspy` |

### 管理员命令

管理员可设置其他玩家的社交监听开关：

```yaml
/axs chat spy Steve on    # 开启 Steve 的社交监听
/axs chat spy Steve off   # 关闭 Steve 的社交监听
```

被操作的玩家会收到通知消息，告知其社交监听已被管理员变更。

<Callout type="info">
监听者不会收到自己参与的私聊的重复提示。监听消息使用 `spy-format` 模板渲染（如 `&5[监听 {player_name} -> {target_name}] &r{message}`），与私聊双方看到的格式不同。
</Callout>

## 忽略列表

玩家可忽略指定玩家的消息。忽略关系双向生效：你忽略的人发消息你收不到，你给被忽略的人发消息也会被拦截。

| 命令 | 说明 | 权限 |
|---|---|---|
| `/chat ignore <玩家>` | 忽略指定玩家 | `arcartxsuite.chat.use` |
| `/chat unignore <玩家>` | 取消忽略指定玩家 | `arcartxsuite.chat.use` |

忽略对频道消息、私聊与跨服私聊均生效。忽略列表持久化存储，玩家下次登录自动生效。

## 内容审核

消息会经过敏感词过滤。命中屏蔽词时消息被拦截，发送者收到系统提示。

<Callout type="warn">
敏感词过滤统一配置在宿主 `config.yml` 的 `moderation` 节。模块内 `filter` 配置节仅作向后兼容保留，不再生效。请在 `plugins/ArcartX-Suite/config.yml` 中配置全局敏感词过滤（支持标点穿透防护、白名单、多 URL 云端词库）。
</Callout>

## 发言冷却

限制玩家连续发送消息的频率：

| 配置 | 默认值 | 说明 |
|---|---|---|
| `settings.cooldown-millis` | `750` | 冷却时间（毫秒），设为 0 关闭冷却 |

冷却触发时玩家发言被拒绝并收到提示。

## 重复消息检测

防止玩家在短时间内发送相同内容的消息：

| 配置 | 默认值 | 说明 |
|---|---|---|
| `settings.duplicate-window-millis` | `4000` | 重复判定窗口（毫秒），设为 0 关闭检测 |

判定前会对消息做规范化处理（去除颜色代码、压缩空白、忽略大小写），只有内容真正不同的消息才视为非重复。

<Callout type="info">
冷却检测和重复检测独立工作：冷却检测限制发送频率，重复检测限制相同内容。两者均可通过设为 0 分别关闭。
</Callout>

## 强制接管模式

`force-takeover` 模式可强制接管其他聊天插件的消息广播，解决消息被改写、重复或复用旧消息的问题。

```yaml
compatibility:
  other-chat-plugins:
    force-takeover: false
```

| 值 | 行为 |
|---|---|
| `false`（默认） | 正常拦截聊天事件并自行分发 |
| `true` | 更激进地抢占聊天事件并阻止其他插件广播 |

<Callout type="warn">
`force-takeover: true` 会优先抢占聊天事件，可能导致其他依赖聊天事件的插件无法正常工作。仅在服务器安装其他聊天插件并出现冲突时开启。模块兼容 Paper / Purpur、Spigot、Mohist / Arclight 等服务端。
</Callout>
