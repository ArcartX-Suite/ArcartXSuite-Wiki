# 联动

Chat 模块通过 EventBus、跨服通道等机制与其他模块和外部系统联动。

## EventBus 事件

Chat 模块在玩家成功发送频道消息时发布事件，其他模块可通过 EventBus 监听实现联动（如任务进度）。

| 事件 Topic | 触发时机 | Payload |
|---|---|---|
| `axs.chat.chat_message_sent` | 玩家发送频道消息成功 | `channel_id`（频道 ID）、`type`（消息类型，当前为 `channel`） |

<Callout type="info">
私聊消息不发布 EventBus 事件。EventBus 不可用时事件不发布，不影响 Chat 正常运行。
</Callout>

## 模块集成

### Essentials 模块

Essentials 可委托 Chat 处理禁言：

| 集成点 | 说明 |
|---|---|
| 禁言命令 | Essentials 的 `/mute` 命令可委托给 Chat 统一处理 |
| 解除禁言 | Essentials 的 `/unmute` 命令可委托给 Chat |
| 禁言查询 | 查询玩家禁言状态与禁言列表 |

### Tooltip 模块

Tooltip 模块可用时，`[item]` 物品展示会注入动态 tooltip Lore，使客户端 UI 显示 TACZ 枪属性、Apotheosis affix 等完整物品信息。Tooltip 不可用时物品照常展示，仅无动态 Lore。

### Tab 模块

频道切换、私聊/提及接收开关、社交监听开关、忽略、禁言、发送私聊等操作后，自动刷新 Tab 显示。

## 跨服转发

频道配置 `cross-server: true` 后，消息通过宿主跨服通道同步到其他子服，私聊与频道消息均支持。

<Callout type="info">
跨服转发需要宿主 `config.yml` 的 `cross-server` 节配置 Redis 或 Proxy 后端，详见 [跨服部署](/docs/guide/cross-server-setup)。消息自动去重，不会重复展示。
</Callout>

## 数据管理

- `/axs purge` 可清理玩家聊天数据（频道状态、禁言记录、忽略列表、玩家档案）
- `/axs migrate` 支持 SQLite 与 MySQL 之间迁移聊天数据
