# 聊天格式化

> **付费模块**

Chat 模块将频道格式模板渲染为最终消息文本，并处理物品展示、颜色转义、消息换行等增强功能。

## 模板渲染

格式模板按以下顺序处理：

1. **变量替换** — 将 `{变量名}` 占位符替换为实际值
2. **PAPI 解析** — 按聊天上下文（发送者玩家）解析 PlaceholderAPI 占位符
3. **颜色转义** — 将 `&` 颜色代码转为 Minecraft 颜色代码

### 格式模板变量

所有格式模板均可使用：

| 变量 | 说明 | 示例 |
|---|---|---|
| `{channel}` | 频道显示名称 | `全服` |
| `{player_name}` | 发送者名称 | `Steve` |
| `{player_display_name}` | 发送者显示名称 | `Steve` |
| `{target_name}` | 私聊目标名称（非私聊为空） | `Alex` |
| `{message}` | 消息内容 | `你好，一起去挖矿吗？` |

### 物品展示变量

物品展示格式（`function.item.format`）使用独立的变量集：

| 变量 | 说明 | 示例 |
|---|---|---|
| `{item_name}` | 物品名称 | `钻石剑` |
| `{item_amount}` | 物品数量 | `1` |
| `{item_material}` | 物品材质键 | `minecraft:diamond_sword` |

<Callout type="info">
物品名称优先解析为原版中文名，不可用时回退到物品自定义名称，再回退到材质键格式化名称。
</Callout>

## 颜色代码

模板中支持标准 `&` 颜色代码：

| 代码 | 颜色 | 代码 | 颜色 |
|---|---|---|---|
| `&0` | 黑色 | `&a` | 绿色 |
| `&1` | 深蓝 | `&b` | 青色 |
| `&2` | 深绿 | `&c` | 红色 |
| `&3` | 深青 | `&d` | 粉色 |
| `&4` | 深红 | `&e` | 黄色 |
| `&5` | 紫色 | `&f` | 白色 |
| `&6` | 金色 | `&r` | 重置 |
| `&7` | 灰色 | `&k` | 随机字符 |
| `&8` | 深灰 | `&l` | 粗体 |
| `&9` | 蓝色 | `&o` | 斜体 |
| `&n` | 下划线 | `&m` | 删除线 |

## 自定义组件

自定义组件通过正则匹配聊天消息中的特定文本并替换为自定义内容，可实现表情符号、关键词高亮等扩展功能。

### 配置结构

`function.custom-components` 是一个动态节，用户可自由增删条目：

```yaml
function:
  custom-components:
    star:
      enabled: true
      pattern: ":star:"
      replacement: "★"
    heart:
      enabled: true
      pattern: ":heart:"
      replacement: "❤"
    highlight:
      enabled: true
      pattern: "(?i)important"
      replacement: "&c[重要]&r"
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `enabled` | `boolean` | 是否启用此组件 |
| `pattern` | `string` | 匹配正则表达式（Java 正则语法） |
| `replacement` | `string` | 替换文本（支持 `&` 颜色码） |

<Callout type="warn">
`pattern` 必须是合法的 Java 正则表达式，非法正则会跳过并输出警告日志。`replacement` 中的 `$` 和 `\` 具有特殊含义（反向引用），如需字面量请进行转义。
</Callout>

<Callout type="info">
自定义组件在敏感词过滤之前按配置顺序依次应用，前一个组件的替换结果会作为后一个组件的输入，组件顺序可能影响最终结果。
</Callout>

## 物品展示

物品展示功能允许玩家在聊天中展示手持物品，通过 `[item]` 占位标记触发（可自定义 `function.item.token`）。

| 场景 | 处理方式 |
|---|---|
| 手持物品有效 | 消息中显示物品展示文本，其他玩家悬停可预览物品 |
| 手持空气或无效 | 显示 `failed-format` 配置的文本（如 `&c[物品不可用]`） |
| 功能未启用 | `[item]` 作为普通文本发送 |

<Callout type="info">
物品展示支持 Tooltip 模块注入动态 tooltip Lore（如 TACZ 枪属性、Apotheosis affix）。
</Callout>

## 消息换行

聊天卡片中的消息文本按配置的行宽自动换行，换行时保留当前生效的颜色代码：

| 字段 | 默认值 | 说明 |
|---|---|---|
| `cards.char-width-full` | `31` | 全角字符（中文等）占位宽度 |
| `cards.char-width-half` | `18` | 半角字符（英文/数字等）占位宽度 |
| `cards.max-line-width` | `750` | 文字区最大宽度（超过此值自动换行） |

单条消息最多换行 10 行显示。

## 重复消息判定

重复检测会先对消息做规范化处理：去除颜色代码、压缩连续空白、忽略大小写。规范化后内容相同的消息才视为重复。

<Callout type="info">
重复检测窗口由 `settings.duplicate-window-millis` 配置（默认 4000 毫秒）。设为 0 可关闭重复检测。详见 [管理与审核](/docs/chat/moderation)。
</Callout>
