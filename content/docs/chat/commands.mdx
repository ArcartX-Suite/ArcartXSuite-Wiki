## 玩家命令

Chat 模块注册了三个玩家命令（`/chat` 别名 `/axschat`，`/msg` 别名 `/axsmsg`，`/reply` 别名 `/r`、`/axsreply`），通过 `TabExecutor` 实现自动补全。所有玩家命令仅限玩家执行（控制台执行会提示）。

### /chat 频道管理

| 命令 | 说明 | 权限 |
|---|---|---|
| `/chat` | 查看当前频道、开关状态、回复目标与忽略数 | `arcartxsuite.chat.use` |
| `/chat help` | 显示聊天命令帮助 | `arcartxsuite.chat.use` |
| `/chat channel <频道ID>` | 切换到指定频道 | `arcartxsuite.chat.use` + 频道 `send-permission` |
| `/chat toggle <private\|mentions> [on\|off]` | 切换私聊接收 / 提及接收开关 | `arcartxsuite.chat.use` |
| `/chat ignore <玩家>` | 忽略指定玩家的私聊 | `arcartxsuite.chat.use` |
| `/chat unignore <玩家>` | 取消忽略指定玩家 | `arcartxsuite.chat.use` |
| `/chat socialspy [on\|off]` | 切换社交监听（监听全服私聊） | `arcartxsuite.chat.socialspy` |
| `/chat redpacket <normal\|lucky> <总金额> <个数> [祝福语]` | 发送货币红包（`normal` 均分 / `lucky` 拼手气） | `arcartxsuite.chat.use` + `redpacket.send-permission`（若配置） |
| `/chat grab <红包ID>` | 抢红包（也可直接点击红包卡片/文字按钮） | `arcartxsuite.chat.use` + `redpacket.claim-permission`（若配置） |

#### /chat（无参数）

查看当前聊天状态，输出三行信息：

```
当前频道: 普通
私聊接收 / 提及接收 / 社交监听: true / true / false
最近私聊对象 / 忽略数: Steve / 3
```

#### 切换聊天频道（/chat channel）

切换到指定频道。频道 ID 不区分大小写。需要频道 `send-permission` 权限。

```
/chat channel global    # 切换到全服频道
/chat channel staff     # 切换到管理频道
```

#### 调整私聊与提及接收（/chat toggle）

切换私聊接收或提及接收开关。不传 `on|off` 时切换当前状态。

```
/chat toggle private        # 切换私聊接收
/chat toggle mentions off   # 关闭提及接收
```

#### 切换社交监听（/chat socialspy）

切换社交监听。开启后可看到全服私聊内容（使用 `spy-format` 格式渲染）。需要 `arcartxsuite.chat.socialspy` 权限。

```
/chat socialspy         # 切换社交监听
/chat socialspy on      # 开启社交监听
```

### /msg 私聊

| 命令 | 说明 | 权限 |
|---|---|---|
| `/msg <玩家> <消息>` | 向指定玩家发送私聊消息 | `arcartxsuite.chat.msg` |

```
/msg Steve 你好，一起去挖矿吗？
```

<Callout type="info">
私聊消息使用私聊频道的 `sender-format`（发送者视角）和 `recipient-format`（接收者视角）渲染。如果私聊频道配置了 `cross-server: true` 且跨服通道活跃，私聊可跨服送达。
</Callout>

### /reply 回复

| 命令 | 说明 | 权限 |
|---|---|---|
| `/reply <消息>` | 回复最近一次私聊的对方 | `arcartxsuite.chat.msg` |

```
/reply 好的，马上过去
```

<Callout type="info">
`/reply` 会自动回复最近一次私聊的对象。如果还没有私聊过任何人，会提示"当前没有可回复的私聊对象"。
</Callout>

## 管理员命令

管理员命令通过 `/axs chat <子命令>` 执行，需要 `ArcartXSuite.chat.mute` 权限（spy 命令）或管理员权限。

| 命令 | 说明 | 权限 |
|---|---|---|
| `/axs chat help` | 显示管理命令帮助 | `arcartxsuite.admin` |
| `/axs chat status` | 查看模块运行状态 | `arcartxsuite.admin` |
| `/axs chat mute <玩家> <时长> [原因]` | 禁言指定玩家 | `arcartxsuite.admin` |
| `/axs chat unmute <玩家>` | 解除指定玩家的禁言 | `arcartxsuite.admin` |
| `/axs chat spy <玩家> <on\|off>` | 设置指定玩家的社交监听开关 | `arcartxsuite.admin` |
| `/axs chat redpacket <normal\|lucky> <金额> <个数> [祝福语]` | 发放免扣款货币红包（不扣管理员余额） | `arcartxsuite.admin` + `redpacket.admin-permission`（若配置） |
| `/axs chat redpacket <预设ID> [个数]` | 发放预设奖励池红包（预设见 `chat/redpackets/` 目录） | `arcartxsuite.admin` + `redpacket.admin-permission`（若配置） |
| `/axs chat redpacket list` | 列出所有可用红包预设 | `arcartxsuite.admin` |
| `/axs chat redpacket reload` | 重新加载红包预设文件 | `arcartxsuite.admin` |

### 查看聊天模块状态（/axs chat status）

查看 Chat 模块运行状态：

```
Chat 状态
频道数: 4
缓存状态: 15
缓存禁言: 2
跨服通道: 已启用
```

### 禁言玩家（/axs chat mute）

禁言指定玩家。时长格式为 `<数字><单位>`，单位支持 `s`（秒）、`m`（分）、`h`（时）、`d`（天），或 `permanent` 永久禁言。

```
/axs chat mute Steve 30m 刷屏
/axs chat mute Steve 7d 广告
/axs chat mute Steve permanent 恶意行为
```

| 参数 | 必填 | 说明 |
|---|---|---|
| 玩家 | 是 | 被禁言的玩家名（支持离线玩家，通过档案查询） |
| 时长 | 是 | 禁言时长：`<数字><s\|m\|h\|d>` 或 `permanent` |
| 原因 | 否 | 禁言原因，显示在禁言通知卡片中 |

### 解除玩家禁言（/axs chat unmute）

解除指定玩家的禁言。

```
/axs chat unmute Steve
```

### 管理社交监听（/axs chat spy）

设置指定玩家的社交监听开关。玩家会收到通知消息告知其社交监听已被管理员变更。

```
/axs chat spy Steve on
/axs chat spy Steve off
```

## 红包系统

**红包类型**：

| 类型 | 说明 | 发送方式 |
|---|---|---|
| `normal` | 普通红包：总金额平分为指定份数 | 玩家 `/chat redpacket normal ...`（扣余额）/ 管理员 `/axs chat redpacket normal ...`（免扣款） |
| `lucky` | 拼手气红包：总金额随机分配 | 同上，类型写 `lucky` |
| 预设红包（`pool`） | 从 `chat/redpackets/` 奖励池按权重抽取货币/物品/指令奖励 | 仅管理员 `/axs chat redpacket <预设ID> [个数]` |

**预设红包文件**：`chat/redpackets/*.yml`，每文件一个 `preset` 节：

```yaml
preset:
  id: "newyear"            # 预设 ID（缺省取文件名）
  enabled: true
  display-name: "新年红包"  # 显示名
  wish: "恭喜发财"          # 卡片祝福语
  count: 5                  # 份数（命令行可覆盖；无放回时受奖励池总量收缩）
  replacement: false        # 是否有放回抽取
  expire-minutes: 0         # 过期分钟数，0 = 使用全局配置
  rewards:                  # 奖励池条目
    - type: currency        # currency / item / command
      weight: 3             # 抽取权重
      quantity: 2           # 数量（无放回时占用池位）
      currency: "money"
      amount: "100"
      description: "100 金币"   # 缺省自动生成
    - type: item
      source: minecraft     # 支持 mythic/neige/overture/mmoitems
      id: "DIAMOND"
      amount: 1
      weight: 1
    - type: command
      command: "give {player} apple 1"
      weight: 1
```

**规则与限制**（均可在 `redpacket` 配置节调整）：金额上下限、每份最小金额、最大份数、发送冷却、过期时间、过期退款（仅玩家货币红包）、发送者可否自领、领取播报与手气王播报等。

## 权限节点

| 权限节点 | 说明 | 默认 |
|---|---|---|
| `arcartxsuite.chat.use` | 使用 `/chat` 命令（频道切换、开关、忽略） | 所有玩家 |
| `arcartxsuite.chat.msg` | 使用 `/msg` 和 `/reply` 私聊命令 | 所有玩家 |
| `arcartxsuite.chat.socialspy` | 使用 `/chat socialspy` 切换社交监听 | 管理员 |
| `arcartxsuite.admin` | 使用 `/axs chat` 管理命令，包括禁言、解禁和管理社交监听 | OP |

<Callout type="info">
频道的 `send-permission` 和 `receive-permission` 可自定义权限节点。例如管理频道可设为 `ArcartXSuite.chat.mute`，仅管理员可发送和接收。
</Callout>
