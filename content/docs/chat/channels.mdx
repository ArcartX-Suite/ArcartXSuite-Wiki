# 频道系统

> **付费模块**

频道（Channel）是 Chat 模块的核心概念。每个频道是一个独立的聊天空间，拥有自己的模式、权限、格式模板和跨服策略。玩家同一时间只处于一个频道中，通过 `/chat channel <频道ID>` 切换。

## 频道模式

Chat 模块支持四种频道模式：

| 模式 | 配置值 | 跨服默认 | 典型场景 |
|---|---|---|---|
| 普通 | `normal` | `false` | 默认聊天频道，支持 `range` 距离限制实现附近聊天 |
| 全局 | `global` | `true` | 全服公共频道，跨服广播 |
| 私聊 | `private` | `true` | 一对一私聊，`/msg` 与 `/reply` 复用此频道格式 |
| 管理 | `staff` | `true` | 管理员内部频道，仅限有权限的玩家发送与接收 |

<Callout type="info">
`cross-server` 字段未显式配置时，`global` 和 `staff` 模式默认开启跨服同步，`normal` 和 `private` 模式默认关闭。无法识别的 `mode` 值按 `normal` 处理。
</Callout>

## 频道定义字段

每个频道由 `chat/channels/` 目录下的 yml 文件定义：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | `boolean` | `true` | 是否启用此频道 |
| `display-name` | `string` | 文件名 | UI / 消息中显示的频道名 |
| `mode` | `string` | `normal` | 频道模式 |
| `send-permission` | `string` | `""` | 发送所需权限，空串表示无限制 |
| `receive-permission` | `string` | 继承 `send-permission` | 接收所需权限 |
| `cross-server` | `boolean` | `mode` 为 `global`/`staff` 时 `true` | 是否跨服传输 |
| `range` | `double` | `0` | 本地聊天半径（0 表示全图），仅 `normal` 模式生效 |
| `format` | `string` | `&7[{channel}] &f{player_name}&7: &r{message}` | 常规消息格式模板 |
| `console-format` | `string` | `[{channel}] {player_name}: {message}` | 控制台消息格式模板 |
| `sender-format` | `string` | `&d[私聊 -> {target_name}] ...` | 私聊发送者视角格式模板 |
| `recipient-format` | `string` | `&d[私聊 <- {player_name}] ...` | 私聊接收者视角格式模板 |
| `spy-format` | `string` | `&5[监听 {player_name} -> {target_name}] ...` | 监听视角格式模板 |

<Callout type="info">
`receive-permission` 未配置时自动继承 `send-permission` 的值。如需让更多玩家能接收但仅少数能发送，可分别配置两个字段。发送者始终能看到自己发送的消息，不受接收权限限制。
</Callout>

## 频道文件

- 频道定义文件位于 `channels-directory` 指定的目录下（默认 `chat/channels/`）
- 文件名（去掉 `.yml` 后缀）即为频道 ID，自动转为小写
- `enabled: false` 的频道会被跳过
- 首次启动时自动释放 `Normal.yml`、`Global.yml`、`Private.yml`、`Staff.yml` 四个默认频道
- `settings.default-channel` 指定玩家首次加入时的默认频道；配置的 ID 不存在时自动回退到首个有效频道

<Callout type="warn">
如果频道目录为空（没有任何 `.yml` 文件），所有聊天功能将不可用。
</Callout>

## 范围聊天

`normal` 模式频道支持 `range` 字段实现附近聊天。当 `range` 大于 0 时，消息仅发送给**同世界**且距离发送者 `range` 格内的玩家；`range: 0` 为全图广播。

<Callout type="info">
范围聊天仅对 `normal` 模式生效。`global`、`staff` 模式忽略 `range` 字段，`private` 模式不涉及范围判定。
</Callout>

### 范围聊天配置示例

```yaml
# 附近频道示例：仅 50 格内玩家可见
enabled: true
display-name: "附近"
mode: "normal"
send-permission: ""
receive-permission: ""
cross-server: false
range: 50
format: "&8[附近] &f{player_name}&7: &r{message}"
console-format: "[附近] {player_name}: {message}"
sender-format: "&d[私聊 -> {target_name}] &f{player_name}&7: &r{message}"
recipient-format: "&d[私聊 <- {player_name}] &f{player_name}&7: &r{message}"
spy-format: "&5[监听 {player_name} -> {target_name}] &r{message}"
```

## 权限模型

频道权限分为发送权限和接收权限：

- **发送权限**：发送消息与切换频道时校验 `send-permission`，空串表示无限制
- **接收权限**：接收消息时校验 `receive-permission`，未配置时继承 `send-permission`

<Callout type="info">
频道切换仅校验 `send-permission`，不校验 `receive-permission`。这意味着玩家可以切换到一个自己无法接收的频道（但发送时会被 `send-permission` 拦截）。
</Callout>

## 跨服同步

频道配置 `cross-server: true` 后开启跨服消息转发，私聊与频道消息均可跨服送达，消息自动去重不会重复展示。

<Callout type="info">
跨服转发需要宿主 `config.yml` 的 `cross-server` 节配置 Redis 或 Proxy 后端，单服无需开启。详见 [跨服部署](/docs/guide/cross-server-setup)。
</Callout>

## 频道切换

玩家通过 `/chat channel <频道ID>` 切换当前频道。切换时校验 `send-permission`，成功后保存到玩家数据并刷新 Tab 显示。
