## 启用界面

在 `plugins/ArcartX-Suite/data/vanilla/config.yml` 中合并以下设置，执行 `/axs reload vanilla`：

```yaml
beacon:
  enabled: true
  push-interval-ticks: 2
hopper:
  enabled: true
  push-interval-ticks: 2
dispenser:
  enabled: true
  push-interval-ticks: 2
```

右键对应方块即可打开。发射器与投掷器共用 `dispenser` 开关和界面模板，实际名称及说明随打开的容器变化。关闭对应开关后恢复原版界面。

无需 Warehouse 也能使用。启用 Warehouse 时右侧显示个人仓库，否则显示操作指引；布局在打开前确定。

## 信标

1. 先检查信标基座和光束，界面显示当前基座等级。
2. 选择主效果；四级基座还可选择生命恢复，或将主效果提升为 II 级。
3. 在支付槽放入一个铁锭、金锭、绿宝石、钻石或下界合金锭，也可点击对应材料按钮补足一个。
4. 点击“确认设置”。确认前的选择不会直接消耗材料；确认后查看当前效果与支付槽。

补足优先使用背包，再使用可用的个人仓库。替换旧支付物品前需有空间将其退回背包。实际效果、支付消耗和其他插件对操作的修改由服务端处理。

关闭信标时，未使用的支付物品按原版退回。Warehouse 自动存入开启时，背包装不下的部分尝试入库；未开启、拒收或放不下的剩余部分按原版处理。异常取料记录见[自动存入与材料恢复](/docs/warehouse/material-recovery)。

## 漏斗

左侧五格是真实漏斗物品槽，可与下方背包、快捷栏正常取放。界面显示已用槽位、物品总量，以及自动传输是否被红石锁定。

吸取、输出方向、速度和红石锁定仍按原版及服务端规则运行。打开或关闭界面都不会把漏斗库存清空，也不会自动搬入仓库。

## 发射器与投掷器

左侧九格是真实容器物品槽。界面显示库存占用与当前容器的行为说明：

| 容器 | 收到红石脉冲后的行为 |
| --- | --- |
| 发射器 | 按原版规则使用或发射对应物品 |
| 投掷器 | 按原版投出物品，或传入前方容器 |

红石触发、朝向和物品用途继续由原版及服务端插件处理。关闭后物品保留在原容器内。

## 仓库取放

启用 Warehouse 后，可搜索、分类、排序和翻页。左键取一组、右键取半组；拿着物品时可点击存入区存回仓库，再将光标上的物品放进真实容器槽。

没有 Warehouse 时仍可直接使用背包和容器物品，不影响红石行为或信标设置。
