## 玩家命令

原版容器替换无需单独玩家命令。玩家打开已启用的工作台、熔炉、高炉、烟熏炉、切石机、锻造台、酿造台、村民交易、铁砧、附魔台、砂轮、织布机或制图台时自动显示替换界面。材料转移记录的查询、导出与人工确认由 [Warehouse 管理命令](/docs/warehouse/material-recovery) 提供。

| 交互方式 | 触发条件 | 说明 |
| --- | --- | --- |
| 打开工作台 | 右键工作台方块 | 自动呈现 ArcartX UI 工作台界面 |
| 打开熔炉 | 右键熔炉方块 | 自动呈现 ArcartX UI 熔炉界面 |
| 打开高炉或烟熏炉 | 右键对应方块 | 查看专用烧炼配方和加工进度 |
| 打开切石机 | 右键切石机 | 选择切割成品并填入石材 |
| 打开锻造台 | 右键锻造台 | 先放入目标装备，再选择升级或纹饰方案补齐辅材 |
| 打开铁砧 | 右键铁砧 | 放入目标及材料，确认名称和费用后取出产物 |
| 打开附魔台 | 右键附魔台 | 放入装备或书、补足青金石，选择附魔选项 |
| 打开砂轮 | 右键砂轮 | 放入物品，检查产物后完成修复或祛魔 |
| 打开织布机 | 右键织布机 | 放入旗帜和染料，选择纹样后从产物槽领取 |
| 打开制图台 | 右键制图台 | 放入已绘制地图，补足材料后从产物槽领取 |
| 切换侧栏 | 点击配方书或仓库按钮 | 配方类界面在配方书与仓库之间切换；其他界面无仓库时显示指引 |
| 搜索配方 | 在搜索框输入文本 | 实时过滤配方列表（中英文模糊匹配） |
| 仓库分类与排序 | 展开选择列表 | 直接选择 Warehouse 配置的筛选项 |
| 选中配方 | 左键点击配方图标 | 显示材料预览和配方产出数量 |
| 填入材料 | 右键配方或点击填入按钮 | 从工作区、储物栏及可用个人仓库补齐一份 |
| 切换显示模式 | 点击显示切换按钮 | 切换"显示全部"与"仅显示可合成" |

## 管理命令

容器替换的重载与模块状态通过 Suite `/axs` 命令统一管理，NPC 兑换命令见下方：

| 命令 | 权限 | 说明 |
| --- | --- | --- |
| `/axs reload vanilla` | `arcartxsuite.admin` | 重载 VanillaUI 模块配置与 UI 文件 |
| `/axs reload all` | `arcartxsuite.admin` | 重载本体配置 + 全部模块（含 VanillaUI） |
| `/axs status` | `arcartxsuite.admin` | 查看全部模块运行状态（含 VanillaUI） |

> `/axs reload vanilla` 会重新加载 `config.yml` 配置文件，并根据 `ui.overwrite-ui-files` 决定是否覆盖 UI 文件。reload 后工作台/熔炉 UI 立即生效，正在使用 UI 的玩家需重新打开界面。

## 权限

| 权限节点 | 默认 | 说明 |
| --- | --- | --- |
| `arcartxsuite.admin` | OP | 执行 `/axs reload vanilla` 等管理命令 |
| `arcartxsuite.module.vanilla` | OP | 模块级管理权限（预留） |

> VanillaUI 模块本身不定义独立权限节点。玩家使用工作台/熔炉界面替换功能无需任何权限，所有在线玩家均可使用。

## NPC 兑换管理

以下命令的管理操作需要 `arcartxsuite.vanilla.admin`。兑换所和条目还可单独设置玩家使用权限。

| 命令 | 用途 |
| --- | --- |
| `/axs vanilla open <兑换所ID>` | 打开兑换页，仍需满足使用条件 |
| `/axs vanilla edit [兑换所ID]` | 打开游戏内编辑器 |
| `/axs vanilla ledger [玩家UUID]` | 查询待核对兑换记录 |
| `/axs vanilla evidence <凭证UUID>` | 导出完整兑换凭证 |
| `/axs vanilla confirm <凭证UUID> confirm` | 人工核对后结案，不发放或退回资产 |
| `/axs vanilla status` | 查看界面服务状态 |

也可在编辑器顶部使用“交易核对”，输入凭证 UUID 后导出或结案。详细步骤见 [NPC 兑换与在线编辑](/docs/vanilla/npc-trading)。

## UI 自定义说明

导出的界面文件位于 `plugins/ArcartX-Suite/ui/`，十三种原版界面及 NPC 界面的文件名见[功能配置](/docs/vanilla/configuration)。修改后通过 `/axs reload vanilla` 重载生效；开启 `ui.overwrite-ui-files` 会覆盖为默认模板，修改前请备份。
