## 玩家命令

玩家打开已启用的原版容器时会看到替换界面。使用 `/axs vanilla backpack` 打开[随身背包](/docs/vanilla/backpack)。材料转移凭证可在 [Warehouse 管理命令](/docs/warehouse/material-recovery) 中查询、导出与确认。

| 交互方式 | 触发条件 | 说明 |
| --- | --- | --- |
| 打开工作台 | 右键工作台方块 | 自动呈现 ArcartX UI 工作台界面 |
| 打开熔炉 | 右键熔炉方块 | 自动呈现 ArcartX UI 熔炉界面 |
| 切换侧栏 | 点击配方书或仓库按钮 | 在配方书与仓库之间切换；无仓库时显示配方书 |
| 搜索配方 | 在搜索框输入文本 | 实时过滤配方列表（中英文模糊匹配） |
| 仓库分类与排序 | 展开选择列表 | 直接选择 Warehouse 配置的筛选项 |
| 选中配方 | 左键点击配方图标 | 显示材料预览和配方产出数量 |
| 填入材料 | 右键配方或点击填入按钮 | 从工作区、储物栏及可用个人仓库补齐一份 |
| 切换显示模式 | 点击显示切换按钮 | 切换"显示全部"与"仅显示可合成" |

## 管理命令

通过 Suite 的 `/axs` 命令管理界面、随身背包和配方。

| 命令 | 权限 | 说明 |
| --- | --- | --- |
| `/axs reload vanilla` | `arcartxsuite.admin` | 重载 VanillaUI 模块配置与 UI 文件 |
| `/axs reload all` | `arcartxsuite.admin` | 重载本体配置 + 全部模块（含 VanillaUI） |
| `/axs status` | `arcartxsuite.admin` | 查看全部模块运行状态（含 VanillaUI） |
| `/axs vanilla backpack help` | `arcartxsuite.vanilla.backpack.admin` | 查询背包状态与容量管理命令 |
| `/axs vanilla recipes` | `arcartxsuite.vanilla.recipe.admin` | 打开配方编辑器 |
| `/axs vanilla recipes reload` | `arcartxsuite.vanilla.recipe.admin` | 重载配方文件 |

> `/axs reload vanilla` 会重新加载 `config.yml` 配置文件，并根据 `ui.overwrite-ui-files` 决定是否覆盖 UI 文件。reload 后工作台/熔炉 UI 立即生效，正在使用 UI 的玩家需重新打开界面。

## 权限

| 权限节点 | 默认 | 说明 |
| --- | --- | --- |
| `arcartxsuite.admin` | OP | 执行 `/axs reload vanilla` 等管理命令 |
| `arcartxsuite.vanilla.backpack.admin` | OP | 查看和调整背包的个人仓库容量 |
| `arcartxsuite.vanilla.recipe.admin` | OP | 打开配方编辑器或重载配方 |

玩家可直接使用已启用的替换界面。随身背包的个人仓库存取遵循 Warehouse 的权限及二级密码要求。

## UI 自定义说明

界面文件 `ui/vanilla_crafting.yml` 与 `ui/vanilla_furnace.yml` 可自定义外观（颜色、布局、文字等）。修改后通过 `/axs reload vanilla` 重载生效；开启 `ui.overwrite-ui-files` 会覆盖为默认模板。
