## 启用界面

在 `plugins/ArcartX-Suite/data/vanilla/config.yml` 中设置对应开关，执行 `/axs reload vanilla`：

```yaml
grindstone:
  enabled: true
  push-interval-ticks: 2
loom:
  enabled: true
  push-interval-ticks: 2
cartography:
  enabled: true
  push-interval-ticks: 2
```

右键对应方块打开。三种界面独立启用，关闭某项后恢复对应原版界面。无需 Warehouse 即可使用；启用 Warehouse 时显示个人仓库，未启用时显示操作指引，打开前已确定布局。

## 砂轮

1. 将装备或附魔书放入第一个输入槽。
2. 需要修复时，可在第二格放入同类物品。
3. 检查真实产物槽中的耐久、名称和附魔，再取出结果。

砂轮按原版规则移除非诅咒附魔，诅咒不会被移除。材料消耗、修复结果和经验返还由服务端处理；界面不会自行生成成品或发放经验。

## 织布机

1. 将目标旗帜放入第一格。
2. 放入染料，或点击色块补足一个对应染料。补足优先使用背包，再使用可用的个人仓库。
3. 在纹样卡中选择需要的样式。纹样较多时可翻页，每张卡显示旗帜预览与名称。
4. 从真实产物槽领取旗帜，才会消耗旗帜与染料。

特殊旗帜图案放入第三格，可用纹样随当前输入更新。特殊图案是否消耗、旗帜层数限制及最终产物遵循原版规则。更换旗帜或材料后，请以更新后的列表为准。

系统保留玩家放入的旗帜及图案，不会自动从仓库挑另一面旗帜。补足前，旧染料需要有空间退回背包；背包装不下时不继续取料。

## 制图台

先将**已绘制的地图**放入第一格，再选择加工方式：

| 操作 | 第二格材料 | 结果 |
| --- | --- | --- |
| 扩展地图 | 纸 | 扩大地图范围，最高比例为 4 |
| 复制地图 | 空地图 | 复制当前地图 |
| 锁定地图 | 玻璃板 | 锁定地图内容，不能继续扩展 |

可手动放入材料，也可点击对应按钮补足一个。补足优先使用背包，再使用可用个人仓库。**按钮只补料，需从真实产物槽领取结果才完成加工。**

界面显示地图编号、比例与锁定状态。目标地图始终由玩家选择；加工结果以真实产物槽和服务端规则为准。

## 仓库取放与关闭

仓库支持搜索、分类、排序、翻页，以及默认排序下的置顶。左键取一组、右键取半组，拿着物品时可点击存入区存回。没有 Warehouse 时，材料直接从真实背包取放。

关闭三种界面时，输入材料先按原版规则退回背包。开启 Warehouse 自动存入后，背包装不下的部分尝试入库；未开启、拒收或仓库放不下的部分按原版掉落。产物预览不会被当作额外成品存入仓库。

从仓库补足材料时，中断后的不确定转移保留凭证，不自动重复补发。处理方法见[自动存入与材料恢复](/docs/warehouse/material-recovery)。

## 常见问题

| 情况 | 检查方法 |
| --- | --- |
| 织布机没有纹样 | 检查旗帜、染料、特殊图案，以及是否达到原版层数上限 |
| 制图台无法扩展 | 检查是否为已绘制地图、是否锁定，以及比例是否已达到 4 |
| 补足材料失败 | 检查库存、光标是否为空、背包是否有退回旧材料的空间，以及是否有上一笔材料仍在处理 |
| 砂轮没有产物 | 检查物品是否可处理、两个输入是否兼容，及其他插件是否修改了相关规则 |
| 提示服务端不支持纹样选择 | 当前原生纹样接口适配面向 1.20.1；核对服务端版本，必要时关闭织布机替换使用原版界面 |
