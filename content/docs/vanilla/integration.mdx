# 联动

VanillaUI 模块是纯界面替换模块，**不发布 EventBus 事件**、**不注册对外能力接口**、**不与其他模块直接联动**。其他模块无法通过模块机制获取 VanillaUI 的功能。

## 依赖

模块不依赖任何外部插件与其他模块，可独立运行。仅需 ArcartX 客户端 MOD 渲染界面。

## 数据存储

VanillaUI 模块**不使用数据库存储**，配方书开关状态等均为内存状态，玩家重新打开界面时默认关闭，模块重载后重置。模块不参与 `/axs purge` 和 `/axs migrate`。

## 跨服同步

VanillaUI 模块**不涉及**跨服同步，所有状态仅在玩家当前所在子服有效。

## UI 资源

模块根据配置导出 UI 文件：

| 条件 | 导出的 UI 文件 |
| --- | --- |
| `crafting.enabled = true` | `ui/vanilla_crafting.yml` |
| `furnace.enabled = true` | `ui/vanilla_furnace.yml` |

> UI 文件是否覆盖用户修改由 `ui.overwrite-ui-files` 配置项控制。设为 `false` 时仅首次导出，设为 `true` 时每次启动/reload 都覆盖。

> 关于物品来源与图标渲染的通用知识，参考 [物品来源](/docs/guide/item-sources) 与 [图标系统](/docs/guide/icons)。
