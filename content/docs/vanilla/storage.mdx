## 启用界面

在 `plugins/ArcartX-Suite/data/vanilla/config.yml` 中合并以下设置，执行 `/axs reload vanilla`：

```yaml
container:
  enabled: true
  push-interval-ticks: 2
shulker-box:
  enabled: true
  push-interval-ticks: 2
```

`container` 控制共用原版容器界面的箱子、陷阱箱、木桶与末影箱；`shulker-box` 独立控制潜影盒。关闭对应开关后恢复原版界面。

普通箱子和大箱子按实际行数显示。当前窗口的储物格行数在打开时确定；大箱子直接使用六行紧凑布局，无需等待切版。

## 真实容器取放

| 容器 | 存储与交互 |
| --- | --- |
| 箱子、陷阱箱 | 保留原来的单箱或大箱库存，使用真实槽位取放 |
| 木桶 | 物品保留在原木桶中 |
| 末影箱 | 使用原版末影箱库存，个人存储规则保持不变 |
| 潜影盒 | 物品保留在盒内，嵌套等放入限制仍由原版处理 |

界面显示已用槽位和物品总量。下方背包及快捷栏与当前容器一起使用，物品名称、附魔、耐久等数据由原版保留。

**关闭界面不会清空容器，也不会把其中库存自动搬入玩家背包或仓库。** 其他玩家、漏斗或插件对容器的操作仍遵循服务端规则，原版权限和交互事件继续生效。

## 与仓库一起使用

启用 Warehouse 后，右侧显示个人仓库，可搜索、分类、排序和翻页。左键取一组、右键取半组；取到光标后，可放入左侧真实容器。

从容器取出物品后，也可点击仓库存入区将光标上的物品存入个人仓库。物品是否可以入库，仍按 Warehouse 的权限、容量、黑名单和物品锁规则处理。

未启用 Warehouse 时，右侧直接显示操作指引，背包与容器仍能正常取放。是否显示仓库在界面打开前确定。

## 共用容器模板

原版通用容器窗口使用同一个模板，支持 1～6 行，每行九格。使用同类原版窗口的运输矿车或插件箱子菜单也会使用该模板；需要保留这些菜单的原版外观时，可关闭 `container.enabled`。

发射器、投掷器、漏斗使用各自的独立开关，不由 `container` 控制。操作见[信标与红石容器](/docs/vanilla/utility)。
