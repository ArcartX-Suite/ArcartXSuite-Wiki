## 先改哪些内容

先只启用一种需要替换的容器，用普通玩家打开并完成一次实际制作或取放，再开启其他类型。界面能打开后，才调整配方书、图标与展示位置。

调整后同时检查物品数量、配方消耗和关闭界面后的材料去向。配方浏览与填入步骤见[配方书与材料填入](/docs/vanilla/recipe-book)。通常保留默认布局并修改需要的开关即可。

配置位置：`plugins/ArcartX-Suite/data/vanilla/config.yml`。定义文件与子目录均相对此模块目录。本文中的 YAML 片段用于修改对应小节，请保留文件中的其他设置。

修改后执行 `/axs reload vanilla`；涉及插件安装或全局设置的变更请重启后验证。

## 配置文件位置

VanillaUI 模块的配置文件为 `config.yml`，位于模块数据目录下。模块启动时自动从 Jar 中导出默认配置，用户修改后执行 `/axs reload vanilla` 即可热重载。

| 项目 | 说明 |
| --- | --- |
| 配置文件名 | `config.yml` |
| 配置版本 | `2`（当前 schema） |
| 同步策略 | `strict`（严格同步，配置变更需 reload 生效） |
| 配置校验 | 启用字段类型与范围校验 |

### 顶层字段

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `config-version` | `int` | `2` | 配置版本号，请勿手动修改，由模块自动管理迁移 |

### 界面显示（ui）

UI 统一配置节，管理所有界面的 ID 与覆盖策略。

| 字段 | 类型 | 默认值 | 校验规则 | 说明 |
| --- | --- | --- | --- | --- |
| `ui.overwrite-ui-files` | `boolean` | `false` | 布尔值 | 是否覆盖用户已修改的 UI 文件 |

六种界面的 UI ID 可独立修改，文件统一导出到 `plugins/ArcartX-Suite/ui/`：

| 容器 | UI ID 配置字段 | 默认 UI ID | 默认文件 |
| --- | --- | --- | --- |
| 工作台 | `ui.crafting-ui-id` | `AXS:vanilla_crafting` | `vanilla_crafting_v2.yml` |
| 熔炉 | `ui.furnace-ui-id` | `AXS:vanilla_furnace` | `vanilla_furnace_v2.yml` |
| 高炉 | `ui.blast-furnace-ui-id` | `AXS:vanilla_blast_furnace` | `vanilla_blast_furnace_v2.yml` |
| 烟熏炉 | `ui.smoker-ui-id` | `AXS:vanilla_smoker` | `vanilla_smoker_v2.yml` |
| 切石机 | `ui.stonecutter-ui-id` | `AXS:vanilla_stonecutter` | `vanilla_stonecutter_v2.yml` |
| 锻造台 | `ui.smithing-ui-id` | `AXS:vanilla_smithing` | `vanilla_smithing_v2.yml` |

### 工作台界面（crafting）

工作台界面替换配置节。

| 字段 | 类型 | 默认值 | 校验规则 | 说明 |
| --- | --- | --- | --- | --- |
| `crafting.enabled` | `boolean` | `true` | 布尔值 | 是否启用工作台 UI 替换 |

> `crafting.enabled` 设为 `false` 时，模块不会注册工作台 UI，原版工作台界面保持不变。UI 文件也不会被导出到Suite数据目录。

### 熔炉界面（furnace）

熔炉界面替换配置节。

| 字段 | 类型 | 默认值 | 校验规则 | 说明 |
| --- | --- | --- | --- | --- |
| `furnace.enabled` | `boolean` | `true` | 布尔值 | 是否启用熔炉 UI 替换 |
| `furnace.push-interval-ticks` | `int` | `2` | 范围 `1`-`100` | 熔炉状态推送间隔（tick） |

> `furnace.push-interval-ticks` 控制服务端轮询熔炉方块状态的频率。每秒 20 tick，默认 `2` tick 即每秒推送 10 次。值越小推送越频繁，UI 进度条越平滑，但服务端开销越大。建议保持默认值 `2`。

### 高炉、烟熏炉、切石机与锻造台

以下配置合并到主配置顶层，四种界面默认均启用。已有其他配置时请保留原内容。

```yaml
blast-furnace:
  enabled: true
  push-interval-ticks: 2
smoker:
  enabled: true
  push-interval-ticks: 2
stonecutter:
  enabled: true
smithing:
  enabled: true
```

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `blast-furnace.enabled` | `true` | 启用高炉界面 |
| `blast-furnace.push-interval-ticks` | `2` | 高炉进度刷新间隔，范围 1～100 tick |
| `smoker.enabled` | `true` | 启用烟熏炉界面 |
| `smoker.push-interval-ticks` | `2` | 烟熏炉进度刷新间隔，范围 1～100 tick |
| `stonecutter.enabled` | `true` | 启用切石机界面与配方选择 |
| `smithing.enabled` | `true` | 启用锻造台升级、纹饰与辅料补齐 |

关闭某项后，该容器使用原版界面，不影响其他已启用容器。锻造台需先手动放入目标装备，再补齐模板与辅材，操作见[配方书与材料填入](/docs/vanilla/recipe-book)。

### 工作台与熔炉配置示例

```yaml
# ArcartXSuite Vanilla - 原版界面替换模块配置
# 替换原版工作台和熔炉界面为 ArcartX UI 纯色块风格界面。
# 重载: /axs reload vanilla

# 配置版本号（请勿手动修改）
config-version: 2

# UI 配置（统一管理所有界面的 id 与覆盖策略）
ui:
  # 工作台 UI id（与 vanilla_crafting.yml 文件名对应）
  crafting-ui-id: "AXS:vanilla_crafting"
  # 熔炉 UI id（与 vanilla_furnace.yml 文件名对应）
  furnace-ui-id: "AXS:vanilla_furnace"
  # 是否覆盖用户已修改的 UI 文件
  overwrite-ui-files: false

# 工作台界面替换
crafting:
  # 是否启用工作台 UI 替换
  enabled: true

# 熔炉界面替换
furnace:
  # 是否启用熔炉 UI 替换
  enabled: true
  # 熔炉状态推送间隔（tick），每秒 20 tick，默认 2 tick（每秒 10 次）
  push-interval-ticks: 2
```

### 仅启用工作台

```yaml
config-version: 2

ui:
  crafting-ui-id: "AXS:vanilla_crafting"
  furnace-ui-id: "AXS:vanilla_furnace"
  overwrite-ui-files: false

crafting:
  enabled: true

furnace:
  enabled: false
  push-interval-ticks: 2
```

### 仅启用熔炉（降低推送频率）

```yaml
config-version: 2

ui:
  crafting-ui-id: "AXS:vanilla_crafting"
  furnace-ui-id: "AXS:vanilla_furnace"
  overwrite-ui-files: false

crafting:
  enabled: false

furnace:
  enabled: true
  # 每 5 tick 推送一次（每秒 4 次），降低服务端开销
  push-interval-ticks: 5
```

### 强制覆盖 UI 文件

```yaml
config-version: 2

ui:
  crafting-ui-id: "AXS:vanilla_crafting"
  furnace-ui-id: "AXS:vanilla_furnace"
  # 每次 reload 都用 Jar 内置 UI 文件覆盖用户修改
  overwrite-ui-files: true

crafting:
  enabled: true

furnace:
  enabled: true
  push-interval-ticks: 2
```

> `overwrite-ui-files: true` 适用于排查 UI 问题时恢复默认配置。日常使用建议设为 `false`，以保留自定义修改。

## 仓库联动

Warehouse 为可选模块，无需在本页配置中单独开启。启用后，六种界面都可显示个人仓库，并将可用仓库材料计入“仅可制作”和填入材料。锻造台仍需玩家先放入目标装备。没有 Warehouse 时直接显示配方书，使用工作区和背包材料。

工作台、切石机与锻造台关闭后的溢出入库，由 Warehouse 的自动存入开关控制，详见[自动存入与材料恢复](/docs/warehouse/material-recovery)。
