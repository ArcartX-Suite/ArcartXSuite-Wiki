## 先改哪些内容

先只启用一种需要替换的容器，用普通玩家打开并完成一次实际制作或取放，再开启其他类型。界面能打开后，才调整配方书、图标与展示位置。

调整后同时检查物品数量、配方消耗和关闭界面后的材料去向。配方浏览与填入步骤见[配方书与材料填入](/docs/vanilla/recipe-book)。通常保留默认布局并修改需要的开关即可。

配置位置：`plugins/ArcartX-Suite/data/vanilla/config.yml`。定义文件与子目录均相对此模块目录。本文中的 YAML 片段用于修改对应小节，请保留文件中的其他设置。

修改后执行 `/axs reload vanilla`；涉及插件安装或全局设置的变更请重启后验证。

## 配置文件位置

配置位于 `plugins/ArcartX-Suite/data/vanilla/`。修改界面开关或提示文本后执行 `/axs reload vanilla`；只修改配方时可执行 `/axs vanilla recipes reload`。

| 项目 | 说明 |
| --- | --- |
| `config.yml` | 界面开关、UI ID、刷新间隔和整理方式 |
| `message.yml` | 界面操作提示及随身背包消息 |
| `recipes.yml` | 自定义配方的材料、产物和使用要求 |

### 界面显示（ui）

UI 统一配置节，管理所有界面的 ID 与覆盖策略。

| 字段 | 类型 | 默认值 | 校验规则 | 说明 |
| --- | --- | --- | --- | --- |
| `ui.overwrite-ui-files` | `boolean` | `false` | 布尔值 | 是否覆盖用户已修改的 UI 文件 |

### 其他工作区与容器

以下配置节均使用 `enabled` 单独控制，默认开启。需要保留某类容器的原版界面时，将该节的 `enabled` 设为 `false`。

| 用途 | 配置节 |
| --- | --- |
| 熔炼与制作 | `blast-furnace`、`smoker`、`stonecutter`、`smithing`、`brewing` |
| 交易与装备 | `merchant`、`anvil`、`enchanting`、`grindstone` |
| 工具与存储 | `loom`、`cartography`、`beacon`、`hopper`、`dispenser`、`container`、`shulker-box` |

`dispenser` 同时控制发射器和投掷器。普通箱子、木桶和末影箱使用 `container`。配置中已有 `push-interval-ticks` 的工作区可在各自配置节调整刷新间隔。

随身背包使用独立的 [`backpack` 配置节](/docs/vanilla/backpack)。自定义配方默认启用，关闭时将 `recipes.enabled` 设为 `false`。配方定义和编辑器使用方式见[自定义合成配方](/docs/vanilla/custom-recipes)。

### 工作台界面（crafting）

工作台界面替换配置节。

| 字段 | 类型 | 默认值 | 校验规则 | 说明 |
| --- | --- | --- | --- | --- |
| `crafting.enabled` | `boolean` | `true` | 布尔值 | 是否启用工作台 UI 替换 |

> `crafting.enabled` 设为 `false` 时，模块不会注册工作台 UI，原版工作台界面保持不变。UI 文件也不会被导出到Suite数据目录。

### 熔炉界面（furnace）

熔炉界面替换配置节。

| 字段 | 类型 | 默认值 | 校验规则 | 说明 |
| --- | --- | --- | --- | --- |
| `furnace.enabled` | `boolean` | `true` | 布尔值 | 是否启用熔炉 UI 替换 |
| `furnace.push-interval-ticks` | `int` | `2` | 范围 `1`-`100` | 熔炉状态推送间隔（tick） |

> `furnace.push-interval-ticks` 控制熔炉状态的检查间隔。每秒 20 tick，默认每 `2` tick 检查一次，状态变化时更新界面。建议保持默认值 `2`。

### 工作台和普通熔炉配置片段

```yaml
# ArcartXSuite Vanilla - 原版界面替换模块配置
# 替换原版工作台和熔炉界面为 ArcartX UI 纯色块风格界面。
# 重载: /axs reload vanilla

# 配置版本号（请勿手动修改）
config-version: 2

# UI 配置（统一管理所有界面的 id 与覆盖策略）
ui:
  # 工作台 UI ID
  crafting-ui-id: "AXS:vanilla_crafting"
  # 熔炉 UI ID
  furnace-ui-id: "AXS:vanilla_furnace"
  # 是否覆盖用户已修改的 UI 文件
  overwrite-ui-files: false

# 工作台界面替换
crafting:
  # 是否启用工作台 UI 替换
  enabled: true

# 熔炉界面替换
furnace:
  # 是否启用熔炉 UI 替换
  enabled: true
  # 熔炉状态检查间隔，单位 tick
  push-interval-ticks: 2
```

### 关闭普通熔炉替换

```yaml
config-version: 2

ui:
  crafting-ui-id: "AXS:vanilla_crafting"
  furnace-ui-id: "AXS:vanilla_furnace"
  overwrite-ui-files: false

crafting:
  enabled: true

furnace:
  enabled: false
  push-interval-ticks: 2
```

### 仅启用熔炉（降低推送频率）

```yaml
config-version: 2

ui:
  crafting-ui-id: "AXS:vanilla_crafting"
  furnace-ui-id: "AXS:vanilla_furnace"
  overwrite-ui-files: false

crafting:
  enabled: false

furnace:
  enabled: true
  # 每 5 tick 检查一次状态
  push-interval-ticks: 5
```

### 强制覆盖 UI 文件

```yaml
config-version: 2

ui:
  crafting-ui-id: "AXS:vanilla_crafting"
  furnace-ui-id: "AXS:vanilla_furnace"
  # 每次 reload 都用 Jar 内置 UI 文件覆盖用户修改
  overwrite-ui-files: true

crafting:
  enabled: true

furnace:
  enabled: true
  push-interval-ticks: 2
```

> `overwrite-ui-files: true` 适用于排查 UI 问题时恢复默认配置。日常使用建议设为 `false`，以保留自定义修改。

## 背包与箱柜整理

随身背包顶栏提供“整理背包”，整理玩家的 27 格储物栏，快捷栏、装备和副手保留原位。箱子、木桶、末影箱与潜影盒的顶栏提供“整理容器”，只整理当前打开的真实容器。两者使用权限 `arcartxsuite.vanilla.sort`。

```yaml
inventory-sort:
  mode: type
```

可选 `type`（按类型）、`name`（按材质名称）或 `amount`（按堆叠数量降序）。保存后执行 `/axs reload vanilla`。

## 提示文本

在 `message.yml` 的 `ui-notices` 中修改界面内的操作提示；`extra-backpack` 中配置随身背包消息。保留消息中的占位符，修改后执行 `/axs reload vanilla`。

## 仓库联动

Warehouse 为可选模块，无需在本页配置中单独开启。启用后，工作台与熔炉可显示个人仓库，并将可用仓库材料计入“仅可制作”和填入材料。没有 Warehouse 时仍可使用背包材料和配方书。

工作台关闭后的溢出入库，由 Warehouse 的自动存入开关控制，详见[自动存入与材料恢复](/docs/warehouse/material-recovery)。
