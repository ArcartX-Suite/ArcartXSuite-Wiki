---
title: "自定义原版配方"
description: "在游戏中创建工作台配方，或用配置定义炉类、切石、锻造和酿造配方。"
---

Suite 2.0 的自定义配方由 Vanilla 管理。在 `data/vanilla/config.yml` 设置 `recipes.enabled: true` 后重载模块。实体工作台与随身背包顶栏的 3×3 工作台共用配方。

## 在游戏中创建工作台配方

1. 持有 `arcartxsuite.vanilla.recipe.admin` 权限，点击工作台顶栏“配方管理”或执行 `/axs vanilla recipes`。
2. 点击“新建”并填写配方 ID。选择“有序”或“无序”，再点选中间的材料格与右侧背包样品。
3. 点击结果格，从背包选取产物，并填写每次合成的产物数量。需要限制使用时填写权限节点。
4. 点击“发布配方”。材料和产物样品只用于读取。玩家按配方摆放物品后，从原版结果槽领取成品。

“精确物品”匹配样品的完整物品数据。选择“材质备选”后，可在同一个格子追加多种允许的材质。右键清空材料格或结果格。有序配方遵循原版工作台的相对形状，无序配方允许任意摆放顺序。

## 配置文件

配置位于 `plugins/ArcartX-Suite/data/vanilla/recipes.yml`。下例把 1 个粗铜烧炼为 1 个铜锭，用于说明配置结构。实服请为自定义配方选用独立材料或样品，避免与已有配方争用同一输入。

```yaml
config-version: 1
recipes:
  example_furnace:
    station: furnace
    ingredients:
      - materials: [RAW_COPPER]
    result: { source: minecraft, id: copper_ingot, amount: 1 }
    cooking-ticks: 200
    experience: 0.7
```

| `station` | 材料顺序与可用字段 |
| --- | --- |
| `shaped` | 9 个材料格，按从左到右、从上到下排列，空格写 `{}` |
| `shapeless` | 1～9 个材料格 |
| `furnace`、`blast_furnace`、`smoker` | 1 个原料。可配置 `cooking-ticks` 和 `experience` |
| `stonecutter` | 1 个原料 |
| `smithing` | 模板、基底、辅材。用 `smithing-data` 选择 `INHERIT_BASE` 或 `FIXED_RESULT` |
| `brewing` | 瓶位输入、酿造材料。每瓶生成 1 个产物，需要 Paper PotionMix |

材料格用 `materials` 配置材质备选，或用 `exact` 配置固定物品模板和编辑器保存的快照。产物 `result` 可用固定物品库模板，也可由编辑器保存样品。锻造的 `FIXED_RESULT` 需要平台支持固定产物数据。每个配方 ID 在文件内唯一，权限字段适用于工作台配方。

编辑文件后执行 `/axs vanilla recipes reload`。配置校验或注册失败时，已生效配方继续可用。原版实际匹配决定产物，仓库填料也会检查即将摆入的材料是否命中所选工作台配方。
