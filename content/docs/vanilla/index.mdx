| 项目 | 说明 |
| --- | --- |
| 模块 ID | `vanilla` |
| 主配置 | `plugins/ArcartX-Suite/data/vanilla/config.yml` |
| 主要调整内容 | 需要替换的容器类型与配方书显示 |
| 重载 | `/axs reload vanilla` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 启用一个容器类型。
2. 重载后打开已启用的工作台、高炉等对应方块。
3. 选择配方并填入材料。锻造台先放入目标装备，再补齐模板与辅材。

## 检查是否配置成功

检查配方显示、物品填充和合成结果。

功能未生效时，先检查模块状态、所用定义 ID、玩家权限及客户端安装情况，随后对照[日志与报错提示](/docs/guide/config-management)逐项检查。

## 可以配置的功能

| 功能 | 说明 |
| --- | --- |
| 工作台界面替换 | 打开工作台时显示自定义界面，保留原版材料槽与合成功能 |
| 熔炉界面替换 | 打开熔炉时显示自定义界面，保留原版原料、燃料与产物槽 |
| 高炉与烟熏炉 | 使用各自的烧炼配方，显示燃料余量和加工进度 |
| 切石机 | 浏览切割配方，填入石材后选择对应成品，从原版产物槽领取 |
| 锻造台 | 支持装备升级和盔甲纹饰；目标装备由玩家放入，模板与辅材可从仓库补齐 |
| 酿造台 | 预览酿造配方，补齐药水与材料，显示原位酿造进度和燃料次数 |
| 村民交易 | 显示当前价格、库存与可交易次数，补齐后从原版产物槽成交 |
| 铁砧 | 修复、改名与附魔合并，显示原版等级费用与材料消耗 |
| 附魔台 | 显示三档原版附魔选项，可从背包或仓库补足青金石 |
| 砂轮 | 修复同类装备或移除非诅咒附魔，经验返还由原版处理 |
| 织布机 | 预览并选择纹样，保留目标旗帜，可从仓库补足染料 |
| 制图台 | 扩展、复制和锁定地图，可从仓库补足对应辅材 |
| 信标 | 选择主辅效果，从背包或仓库补足支付物品，再确认设置 |
| 漏斗 | 五格真实库存、占用统计与红石锁定状态 |
| 发射器与投掷器 | 共用九格容器界面，按实际容器显示行为说明 |
| 箱柜与末影箱 | 普通箱子、大箱子、陷阱箱、木桶和末影箱共用按行数适配的真实槽位模板 |
| 潜影盒 | 使用真实盒内库存，保留原版嵌套与物品放入限制 |
| 随身背包 | 装备、原版背包、个人仓库及随身工作台 |
| 自定义配方 | 管理工作台配方并向其他原版工位发布定义 |
| 在线编辑 | 在游戏内编辑兑换所、条目，从真实背包选物并保存 |
| 配方书 | 工作台显示已解锁的 3×3 材料预览，熔炉显示原料与产物预览 |
| 仓库分类与排序 | 个人仓库筛选项展开列表直接选择；当前模板不提供配方分类标签 |
| 中文搜索 | 配方书搜索框支持中英文物品名称模糊搜索 |
| 填入材料 | 右键配方或点击填入按钮，使用工作区、储物栏、可用个人仓库补齐一份，已就位时不重复扣料 |
| 可制作状态 | 按工作区、背包与可用仓库的材料总量判断，材料足够的配方显示绿色细线 |
| 无仓库服务器 | 配方类界面显示配方书，装备与工艺类界面显示操作指引；均可使用背包材料 |
| 异常取料记录 | 从仓库填料中断时保留记录；无法确认是否收到的材料需管理员核对 |
| 临时材料退回 | 关闭工作台、切石机、锻造台、村民交易、铁砧、附魔台、砂轮、织布机、制图台或信标时，背包装不下的输入材料按 Warehouse 自动存入设置处理 |
| 熔炉进度 | 显示剩余燃料与烧炼进度，可配置刷新间隔 |
