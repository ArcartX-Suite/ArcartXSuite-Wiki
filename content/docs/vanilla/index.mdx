| 主要调整内容 | 需要替换的容器类型与配方书显示 |
| 重载 | `/axs reload vanilla` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 启用一个容器类型。
2. 重载后打开工作台。
3. 选择配方并尝试填充。

## 检查是否配置成功

检查配方显示、物品填充和合成结果。

打开工作台仍是原版界面时，核对 `crafting.enabled` 和界面注册。界面出现但只缺仓库材料时，检查 Warehouse 个人仓库是否可用及是否已解锁二级密码，见[配方填入](/docs/vanilla/recipe-book)。

## 可以配置的功能

| 功能 | 说明 |
| --- | --- |
| 工作台界面替换 | 打开工作台时显示自定义界面，保留原版材料槽与合成功能 |
| 熔炉界面替换 | 打开熔炉时显示自定义界面，保留原版原料、燃料与产物槽 |
| 更多容器与工作区 | 支持高炉、烟熏炉、切石机、锻造台、酿造台、村民交易、铁砧、附魔台、砂轮、织布机、制图台、信标、漏斗、发射器、投掷器、箱类容器和潜影盒 |
| 随身背包 | 使用 `/axs vanilla backpack` 随时打开个人仓库入口 |
| 自定义配方 | 管理工作台、熔炼、切石、锻造和酿造配方 |
| 配方书 | 工作台显示已解锁的 3×3 材料预览，熔炉显示原料与产物预览 |
| 仓库分类与排序 | 个人仓库筛选项展开列表直接选择；当前模板不提供配方分类标签 |
| 中文搜索 | 配方书搜索框支持中英文物品名称模糊搜索 |
| 填入材料 | 右键配方或点击填入按钮，使用工作区、储物栏、可用个人仓库补齐一份，已就位时不重复扣料 |
| 可制作状态 | 按工作区、背包与可用仓库的材料总量判断，材料足够的配方显示绿色细线 |
| 无仓库服务器 | 右侧显示配方书，使用工作区和背包中的材料 |
| 异常取料记录 | 从仓库填料中断时保留记录；无法确认是否收到的材料需管理员核对 |
| 工作台退回溢出 | 由 Warehouse 自动存入设置控制，关闭时保留原版掉落 |
| 熔炉进度 | 显示剩余燃料与烧炼进度，可配置刷新间隔 |
