| 项目 | 说明 |
| --- | --- |
| 模块 ID | `vanilla` |
| 主配置 | `plugins/ArcartX-Suite/data/vanilla/config.yml` |
| 主要调整内容 | 需要替换的容器类型与配方书显示 |
| 重载 | `/axs reload vanilla` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 启用一个容器类型。
2. 重载后打开工作台。
3. 选择配方并尝试填充。

## 检查是否配置成功

检查配方显示、物品填充和合成结果。

功能未生效时，先检查模块状态、所用定义 ID、玩家权限及客户端安装情况，随后对照[日志与报错提示](/docs/guide/config-management)逐项检查。

## 可以配置的功能

| 功能 | 说明 |
| --- | --- |
| 工作台界面替换 | 通过 `match: [合成界面]` 替换原版工作台，呈现 ArcartX UI 纯色块风格界面 |
| 熔炉界面替换 | 通过 `match: [熔炉界面]` 替换原版熔炉，呈现 ArcartX UI 纯色块风格界面 |
| 配方书 | 工作台和熔炉均支持配方书功能，按分类展示可用配方，点击配方预览合成网格 |
| 分类筛选 | 工作台支持全部/工具/建筑/食品/红石分类，熔炉支持全部/食品/建筑/杂项分类 |
| 中文搜索 | 配方书搜索框支持中英文物品名称模糊搜索 |
| 一键填充材料 | Shift+左键点击配方图标，自动从背包填充材料到合成/烧制槽位，已有正确材料保留并追加 |
| 可合成状态标记 | 配方图标根据玩家背包材料是否充足标记为可合成（蓝色）或不可合成（红色） |
| 熔炉状态推送 | 定时轮询熔炉方块状态，推送燃烧时间、烧制进度与火焰图标可见性到客户端 |
| 燃料/燃烧进度条 | 熔炉 UI 使用纯色块动态宽度模拟燃料进度条与燃烧进度条 |
