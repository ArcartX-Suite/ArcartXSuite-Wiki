## 启用与打开

在 `plugins/ArcartX-Suite/data/vanilla/config.yml` 中保留以下配置，执行 `/axs reload vanilla`：

```yaml
anvil:
  enabled: true
  push-interval-ticks: 2
enchanting:
  enabled: true
  push-interval-ticks: 2
```

右键铁砧或附魔台即可打开。两个开关互相独立，关闭后使用原版界面。无需 Warehouse 也能使用；有可用仓库时，右侧显示个人仓库，是否显示在打开前确定。

## 铁砧：修复、改名与合并

1. 将要操作的物品放入“目标物品”槽。
2. 如需修复或合并附魔，在第二格放入修复材料、同类装备或附魔书。可先从仓库取到光标，再放进材料槽。
3. 如需改名，在名称框输入文字；清空可移除自定义名称。输入后稍等，或按回车确认名称。
4. 查看等级费用与材料消耗，从真实产物槽领取结果。

名称确认期间暂时不能取出产物，确认后恢复。等级不足或代价过高时按界面提示处理；创造模式及其他插件对铁砧的修改仍遵循服务端规则。

系统不会替玩家从仓库挑选装备或附魔书。结果、耐久、附魔合并、经验消耗和铁砧损坏均由原版处理。

## 附魔台：选择附魔与补足青金石

1. 将装备或书放入目标槽。
2. 手动放入青金石，或点击“补足 1 / 2 / 3 个”。补足按钮优先使用背包，再使用可用的个人仓库；已有足量材料时不重复取出。
3. 查看三个附魔选项的线索、等级门槛与青金石需求。
4. 点击可用选项，在目标槽内完成附魔后取回物品。

书架布置会影响原版选项。等级门槛与实际扣除的等级不同：通常三个选项分别消耗 1、2、3 级及对应数量的青金石，实际结果以服务端规则为准。创造模式按原版处理。

更换装备或选项变化后，以界面更新的选项为准。目标装备始终由玩家选择，补足材料不会自动取另一件装备。

## 仓库与关闭界面

仓库支持分类、排序、搜索和默认排序下的置顶；左键取一组、右键取半组。拿着物品时可点击存入区存回仓库。操作方法见[配方书与材料填入](/docs/vanilla/recipe-book)。

关闭铁砧或附魔台时，输入物品先按原版规则退回背包。启用 Warehouse 自动存入后，背包装不下的部分尝试存入仓库；未启用、拒收或仓库放不下的部分按原版掉落。铁砧的产物预览不会被额外存入仓库。

从仓库补足青金石时，中断后的不确定记录按[自动存入与材料恢复](/docs/warehouse/material-recovery)处理，不自动重复发放。

## 常见问题

| 情况 | 检查方法 |
| --- | --- |
| 没有出现替换界面 | 确认对应开关已开启、模块已加载，且客户端支持 ArcartX UI |
| 铁砧没有产物 | 核对两个输入是否兼容、名称是否已确认，以及是否超过修复上限 |
| 附魔选项不可用 | 检查装备是否可附魔、当前等级和青金石数量，以及周围书架是否生效 |
| 无法补足青金石 | 检查背包和已解锁个人仓库的库存、光标是否为空，以及是否有上一笔转移尚未结束 |
| 提示服务端不支持相关操作 | 当前原生接口适配面向 1.20.1；核对实际服务端版本，保留原版界面作为替代 |
