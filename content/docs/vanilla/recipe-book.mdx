## 配方与操作

支持工作台、熔炉、高炉、烟熏炉、切石机和锻造台。工作台与三种炉子的配方书展示玩家已经解锁的对应配方；切石机和锻造台按原版规则提供各自配方，不要求配方书解锁。

| 操作 | 效果 |
| --- | --- |
| 打开配方书 / 查看仓库 | 切换右侧面板；拿起物品不会强制切页 |
| 左键点击配方 | 选择并预览材料；切石机已有匹配石材时，同时选择原版切割配方 |
| 右键点击配方，或点击填入材料 | 将材料放入真实原料槽；持有光标物品或正在处理转移时不可填料 |
| 搜索框输入 | 按中英文结果名筛选 |
| 所有配方 / 仅可制作 | 切换材料可用性筛选 |
| 刷新材料 | 更新材料可用状态，并保留仍有效的选择与页码 |
| 滚轮 / 翻页按钮 | 翻阅配方或仓库条目 |

仓库面板可展开分类与排序列表直接选择；它们只筛选仓库物品，不筛选配方。配方使用搜索框和“仅可制作”查找。

## 材料来源与可制作标记

判断配方是否可制作、填入材料时，依次使用以下来源：

1. 当前工作区已有材料。
2. 玩家储物栏，包括快捷栏。
3. 可用且已解锁的个人仓库。

仓库材料按实际总量计算，不受当前页、搜索或分类影响。配方允许的替代材料也可使用；需要指定附魔或其他属性的配方，会按完整物品要求匹配。

配方上的绿色细线表示当前材料足够。材料数量改变后，可点击“刷新材料”更新标记；实际填入时会重新检查。仓库未启用或锁定时，只计算工作区和玩家背包中的材料。

## 填料规则

当前操作用于补齐一份配方。工作区已符合配方时保留已有材料，不再次扣取或自动补满。

填入前会检查原有材料能否退回背包。退回空间或所需材料不足时，不从仓库扣料。实际合成、烧炼和成品领取仍按原版规则处理。

填料处理中暂时不能移动、丢弃或交换物品，请等待结果提示。此时关闭界面可能取消填入。

## 高炉与烟熏炉

高炉只展示高炉配方，烟熏炉只展示烟熏配方。选择后右键或点击“填入材料”，补入一份原料；燃料需自行放入，已有匹配原料时不会重复扣取。界面显示剩余燃料比例和加工进度。

## 切石机

1. 选择需要的成品，查看石材与产出数量。
2. 右键配方或点击“填入材料”，从背包和可用仓库取一份石材，并选择对应切割配方。
3. 从左侧真实产物槽领取成品。已有匹配石材时，可直接左键另一种成品切换配方。

选择配方本身不发放成品，材料消耗和产物领取仍由原版处理。

## 锻造台

先将需要升级或添加纹饰的装备放入“目标装备”槽，再选择配方并右键，或点击“补齐辅料”。系统保留这件装备，从背包与可用仓库补齐模板和辅材；不会自动挑选另一件装备。

升级与纹饰结果以真实产物槽为准。纹饰列表用模板图标区分方案，预览不会代替实际装备结果。放入装备后，可点击“刷新材料”更新可制作标记。附魔、名称、耐久等属性按原版锻造规则处理。

## 仓库与界面布局

启用 Warehouse 后可在右侧切换仓库与配方书；未启用时直接显示配方书，仍可使用工作区和背包材料。

仓库条目旁的数量表示总库存。左键取一组、右键取半组，取出后自动补足显示；拿起物品后可点击仓库存入区存回。默认排序下，点击格子右上角的 ☆ 置顶、★ 取消；普通条目悬停时显示星标，已置顶条目持续显示。

## 关闭界面后的材料

关闭工作台、切石机或锻造台时，输入材料先按原版规则退回背包。Warehouse 自动存入开启时，只有放不下的部分尝试存仓库；未开启、拒收或未存下的剩余部分按原版退回、掉落。规则由 Warehouse 提供，即使不用本模块的自定义 UI 也生效。

熔炉、高炉和烟熏炉的物品仍保留在对应方块内，关闭界面不会取走原料、燃料或成品。
