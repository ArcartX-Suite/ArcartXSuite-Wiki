## 配方与操作

除右键工作台方块外，也可从[随身背包](/docs/vanilla/backpack)顶栏的“合成”按钮打开 `3×3` 工作台。先放下光标物品，再进入合成；入口不要求安装 Warehouse。

支持工作台、熔炉、高炉、烟熏炉、切石机、锻造台、酿造台和村民交易。工作台与三种炉子的配方书展示玩家已经解锁的对应配方；切石机和锻造台按原版规则提供各自配方，不要求配方书解锁。

| 操作 | 效果 |
| --- | --- |
| 打开配方书 / 查看仓库 | 切换右侧面板；拿起物品不会强制切页 |
| 左键点击配方 | 选择并预览材料；切石机已有匹配石材时，同时选择原版切割配方 |
| 右键点击配方，或点击填入材料 | 将材料放入真实原料槽；持有光标物品或正在处理转移时不可填料 |
| 搜索框输入 | 按中英文结果名筛选 |
| 所有配方 / 仅可制作 | 切换材料可用性筛选 |
| 刷新材料 | 更新材料可用状态，并保留仍有效的选择与页码 |
| 滚轮 / 翻页按钮 | 翻阅配方或仓库条目 |

仓库面板可展开分类与排序列表直接选择；它们只筛选仓库物品，不筛选配方。配方使用搜索框和“仅可制作”查找。

## 材料来源与可制作标记

判断配方是否可制作、填入材料时，依次使用以下来源：

1. 当前工作区已有材料。
2. 玩家储物栏，包括快捷栏。
3. 可用且已解锁的个人仓库。

仓库材料按实际总量计算，不受当前页、搜索或分类影响。配方允许的替代材料也可使用；需要指定附魔或其他属性的配方，会按完整物品要求匹配。

配方上的绿色细线表示当前材料足够。材料数量改变后，可点击“刷新材料”更新标记；实际填入时会重新检查。仓库未启用或锁定时，只计算工作区和玩家背包中的材料。

## 填料规则

当前操作用于补齐一份配方。工作区已符合配方时保留已有材料，不再次扣取或自动补满。

填入前会检查原有材料能否退回背包。退回空间或所需材料不足时，不从仓库扣料。实际合成、烧炼和成品领取仍按原版规则处理。

填料处理中暂时不能移动、丢弃或交换物品，请等待结果提示。此时关闭界面可能取消填入。

## 高炉与烟熏炉

高炉只展示高炉配方，烟熏炉只展示烟熏配方。选择后右键或点击“填入材料”，补入一份原料；燃料需自行放入，已有匹配原料时不会重复扣取。界面显示剩余燃料比例和加工进度。

## 切石机

1. 选择需要的成品，查看石材与产出数量。
2. 右键配方或点击“填入材料”，从背包和可用仓库取一份石材，并选择对应切割配方。
3. 从左侧真实产物槽领取成品。已有匹配石材时，可直接左键另一种成品切换配方。

选择配方本身不发放成品，材料消耗和产物领取仍由原版处理。

## 锻造台

先将需要升级或添加纹饰的装备放入“目标装备”槽，再选择配方并右键，或点击“补齐辅料”。系统保留这件装备，从背包与可用仓库补齐模板和辅材；不会自动挑选另一件装备。

升级与纹饰结果以真实产物槽为准。纹饰列表用模板图标区分方案，预览不会代替实际装备结果。放入装备后，可点击“刷新材料”更新可制作标记。附魔、名称、耐久等属性按原版锻造规则处理。

## 酿造台

选择配方可预览基底药水、材料与结果。空台默认补入一瓶及一份材料；已有匹配药水时保留原位，不重复取瓶。不匹配的旧输入需有空间退回背包。

烈焰粉需自行放入。界面显示进度和剩余燃料次数，酿造期间不能自动替换材料。药水在原来的瓶槽完成转换，列表以服务端实际配方为准。

## 村民交易

打开村民或流浪商人后，默认显示当前报价。列表显示支付物品、库存和可交易次数。左键选择报价，右键或点击按钮补齐一次所需物品，再从真实产物槽领取。

价格包含当前需求与玩家折扣。旧报价、已售罄条目或被其他插件取消的选择不会继续填料。成交、次数和经验仍按原版规则处理。

## 铁砧与附魔台

这两个界面没有配方列表。目标装备由玩家放入；铁砧材料手动取放，附魔台可从背包与可用仓库补足 1、2、3 个青金石。改名、附魔选项、经验费用和关闭时的物品去向见[铁砧与附魔台](/docs/vanilla/equipment)。

## 砂轮、织布机与制图台

这三种界面也没有普通配方列表。砂轮保留两格输入与真实产物槽；织布机选择服务端提供的纹样，并可从背包或仓库补足染料；制图台保留玩家指定的地图，可补足纸、空地图或玻璃板。完整步骤见[砂轮、织布机与制图台](/docs/vanilla/artisan)。

## 信标与红石容器

信标可选择主辅效果、从背包与仓库补足支付物品，再确认设置。漏斗、发射器与投掷器使用真实容器槽位，仓库物品手动取放，没有普通配方列表。完整步骤见[信标与红石容器](/docs/vanilla/utility)。

## 箱柜、末影箱与潜影盒

这些界面没有配方书，直接操作原存储槽位。普通容器按实际行数显示，大箱子打开即显示六行布局；关闭后物品保留在原存储中。使用步骤见[箱柜、末影箱与潜影盒](/docs/vanilla/storage)。

## 仓库与界面布局

启用 Warehouse 后可在右侧切换仓库与配方书；未启用时，配方类界面直接显示配方书，装备与工艺类界面显示操作指引；仍可使用背包材料。

仓库条目旁的数量表示总库存。左键取一组、右键取半组，取出后自动补足显示；拿起物品后可点击仓库存入区存回。默认排序下，点击格子右上角的 ☆ 置顶、★ 取消；普通条目悬停时显示星标，已置顶条目持续显示。

## 关闭界面后的材料

关闭工作台、切石机、锻造台、村民交易、铁砧、附魔台、砂轮、织布机、制图台或信标时，输入材料先按原版规则退回背包。Warehouse 自动存入开启时，只有放不下的部分尝试存仓库；未开启、拒收或未存下的剩余部分按原版退回、掉落。规则由 Warehouse 提供，即使不用本模块的自定义 UI 也生效。

箱柜、末影箱、潜影盒、漏斗、发射器、投掷器、熔炉、高炉、烟熏炉与酿造台的物品仍保留在对应方块内，关闭界面不会取走原料、燃料或成品。

界面操作结果使用居中高亮提示并自动渐隐。提示显示期间不覆盖或刷新计时，完全隐藏后才接受新提示。
