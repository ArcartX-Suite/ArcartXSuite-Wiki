## 配方与操作

配方内容随当前工作区变化。工作台展示玩家已解锁的有序和无序合成，高炉、烟熏炉与熔炉各使用对应的配方。切石、锻造和酿造可使用本模块注册的对应配方。

| 操作 | 效果 |
| --- | --- |
| 打开配方书 / 查看仓库 | 切换右侧面板；拿起物品不会强制切页 |
| 左键点击配方 | 选择配方，工作台显示 3×3 材料预览，熔炉显示原料与产物预览 |
| 右键点击配方，或点击填入材料 | 将材料放入真实原料槽；持有光标物品或正在处理转移时不可填料 |
| 搜索框输入 | 按中英文结果名筛选 |
| 所有配方 / 仅可制作 | 切换材料可用性筛选 |
| 刷新材料 | 更新材料可用状态，并保留仍有效的选择与页码 |
| 滚轮 / 翻页按钮 | 翻阅配方或仓库条目 |

仓库面板可展开分类与排序列表直接选择；它们只筛选仓库物品，不筛选配方。配方使用搜索框和“仅可制作”查找。

## 材料来源与可制作标记

判断配方是否可制作、填入材料时，依次使用以下来源：

1. 当前工作区已有材料。
2. 玩家储物栏，包括快捷栏。
3. 可用且已解锁的个人仓库。

仓库材料按实际总量计算，不受当前页、搜索或分类影响。配方允许的替代材料也可使用；需要指定附魔或其他属性的配方，会按完整物品要求匹配。

配方上的绿色细线表示当前材料足够。材料数量改变后，可点击“刷新材料”更新标记；实际填入时会重新检查。仓库未启用或锁定时，只计算工作区和玩家背包中的材料。

## 填料规则

当前操作用于补齐一份配方。工作区已符合配方时保留已有材料，不再次扣取或自动补满。

填入前会检查原有材料能否退回背包。退回空间或所需材料不足时，不从仓库扣料。熔炉只填原料，燃料需要自行放入；原料已符合配方时不替换。实际合成、烧炼和产物仍按原版规则处理。

填料处理中暂时不能移动、丢弃或交换物品，请等待结果提示。此时关闭界面可能取消填入。

## 仓库与界面布局

启用 Warehouse 后可在右侧切换仓库与配方书；未启用时直接显示配方书，仍可使用工作区和背包材料。

仓库条目旁的数量表示总库存。左键取一组、右键取半组，取出后自动补足显示；拿起物品后可点击仓库存入区存回。默认排序下，点击格子右上角的 ☆ 置顶、★ 取消；普通条目悬停时显示星标，已置顶条目持续显示。

## 退出工作台

材料先按原版规则退回背包。Warehouse 自动存入开启时，只有放不下的部分尝试存仓库；未开启、拒收或未存下的剩余部分按原版退回、掉落。规则由 Warehouse 提供，即使不用本模块的自定义 UI 也生效。
