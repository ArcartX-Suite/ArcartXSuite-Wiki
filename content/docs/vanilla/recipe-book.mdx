## 配方与操作

仅展示玩家已经解锁的有序合成、无序合成与熔炉配方。烟熏炉、高炉以及其它原版容器暂未接入。

| 操作 | 效果 |
| --- | --- |
| 打开配方书 / 查看仓库 | 切换右侧面板；拿起物品不会强制切页 |
| 左键点击配方 | 选择配方，工作台显示 3×3 材料预览，熔炉显示原料与产物预览 |
| 右键点击配方，或点击填入材料 | 将材料放入真实原料槽；持有光标物品或正在处理转移时不可填料 |
| 搜索框输入 | 按中英文结果名筛选 |
| 所有配方 / 仅可制作 | 切换材料可用性筛选 |
| 刷新材料 | 更新材料可用状态，并保留仍有效的选择与页码 |
| 滚轮 / 翻页按钮 | 翻阅配方或仓库条目 |

配方分类标签不属于当前默认模板。仓库面板的分类与排序使用 Warehouse 配置，可展开列表直接选择，不能将仓库分类当成配方分类。

## 材料来源与可制作标记

“可制作”和实际填料共用材料计划器，按以下来源顺序分配：

1. 当前工作区已有材料。
2. 玩家储物栏，包括快捷栏。
3. 可用且已解锁的个人仓库。

仓库数量使用真实 `long` 总量，不读取图标 Count，不受当前页、搜索或分类影响。使用真实 `RecipeChoice` 匹配替代材料与精确物品，不仅比较 Material；同一份材料不会重复满足多个位置。

绿色细线表示当前快照可以形成填料计划。执行时会再次检查库存、仓库与容器，快照过期并不意味着允许按旧数量扣料。仓库未启用或锁定时，只使用可用的本地材料。

## 填料规则

当前操作用于补齐一份配方。工作区已符合配方时保留已有材料，不再次扣取或自动补满。

计划阶段同时检查旧材料退回空间。空间或材料不足时不执行仓库扣料；熔炉只自动填原料，不自动取燃料，也不重设已匹配的原料槽。实际合成、烧炼和产物仍由原版处理。

仓库取料采用持久化托管凭证。填料处理中会短暂拦截该玩家会改变库存的操作，关闭界面仍允许，但可能使计划失效。

## 仓库与界面布局

服务器在下发 UI 前确定是否具有仓库能力，打开界面不再先显示另一个布局或加载标题。没有仓库时右侧直接显示配方书。

仓库图标只显示一个物品，总量由 Text 展示。左键取一组、右键取半组；拿起物品后可在仓库存入区存回。默认排序下，格子右上角的 ☆ / ★ 可置顶或取消；普通条目仅悬停时显示星标，已置顶条目持续显示。

## 退出工作台

材料先按原版规则退回背包。Warehouse 自动存入开启时，只有放不下的部分尝试存仓库；未开启、拒收或未存下的剩余部分按原版退回、掉落。规则由 Warehouse 提供，即使不用本模块的自定义 UI 也生效。

恢复凭证、人工核对与管理命令见[自动存入与材料恢复](/docs/warehouse/material-recovery)。无法确认的转移不会自动补发，不能将此机制描述为全部崩溃点自动恢复。
