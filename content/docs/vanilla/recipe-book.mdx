# 配方书与一键填充

> **福利模块**

配方书是工作台与熔炉界面替换的核心功能。玩家打开界面后可浏览已解锁配方、按分类筛选、中英文搜索，并通过 Shift+左键一键填充材料。

## 配方数据来源

- 配方数据来源于服务端已注册的原版配方（有序合成、无序合成、熔炉烧制），其他插件注册的配方只要走原版配方注册即可显示
- 仅展示玩家**已解锁**的配方，与原版配方书行为一致（玩家通过合成、进度等原版方式解锁）
- 烟熏炉与高炉配方暂不展示

## 玩家操作

| 操作 | 效果 |
| --- | --- |
| 点击配方书按钮 | 打开/关闭配方书面板 |
| 点击分类标签 | 按分类筛选配方 |
| 搜索框输入文本 | 中英文模糊搜索配方结果名 |
| 点击显示切换按钮 | 切换"显示全部"与"仅显示可合成" |
| 左键点击配方图标 | 在合成网格上叠加半透明材料预览 |
| Shift+左键点击配方图标 | 一键从背包填充材料到槽位 |

## 分类规则

### 工作台分类

| 分类标签 | 包含内容 |
| --- | --- |
| 全部 | 所有配方 |
| 工具 | 工具、武器、装备类物品 |
| 建筑 | 方块类物品 |
| 食品 | 可食用物品及杂项 |
| 红石 | 红石元件类物品 |

### 熔炉分类

| 分类标签 | 包含内容 |
| --- | --- |
| 全部 | 所有配方 |
| 食品 | 可食用物品的烧制配方 |
| 建筑 | 方块类烧制产物 |
| 杂项 | 其余烧制配方 |

## 可合成标记

配方图标根据玩家背包材料是否充足实时标记：

- **蓝色**：背包材料充足，可直接合成
- **红色**：材料不足

> 可合成检测仅按物品类型统计数量，不检查 NBT 或耐久度。

## 一键填充行为

- 已有**正确**材料的槽位会保留并追加到满组
- 槽位中**不匹配**的物品自动退回背包
- 每次点击对每个空槽位填充 1 个材料（非整组），需要多组时多次点击
- 熔炉输入槽已有正确材料时追加材料，不影响正在进行的烧制进度
