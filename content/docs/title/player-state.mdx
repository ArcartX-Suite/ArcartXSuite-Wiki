# 称号状态规则

本页说明玩家称号的生效规则与状态行为，帮助管理员理解称号的生命周期语义。

## 有效期格式

授予称号时支持三种时长格式：

| 模式 | 格式示例 | 说明 |
|---|---|---|
| 永久 | `permanent` | 永不过期 |
| 临时时长 | `7d`、`12h`、`30m`、`30s` | 从授予时刻开始计时 |
| 日期区间 | `2025-01-01~2025-12-31` | 固定日期范围，激活日 00:00 生效、结束日次日 00:00 过期（使用服务器系统时区） |

- 未到激活时间的称号暂不生效
- 已到期的称号由定时任务自动清理（周期由 `settings.expiration-cleanup-interval-ticks` 控制，默认 60 秒）

## 重复授予

玩家已拥有某称号时再次授予：刷新发放时间与有效期，**保留原隐藏状态**。

## 装备与分组

- 每个分组相当于一个装备槽位，同一分组同时只能装备一个称号
- 装备新称号到已装备的分组时直接替换原称号
- 分组可通过 `permission` 字段控制访问权限，无权限的玩家无法装备该分组称号，也无法在 UI 中看到
- 无分组权限的称号不计入拥有数量、不参与属性汇总、不计入套装完成度

## 隐藏

隐藏称号后不参与头顶/聊天展示，但收藏属性仍然生效。玩家通过 UI 或命令切换隐藏状态。

## 展示称号

主展示称号按以下优先级确定：

1. 玩家显式指定的称号（必须已装备且有权限）
2. 按 `display-title.groups` 配置的分组顺序，取第一个已装备且有权限的称号
3. 以上均不满足时无展示称号

> 卸下某分组称号时，若该称号恰好是展示称号，展示称号自动清除。

## 属性生效规则

| 属性类型 | 生效条件 |
|---|---|
| 展示属性（`display-attributes`） | 装备该称号时 |
| 收藏属性（`collection-attributes`） | 拥有该称号且未过期时 |
| 套装属性 | 套装达到阈值激活时 |

称号过期/被回收后，对应属性与显示效果自动移除。玩家下线时清理显示效果与属性，数据库记录保留，下次上线重新加载。

## 数据存储

称号数据写入数据库持久化，共享存储模式下跨服同步。玩家数据清理与存储迁移分别通过 `/axs purge` 与 `/axs migrate` 执行，详见 [命令](/docs/title/commands) 与 [联动](/docs/title/integration)。
