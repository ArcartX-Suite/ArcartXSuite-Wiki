## 玩家命令

玩家命令通过 `/title` 触发（别名 `/axstitle`），需要 `arcartxsuite.title.use` 权限。

| 命令 | 参数 | 说明 |
|---|---|---|
| `/title` | — | 打开称号菜单（等同于 `open`） |
| `/title help` | — | 显示玩家命令帮助 |
| `/title open` | — | 打开称号菜单 |
| `/title equip` | `<titleId>` | 装备指定称号到其所属分组 |
| `/title unequip` | `<groupId>` | 卸下指定分组中已装备的称号 |
| `/title unequip` | `all` | 卸下所有分组中已装备的称号 |
| `/title hide` | `<titleId>` | 隐藏指定称号（不展示但收藏属性仍生效） |
| `/title unhide` | `<titleId>` | 取消隐藏指定称号 |

> Tab 补全：`equip` / `hide` / `unhide` 补全称号 ID，`unequip` 补全分组 ID 和 `all`。

## 管理员命令

管理员命令通过 `/axs title` 触发。

| 命令 | 参数 | 说明 |
|---|---|---|
| `/axs title help` | — | 显示管理命令帮助 |
| `/axs title status` | — | 查看模块状态（缓存玩家数、各属性插件挂钩情况） |
| `/axs title give` | `<玩家> <称号ID> <时长>` | 发放称号给指定玩家 |
| `/axs title revoke` | `<玩家> <称号ID>` | 收回指定玩家的称号 |
| `/axs title open` | `<玩家>` | 为指定在线玩家打开称号菜单 |

### 时长格式

`give` 命令的 `<时长>` 参数支持以下格式：

| 格式 | 说明 | 示例 |
|---|---|---|
| `permanent` | 永久称号 | `permanent` |
| `<数字>s` | 秒 | `30s` |
| `<数字>m` | 分钟 | `30m` |
| `<数字>h` | 小时 | `12h` |
| `<数字>d` | 天 | `7d` |
| `yyyy-MM-dd~yyyy-MM-dd` | 日期区间（开始日~结束日，结束日当天 00:00 过期） | `2025-01-01~2025-12-31` |

> Tab 补全：`give` 的 `<时长>` 参数补全 `permanent` / `7d` / `30d` / `12h`。

## 权限节点

| 权限节点 | 默认 | 说明 |
|---|---|---|
| `arcartxsuite.title.use` | op | 使用玩家命令 `/title` 的基础权限 |
| `arcartxsuite.title.group.<groupId>` | true | 访问指定分组的权限（由分组配置的 `permission` 字段决定） |
| `arcartxsuite.admin` | op | 使用 `/axs` 管理命令的权限 |

> 分组权限通过 `groups.<id>.permission` 配置，留空表示无限制。推荐权限节点约定为 `arcartxsuite.title.group.<groupId>`。

## 称号菜单 UI

玩家可在菜单中执行：浏览/筛选称号、选中查看详情、装备/卸下、隐藏/取消隐藏、设为主展示称号、查看套装进度。
