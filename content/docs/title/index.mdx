| 主要调整内容 | titles/ 称号定义、分组、品质与套装 |
| 重载 | `/axs reload title` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。本模块还需要安装 `PlaceholderAPI`。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 修改一个默认称号。
2. 按命令页为测试玩家授予称号。
3. 执行 `/title` 打开菜单并装备。

## 检查是否配置成功

检查称号名称、有效期和聊天或头顶展示。

已发放却看不到称号时，先用 `/title` 确认该玩家已装备对应分组的称号，再检查隐藏状态、到期时间和分组权限。菜单中已正确装备但聊天仍不显示时，核对聊天模板使用的[称号占位符](/docs/title/commands)。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| 分组管理 | 称号按组归类（冒险类、探索类、活动类等），每个分组有独立显示名、排序权重和访问权限，同一分组只能装备一个称号 |
| 品质系统 | 普通、传说、神话等多品质等级，每个品质有独立排序权重，用于称号分级展示 |
| 双类型称号 | `text`（文字称号）和 `icon`（图标称号），图标称号支持 ArcartX 自定义文字贴图格式 |
| 日期区间 | 支持 `yyyy-MM-dd~yyyy-MM-dd` 格式指定激活和过期日期，区间外的称号不生效 |
| 套装系统 | 多个称号组成一套，达到阈值后激活额外套装属性加成，UI 内实时展示进度 |
| 头顶显示 | 称号可配置 `overhead-mode`（`texture` 贴图 / `text` 文本 / `none` 关闭），装备后自动显示在玩家头顶 |
| 聊天 / Tab 前后缀 | 每个称号可独立配置 `chat-prefix`、`chat-suffix`、`tab-prefix`、`tab-suffix` |
| 展示属性 | `display-attributes` 仅在装备该称号时生效的属性加成 |
