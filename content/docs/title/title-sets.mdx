# 称号套装系统

## 套装概述

称号套装（Title Set）是 Title 模块的进阶玩法机制。多个称号可以组成一个套装，当玩家拥有的套装内称号数量达到指定阈值后，激活额外的套装奖励属性。套装系统鼓励玩家收集同系列称号，为收集玩法提供长期目标。

套装在主配置 `config.yml` 的 `sets` 节中配置。

## 套装定义字段

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `id` | string | — | 套装唯一标识（根键） |
| `display-name` | string | 套装 ID | 套装显示名称 |
| `required-titles` | list | — | 套装所需的称号 ID 列表 |
| `completion-threshold` | int | `-1` | 激活阈值，`<= 0` 时使用所需称号总数 |
| `bonus-attributes` | map | `{}` | 套装激活后的奖励属性键值对 |
| `bonus-attribute-lines` | list | `[]` | 奖励属性文本行 |

> `required-titles` 中引用不存在的称号 ID 会被忽略并记录警告。若清理后 `required-titles` 为空，该套装会被整体跳过。

## 激活阈值

`completion-threshold` 决定套装激活所需的最少称号数量：

| `completion-threshold` 配置值 | `required-titles` 数量 | 实际所需数量 | 说明 |
|---|---|---|---|
| `-1`（默认） | 3 | 3 | 未配置阈值时，需集齐全部所需称号 |
| `0` | 3 | 3 | `<= 0` 时使用所需称号总数 |
| `2` | 3 | 2 | 达到 2 个即激活，无需集齐全部 |
| `5` | 3 | 3 | 阈值超过所需数量时，取较小值（所需称号总数） |

### 阈值配置示例

```yaml
sets:
  # 需集齐全部 3 个称号才激活
  adventure_full:
    display-name: "&f冒险套装（完整版）"
    required-titles:
      - adventurer
      - explorer
      - starwalker
    completion-threshold: -1
    bonus-attributes:
      attack: 15
      defense: 10
    bonus-attribute-lines:
      - "&c套装攻击力: +15"
      - "&a套装防御力: +10"

  # 只需 2 个即激活（降低门槛）
  adventure_easy:
    display-name: "&f冒险套装（简易版）"
    required-titles:
      - adventurer
      - explorer
      - starwalker
    completion-threshold: 2
    bonus-attributes:
      attack: 8
    bonus-attribute-lines:
      - "&c套装攻击力: +8"
```

## 套装完成度规则

- 套装完成度仅统计玩家「拥有」状态，不要求「装备」
- 无分组权限的称号不计入套装完成度
- 套装 UI 中实时展示完成进度（如 `2/3`）、激活状态与奖励属性文本

## 总属性汇总

玩家总属性由三部分叠加：收集属性（所有拥有称号）+ 展示属性（所有已装备称号）+ 套装奖励属性（所有已激活套装）。同名属性值累加。

> 例如收集属性 `attack: 5` + 展示属性 `attack: 3` + 套装奖励 `attack: 10` = 总属性 `attack: 18`。

## 奖励属性格式

- `bonus-attributes` 键值对生成 `属性名: +数值` 行
- `bonus-attribute-lines` 文本行中可解析为「属性名:数值」格式的行与键值对合并
- 不可解析的复杂行按原样保留

```yaml
sets:
  warrior_set:
    display-name: "&c战士套装"
    required-titles:
      - adventurer
      - myth_hunter
    completion-threshold: 2
    bonus-attributes:
      attack: 10
      critical_damage: 5
    bonus-attribute-lines:
      - "&c套装攻击力: +10"
      - "&4套装暴击伤害: 5(%)"
```

> `bonus-attribute-lines` 中 `套装暴击伤害: 5(%)` 因后缀 `(%)` 不参与合并，按原样保留。

## 套装占位符

`<setId>` 替换为实际套装 ID，`<key>` 替换为属性名：

| 占位符 | 返回值 | 说明 |
|---|---|---|
| `%axstitle_set_<setId>_completion%` | `int` | 套装已拥有称号数量 |
| `%axstitle_set_<setId>_total%` | `int` | 套装所需称号总数 |
| `%axstitle_set_<setId>_active%` | `true` / `false` | 套装是否已激活 |
| `%axstitle_set_bonus_attr_<key>%` | `double` | 已激活套装的加成属性值 |

> 未激活的套装奖励属性值为 `0`。

## 套装与属性插件同步

套装奖励属性与展示属性、收集属性合并后统一同步到属性插件（AttributePlus / MythicLib / CraneAttribute / Symphony），详见 [联动](/docs/title/integration) 文档。

## 完整套装配置示例

```yaml
sets:
  # 冒险套装：集齐 2 个即激活
  adventure_set:
    display-name: "&f冒险套装"
    required-titles:
      - adventurer
      - explorer
    completion-threshold: 2
    bonus-attributes:
      attack: 10
      defense: 5
    bonus-attribute-lines:
      - "&c套装攻击力: +10"
      - "&a套装防御力: +5"

  # 探索套装：需集齐全部 3 个
  exploration_set:
    display-name: "&6探索套装"
    required-titles:
      - starwalker
      - adventurer
      - explorer
    completion-threshold: -1
    bonus-attributes:
      luck: 10
      prestige: 5
    bonus-attribute-lines:
      - "&e套装幸运值: +10"
      - "&6套装声望: +5"

  # 活动套装：只需 1 个即激活（低门槛）
  activity_set:
    display-name: "&c活动套装"
    required-titles:
      - myth_hunter
    completion-threshold: 1
    bonus-attributes:
      critical_damage: 5
    bonus-attribute-lines:
      - "&4套装暴击伤害: 5(%)"
```

> 套装配置中的 `required-titles` 引用的称号 ID 必须已在 `titles/` 目录中存在，否则该条目会被忽略并记录警告。
