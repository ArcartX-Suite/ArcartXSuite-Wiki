# 联动

## 公开能力接口

Title 模块提供以下公开能力，供其他模块/插件调用：

### TitleGrantable（授予称号）

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `giveTitle` | `UUID playerId`, `String titleId`, `String duration`, `String source` | `boolean` | 给予玩家称号，`duration` 支持 `permanent` / `7d` / `30m` / `2025-01-01~2025-12-31` 等格式，`source` 为来源标识 |

```java
TitleGrantable grantable = getCapability(TitleGrantable.class);
boolean success = grantable.giveTitle(playerUuid, "adventurer", "7d", "EventPacket");
```

> 授予成功后自动同步外部属性、刷新菜单、刷新 Tab 显示。

### TitleConfigQueryable（称号配置查询）

查询称号配置元数据，供 QuestGps 等模块在任务奖励展示等场景使用：

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|
| `queryTitle` | `String titleId` | `TitleInfo` / `null` | 返回称号的 `displayName`、`qualityName`、`description`，未找到返回 `null` |

## EventBus 事件

Title 模块不发布 EventBus 主题事件。其他模块如需感知称号变更，可通过 PAPI 占位符轮询。

## 跨服同步

### 共享存储模式（推荐）

`storage.shared: true` 时，Title 模块复用本体 `config.yml` 的 `storage` 节配置。多服环境下，所有服务器共享同一数据库，玩家称号数据自动跨服同步：玩家在 A 服装备称号后，登录 B 服时自动加载最新状态并重新同步外部属性。

### 自建存储模式

`storage.shared: false` 时，模块使用独立数据库连接。若多服指向同一 MySQL 数据库，同样可跨服同步；若各服使用独立 SQLite 文件，则无法跨服。

## 数据清理与迁移

- `/axs purge` 可按 UUID 或全量清理玩家称号数据
- `/axs migrate` 支持存储切换时的数据迁移（SQLite ↔ MySQL、共享 ↔ 自建）

## 与其他模块联动

### EventPacket

EventPacket 模块可在事件触发时授予称号：配置动作类型 `grant_title` 即可调用授予接口，称号授予后自动同步属性与界面。

### QuestGps

QuestGps 模块可查询称号的显示名、品质与描述，用于任务面板中展示称号奖励信息。

### 属性插件

展示属性、收集属性与套装奖励属性合并后同步到各属性插件：

| 插件 | 同步方式 |
|---|---|
| AttributePlus | 属性源写入 |
| MythicLib | Stat Modifier 注册（增量同步，未注册的属性键跳过并记录警告） |
| CraneAttribute | 属性源写入 |
| Symphony | flat 属性设置 |

> 属性源前缀由各插件的 `source-prefix` 配置控制。玩家装备/卸下/授予/回收称号时自动重新同步。

### Tab 模块

装备/卸下/隐藏/授予/回收称号时自动触发全局 Tab 刷新，确保 Tab 列表中的称号前后缀实时更新。

### 头顶显示

`overhead-mode` 为 `texture` 时在玩家头顶渲染自定义贴图（需 ArcartX 客户端），不可用时自动降级为 `text` 模式（计分板前后缀）。
