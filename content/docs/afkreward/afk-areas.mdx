# 区域与双模式挂机

> **付费模块**

AfkReward 模块的核心是「区域」概念。每个区域是一个 X-Z 平面上的多边形，玩家进入后自动累计挂机时间（REGION 模式），或通过命令手动开始原地挂机（MANUAL 模式）。两种模式可并存于同一区域，共用同一套奖励档位与倍率配置，但在行为约束、发奖时机、崩溃恢复等方面存在显著差异。

## 区域文件结构

每个区域为独立的 `area-<id>.yml` 文件，位于 `data/afkreward/areas/` 目录下。文件名中的 `<id>` 作为区域内部 ID，同时用于奖励权限 `axs.afkreward.start.<id>.<tier>`。模块首次启动时自动导出 `area-default.yml` 模板。

```yaml
id: default
name: "泡澡池"
enabled: true
world: bskyblock_world
manual-enabled: true
reward-weight: 1.0
pos:
  - "-11,138"
  - "17,114"
  - "40,114"
teleport:
  world: bskyblock_world
  x: 20.5
  y: 64.0
  z: 140.5
  yaw: 0
  pitch: 0
reward:
  round: 15
  ...
multiplier:
  enable: false
  ...
```

### 区域顶层字段

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `id` | `string` | 文件名 ID | 区域唯一 ID |
| `name` | `string` | `id` | 区域显示名称（用于权限 `axs.afkreward.area.<name>`） |
| `enabled` | `boolean` | `true` | 是否启用区域 |
| `world` | `string` | — | 区域所在世界名（必填，缺失则跳过） |
| `manual-enabled` | `boolean` | `true` | 是否允许 `/afk start` 原地挂机 |
| `reward-weight` | `double` | `1.0` | 区域奖励权重，最终倍率会乘以该值 |
| `pos` | `list<string>` | — | 区域边界点（`x,z` 格式），至少 3 个点 |
| `teleport` | `section` | — | 原地挂机传送点（缺失则不支持原地挂机） |

> 区域名重复时后加载的文件会被跳过并打印警告。`world` 字段缺失或 `teleport` 世界未加载时，整个区域文件会被跳过。

## 区域边界判定

区域边界为 X-Z 平面上的多边形，使用射线法判断玩家是否在区域内。每个点格式为 `x,z`（不含 Y 坐标），至少需要 3 个点。

```yaml
pos:
  - "-11,138"
  - "17,114"
  - "40,114"
  - "48,128"
  - "51,138"
  - "42,167"
  - "20,172"
  - "10,171"
  - "-4,159"
```

> 边界判定只关注 X 和 Z 坐标，不限制 Y 坐标（高度）。玩家在区域内无论高低均可触发挂机。

### 多区域重叠

服务端每秒遍历所有已启用区域判断玩家位置。多个区域重叠时，**第一个匹配的区域**生效（按配置顺序）。

## REGION 模式（区域挂机）

玩家进入配置的多边形区域后自动开始累计挂机时间，无需手动操作。

### 关键行为

| 行为 | 说明 |
|---|---|
| 位置检测 | 每秒检测玩家方块坐标，视角转动不触发 |
| 权限检查 | 进入时检查 `axs.afkreward.area.<name>`，无权限时提示一次 |
| 人数限制 | `reward.player.enable` 为 `true` 时，超出 `limit` 则拒绝进入 |
| 周期发奖 | 每累计 `round` 分钟发放一次奖励（实时发奖） |
| 进入/离开信号 | 进入触发 `afk_enter_area` 信号并发送进入提示；离开时清零计时并发送离开提示 |

> REGION 模式不限制玩家行为，玩家可在区域内自由活动、战斗、交互。

## MANUAL 模式（原地挂机）

玩家通过 `/afk start <区域名>` 手动开始原地挂机，系统将玩家传送至区域的传送点并锁定行为。

### 启动条件检查

`/afk start` 按以下顺序检查，任一失败则拒绝开始：

| 检查项 | 配置字段 | 失败提示 |
|---|---|---|
| 战斗冷却 | `manual.combat-cooldown-seconds` | `hints.manual.in-combat` |
| 区域有效性 | 区域启用 + 配置了 `teleport` + `manual-enabled` | `hints.manual.no-teleport` |
| 区域权限 | `axs.afkreward.area.<name>` | `hints.no-permission-area` |
| 人数上限 | `reward.player.limit` | `hints.player-limit` |
| 重复挂机 | 已在挂机中 | `hints.manual.already` |
| Essentials AFK 互斥 | 玩家已处于 Essentials AFK 状态 | `hints.manual.essentials-afk` |

> 战斗冷却在玩家造成或受到伤害时刷新时间戳，冷却期内无法开始原地挂机。

### 启动与结束

**启动**：保存原始状态（移速、位置）→ 传送至 `teleport` 点 → 关闭碰撞 → `restrict-actions` 为 `true` 时移速归零 → 触发 `afk_start` 信号并发送开始提示。

**结束结算**（`/afk end` 或强制结束）：按 `挂机总秒数 / (round × 60)` 计算奖励次数并一次性发放 → 恢复移速与碰撞 → `manual.return-on-end: true` 时传送回挂机前位置 → `manual.broadcast-rewards: true` 时全服广播 → 触发 `afk_end` 信号、字幕与邮件预设 → 刷新排行榜。

### 强制结束原因

| 原因 | 触发条件 | 提示消息键 |
|---|---|---|
| 战斗 | 受到/造成伤害时触发（需手动配置） | `hints.manual.end-reason.combat` |
| 区域删除 | 区域被删除或 `enabled` 设为 `false` | `hints.manual.end-reason.area_removed` |
| 权限失效 | 权限复检时发现无区域权限 | `hints.manual.end-reason.no_permission` |
| 时长上限 | 触发 `anti-abuse.time-limit` 的 `KICK` 动作 | `hints.manual.end-reason.time_limit` |
| 人数上限 | 区域人数达到上限 | `hints.manual.end-reason.full` |

> 权限复检间隔由 `manual.permission-recheck-seconds` 控制（默认 5 秒）。MANUAL 模式不检测位置，只累加时间并定期复查区域与权限。

## 行为保护（protections）

MANUAL 挂机期间可封锁以下行为：

| 保护项 | 配置字段 | 说明 |
|---|---|---|
| 移动 | `movement` | 禁止坐标变化（视角转动允许） |
| 传送 | `teleport` | 禁止传送（模块自身回传除外） |
| 交互 | `interact` | 禁止交互方块或空气 |
| 破坏方块 | `block-break` | 禁止破坏方块 |
| 打开容器 | `inventory` | 禁止打开容器或背包界面 |
| 受到伤害 | `receive-damage` | 受到伤害时无敌 |
| 造成伤害 | `deal-damage` | 禁止对其他实体造成伤害 |
| 怪物锁定 | `entity-target` | 禁止被怪物锁定为目标 |
| 进入载具 | `vehicle-enter` | 禁止进入载具 |
| 右键实体 | `interact-entity` | 禁止右键实体 |
| 丢弃物品 | `drop-item` | 禁止丢弃物品 |
| 副手换手 | `swap-hand` | 禁止副手换手 |
| 拾取掉落物 | `pickup-item` | 禁止拾取掉落物 |
| 获得经验 | `experience` | 经验获取量设为 0 |
| 碰撞 | `collidable` | 关闭实体碰撞 |

> 所有保护开关默认开启。`restrict-actions` 为 `true` 时额外设置移速为 0.0001，进一步限制移动。

## 传送点配置

原地挂机时玩家被传送到的目标位置。传送点世界必须已加载，否则区域会被跳过。

```yaml
teleport:
  world: bskyblock_world
  x: 20.5
  y: 64.0
  z: 140.5
  yaw: 0
  pitch: 0
```

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `teleport.world` | `string` | 区域 `world` | 传送目标世界 |
| `teleport.x` | `double` | `0` | X 坐标 |
| `teleport.y` | `double` | `64` | Y 坐标 |
| `teleport.z` | `double` | `0` | Z 坐标 |
| `teleport.yaw` | `double` | `0` | 视角水平偏转角 |
| `teleport.pitch` | `double` | `0` | 视角俯仰角 |

> `teleport` 配置缺失时该区域不支持原地挂机，`/afk start` 会提示"该区域不支持原地挂机"。

## 崩溃恢复

服务器重启后自动恢复上次未正常结束的 MANUAL 挂机：按实际挂机时长（含停机时间）计算奖励次数并一次性发放，然后清除记录。

| 时机 | 操作 |
|---|---|
| 开始 MANUAL 挂机 | 保存挂机记录到数据库 |
| 正常结束挂机 | 删除记录 |
| 玩家退服 / 服务关闭 | 保存当前挂机记录 |

> 挂机记录仅用于崩溃恢复，不跨服共享。

## 双模式对比

| 维度 | REGION 模式 | MANUAL 模式 |
|---|---|---|
| 触发方式 | 进入区域自动触发 | `/afk start <区域名>` 手动触发 |
| 位置检测 | 每秒检测玩家坐标 | 不检测位置，只累加时间 |
| 行为约束 | 不限制 | 封锁 15 种行为 + 移速归零 |
| 发奖时机 | 每达到 `round` 周期实时发奖 | 结束时一次性结算全部奖励 |
| 传送 | 不传送 | 传送至 `teleport` 点，可选回传 |
| 权限复检 | 每秒检测 | 每 `permission-recheck-seconds` 秒复查 |
| 崩溃恢复 | 无（离开即清零） | 自动恢复未结束的 session |
| 广播 | 无 | 可选全服广播奖励 |
| 信号 | `afk_enter_area` / `afk_leave_area` | `afk_start` / `afk_end` |

> 两种模式共用同一套奖励档位与倍率配置。同一玩家同一时间只能处于一种模式。
