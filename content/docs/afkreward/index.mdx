| 项目 | 说明 |
| --- | --- |
| 模块 ID | `afkreward` |
| 主配置 | `plugins/ArcartX-Suite/data/afkreward/config.yml` |
| 主要调整内容 | areas/ 区域坐标、挂机模式与奖励档位 |
| 重载 | `/axs reload afkreward` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。本模块还需要安装 `PlaceholderAPI`。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 修改默认区域坐标。
2. 配置一个简单奖励。
3. 进入区域并执行 `/afkreward status`。

## 检查是否配置成功

等待一个奖励周期，检查状态显示和实际奖励。

`/afkreward status` 未显示预期区域时，核对区域的世界名、边界及玩家站位。已在区域内但奖励没有发放时，检查[奖励档位](/docs/afkreward/reward-tiers)所需权限、发放周期和每日次数上限。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| 双模式挂机 | 区域挂机（REGION，进入区域自动累计）与原地挂机（MANUAL，`/afk start` 手动开始并传送） |
| 周期命令奖励 | 按配置的 `round` 分钟周期发放命令奖励，支持 `{player}`、`{multiplier}` 等占位符 |
| 奖励档位 | 按权限节点 `axs.afkreward.start.<id>.<tier>` 匹配不同档位（如 vip3/vip2/vip1/common），从高到低匹配 |
| 物品奖励 | 通过 ItemSourceRegistry 直接发放物品（minecraft/mythic/neige/overture/mmoitems），背包满转邮件或掉落 |
| 倍率系统 | 基础倍率、周末倍率、定时倍率调度，叠加方式可选 `MAX` / `MULTIPLY` / `LAST` |
| 原地挂机保护 | 挂机期间封锁移动/交互/破坏/传送/受击/攻击/拾取/换手/经验等 15 种行为 |
| 低 TPS 暂停 | 服务器 TPS 低于阈值时自动暂停挂机结算 |
| 崩溃恢复 | 服务器重启后自动结算上次未正常结束的 MANUAL 挂机 session |
| 排行榜 | 挂机总时长排行榜，内存数据与 DB 数据合并后实时排序 |
