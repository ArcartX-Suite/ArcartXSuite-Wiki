# 命令与占位符

## 玩家命令

玩家命令通过 `/map` 触发（别名 `/axsmap`），仅限玩家执行。

| 命令 | 说明 | 权限 |
|---|---|---|
| `/map` 或 `/map open [世界ID]` | 打开地图界面，可指定世界 | `arcartxsuite.map.use` |
| `/map hud [on/off/toggle]` | 切换小地图 HUD 显示状态 | `arcartxsuite.map.use` |
| `/map cleartrack` | 清除当前导航追踪 | `arcartxsuite.map.use` |
| `/map claim <分享码>` | 领取聊天栏分享的地图点位（路径点/标记点） | `arcartxsuite.map.use` |
| `/map help` | 显示玩家命令帮助 | `arcartxsuite.map.use` |

> 非玩家执行时提示「该命令只能由玩家执行」。无权限时提示「你没有权限执行这个命令」。服务未就绪时提示「Map 模块当前未启用」。

### Tab 补全

| 参数位置 | 补全内容 |
|---|---|
| 第 1 参数 | `help` / `open` / `hud` / `cleartrack` / `claim` |
| 第 2 参数（`open`） | 已配置的世界 ID 列表 |
| 第 2 参数（`hud`） | `on` / `off` / `toggle` |

## 管理员命令

管理命令通过 `/axs map <action>` 触发。

| 命令 | 说明 |
|---|---|
| `/axs map help` | 显示管理命令帮助 |
| `/axs map status` | 查看模块运行状态 |
| `/axs map open <玩家> [世界ID]` | 为指定玩家打开地图，可指定世界 |
| `/axs map list` | 列出已配置的世界 |
| `/axs map anchors [世界ID]` | 列出已配置的锚点，可按世界过滤 |
| `/axs map unlock <玩家> <锚点ID>` | 为在线玩家免费解锁锚点（跳过付费/距离门槛） |
| `/axs map refresh <世界ID>` | 刷新该世界的预加载版本号，客户端下次同步时自动重拉地形 |

### Tab 补全

| 参数位置 | 补全内容 |
|---|---|
| 第 2 参数 | `help` / `status` / `open` / `list` / `anchors` / `unlock` / `refresh` |
| 第 3 参数（`open` / `unlock`） | 在线玩家名 |
| 第 3 参数（`anchors` / `refresh`） | 已配置的世界 ID 列表 |
| 第 4 参数（`open`） | 已配置的世界 ID 列表 |
| 第 4 参数（`unlock`） | 已配置的锚点 ID 列表 |

### status 输出

`/axs map status` 输出以下信息：

| 输出项 | 说明 |
|---|---|
| 世界数量 | 已配置的世界总数 |
| 锚点数量 | 已配置的锚点总数 |
| 追踪中 | 当前正在导航的在线玩家数 |
| Waypoint | 路径点运行时是否就绪（true/false） |

> 路径点就绪状态：导航未启用时返回 `true`；导航启用时取决于 ArcartX Waypoint 是否可用。

## 权限节点

| 权限节点 | 默认 | 说明 |
|---|---|---|
| `arcartxsuite.map.use` | 所有玩家 | 使用 `/map` 玩家命令的权限 |
| `arcartxsuite.map.admin` | OP | 路径点/标记点上限提升等管理权限 |

> 管理命令通过 `/axs` 主命令的权限控制，无需额外权限节点。锚点的使用权限通过锚点定义的 `permission` 字段单独控制。

## PlaceholderAPI 占位符

Map 模块**不提供独立的 PlaceholderAPI 占位符**。地图数据来自配置文件、玩家位置、世界坐标、锚点和玩家路径点/标记点，均通过 Packet 发送给 UI 客户端渲染。

> 小地图上的世界名由 UI 使用 `Placeholder.parse("%multiverse-core_alias%")` 解析（Multiverse-Core 提供）；坐标用 `Player.getPosX/Y/Z` 本地实时取值。

## UI 可用数据字段

Map 模块的 UI 交互通过 ArcartX Packet 通讯完成。客户端向服务端发送的 Packet 使用 `ui.packet-id`（默认 `AXS_MAP`）作为标识符，写操作需携带服务端下发的 `action_token`。

### HUD Packet 字段（`init` / `update`）

| 字段 | 类型 | 说明 |
|---|---|---|
| `packetId` | `String` | Packet 标识符 |
| `visible` | `boolean` | 小地图是否可见 |
| `worldId` | `String` | 当前世界 ID |
| `dimension` | `String` | MC 维度 key（供 mod 匹配本地维度） |
| `litEnabled` | `boolean` | 是否启用点亮机制 |
| `litRegions` | `List` | 已点亮多边形区域并集 |
| `playerYaw` | `float` | 玩家朝向角度 |

| `settings` | `Map<String, String>` | 仅 `init` 包携带：玩家地图设置字典（雷达/小地图外观等服务端留存偏好），UI 逐项 `applySetting` 套回 mod |

> 玩家坐标不再经服务端下发——HUD 用 `Player.getPosX/Y/Z` 在客户端本地实时取值。

## 客户端 Mod 要求

地图画面渲染需安装 **ArcartX-Suite-Map 客户端 mod**。未安装时地图渲染区保持空白，列表与详情面板功能不受影响。

客户端默认按键：`V` 切实体雷达、`Z` 循环小地图缩放档、`N` 循环洞穴深度、`B` 循环雷达名称字号（可在 MC 控制设置中改键）；`[` 切形状、`+`/`-` 调尺寸、`,`/`.` 微调缩放（仅 HUD 激活且无界面打开时生效）。同一组选项也可在大地图顶栏「设置」面板中调整。

> 自定义地图 UI 时可参考官方 `map_menu.yml` / `map_hud.yml` 中的字段绑定方式。

## 消息文件

消息文件 `messages.yml` 位于模块数据目录，支持 `&` 颜色码和 `{0}` `{1}` 占位符。修改后执行 `/axs reload map` 生效。

详细消息键列表参考 [配置 - 消息文件](./configuration#消息文件)。
