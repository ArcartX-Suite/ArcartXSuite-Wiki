# 命令与占位符

## 玩家命令

玩家命令通过 `/map` 触发（别名 `/axmap`），仅限玩家执行。

| 命令 | 说明 | 权限 |
|---|---|---|
| `/map` 或 `/map open [世界ID]` | 打开地图界面，可指定世界 | `arcartxsuite.map.use` |
| `/map hud [on/off/toggle]` | 切换小地图 HUD 显示状态 | `arcartxsuite.map.use` |
| `/map cleartrack` | 清除当前导航追踪 | `arcartxsuite.map.use` |
| `/map claim <分享码>` | 领取聊天栏分享的地图点位（路径点/标记点） | `arcartxsuite.map.use` |
| `/map help` | 显示玩家命令帮助 | `arcartxsuite.map.use` |

> 非玩家执行时提示「该命令只能由玩家执行」。无权限时提示「你没有权限执行这个命令」。服务未就绪时提示「Map 模块当前未启用」。

### Tab 补全

| 参数位置 | 补全内容 |
|---|---|
| 第 1 参数 | `help` / `open` / `hud` / `cleartrack` / `claim` |
| 第 2 参数（`open`） | 已配置的世界 ID 列表 |
| 第 2 参数（`hud`） | `on` / `off` / `toggle` |

## 管理员命令

管理命令通过 `/axs map <action>` 触发，由 `ModuleCommandHandler` 注册。

| 命令 | 说明 |
|---|---|
| `/axs map help` | 显示管理命令帮助 |
| `/axs map status` | 查看模块运行状态 |
| `/axs map open <玩家> [世界ID]` | 为指定玩家打开地图，可指定世界 |
| `/axs map list` | 列出已配置的世界 |
| `/axs map anchors [世界ID]` | 列出已配置的锚点，可按世界过滤 |

### Tab 补全

| 参数位置 | 补全内容 |
|---|---|
| 第 2 参数 | `help` / `status` / `open` / `list` / `anchors` |
| 第 3 参数（`open`） | 在线玩家名 |
| 第 3 参数（`anchors`） | 已配置的世界 ID 列表 |
| 第 4 参数（`open`） | 已配置的世界 ID 列表 |

### status 输出

`/axs map status` 输出以下信息：

| 输出项 | 说明 |
|---|---|
| 世界数量 | 已配置的世界总数 |
| 锚点数量 | 已配置的锚点总数 |
| 追踪中 | 当前正在导航的在线玩家数 |
| Waypoint | 路径点运行时是否就绪（true/false） |

> 路径点就绪状态：导航未启用时返回 `true`；导航启用时取决于 ArcartX Waypoint 桥接是否可用。

## 权限节点

| 权限节点 | 默认 | 说明 |
|---|---|---|
| `arcartxsuite.map.use` | 所有玩家 | 使用 `/map` 玩家命令的权限（plugin.yml 注册，默认 true） |
| `arcartxsuite.map.admin` | OP | 路径点/标记点上限提升等管理权限 |

> 管理命令通过 `/axs` 主命令的权限控制，无需额外权限节点。锚点的使用权限通过锚点定义的 `permission` 字段单独控制。

## PlaceholderAPI 占位符

Map 模块**不提供独立的 PlaceholderAPI 占位符**。地图数据来自配置文件、玩家位置、世界坐标、锚点和玩家路径点/标记点，均通过 Packet 发送给 UI 客户端渲染。

> 小地图上的世界名由 UI 使用 `Placeholder.parse("%multiverse-core_alias%")` 解析（Multiverse-Core 提供）；坐标用 `Player.getPosX/Y/Z` 本地实时取值。

## UI Packet 通讯

Map 模块的 UI 交互通过 ArcartX Packet 通讯完成。客户端向服务端发送的 Packet 使用 `ui.packet-id`（默认 `AXS_MAP`）作为标识符，`data` 列表第一个元素为操作名。

### 客户端 → 服务端操作

| 操作名 | 参数 | 说明 | Token 校验 |
|---|---|---|---|
| `refresh` | — | 刷新菜单数据 | 否 |
| `open_menu` | `data[1]` = 世界ID（可选） | 打开地图菜单 | 否 |
| `open_world` | `data[1]` = 世界ID | 切换到指定世界 | 否 |
| `select_anchor` | `data[1]` = 锚点ID | 选中锚点（显示详情） | 否 |
| `select_waypoint` | `data[1]` = 路径点ID | 选中路径点（显示详情） | 否 |
| `select_external` | `data[1]` = 目标ID | 选中外部目标（显示详情） | 否 |
| `select_pin` | `data[1]` = 标记点ID | 选中标记点（显示详情） | 否 |
| `deselect` | — | 取消当前选中 | 否 |
| `unlock_anchor` | `data[1]` = 锚点ID, `data[2]` = action_token | 解锁锚点 | 是 |
| `teleport_anchor` | `data[1]` = 锚点ID, `data[2]` = action_token | 传送到锚点 | 是 |
| `track_anchor` | `data[1]` = 锚点ID | 追踪锚点导航 | 否 |
| `track_waypoint` | `data[1]` = 路径点ID | 追踪路径点导航 | 否 |
| `track_external` / `external_navigate` | `data[1]` = 目标ID | 外部目标"导航"——转发给来源的 `MapNavigationHandler.onNavigateRequest` 执行 | 否 |
| `external_nav_cancel` | `data[1]` = 目标ID | 外部目标"取消"——转发给来源的 `onCancelRequest`，目标标记保留 | 否 |
| `teleport_to_world` | `data[1]` = 世界ID | 传送到指定世界（就近已解锁锚点） | 否 |
| `cross_world_navigate` | `data[1]` = `类型:目标ID` | 跨世界导航：先传送到目标世界再开始导航 | 否 |
| `clear_track` | — | 清除当前导航追踪 | 否 |
| `create_waypoint` | `data[1]` = action_token | 在当前位置创建路径点 | 是 |
| `delete_waypoint` | `data[1]` = 路径点ID, `data[2]` = action_token | 删除指定路径点 | 是 |
| `update_waypoint` | `data[1]` = 路径点ID, `data[2]` = 新名称, `data[3]` = 新描述, `data[4]` = action_token | 重命名/改描述 | 是 |
| `create_pin` | `data[1]` = X, `data[2]` = Z, `data[3]` = action_token | 在指定地图坐标创建标记点 | 是 |
| `delete_pin` | `data[1]` = 标记点ID, `data[2]` = action_token | 删除指定标记点 | 是 |
| `update_pin` | `data[1]` = 标记点ID, `data[2]` = 新名称, `data[3]` = 新描述, `data[4]` = action_token | 重命名/改描述 | 是 |
| `share_waypoint` | `data[1]` = 路径点ID | 分享路径点到聊天栏 | 否 |
| `share_pin` | `data[1]` = 标记点ID | 分享标记点到聊天栏 | 否 |
| `claim_share` | `data[1]` = 分享码 | 聊天卡片点击领取分享点位 | 否 |

> Token 校验：`unlock_anchor` / `teleport_anchor` / `create_waypoint` / `delete_waypoint` / `update_waypoint` / `create_pin` / `delete_pin` / `update_pin` 八个写操作需要 action token 防重放。服务端在每次 `init`/`update` 包中下发 `action_token`，客户端写操作时需携带匹配的 token。Token 校验失败时操作被静默忽略。
>
> `claim_share` 不经 token 校验（点击者未必开着地图菜单），分享码本身即凭据，服务端校验存在性、有效期与数量上限。

## UI 客户端 Mod 交互

地图画面渲染由 **Arcart-Suite-Map 客户端 mod** 负责。mod 初始化后注册 Aria 全局函数 `axsmap.getMapRenderer()`，返回 `JavaObjectMirror` 包装的 `MapRenderer` 实例；UI 脚本懒加载缓存到 `var.mapRenderer` 后调用：

| 方法 | 调用时机 | 说明 |
|---|---|---|
| `setRegion(x, y, w, h, scale)` | 大地图 UI `tick` 每帧 | 传递地图渲染区的屏幕坐标和缩放比例 |
| `setHudAnchor(anchorX, anchorY, scale)` | HUD UI `tick` 每帧 | 传递小地图右上角锚点；mod 据此向左下延伸 hudSize×hudSize 区域 |
| `setWorldId(worldId)` | `packetHandler` init/update | 设置当前世界 ID |
| `setWorldDimension(worldId, dimension)` | `packetHandler` init/update | 注册 worldId → MC 维度 key 映射 |
| `setLitRegions(worldId, regions)` | `packetHandler` init/update | 下发已点亮区域多边形并集（传 `none` = 全亮） |
| `clearMarkers()` + `addMarker(id, type, name, x, z, selected, tracked, unlocked)` | `packetHandler` init/update 后 | 同步标点（`anchor`/`waypoint`/`external`/`pin`） |
| `getHudSize()` / `getHudShape()` | HUD UI `tick` | 读取 mod 内的小地图尺寸/形状供装饰控件使用 |
| `getMode()` / `deactivate()` / `closeHud()` | HUD UI `tick`/`close` | 渲染模式管理与停用（`deactivate` 延迟防抖，`closeHud` 立即停用） |

> mod 未安装时 `axsmap.getMapRenderer()` 抛异常（UI 已用 `try/catch` 兜底），地图渲染区保持空白，列表与详情面板功能不受影响。HUD 停止调用 `setHudAnchor` 约 150ms 后 mod 看门狗自动停用渲染。
>
> 小地图形状（圆形/方形）、尺寸、缩放由玩家在客户端用按键调整：`[` 切换形状、`+`/`-` 调整尺寸、`,`/`.` 调整缩放。

## 消息文件

消息文件 `messages.yml` 位于模块数据目录，支持 `&` 颜色码和 `{0}` `{1}` 占位符。修改后执行 `/axs reload map` 生效。

详细消息键列表参考 [配置 - 消息文件](./configuration#消息文件)。
