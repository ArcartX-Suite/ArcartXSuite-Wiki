# 锚点系统

## 概述

锚点是 Map 模块的核心功能之一，表示地图上可解锁、可传送的标记点。每个锚点绑定一个世界坐标，玩家可通过消耗货币和物品解锁锚点，解锁后可消耗货币传送到锚点位置。锚点还可配置点亮区域，解锁后在小地图上照亮对应范围（战争迷雾）。

> 锚点定义在各世界文件 `data/map/worlds/<世界ID>.yml` 的 `anchors` 节中，锚点所属世界由所在文件名决定。

## 锚点定义

锚点定义写在 `worlds/<世界ID>.yml` 的 `anchors` 节下，每个根键为锚点 ID：

```yaml
# data/map/worlds/world.yml
enabled: true
display-name: "主世界"

anchors:
  spawn:
    enabled: true
    display-name: "新手村"
    x: 0
    y: 80
    z: 0
    description: "所有玩家默认可见的主城锚点。"
    permission: ""
    sort-order: 0
    unlock:
      default: true          # 所有玩家进服自动免费解锁
      on-permission: false
    unlock-currencies: []
    teleport-currencies:
      - currency: "money"
        amount: 10
    unlock-items: []
    light-radius: 100        # 解锁后点亮半径 100 范围

  mine:
    enabled: true
    display-name: "矿洞入口"
    x: 128
    y: 64
    z: -42
    description: "示例锁定锚点，演示货币 + 物品解锁。"
    permission: ""
    sort-order: 10
    unlock-currencies:
      - currency: "money"
        amount: 200
      - currency: "points"
        amount: 5
    teleport-currencies:
      - currency: "money"
        amount: 30
    unlock-items:
      - amount: 2
        matcher:
          material-ids:
            - "ender_pearl"
    light-region:
      points: [[100, -70], [160, -70], [160, -10], [100, -10]]
```

### 字段说明

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | `boolean` | `true` | 是否启用此锚点 |
| `display-name` | `String` | 锚点 ID | 在地图上显示的名称 |
| `x` / `y` / `z` | `double` | `0` | 锚点坐标（世界由所在文件名决定） |
| `description` | `String` | `""` | 锚点描述文本，显示在详情面板 |
| `permission` | `String` | `""` | 使用此锚点所需权限（留空 = 无限制） |
| `sort-order` | `int` | 当前锚点数 | 排序权重（越小越靠前） |
| `unlock.default` | `boolean` | `false` | 所有玩家进服时自动免费解锁 |
| `unlock.on-permission` | `boolean` | `false` | 拥有 `permission` 权限的玩家进服时自动免费解锁 |
| `unlock-currencies` | `List` | `[]` | 解锁需消耗的货币列表 |
| `teleport-currencies` | `List` | `[]` | 传送需消耗的货币列表 |
| `unlock-items` | `List` | `[]` | 解锁需消耗的物品列表 |
| `light-region.points` | `List` | — | 点亮多边形顶点 `[[x,z],...]`（至少 3 点） |
| `light-radius` | `double` | `0` | 以锚点为中心的圆形点亮半径（方块数） |

> 锚点 ID 不区分大小写。不配 `light-region` 和 `light-radius` 时该锚点不参与点亮。

<Callout type="warn">
`unlock.on-permission: true` 但锚点未设置 `permission` 时，自动解锁不会生效。注意：**解锁记录 ≠ 使用权限**——自动解锁的玩家若锚点配了 `permission`，仍需有权限才能传送。
</Callout>

## 解锁与传送

### 解锁条件

玩家在详情面板点击「解锁」时依次检查：锚点存在且未解锁、`permission` 权限、物品与货币余额充足。全部通过才扣除费用并写入解锁记录；任一步失败时自动回滚，不会出现"扣了费没解锁"的情况。

### 传送条件

点击「传送」时检查：锚点存在且已解锁、权限、目标世界已加载、货币余额充足。传送失败时货币自动退还。

> 传送目标为锚点定义的 `x`/`y`/`z`，保留玩家当前视角朝向。

### 费用文本

详情面板自动生成费用文本：仅货币 `金币 x200`，多货币 `金币 x200 + 点券 x5`，含物品 `+ 物品条件 x2`，无费用显示 `免费解锁` / `免费传送`。

## 货币消耗

```yaml
unlock-currencies:
  - currency: "money"
    amount: 200
  - currency: "points"
    amount: 5
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `currency` | `String` | 货币 ID（不区分大小写） |
| `amount` | `BigDecimal` | 消耗金额，必须 `> 0` |

> 货币系统支持 Vault、PlayerPoints 等，通过宿主货币桥接解析。

## 物品消耗

```yaml
unlock-items:
  - amount: 2
    matcher:
      material-ids:
        - "ender_pearl"
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `amount` | `int` | 消耗数量（最小 1） |
| `matcher` | `ItemMatcher` | 物品匹配器配置 |

> 物品匹配器语法详见 [物品来源](/docs/guide/item-sources)。

## 权限控制

| 配置 | 效果 |
|---|---|
| `permission: ""` | 无权限限制 |
| `permission: "arcartxsuite.map.vip"` | 仅拥有该权限的玩家可解锁和传送 |

路径点与标记点数量上限通过 `waypoints.limits` 按权限区分：

```yaml
waypoints:
  default-max-count: 50
  limits:
    - permission: "ArcartXSuite.map.vip"
      max-count: 100
```

最终上限取 `default-max-count` 与所有匹配权限上限的最大值，按世界独立计算。

| 权限节点 | 默认 | 说明 |
|---|---|---|
| `arcartxsuite.map.use` | 所有玩家 | 使用 `/map` 玩家命令 |
| `arcartxsuite.map.admin` | OP | 管理权限 |

## 自动解锁

每个锚点可通过 `unlock` 节配置自动解锁：

```yaml
anchors:
  spawn:
    unlock:
      default: true          # 所有玩家进服自动免费解锁
      on-permission: false

  vip_hall:
    permission: "arcartxsuite.map.vip"
    unlock:
      on-permission: true    # VIP 玩家进服自动解锁
```

| 字段 | 说明 |
|---|---|
| `unlock.default` | 所有玩家进服时自动免费解锁（不消耗解锁费用） |
| `unlock.on-permission` | 拥有锚点 `permission` 权限的玩家进服时自动免费解锁 |

> 自动解锁在客户端初始化完成时触发，每个玩家一次会话只执行一次。不配 `unlock` 节 = 需手动解锁。

## 锚点排序

锚点在地图菜单中按 `sort-order` 升序排列，相同值按 `display-name` 字母序（不区分大小写），仅对同一世界内生效。

## 玩家数据清除

`/axs purge` 支持按 UUID 或全量清理玩家地图数据（解锁记录、路径点、标记点）。
