# 客户端 Mod（ArcartX-Suite-Map）

ArcartX-Suite-Map 是 Map 模块的客户端渲染端。**地图画面完全由该 mod 在客户端实时渲染**——服务端不下发任何地图纹理。玩家必须安装对应版本/加载器的此 mod，大地图与小地图功能才可用。

## 安装要求

放入客户端 `mods/` 目录。下载时按你的 MC 版本 + 加载器选择对应 jar：

| Minecraft | Fabric | Forge | NeoForge |
|-----------|:------:|:-----:|:--------:|
| 1.20.1    | ✔      | ✔     | —        |
| 1.20.4    | ✔      | ✔     | —        |
| 1.21.1    | ✔      | —     | ✔        |
| 1.21.4    | ✔      | —     | ✔        |
| 1.21.8    | ✔      | —     | ✔        |
| 1.21.11   | ✔      | —     | ✔        |

另需对应版本/加载器的 **ArcartX 客户端 Mod（2.7.77+）**。

<Callout type="info">
客户端未装此 mod 时：地图打开后无地形画面，仅显示服务端推送的锚点/路径点列表。
</Callout>

## 玩家功能

| 功能 | 说明 |
|---|---|
| 全屏大地图 | `/map` 打开；滚轮缩放、拖动平移、世界切换、锚点/路径点/标记点列表与详情 |
| 小地图 HUD | 常驻圆形/方形小地图；玩家位置箭头、朝向、世界名、坐标、导航状态 |
| 实体雷达 | 周围实体圆点+名称标签；按 **V** 或设置面板开关；玩家/怪物/动物逐类显隐 |
| 洞穴图层 | 地下自动切换洞穴模式；大地图左下角手动切地表↔洞穴；按 **N** 循环切片深度 16/30/48/64 |
| 标记显示 | 锚点 `◎` / 路径点 `⚑` / 外部目标 `✦` / 标记点 `◈` |
| 导航指示 | 路标箭头、目标距离、路径标记 |
| 设置面板 | 大地图顶栏"设置"：小地图外观（形状/四角/尺寸/缩放）+ 实体显示偏好；跨设备自动恢复 |

## 服务端配合使用

| 服务端配置 | 影响 |
|---|---|
| `worlds/<世界ID>.yml` | 定义每世界的地图边界/锚点 |
| `config.yml` 的 `keybinds` 节 | 打开地图/切换小地图的按键由宿主统一注册 |
| 锚点 `light-region`/`light-radius` | 战争迷雾点亮范围 |

地图 UI 细节（控件/Aria）见服务端模块的 `map_hud.yml`/`map_menu.yml` 及 [配置](/docs/map/configuration)。
