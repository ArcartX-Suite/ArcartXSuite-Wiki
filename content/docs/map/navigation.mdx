# 导航追踪与路径标记

## 概述

Map 模块的导航功能允许玩家追踪锚点和自定义路径点，在客户端显示方向指引路标和路径提示。路径提示有两种互补的可视化方式（独立开关、可同时启用）：模型路径标记（依赖 Adyeshach）和贴图路径标记（无需实体）。

玩家**可同时追踪多个锚点/路径点**（各自独立做到达判定），但**屏幕路标与路径标记链始终只跟随"最新激活且同世界"的主目标**——避免多信标误导玩家；取消主目标后其余目标自动接管。

**第三方插件注册路径点默认不走此链路**：由来源模块/插件（如 QuestGPS）注入的目标，玩家点击"导航"时地图把请求转发给来源处理，路标与追踪由来源自行实现。例外：目标声明 `useMapNavigation=true` 时由地图内置导航执行，与锚点/路径点同链路。

> 导航功能依赖 ArcartX Waypoint。Waypoint 不可用时锚点/路径点导航不可用，但地图菜单、HUD 与第三方路径点转发不受影响。

## 导航配置

```yaml
navigation:
  enabled: true
  refresh-ticks: 20
  world-hint-interval: 30
  finish-range: 0
  finish-commands: []
  finish-rearm-buffer: 3.0
  waypoint:
    enabled: true
    style-id: "default"
    title-template: ""
  model-marker:
    enabled: true
    model-id: "waypoint"
    scale: 1.0
    default-state: "idle"
    animation: "rotate"
    y-offset: 2.0
    path-interval: 3.0
    path-max-markers: 20
    path-update-ticks: 10
    path-max-distance: 64.0
    path-reshow-buffer: 8
    path-max-iterations: 2000
  texture-marker:
    enabled: false
    texture: "nav_arrow"
    width: 100
    height: 100
    facing: false
    glowing: true
    y-offset: 0.1
    pitch: 90
    orient-to-path: true
    life-time: -1
    pulse:
      enabled: true
      from: 0.8
      to: 1.2
      duration: 20
      stagger: 2
    path-interval: 3.0
    path-max-markers: 20
    path-update-ticks: 10
    path-max-distance: 64.0
    path-reshow-buffer: 8
    path-max-iterations: 2000
```

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `navigation.enabled` | `boolean` | `true` | 是否启用导航追踪功能 |
| `navigation.refresh-ticks` | `int` | `20` | 目标刷新间隔（tick） |
| `navigation.waypoint.enabled` | `boolean` | `true` | 是否向客户端推送路标；`false` 时仅保留追踪态/到达判定/路径标记 |
| `navigation.waypoint.style-id` | `String` | `default` | 路标样式 ID（ArcartX `waypoint/` 目录下定义） |
| `navigation.waypoint.title-template` | `String` | `""` | 路标标题模板（`%label%`/`%type%`/`%distance%`/`%world%`/`%x%`/`%y%`/`%z%`），留空显示目标名 |
| `navigation.world-hint-interval` | `int` | `30` | 目标在其他世界时的提示节流间隔（秒），0 = 不提示 |
| `navigation.finish-range` | `double` | `0` | 到达触发半径（格），0 = 不启用；到达不取消导航 |
| `navigation.finish-commands` | `List<String>` | `[]` | 到达命令（控制台执行，`%player%` 占位） |
| `navigation.finish-rearm-buffer` | `double` | `3.0` | 到达判定滞回缓冲（格）：触发后须离开 `finish-range + 本值` 才重新武装 |

### 路标样式优先级

1. `navigation.waypoint.style-id`（导航专用）
2. `waypoints.default-style-id`（路径点默认）
3. 内置默认样式

## 追踪文本

追踪文本显示在菜单标题栏和 HUD 底部：

| 目标类型 | 追踪文本格式 | 示例 |
|---|---|---|
| 锚点 | `当前导航锚点: {label}` | `当前导航锚点: 新手村` |
| 路径点 | `当前导航路径点: {label}` | `当前导航路径点: 标记点-1` |
| 第三方插件注册路径点 | `当前导航任务点: {label}` | `当前导航任务点: 击杀世界Boss` |
| 多目标 | `正在导航 {N} 个目标` | `正在导航 2 个目标` |
| 无导航 | `当前未导航` | — |

## 导航操作

- **追踪**：在锚点/路径点详情面板点击「追踪」，目标加入追踪并成为主目标；旧目标保留追踪态与到达判定
- **取消单个目标**：详情面板点击「取消导航」，其余目标不受影响；若取消的是主目标，其余同世界目标自动接管路标/路线
- **清除全部**：点击「清除追踪」或 `/map cleartrack`
- **第三方路径点**：点击「导航」转发给来源处理（来源自导航），或点击「取消」通知来源停止；来源停止后目标标记仍保留在地图上

### 跨世界导航

目标在其他世界时，详情面板提供跨世界导航操作：

| 目标类型 | 行为 |
|---|---|
| 锚点 | 直接传送该锚点（扣传送费）→ 追踪 |
| 路径点/第三方目标 | 在目标世界找距目标最近的**已解锁**锚点 → 传送（扣该锚点传送费）→ 追踪目标 |

> 目标世界没有已解锁锚点时提示无法就近传送。

## 到达判定

- `finish-range > 0` 时进入半径触发**一次**到达回调与 `finish-commands`（控制台执行，支持 `%player%`/`%world%`/`%x%`/`%y%`/`%z%` 占位），并提示「已到达导航目标附近」
- 触发后须离开 `finish-range + finish-rearm-buffer` 才重新武装——防止边界抖动重复触发
- **到达不取消导航**：导航保持到玩家显式取消
- 目标在异世界时路标被抑制，按 `world-hint-interval` 节流提示；玩家传送到目标世界后自动恢复显示

## 导航互斥

Map 模块内部允许多个目标并行追踪（仅主目标有路标/路线）。跨来源互斥（QuestGPS ↔ Map）由双方协作：

| 方向 | 行为 |
|---|---|
| 来源 → 地图 | 来源开始自身导航时地图静默清除自身路标 |
| 地图 → 来源 | 玩家开始锚点/路径点导航时来源自动停止自身导航（目标标记保留在地图上） |

## 路径提示

- **模型路径标记**（`navigation.model-marker`）：沿寻路路径放置标记模型，客户端独立渲染，仅追踪玩家可见。需 Adyeshach。
- **贴图路径标记**（`navigation.texture-marker`）：沿路径向玩家单人下发贴图箭头，无需实体，天然玩家私有。

### 模型路径标记配置

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `model-marker.enabled` | `boolean` | `false` | 是否启用模型路径标记 |
| `model-marker.model-id` | `String` | `nav_beacon` | 模型 ID（资源包中的模型标识） |
| `model-marker.scale` | `double` | `1.0` | 缩放比例 |
| `model-marker.default-state` | `String` | `idle` | 默认状态 |
| `model-marker.animation` | `String` | `rotate` | 动画类型 |
| `model-marker.y-offset` | `double` | `2.0` | Y 轴偏移（方块） |
| `model-marker.path-*` | — | 见下表 | 路径寻路参数 |

### 贴图路径标记配置

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `texture-marker.enabled` | `boolean` | `false` | 是否启用贴图路径标记（需资源包中存在对应贴图） |
| `texture-marker.texture` | `String` | `nav_arrow` | 贴图资源 ID |
| `texture-marker.width` / `height` | `double` | `100` | 贴图渲染宽/高 |
| `texture-marker.facing` | `boolean` | `false` | `true` 始终面向玩家；`false` 按 pitch/yaw 定向（贴地箭头） |
| `texture-marker.glowing` | `boolean` | `true` | 是否泛光 |
| `texture-marker.y-offset` | `double` | `0.1` | 贴图相对路径点的 Y 轴偏移 |
| `texture-marker.pitch` | `double` | `90` | 俯仰角（贴地渲染 90） |
| `texture-marker.orient-to-path` | `boolean` | `true` | 朝向下一个路径点（贴地箭头指示方向） |
| `texture-marker.life-time` | `int` | `-1` | 贴图存活时长（-1 = 永续直到移除） |
| `texture-marker.pulse.*` | — | — | 循环缩放脉冲：`enabled`/`from`/`to`/`duration`/`stagger`（按路径点序号错开形成波浪效果） |
| `texture-marker.path-*` | — | 见下表 | 路径寻路参数 |

### 路径寻路参数

两种渲染方式各自带一组同语义的 `path-*` 参数：

| 参数 | 作用 | 调优建议 |
|---|---|---|
| `path-interval` | 点间距 | 值越小标记越密集，视觉引导更清晰但开销越大 |
| `path-max-markers` | 最大点数 | 限制同时存在的标记数量 |
| `path-update-ticks` | 更新间隔 | 值越小路径跟随越平滑但开销越大 |
| `path-max-distance` | 最大距离 | 超过此距离的路径截断 |
| `path-reshow-buffer` | 滞回缓冲 | 超距隐藏后须回到 `path-max-distance - 本值` 以内才重新显示 |
| `path-max-iterations` | 最大迭代 | 路径计算的安全限制（范围 100-50000） |

> 两种渲染方式依赖不同组件：模型标记需 Adyeshach，贴图标记仅需 ArcartX。缺失组件时仅对应提示关闭，互不影响。

## 第三方插件注册路径点

第三方插件注册路径点由其他模块/插件注入：渲染为紫色标记、不占玩家路径点上限，生命周期归来源管理，玩家退出时自动清除。

| 注入方式 | 说明 |
|---|---|
| `select=true` 注入 | 自动切换到目标所在世界并选中该目标 |
| 批量/原子替换 | 目标被移除时自动清除选中与追踪 |
| 排序 | 先按 `sortOrder` 升序，相同按 `title` 字母序 |

来源可为路径点注册"导航/取消"回调；目标声明 `useMapNavigation=true` 时改由地图内置导航执行。开发接入详见 [联动](./integration) 与 [Capability 参考](/docs/api/capability)。

## 自定义路径点与标记点

- **路径点**：玩家创建的可导航点位（含 Y 坐标）
- **标记点（Pin）**：地图上单击放置的纯标记——仅 X/Z 坐标，不可导航

### 数量上限

路径点与标记点**合计**计数，按世界独立计算：

| 计算规则 | 说明 |
|---|---|
| 基础上限 | `waypoints.default-max-count`（默认 50） |
| 权限上限 | `waypoints.limits` 中匹配玩家权限的最大 `max-count` |
| 最终上限 | `max(基础上限, 所有匹配权限上限的最大值)` |

### 点位分享

玩家可把路径点/标记点分享到聊天栏：

| 操作 | 说明 |
|---|---|
| 分享 | 生成分享码，优先发送聊天卡片，卡片不可用时降级文本广播 |
| 领取 | 聊天卡片按钮或 `/map claim <码>` 领取到自己的列表 |

- 分享码有效期 `share.expire-minutes`（默认 30 分钟），重启失效
- 领取时校验分享码存在性、有效期、以及领取者的每世界上限

### 持久化

路径点与标记点存储在数据库中，玩家维度持久化。

## EventBus 主题

Map 模块向 EventBus 发布以下主题（其他模块可订阅）：

| 主题 | 触发时机 | Payload |
|---|---|---|
| `axs.map.nav_started` | 玩家开始锚点/路径点导航 | `type`、`id`、`world_id` |
| `axs.map.nav_cleared` | 玩家停止地图导航（含被来源接管） | `type`、`id`、`world_id`、`reason` |
| `axs.map.external_navigate` | 面板点击第三方插件注册路径点"导航" | `target_id`、`source`、`world_id` |
| `axs.map.external_nav_cancel` | 面板点击第三方插件注册路径点"取消" | `target_id`、`source`、`world_id` |

## 状态检查

- `/axs map status` 可查看路标系统是否就绪（Waypoint 可用性）
- 玩家退出服务器时自动清除其全部导航状态；模块关闭时为所有在线玩家清除追踪并关闭 HUD
