# 导航追踪与路径标记

## 概述

Map 模块的导航功能允许玩家追踪锚点和自定义路径点，在客户端显示方向指引路标和路径标记实体。导航功能通过 `WaypointBridgeAPI` 创建客户端路标，可选通过 `AdyeshachNpcBridgeAPI` 渲染路径标记模型。

**外部目标不走此链路**：外部目标由来源模块/插件（如 QuestGPS）注入展示，玩家点击"导航"时地图只负责把请求**转发给来源注册的 `MapNavigationHandler` 回调**，信标、路径标记、追踪状态由来源全权执行。

导航功能涉及以下组件：

| 组件 | 类 | 职责 |
|---|---|---|
| 导航状态 | `MapNavigationState` | 记录玩家当前追踪的目标类型、ID 和标签 |
| 路标桥接 | `WaypointBridgeAPI` | 创建/移除客户端路标导航 |
| 标记服务 | `NavigationMarkerService` | 沿路径放置 Adyeshach 标记实体 |
| NPC 桥接 | `AdyeshachNpcBridgeAPI` | 创建私有实体渲染客户端模型 |
| 外部目标 | `MapExternalTarget` / `MapExternalTargetSpec` | 其他模块注入的临时导航目标 |
| 导航回调 | `MapNavigationHandler` | 来源注册的"导航/取消"处理器 |
| 能力接口 | `MapNavigable` | 供外部模块/插件调用的导航能力（公开 capability） |

> 导航功能依赖 ArcartX Waypoint。Waypoint 不可用时锚点/路径点导航不可用（`waypointRuntimeReady` 返回 `false`），但地图菜单和 HUD 正常使用，外部目标转发不受影响。

## 导航配置

### 顶层导航配置

```yaml
navigation:
  enabled: true
  waypoint-style-id: "default"
  anchor-id-prefix: "AXS-map-anchor-"
  waypoint-id-prefix: "AXS-map-track-"
  marker:
    enabled: true
    model-id: "waypoint"
    scale: 1.0
    default-state: "idle"
    animation: "rotate"
    y-offset: 2.0
    path-interval: 3.0
    path-max-markers: 20
    path-update-ticks: 10
    path-max-distance: 64.0
    path-max-iterations: 2000
```

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `navigation.enabled` | `boolean` | `true` | 是否启用导航追踪功能 |
| `navigation.waypoint-style-id` | `String` | `default` | 路径点导航样式 ID |
| `navigation.anchor-id-prefix` | `String` | `AXS-map-anchor-` | 锚点导航在客户端的 ID 前缀 |
| `navigation.waypoint-id-prefix` | `String` | `AXS-map-track-` | 路径点导航在客户端的 ID 前缀 |

### 路径点样式

路标样式 ID 通过 `WaypointBridgeAPI.resolveStyleId()` 解析，优先级如下：

| 优先级 | 来源 | 配置项 |
|---|---|---|
| 1 | 导航专用样式 | `navigation.waypoint-style-id` |
| 2 | 路径点默认样式 | `waypoints.default-style-id` |
| 3 | 桥接默认样式 | `WaypointBridgeAPI` 内部默认 |

> 路径点样式参考 /docs/guide/icons 了解图标与样式配置。

## 导航状态

### 状态模型

`MapNavigationState` 记录玩家当前的导航追踪状态：

| 字段 | 类型 | 说明 |
|---|---|---|
| `active` | `boolean` | 是否正在导航 |
| `targetType` | `TargetType` | 目标类型：`NONE` / `ANCHOR` / `WAYPOINT` / `EXTERNAL` |
| `worldId` | `String` | 目标所在世界 ID |
| `targetId` | `String` | 目标唯一标识 |
| `waypointId` | `String` | 关联的客户端路标 ID |
| `label` | `String` | 导航显示标签 |
| `source` | `String` | 来源模块标识（外部目标时有效） |

> `EXTERNAL` 类型仅用于事件与状态标记——外部目标的导航实体由来源自行创建，地图不为其建信标。

### 状态匹配

`MapNavigationState` 提供三个匹配方法，用于 UI 快照构建时标记列表项的 `tracked` 状态：

| 方法 | 匹配条件 | 用途 |
|---|---|---|
| `matchesAnchor(anchorId)` | `active && targetType == ANCHOR && targetId == anchorId` | 判断是否正在追踪指定锚点 |
| `matchesWaypoint(waypointId)` | `active && targetType == WAYPOINT && targetId == waypointId` | 判断是否正在追踪指定路径点 |
| `matchesExternal(targetId)` | `active && targetType == EXTERNAL && targetId == targetId` | 判断是否正在追踪指定外部目标 |

### 追踪文本

导航状态生成追踪文本，显示在菜单标题栏和 HUD 底部：

| 目标类型 | 追踪文本格式 | 示例 |
|---|---|---|
| 锚点 | `当前导航锚点: {label}` | `当前导航锚点: 新手村` |
| 路径点 | `当前导航路径点: {label}` | `当前导航路径点: 标记点-1` |
| 外部目标 | `当前导航任务点: {label}` | `当前导航任务点: 击杀世界Boss` |
| 无导航 | `当前未导航` | — |

## 导航操作

### 追踪锚点

```
玩家点击「追踪」按钮
  └→ UI 发送 track_anchor Packet
       └→ MapService.trackAnchorInternal()
            1. 检查导航是否启用
            2. 检查锚点是否存在
            3. 检查 Waypoint 桥接是否可用
            4. 清除当前追踪（clearTrackSilently）
            5. 生成路标 ID：anchorIdPrefix + sanitize(anchor.id())
            6. 解析样式 ID
            7. 创建客户端路标：waypointBridge.addWaypoint()
            8. 更新导航状态 + 发布 axs.map.nav_started
            9. 显示路径标记（若启用）
            10. 刷新 UI
```

### 追踪路径点

```
玩家点击「追踪」按钮
  └→ UI 发送 track_waypoint Packet
       └→ MapService.trackWaypointInternal()
            1. 检查导航是否启用
            2. 查找玩家路径点
            3. 检查 Waypoint 桥接是否可用
            4. 清除当前追踪
            5. 生成路标 ID：waypointIdPrefix + sanitize(waypoint.waypointId())
            6. 解析样式 ID
            7. 创建客户端路标
            8. 更新导航状态 + 发布 axs.map.nav_started
            9. 显示路径标记
            10. 刷新 UI
```

### 追踪外部目标（转发给来源）

```
玩家点击「导航」按钮
  └→ UI 发送 external_navigate / track_external Packet
       └→ MapService.requestExternalNavigate()
            1. 查找外部目标
            2. 发布 axs.map.external_navigate 事件（监测/兜底用）
            3. 查找目标 source 注册的 MapNavigationHandler
            4. 调用 handler.onNavigateRequest(player, targetId)
            5. 返回 false 或无 handler → 提示「该目标的来源未提供导航支持」
```

> 地图不为外部目标创建信标/路径标记。来源收到回调后自行接管导航（如 QuestGPS 创建任务路标），并通过 `setExternalNavigated` 回推状态让面板按钮切换为"取消"。

### 取消外部目标导航

```
玩家点击「取消」按钮
  └→ UI 发送 external_nav_cancel Packet
       └→ MapService.requestExternalCancel()
            1. 发布 axs.map.external_nav_cancel 事件
            2. 调用来源 handler.onCancelRequest(player, targetId)
            3. 来源停止自身导航，目标标记保留在地图上
```

### 跨世界导航

`cross_world_navigate`（参数 `类型:目标ID`）处理目标在异世界的情况：

| 目标类型 | 流程 |
|---|---|
| `anchor` | 直接传送该锚点（扣传送费）→ 追踪 |
| `waypoint` | 在目标世界找距目标最近的**已解锁**锚点 → 传送（扣该锚点传送费）→ 追踪路径点 |
| `external` | 同上就近锚点传送 → 调 `requestExternalNavigate` 交给来源接管 |

> 目标世界没有已解锁锚点时提示「目标世界没有已解锁的锚点，无法就近传送」。另有 `teleport_to_world`（参数=世界ID）直接传送到世界出生点。

### 清除追踪

```
玩家点击「清除追踪」/ 执行 /map cleartrack
  └→ UI 发送 clear_track Packet
       └→ MapService.clearTrackInternal()
            1. 检查是否有活动导航
            2. 移除客户端路标：waypointBridge.removeWaypoint()
            3. 移除导航状态 + 发布 axs.map.nav_cleared
            4. 隐藏路径标记
            5. 刷新 UI
```

> `clearTrackSilently()` 为内部方法，清除追踪时不发送反馈消息，用于切换追踪目标前的静默清理。

### 路标 ID 生成规则

路标 ID 通过 `sanitize()` 方法清理特殊字符，仅保留 `a-z0-9_-`：

| 目标类型 | 生成规则 | 示例 |
|---|---|---|
| 锚点 | `anchorIdPrefix + sanitize(anchorId)` | `AXS-map-anchor-spawn` |
| 路径点 | `waypointIdPrefix + sanitize(waypointId)` | `AXS-map-track-abc123def456` |

> 外部目标不再由地图生成路标 ID（导航实体归来源管理）。

## 导航互斥

同一时间一个玩家只有一个活跃导航。互斥由双方协作实现：

| 方向 | 机制 |
|---|---|
| 来源 → 地图 | 来源开始自身导航时调用 `MapNavigable.clearTrack(player)`，地图静默清除自身信标并发布 `nav_cleared`（reason=`source_took_over`） |
| 地图 → 来源 | 玩家开始锚点/路径点导航时地图发布 `axs.map.nav_started`，来源订阅后停止自身导航（目标标记保留在地图上） |

## 路径标记模型

### 标记配置

路径标记模型通过 `navigation.marker` 配置节控制：

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `marker.enabled` | `boolean` | `false`（默认配置文件为 `true`） | 是否启用标记模型 |
| `marker.model-id` | `String` | `nav_beacon`（默认配置文件为 `waypoint`） | 模型 ID（资源包中的模型标识） |
| `marker.scale` | `double` | `1.0` | 缩放比例 |
| `marker.default-state` | `String` | `idle` | 默认状态 |
| `marker.animation` | `String` | `rotate` | 动画类型 |
| `marker.y-offset` | `double` | `2.0` | Y 轴偏移（方块） |
| `marker.path-interval` | `double` | `3.0` | 路径标记间距（方块） |
| `marker.path-max-markers` | `int` | `20` | 路径最大标记数 |
| `marker.path-update-ticks` | `int` | `10` | 路径更新间隔（tick） |
| `marker.path-max-distance` | `double` | `64.0` | 路径最大距离（方块） |
| `marker.path-max-iterations` | `int` | `2000` | 路径计算最大迭代次数 |

### 标记服务

`NavigationMarkerService` 负责沿导航路径放置标记实体：

| 操作 | 方法 | 说明 |
|---|---|---|
| 显示标记 | `showMarker(player, worldId, x, y, z)` | 在目标坐标显示单个标记，并启动路径标记定时任务 |
| 隐藏标记 | `hideMarker(player)` | 移除该玩家的所有标记实体 |
| 启动服务 | `start()` | 初始化标记服务 |
| 关闭服务 | `shutdown()` | 清理所有标记实体 |

> 标记服务依赖 `AdyeshachNpcBridgeAPI`。Adyeshach 不存在时标记功能自动关闭，路标导航不受影响。

### 路径标记参数说明

| 参数 | 作用 | 调优建议 |
|---|---|---|
| `path-interval` | 标记间距 | 值越小标记越密集，视觉引导更清晰但实体更多 |
| `path-max-markers` | 最大标记数 | 限制同时存在的标记实体数量，防止性能问题 |
| `path-update-ticks` | 更新间隔 | 值越小更新越频繁，路径跟随越平滑但开销越大 |
| `path-max-distance` | 最大距离 | 超过此距离的路径截断，防止远距离导航生成过多标记 |
| `path-max-iterations` | 最大迭代 | 路径计算的安全限制，防止死循环 |

> 路径标记仅在追踪状态变更时创建/移除，客户端独立渲染。标记实体为 Adyeshach 私有实体，仅追踪玩家可见。

## 外部目标

### 外部目标模型

`MapExternalTarget` 表示由其他模块/插件注入的临时导航目标（紫色标记，不占玩家路径点上限）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `targetId` | `String` | 目标唯一标识 |
| `source` | `String` | 来源标识（如 `questgps`） |
| `worldId` | `String` | 所在世界 ID |
| `title` | `String` | 显示标题 |
| `description` | `String` | 显示描述 |
| `x` / `y` / `z` | `double` | 世界坐标 |
| `iconId` | `String` | 图标 ID（可空） |
| `navigated` | `boolean` | 是否导航中（驱动"导航 ↔ 取消"按钮） |
| `sortOrder` | `int` | 排序权重（越小越靠前） |

### MapNavigable 能力

Map 模块注册 `MapNavigable` **公开 capability**（`@PublicCapability`），AXS 模块内部经 `getCapability(MapNavigable.class)` 获取，外部 Bukkit 插件经 `AxsCapabilities.get(MapNavigable.class)` 获取：

| 方法 | 说明 |
|---|---|
| `upsertExternalTarget(player, spec, select)` | 新增/更新单个外部目标；`select=true` 切到目标世界并选中 |
| `upsertExternalTargets(player, specs)` | 批量推送，一次视图同步 |
| `reconcileExternalTargets(player, source, specs)` | 原子替换某来源的全部目标，仍存在的目标选中态不闪断；空列表 = 清空该来源 |
| `clearExternalTargets(player, source, syncView)` | 按来源清除（空串 = 全部来源） |
| `setExternalNavigated(player, targetId, navigated)` | 来源回推导航状态，驱动面板按钮切换 |
| `registerNavigationSource(owner, source, handler)` | 注册来源导航回调；`owner` 插件禁用时自动注销 |
| `unregisterNavigationSource(source)` | 注销来源导航回调 |
| `clearTrack(player)` | 静默清除地图自身导航（来源起导航时调用，实现互斥） |
| `openMenuFor(player, targetId)` | 打开地图并选中目标；依次匹配外部目标 → 路径点 → 标记点，未命中按世界 ID 兜底 |

详见 [联动](./integration) 与 [Capability 参考](/docs/api/capability)。

### 外部目标管理

`MapService` 为每个玩家维护外部目标映射（内存态，不持久化）：

| 场景 | 行为 |
|---|---|
| 注入目标时 `select=true` | 自动切换到目标所在世界并选中该目标 |
| `reconcile` 后目标被移除 | 若正在选中/追踪该目标，自动清除选中 |
| 按来源清除时正在追踪该来源目标 | 自动清除导航追踪 |
| 玩家退出服务器 | 外部目标自动清除 |

### 外部目标排序

1. 先按 `sortOrder` 升序排列
2. 相同 `sortOrder` 的按 `title` 字母顺序排列（不区分大小写）

## 自定义路径点与标记点

### 路径点模型

`MapWaypoint` 记录玩家创建的可导航路径点（含 Y 坐标）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `waypointId` | `String` | 路径点唯一标识 |
| `name` | `String` | 路径点名称 |
| `description` | `String` | 描述 |
| `world` | `String` | 所在世界 ID |
| `x` / `y` / `z` | `double` | 世界坐标 |
| `createdAt` / `updatedAt` | `long` | 创建/更新时间戳 |

### 标记点模型（Pin）

`MapPin` 记录玩家在地图上单击放置的标记点——**仅 X/Z 坐标，不可导航**，只用于标记位置：

| 字段 | 类型 | 说明 |
|---|---|---|
| `pinId` | `String` | 标记点唯一标识（`idPrefix + "pin-" + UUID`） |
| `name` | `String` | 名称（默认 `autoNamePrefix + "-标记-" + N`） |
| `description` | `String` | 描述 |
| `world` | `String` | 所在世界 ID |
| `x` / `z` | `double` | 世界坐标 |
| `createdAt` / `updatedAt` | `long` | 创建/更新时间戳 |

### 创建路径点 / 标记点

```
玩家点击「创建路径点」/ 在大地图上单击放置标记点
  └→ UI 发送 create_waypoint / create_pin Packet（含 action_token）
       └→ MapUiPacketHandler.beginActionToken() 校验 token
       └→ MapService.createWaypoint() / createPin()
            1. 检查 waypoints.enabled
            2. 检查当前世界是否已配置地图
            3. 计算当前世界数量（路径点 + 标记点合计）
            4. 检查是否已达上限
            5. 生成 ID 与默认名称
            6. 原子创建：createWaypointIfUnderWorldLimit / createPinIfUnderWorldLimit
            7. 刷新缓存，选中新条目，刷新 UI
```

> `update_waypoint` / `update_pin` 支持重命名与改描述（同样需要 token）。

### 数量上限

路径点与标记点**合计**计数，上限通过 `resolveWaypointLimit()` 计算：

| 计算规则 | 说明 |
|---|---|
| 基础上限 | `waypoints.default-max-count`（默认配置 50） |
| 权限上限 | `waypoints.limits` 中匹配玩家权限的最大 `max-count` |
| 最终上限 | `max(default-max-count, 所有匹配权限的 limits 最大值)` |

> 上限按世界独立计算。

### 点位分享

玩家可把路径点/标记点分享到聊天栏：

| 操作 | 说明 |
|---|---|
| `share_waypoint` / `share_pin` | 生成分享码 → 尝试发送聊天卡片 `axs_map_share` → 卡片不可用时降级文本广播 |
| `claim_share` / `/map claim <码>` | 领取分享点位到自己的路径点/标记点列表 |

- 分享码缓存在内存 `shareCache`，有效期 `share.expire-minutes`（默认 30 分钟），重启失效
- 领取时校验分享码存在性、有效期、以及领取者的每世界上限
- 聊天卡片自动导出到 `plugins/ArcartX/chat_card/axs_map_share.yml`，按钮触发 `claim_share` packet

### 持久化

路径点存 `AXS_map_waypoints` 表，标记点存 `AXS_map_pins` 表，主键均为 `(uuid, id)`。

> 数据通过 `CachedPlayerMapData` 缓存，创建/删除后自动刷新缓存。

## EventBus 主题

Map 模块向 EventBus 发布以下主题（来源/其他插件可订阅）：

| 主题 | 触发时机 | Payload |
|---|---|---|
| `axs.map.nav_started` | 玩家开始锚点/路径点导航 | `type`、`id`、`world_id` |
| `axs.map.nav_cleared` | 玩家停止地图导航（含被来源接管） | `type`、`id`、`world_id`、`reason` |
| `axs.map.external_navigate` | 面板点击外部目标"导航" | `target_id`、`source`、`world_id` |
| `axs.map.external_nav_cancel` | 面板点击外部目标"取消" | `target_id`、`source`、`world_id` |

## 服务生命周期

### 启动流程

```
MapModule.startService()
  └→ repository.initialize()  // 创建数据库表
  └→ if navigation.enabled:
       waypointBridge.initialize("Map 导航")
  └→ if navigation.marker.enabled && npcBridge != null:
       npcBridge.initialize()
       markerService = new NavigationMarkerService(...)
       markerService.start()
  └→ 注册 MapNavigable / PlayerDataPurgeable / DatabaseMigratable capability
  └→ Bukkit.getPluginManager().registerEvents(this, plugin)
```

### 关闭流程

```
MapModule.stopService()
  └→ MapService.shutdown()
       └→ HandlerList.unregisterAll(this)  // 注销事件监听
       └→ for each online player:
            clearTrackSilently(player)  // 清除所有追踪
            bridge.closeUi(player, hudUiId)  // 关闭 HUD
       └→ if markerService != null:
            markerService.shutdown()  // 清理标记实体
       └→ repository.shutdown()  // 关闭数据库连接
       └→ waypointBridge.shutdown()  // 关闭路标系统
       └→ 清理所有内存状态
```

> 服务关闭时为所有在线玩家清除追踪并关闭 HUD，防止客户端残留路标和标记。

## 运行时状态检查

### 路径点就绪状态

`waypointRuntimeReady()` 判断路径点导航是否可用：

| 条件 | 返回值 | 说明 |
|---|---|---|
| 导航未启用 | `true` | 无需路标，视为就绪 |
| 导航启用且 Waypoint 可用 | `true` | 路标系统正常 |
| 导航启用但 Waypoint 不可用 | `false` | 路标系统未安装 |

> `/axs map status` 的 `Waypoint` 输出项即 `waypointRuntimeReady()` 的返回值。

### 追踪玩家计数

`trackingPlayerCount()` 返回当前正在导航的在线玩家数。玩家退出服务器时自动清除其导航状态（`onPlayerQuit` 事件处理器）。
