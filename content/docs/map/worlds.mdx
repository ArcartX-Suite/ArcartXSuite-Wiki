# 世界与地图渲染

## 概述

Map 模块的世界配置与地图画面完全解耦：**地图地形由 ArcartX-Suite-Map 客户端 mod 扫描客户端区块实时渲染**，服务端不需要、也不再支持地图纹理图片配置（`texture`/`image-width`/`pixel-offset-x` 等旧字段已废弃）。

服务端只负责：

- 告诉 mod 当前要渲染哪个世界（`worldId`）以及它对应的 MC 维度 key
- 下发已点亮区域（战争迷雾数据）
- 下发标点列表（锚点/路径点/标记点/第三方插件注册路径点）与详情数据

mod 侧负责：区块地形扫描、地图纹理生成、缩放/平移/形状交互、标点与玩家箭头绘制、探索缓存。

| 场景 | UI | 说明 |
|---|---|---|
| 全屏大地图 | `map_menu.yml` | 世界切换、滚轮缩放、拖拽平移、单击放置标记点 |
| 小地图 HUD | `map_hud.yml` | 屏幕四角常驻（默认右上角），圆形/方形切换，实时显示玩家位置与朝向 |

> mod 未安装时渲染区保持空白，UI 的列表、详情面板、解锁、传送、分享等功能不受影响。

## 世界配置

### 目录结构

每个世界一个独立文件，放在 `data/map/worlds/` 目录下（目录名由 `worlds-directory` 配置，默认 `worlds`），**文件名即世界 ID**（对应 Bukkit world name，大小写不敏感）：

```
data/map/
  ArcartXMap.yml
  worlds/
    world.yml            ← 世界 ID = world
    bskyblock_world.yml  ← 世界 ID = bskyblock_world
```

模块启动时按文件名字母顺序加载目录下所有 `.yml` 文件。目录不存在时自动创建并导出示例文件 `worlds/world.yml`。

### 字段说明

```yaml
# worlds/world.yml — 文件名即世界 ID
enabled: true
display-name: ""

anchors:
  spawn:
    enabled: true
    display-name: "出生点"
    x: 0
    y: 64
    z: 0
    description: "默认出生点锚点。"
    permission: ""
    sort-order: 0
    unlock:
      default: true
      on-permission: false
    unlock-currencies: []
    teleport-currencies: []
    unlock-items: []
    # light-region:
    #   points: [[-50, -50], [50, -50], [50, 50], [-50, 50]]
    # light-radius: 100
```

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | `boolean` | `true` | 是否在地图菜单中显示此世界 |
| `display-name` | `String` | `""` | 显示名称；留空时运行时从 Multiverse-Core colourless alias 自动补 |
| `anchors` | `Map` | — | 该世界的锚点列表（见 [锚点系统](./anchors)） |

<Callout type="info">
维度（dimension）完全自动按 Bukkit `world.getKey()` 解析下发给客户端 mod，无需配置。旧版本的 `texture`、`image-width/height`、`pixel-offset-x/z`、`default-zoom`、`hud-zoom`、`hud-size` 字段已全部废弃——缩放与偏移由玩家在客户端用鼠标滚轮/拖拽实时控制。
</Callout>

### 世界选择逻辑

当玩家打开地图或 HUD 时，按以下优先级确定初始世界：

1. 玩家请求指定的世界 ID（已配置时使用）
2. 玩家在地图中已选中的世界
3. 玩家当前所在的世界（已配置时）
4. 配置中的第一个世界

> 均不满足时，地图菜单提示「当前世界未配置地图，且没有可用的默认地图」，HUD 提示「当前没有可显示的小地图世界」。

### 旧格式兼容

若 `worlds/` 目录为空或不存在世界文件，模块回退读取 `ArcartXMap.yml` 中的内联 `worlds` 节（仅取 `enabled`/`display-name`，纹理字段被忽略）：

```yaml
# ArcartXMap.yml — 旧格式降级，不推荐
worlds:
  world:
    enabled: true
    display-name: "主世界"
```

> 内联 `worlds` 节不含 `anchors`——锚点必须写在 `worlds/<worldId>.yml` 的 `anchors` 节中。

## 点亮区域（战争迷雾）

锚点可配置点亮区域：玩家解锁该锚点后，小地图上对应区域从迷雾中亮起。未点亮的区域由 mod 渲染遮罩。

每个锚点支持两种写法（可同时配置，任一生效即可）：

| 字段 | 格式 | 说明 |
|---|---|---|
| `light-region.points` | `[[x,z], ...]` | 多边形顶点列表（至少 3 点），世界坐标 |
| `light-radius` | 数值 | 以锚点为中心的圆形点亮半径（方块数） |

```yaml
anchors:
  spawn:
    # ...
    light-region:
      points: [[-50, -50], [50, -50], [50, 50], [-50, 50]]
    light-radius: 100
```

服务端把已解锁锚点的点亮区域并集下发给客户端。不配置任何点亮字段 = 该锚点不参与点亮。

## 客户端渲染

- **地形扫描**：mod 扫描客户端区块实时生成地图纹理，已探索地形在断开连接时缓存，下次进服可直接显示
- **标点同步**：锚点、路径点、标记点和第三方插件注册路径点以世界坐标下发，mod 根据缩放和视野自行绘制
- **小地图**：按玩家选择的四角位置渲染，支持圆形/方形遮罩
- **看门狗**：HUD 数据停止更新约 150ms 后 mod 自动停用渲染

### 小地图客户端按键

小地图与雷达偏好由玩家在客户端用按键调整。mod 注册了一组原版键位绑定（可在 MC「选项 → 控制 → 按键绑定」中自行改键）：

| 按键（默认） | 作用 |
|---|---|
| `V` | 实体雷达开关 |
| `Z` | 小地图缩放档位循环（0.5× / 1× / 2× / 4×） |
| `N` | 洞穴切片深度循环（16 / 30 / 48 / 64） |
| `B` | 雷达名称字号循环（小 / 中 / 大） |

以下按键仅在小地图 HUD 激活且未打开任何界面时生效，不可改键：

| 按键 | 作用 |
|---|---|
| `[` | 切换圆形 / 方形小地图 |
| `+` / `-` | 调整小地图尺寸（50 ~ 150 px） |
| `,` / `.` | 微调小地图缩放 |

### 大地图交互

全屏地图的鼠标交互：滚轮缩放、左键拖拽平移、单击放置标记点（Pin）、右键复位视野。

地图菜单左下角还提供三个功能按钮（需安装客户端 mod）：

| 按钮 | 作用 |
|---|---|
| 浏览标记（☰） | 展开 / 收起标记浏览面板 |
| 图层（地表 / 洞穴） | 大地图地表 ↔ 洞穴切片视图切换；仅影响大地图浏览，小地图始终跟随玩家实际位置 |
| 深 N | 洞穴切片深度循环（16 / 30 / 48 / 64，等价按 N） |

## 地图设置与实体雷达

### 地图设置面板

大地图顶栏「设置」按钮展开居中模态面板：左栏「小地图」调 HUD 外观，右栏「实体显示」调实体雷达，底部附快捷键提示。

| 分区 | 选项 | 说明 |
|---|---|---|
| 小地图 | 形状 | 圆形 / 方形 |
| 小地图 | 位置 | 左上 / 右上 / 左下 / 右下四角 |
| 小地图 | 尺寸 | ±25 px 步进（范围 50 ~ 150 px） |
| 小地图 | 缩放 | ×0.8 / ×1.25 步进（范围 0.25 ~ 4.0 倍） |
| 实体显示 | 实体雷达 | 小地图与大地图实体圆点总开关（等价按 V） |
| 实体显示 | 名称标签 | 实体名称标签开关 |
| 实体显示 | 类别 | 玩家 / 怪物 / 动物三路独立显隐 |

### 实体雷达

开启后小地图与大地图以圆点显示周围实体，可叠加名称标签；玩家/NPC、敌对生物、被动生物三类可独立显隐，名称字号按 B 键在小 / 中 / 大档循环。Adyeshach 导航标记等盔甲架实体不参与绘制。

### 玩家设置留存

以上全部偏好（雷达开关、名称标签、逐类显隐、名称字号、洞穴深度、小地图缩放/形状/位置/尺寸）双端留存：

- **客户端**：写入 `<游戏目录>/arcartxsuitemap/options.properties`，改动即保存
- **服务端**：按玩家同步存储，进服时自动恢复——换设备或重装客户端后偏好仍保留

## 多世界切换

玩家在地图菜单点击世界列表项即可切换世界视图，标点选中状态自动清除。世界列表按 `worlds/` 目录文件名字母序排列，每项显示世界名称和选中状态。
