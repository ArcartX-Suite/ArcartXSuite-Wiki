## 从一个世界和一个锚点开始

文件名必须对应实际世界。若测试世界为 `world`，在 `plugins/ArcartX-Suite/data/map/worlds/world.yml` 合并下例，并把锚点坐标换成玩家能够站立的安全落点。其他世界使用其真实名称建文件。

```yaml
enabled: true
display-name: "生存世界"
anchors:
  trial_spawn:
    enabled: true
    display-name: "试炼出生点"
    x: 0
    y: 80
    z: 0
    permission: ""
    unlock:
      default: true
```

管理员执行 `/axs reload map` 后，用 `/axs map anchors world` 确认 `trial_spawn` 已加载。普通玩家使用 `/map open world`，在左下角「☰」展开锚点列表并选择「试炼出生点」。确认免费解锁后可传送，实际落点与配置一致。最后在已探索区域确认地形出现。列表正常但地形空白时，先核对 Map 客户端扩展，再检查预加载范围和世界对应关系。

默认解锁只控制拥有状态，锚点另有 `permission` 时仍需持有权限。做付费解锁时先把默认解锁关闭，再逐项加入货币、物品和条件。移动锚点后重新检查落点，避免玩家传送到空气或方块内部。

已有地图地形发生大范围修改时，用 `/axs map refresh <世界ID>` 更新地形版本。先小范围验证，再扩大预加载范围。

## 概述

每个世界单独配置显示名称、锚点、预加载范围和点亮条件。玩家安装 [ArcartX-Suite-Map](./client-mod) 后可查看地图地形。

### 目录结构

每个世界一个独立文件，放在 `data/map/worlds/` 目录下（目录名由 `worlds-directory` 配置，默认 `worlds`），**文件名即世界 ID**（对应 Bukkit world name，大小写不敏感）：

```
data/map/
  config.yml
  worlds/
    world.yml            ← 世界 ID = world
    bskyblock_world.yml  ← 世界 ID = bskyblock_world
```

模块启动时按文件名字母顺序加载目录下所有 `.yml` 文件。目录不存在时自动创建并导出示例文件 `worlds/world.yml`。

### 字段说明

```yaml
# worlds/world.yml — 文件名即世界 ID
enabled: true
display-name: ""

anchors:
  spawn:
    enabled: true
    display-name: "出生点"
    x: 0
    y: 64
    z: 0
    description: "默认出生点锚点。"
    permission: ""
    sort-order: 0
    unlock:
      default: true
      on-permission: false
      currencies: []
      items: []
    teleport:
      currencies: []
      items: []
    light:
      radius: 100
```

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | `boolean` | `true` | 是否在地图菜单中显示此世界 |
| `display-name` | `String` | `""` | 显示名称；留空时运行时从 Multiverse-Core colourless alias 自动补 |
| `anchors` | `Map` | — | 该世界的锚点列表（见 [锚点系统](./anchors)） |

<Callout type="info">
世界维度自动识别，无需手动填写。缩放与视野由玩家在客户端用鼠标滚轮和拖拽调整。
</Callout>

### 世界选择逻辑

当玩家打开地图或 HUD 时，按以下优先级确定初始世界：

1. 玩家请求指定的世界 ID（已配置时使用）
2. 玩家在地图中已选中的世界
3. 玩家当前所在的世界（已配置时）
4. 配置中的第一个世界

> 均不满足时，地图菜单提示「当前世界未配置地图，且没有可用的默认地图」，HUD 提示「当前没有可显示的小地图世界」。

## 点亮区域（战争迷雾）

锚点可配置点亮区域：玩家解锁该锚点后，小地图上对应区域从迷雾中亮起。未点亮的区域由 mod 渲染遮罩。

每个锚点支持两种写法（可同时配置，任一生效即可）：

| 字段 | 格式 | 说明 |
|---|---|---|
| `light.region.points` | `[[x,z], ...]` | 多边形顶点列表（至少 3 点），世界坐标 |
| `light.radius` | 数值 | 以锚点为中心的圆形点亮半径（方块数） |

```yaml
anchors:
  spawn:
    # ...
    light:
      region:
        points: [[-50, -50], [50, -50], [50, 50], [-50, 50]]
      radius: 100
```

启用点亮后，玩家可以看到所有已解锁锚点覆盖的区域。省略锚点的 `light` 小节时，该锚点不会增加点亮范围。

## 检查地形显示

玩家可在地图顶部查看加载、重试、未探索和未点亮提示。地形长时间空白时，先确认客户端 Mod 已安装和所选世界正确，再核对预加载范围及点亮条件。玩家按键和地图操作集中在[客户端 Mod](./client-mod)。

## 多世界切换

玩家在地图菜单点击世界列表项即可切换世界视图，标点选中状态自动清除。世界列表按 `worlds/` 目录文件名字母序排列，每项显示世界名称和选中状态。
