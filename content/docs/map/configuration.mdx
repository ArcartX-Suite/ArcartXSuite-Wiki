# 配置

主配置文件为 `data/map/ArcartXMap.yml`；每个世界一个 `data/map/worlds/<世界ID>.yml` 文件（含该世界的锚点定义）。

## 顶层配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `config-version` | `int` | `4` | 配置版本号（不要手动修改，由模块自动管理） |
| `debug` | `boolean` | `false` | 是否输出调试日志 |
| `worlds-directory` | `String` | `worlds` | 世界配置文件目录（相对模块数据目录），文件名即世界 ID |

## UI 配置（`ui`）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ui.menu-ui-id` | `String` | `AXS:map_menu` | 全屏地图菜单 UI ID |
| `ui.hud-ui-id` | `String` | `AXS:map_hud` | 小地图 HUD UI ID |
| `ui.packet-id` | `String` | `AXS_MAP` | 客户端与服务端 Packet 通信标识符 |
| `ui.register-ui-on-enable` | `boolean` | `true` | 启动/重载时是否自动注册 UI |
| `ui.overwrite-ui-files` | `boolean` | `false` | 是否覆盖用户已修改的 UI 文件 |

> `packet-id` 用于客户端 `Packet.send` 和服务端 `packetHandler` 的通信匹配。修改时需同步更新 UI 配置中的 `packetId` 变量。

## 按键绑定

地图按键（打开地图 / 切换小地图）由**宿主** `plugins/ArcartXSuite/config.yml` 的 `keybinds` 节统一注册，模块不再自管理按键：

```yaml
# plugins/ArcartXSuite/config.yml
keybinds:
  AXS_MAP_MENU:
    enabled: true
    display-name: "打开地图"
    default-key: "M"
  AXS_MAP_HUD:
    enabled: true
    display-name: "切换小地图"
    default-key: "H"
```

> `ArcartXMap.yml` 中旧的 `keybinds` 节已废弃。修改宿主 `keybinds` 后需重启生效。

## 入服行为（`join`）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `join.show-hud-on-join` | `boolean` | `true` | 玩家进服后是否自动显示小地图 HUD |
| `join.show-hud-delay-ticks` | `long` | `20` | 进服后延迟多少 tick 再显示 HUD（等待客户端加载） |

## 存储配置（`storage`）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `storage.shared` | `boolean` | `true` | 是否共享存储模式（true=共享本体数据源，false=模块自建连接池） |

### 共享模式（`shared: true`，推荐）

共享模式下，数据库连接由本体统一管控，各模块共用本体 `config.yml` 的 `storage` 节配置，性能较好。无需配置额外字段。

### 自建模式（`shared: false`）

模块独立创建 HikariCP 连接池，不复用本体连接。需配置以下字段：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `storage.mode` | `String` | `sqlite` | 存储模式：`sqlite` 或 `mysql` |
| `storage.sqlite.file` | `String` | `map.db` | SQLite 文件名（相对模块数据目录） |
| `storage.mysql.host` | `String` | `127.0.0.1` | MySQL 主机地址 |
| `storage.mysql.port` | `int` | `3306` | MySQL 端口 |
| `storage.mysql.database` | `String` | `arcartxsuite` | MySQL 数据库名 |
| `storage.mysql.username` | `String` | `root` | MySQL 用户名 |
| `storage.mysql.password` | `String` | ` ` | MySQL 密码 |
| `storage.mysql.table-prefix` | `String` | `axs_map_` | MySQL 表名前缀 |
| `storage.pool-size` | `int` | `4` | 连接池大小（SQLite 建议 1） |

> 向后兼容：如果 `shared` 字段不存在但 `mode=mysql` 存在，视为 `shared=false`。

## 导航配置（`navigation`）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `navigation.enabled` | `boolean` | `true` | 是否启用导航追踪功能 |
| `navigation.waypoint-style-id` | `String` | `default` | 路径点导航样式 ID |
| `navigation.anchor-id-prefix` | `String` | `AXS-map-anchor-` | 锚点导航在客户端的 ID 前缀 |
| `navigation.waypoint-id-prefix` | `String` | `AXS-map-track-` | 路径点导航在客户端的 ID 前缀 |

### 导航标记模型（`navigation.marker`）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `navigation.marker.enabled` | `boolean` | `false`（默认配置文件中为 `true`） | 是否启用标记模型 |
| `navigation.marker.model-id` | `String` | `nav_beacon`（默认配置文件中为 `waypoint`） | 模型 ID（资源包中的模型标识） |
| `navigation.marker.scale` | `double` | `1.0` | 缩放比例 |
| `navigation.marker.default-state` | `String` | `idle` | 默认状态 |
| `navigation.marker.animation` | `String` | `rotate` | 动画类型 |
| `navigation.marker.y-offset` | `double` | `2.0` | Y 轴偏移（方块） |
| `navigation.marker.path-interval` | `double` | `3.0` | 路径标记间距（方块） |
| `navigation.marker.path-max-markers` | `int` | `20` | 路径最大标记数 |
| `navigation.marker.path-update-ticks` | `int` | `10` | 路径更新间隔（tick） |
| `navigation.marker.path-max-distance` | `double` | `64.0` | 路径最大距离（方块） |
| `navigation.marker.path-max-iterations` | `int` | `2000` | 路径计算最大迭代次数 |

> 导航标记依赖 Adyeshach。Adyeshach 不存在时标记功能自动关闭，路标导航不受影响。

## 世界配置（`worlds/` 目录）

每个世界一个 `worlds/<世界ID>.yml` 文件，**文件名即世界 ID**。世界文件含 `enabled` / `display-name` / `anchors` 三个部分，详见 [世界与地图渲染](./worlds) 和 [锚点系统](./anchors)。

```yaml
# worlds/world.yml
enabled: true
display-name: ""   # 留空时用 Multiverse colourless alias 自动补

anchors:
  spawn:
    enabled: true
    display-name: "出生点"
    x: 0
    y: 64
    z: 0
    description: "默认出生点锚点。"
    permission: ""
    sort-order: 0
    unlock:
      default: true
      on-permission: false
    unlock-currencies: []
    teleport-currencies: []
    unlock-items: []
    light-radius: 100
```

> 兼容降级：`worlds/` 目录为空时，回退读取 `ArcartXMap.yml` 的内联 `worlds` 节（仅 `enabled`/`display-name` 生效）。旧字段 `texture`/`image-width`/`pixel-offset-x`/`default-zoom`/`hud-zoom`/`hud-size` 已废弃——地图由客户端 mod 实时渲染。

## 自动解锁（锚点 `unlock` 节）

配置版本 4 起，全局 `default-unlocks` 节已移除，自动解锁改为各世界文件中锚点的 `unlock` 节：

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `unlock.default` | `boolean` | 所有玩家进服时自动免费解锁 |
| `unlock.on-permission` | `boolean` | 拥有锚点 `permission` 权限的玩家进服时自动免费解锁 |

> 若 `ArcartXMap.yml` 中仍存在 `default-unlocks` 节，启动时输出警告并忽略；3→4 迁移会自动移除该节。

## 路径点与标记点（`waypoints`）

路径点（含 Y 坐标、可导航）与标记点（Pin，仅 X/Z、不可导航）共用此配置：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `waypoints.enabled` | `boolean` | `true` | 是否允许玩家创建自定义路径点/标记点 |
| `waypoints.default-style-id` | `String` | `default` | 默认路径点样式 ID |
| `waypoints.id-prefix` | `String` | `AXS-map-wp-` | 路径点在客户端的 ID 前缀 |
| `waypoints.auto-name-prefix` | `String` | `标记点` | 自动命名前缀（玩家未命名时使用） |
| `waypoints.default-max-count` | `int` | `50`（代码兜底 `5`） | 默认每世界路径点+标记点合计最大数量（最小 1） |
| `waypoints.limits[].permission` | `String` | ` ` | 权限节点（留空=对所有玩家生效） |
| `waypoints.limits[].max-count` | `int` | `50` | 每世界最大路径点+标记点合计数量 |

> 上限取 `default-max-count` 与所有匹配权限的 `limits` 中最大值，路径点与标记点合计计算。

## 分享配置（`share`）

玩家可把自己的路径点/标记点分享到聊天栏，其他玩家点击卡片或 `/map claim <分享码>` 领取。

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `share.enabled` | `boolean` | `true` | 是否启用点位分享 |
| `share.card-id` | `String` | `axs_map_share` | 聊天卡片 ID；卡片不存在时降级为文本广播 |
| `share.expire-minutes` | `int` | `30` | 分享码有效期（分钟，最小 1） |

> 默认分享卡片由模块自动导出到 `plugins/ArcartX/chat_card/axs_map_share.yml`，可修改按钮文本和悬停提示；分享码缓存在内存中，重启后失效。

## 完整配置示例

```yaml
# data/map/ArcartXMap.yml
config-version: 4
debug: false

ui:
  menu-ui-id: "AXS:map_menu"
  hud-ui-id: "AXS:map_hud"
  packet-id: "AXS_MAP"
  register-ui-on-enable: true
  overwrite-ui-files: false

join:
  show-hud-on-join: true
  show-hud-delay-ticks: 20

storage:
  shared: true

navigation:
  enabled: true
  waypoint-style-id: "default"
  anchor-id-prefix: "AXS-map-anchor-"
  waypoint-id-prefix: "AXS-map-track-"
  marker:
    enabled: true
    model-id: "waypoint"
    scale: 1.0
    default-state: "idle"
    animation: "rotate"
    y-offset: 2.0
    path-interval: 3.0
    path-max-markers: 20
    path-update-ticks: 10
    path-max-distance: 64.0
    path-max-iterations: 2000

worlds-directory: "worlds"

waypoints:
  enabled: true
  default-style-id: "default"
  id-prefix: "AXS-map-wp-"
  auto-name-prefix: "标记点"
  default-max-count: 50
  limits:
    - permission: "ArcartXSuite.map.vip"
      max-count: 100

share:
  enabled: true
  card-id: "axs_map_share"
  expire-minutes: 30
```

## 自建存储配置示例

```yaml
# shared: false 时使用模块自建连接池
storage:
  shared: false
  mode: "mysql"
  mysql:
    host: "127.0.0.1"
    port: 3306
    database: "arcartxsuite"
    username: "root"
    password: ""
    table-prefix: "axs_map_"
  pool-size: 4
```

```yaml
# shared: false + SQLite
storage:
  shared: false
  mode: "sqlite"
  sqlite:
    file: "map.db"
  pool-size: 1
```
