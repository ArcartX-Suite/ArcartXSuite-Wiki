## 先改哪些内容

世界显示范围、锚点与传送费用。先使用默认示例完成一次测试，再按本页逐项调整。

配置位置：`plugins/ArcartX-Suite/data/map/config.yml`。定义文件与子目录均相对此模块目录。本文中的 YAML 片段用于修改对应小节，请保留文件中的其他设置。

修改后执行 `/axs reload map`；涉及插件安装或全局设置的变更请重启后验证。

主配置文件为 `data/map/config.yml`；每个世界一个 `data/map/worlds/<世界ID>.yml` 文件（含该世界的锚点定义）。

## 顶层配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `config-version` | `int` | `6` | 配置版本号，由模块自动管理 |
| `debug` | `boolean` | `false` | 是否输出调试日志 |
| `worlds-directory` | `String` | `worlds` | 世界配置文件目录（相对模块数据目录），文件名即世界 ID |

## UI 配置（`ui`）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ui.register-ui-on-enable` | `boolean` | `true` | 启动/重载时是否自动注册 UI |
| `ui.overwrite-ui-files` | `boolean` | `false` | 是否覆盖用户已修改的 UI 文件 |

## 按键绑定

地图按键（打开地图 / 切换小地图）在 `plugins/ArcartX-Suite/config.yml` 的 `keybinds` 节中配置：

```yaml
# plugins/ArcartX-Suite/config.yml
keybinds:
  map-menu:
    name: AXS_MAP_MENU
    default-key: M
    category: ArcartXSuite
    module: map
  map-hud:
    name: AXS_MAP_HUD
    default-key: H
    category: ArcartXSuite
    module: map
```

本体按键修改后执行 `/axs reload all`，重新连接客户端检查实际绑定。

## 导航配置（`navigation`）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `navigation.enabled` | `boolean` | `true` | 是否启用导航追踪功能 |
| `navigation.anchor-id-prefix` | `String` | `AXS-map-anchor-` | 锚点导航在客户端的 ID 前缀 |
| `navigation.waypoint-id-prefix` | `String` | `AXS-map-track-` | 路径点导航在客户端的 ID 前缀 |
| `navigation.refresh-ticks` | `int` | `20` | 目标刷新间隔（tick），驱动 diff 推送与到达判定 |
| `navigation.world-hint-interval` | `int` | `30` | 目标在其他世界时的提示节流间隔（秒），0 = 不提示 |
| `navigation.finish-range` | `double` | `0` | 到达触发半径（格），0 = 不启用；到达不取消导航 |
| `navigation.finish-commands` | `List<String>` | `[]` | 到达命令（控制台执行，`{player}` 占位） |
| `navigation.finish-rearm-buffer` | `double` | `3.0` | 到达判定滞回缓冲（格）：触发后须离开 `finish-range + 本值` 才重新武装 |

> 多目标追踪语义：玩家可同时追踪多个锚点/路径点（追踪态与到达判定并行），但屏幕路标与路径标记链只跟随"最新激活且同世界"的主目标。详见 [导航追踪与路径标记](./navigation)。

### ArcartX 路标（`navigation.waypoint`）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `navigation.waypoint.enabled` | `boolean` | `true` | 是否向客户端推送路标；`false` 时导航仅保留追踪态/到达判定/路径标记，不发路标包 |
| `navigation.waypoint.style-id` | `String` | `default` | 路标样式 ID（ArcartX `waypoint/` 目录下定义） |
| `navigation.waypoint.title-template` | `String` | `""` | 路标标题模板（单行；`{label}`/`{type}`/`{distance}`/`{world}`/`{x}`/`{y}`/`{z}`），留空显示目标名 |

### 模型导航提示（`navigation.model-marker`）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `navigation.model-marker.enabled` | `boolean` | `false`（默认配置文件中为 `true`） | 是否启用模型导航提示 |
| `navigation.model-marker.model-id` | `String` | `nav_beacon`（默认配置文件中为 `waypoint`） | 模型 ID（资源包中的模型标识） |
| `navigation.model-marker.scale` | `double` | `1.0` | 缩放比例 |
| `navigation.model-marker.default-state` | `String` | `idle` | 默认状态 |
| `navigation.model-marker.animation` | `String` | `rotate` | 动画类型 |
| `navigation.model-marker.y-offset` | `double` | `0.0` | Y 轴偏移（方块） |
| `navigation.model-marker.path-interval` | `double` | `3.0` | 路径标记间距（方块） |
| `navigation.model-marker.path-max-markers` | `int` | `20` | 路径最大标记数 |
| `navigation.model-marker.path-update-ticks` | `int` | `10` | 路径更新间隔（tick） |
| `navigation.model-marker.path-max-distance` | `double` | `64.0` | 路径最大距离（方块） |
| `navigation.model-marker.path-reshow-buffer` | `double` | `8.0` | 距离滞回缓冲（方块）：超距隐藏后须回到 `path-max-distance - 本值` 以内才重新显示 |
| `navigation.model-marker.path-max-iterations` | `int` | `2000` | 路径计算最大迭代次数 |

> 模型导航提示依赖 Adyeshach。Adyeshach 不存在时该功能自动关闭，路标与贴图导航不受影响。

### 贴图导航提示（`navigation.texture-marker`，1.5.0 新增）

沿寻路结果向玩家单人下发 ArcartX 世界贴图（WorldTexture）路径提示。与 `model-marker` 互补，可同开也可独立开关；无需 Adyeshach 实体，仅发包，天然玩家私有。

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `navigation.texture-marker.enabled` | `boolean` | `false` | 是否启用贴图路径提示（需资源包中存在 `texture` 对应贴图） |
| `navigation.texture-marker.texture` | `String` | `nav_arrow` | 贴图资源 ID（ArcartX 自定义文字贴图格式 `§k!%<id><type>`，或资源包中注册的贴图名） |
| `navigation.texture-marker.width` / `height` | `double` | `100` | 贴图渲染宽/高 |
| `navigation.texture-marker.facing` | `boolean` | `false` | `true` 始终面向玩家（billboard）；`false` 按 pitch/yaw 定向（贴地箭头） |
| `navigation.texture-marker.glowing` | `boolean` | `true` | 是否泛光 |
| `navigation.texture-marker.y-offset` | `double` | `0.1` | 贴图相对路径点的 Y 轴偏移（方块） |
| `navigation.texture-marker.pitch` | `double` | `90` | 俯仰角（度；贴地渲染 90，`facing=true` 时一般忽略） |
| `navigation.texture-marker.orient-to-path` | `boolean` | `true` | yaw 朝向下一个路径点（贴地箭头指示方向） |
| `navigation.texture-marker.life-time` | `int` | `-1` | 贴图存活时长（-1 = 永续直到显式移除） |
| `navigation.texture-marker.pulse.*` | — | 见注释 | 循环缩放脉冲动画：`enabled`/`from`/`to`/`duration`/`stagger`（按路径点序号错开形成波浪效果） |
| `navigation.texture-marker.path-*` | — | 同 `model-marker` | 同语义的路径寻路参数（`path-interval`/`path-max-markers`/`path-update-ticks`/`path-max-distance`/`path-reshow-buffer`/`path-max-iterations`），互不影响 |

## 世界配置（`worlds/` 目录）

每个世界一个 `worlds/<世界ID>.yml` 文件，**文件名即世界 ID**。世界文件含 `enabled` / `display-name` / `anchors` 三个部分，详见 [世界与地图渲染](./worlds) 和 [锚点系统](./anchors)。

```yaml
# worlds/world.yml
enabled: true
display-name: ""   # 留空时用 Multiverse colourless alias 自动补

anchors:
  spawn:
    enabled: true
    display-name: "出生点"
    x: 0
    y: 64
    z: 0
    description: "默认出生点锚点。"
    permission: ""
    sort-order: 0
    unlock:
      default: true
      on-permission: false
      currencies: []
      items: []
    teleport:
      currencies: []
      items: []
    light:
      radius: 100
```


## 自动解锁（锚点 `unlock` 节）

自动解锁在各世界文件中锚点的 `unlock` 节配置：

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `unlock.default` | `boolean` | 所有玩家进服时自动免费解锁 |
| `unlock.on-permission` | `boolean` | 拥有锚点 `permission` 权限的玩家进服时自动免费解锁 |

> 若 `config.yml` 中仍存在 `default-unlocks` 节，启动时输出警告并忽略；3→4 迁移会自动移除该节。

## 路径点与标记点（`waypoints`）

路径点（含 Y 坐标，可导航）与标记点（Pin，仅 X/Z，可追踪）共用此配置：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `waypoints.enabled` | `boolean` | `true` | 是否允许玩家创建自定义路径点/标记点 |
| `waypoints.default-style-id` | `String` | `default` | 默认路径点样式 ID |
| `waypoints.id-prefix` | `String` | `AXS-map-wp-` | 路径点在客户端的 ID 前缀 |
| `waypoints.auto-name-prefix` | `String` | `标记点` | 自动命名前缀（玩家未命名时使用） |
| `waypoints.default-max-count` | `int` | `50`（代码兜底 `5`） | 默认每世界路径点+标记点合计最大数量（最小 1） |
| `waypoints.limits[].permission` | `String` | ` ` | 权限节点（留空=对所有玩家生效） |
| `waypoints.limits[].max-count` | `int` | `50` | 每世界最大路径点+标记点合计数量 |

> 上限取 `default-max-count` 与所有匹配权限的 `limits` 中最大值，路径点与标记点合计计算。

## 分享配置（`share`）

玩家可把自己的路径点/标记点分享到聊天栏，其他玩家点击卡片或 `/map claim <分享码>` 领取。

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `share.enabled` | `boolean` | `true` | 是否启用点位分享 |
| `share.expire-minutes` | `int` | `30` | 分享码有效期（分钟，最小 1） |

## 更新地图界面

使用旧版地图界面时，先备份 `plugins/ArcartX-Suite/ui/map_menu.yml` 与 `plugins/ArcartX-Suite/ui/map_hud.yml`，再把新版控件和文案合入自定义文件。使用默认界面的服主可设置 `ui.overwrite-ui-files: true` 后重载 Map，确认界面更新后将其设回 `false`。

跨服世界共享与传送见[跨服地图](./cross-server)。
