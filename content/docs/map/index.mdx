| 项目 | 说明 |
| --- | --- |
| 模块 ID | `map` |
| 主配置 | `plugins/ArcartX-Suite/data/map/config.yml` |
| 主要调整内容 | 世界显示范围、锚点与传送费用 |
| 重载 | `/axs reload map` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 按[地图客户端安装](/docs/map/client-mod)安装与 Minecraft 版本和加载器匹配的扩展。
2. 按[单世界与锚点示例](/docs/map/worlds#从一个世界和一个锚点开始)配置 `trial_spawn`，将坐标填为测试世界的安全位置。
3. 执行 `/axs reload map`。让具有 `arcartxsuite.map.use` 的普通玩家进服，执行 `/map`。

## 检查是否配置成功

在列表找到「试炼出生点」，确认显示已解锁，再发起传送并核对落点。回到游戏后用 H 切换小地图，验证探索过的附近地形可以显示。

`/map` 能打开但地形空白时，先按[地图客户端安装](/docs/map/client-mod)核对实例、加载器和 Map JAR。能看到地形但找不到锚点时，用 `/axs map anchors world` 检查定义，`world` 替换成实际世界名。看得见点位但无法传送时，再查解锁、权限和[传送条件](/docs/map/anchors#传送条件)。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| 全屏大地图 | ArcartX UI 驱动的全屏地图菜单，支持世界切换、滚轮缩放、拖拽平移、锚点/路径点/标记点/第三方插件注册路径点列表与详情面板 |
| 小地图 HUD | 常驻小地图（圆形/方形、四角位置、尺寸/缩放可调），实时显示玩家位置、朝向、世界名、坐标和导航追踪状态 |
| 实体雷达 | 小地图与大地图以圆点显示周围实体并可附加名称标签；在设置面板开启，支持玩家/怪物/动物逐类显隐与名称字号档位 |
| 洞穴图层 | 玩家在地下时小地图自动进入洞穴模式；大地图左下角可手动切换地表↔洞穴视图，洞穴切片深度 16/30/48/64 档位（点击「深」按钮循环） |
| 地图设置面板 | 大地图顶栏"设置"按钮展开居中双栏面板：小地图外观（形状/四角位置/尺寸/缩放）+ 实体显示（雷达/名称标签/类别） |
| 客户端实时渲染 | 地形画面由 ArcartX-Suite-Map mod 扫描客户端区块实时生成，无需地图纹理图片，已探索区域缓存落盘 |
| 多世界支持 | 每个世界一个 `worlds/<世界ID>.yml` 配置文件，可分别设置名称、锚点和预加载范围 |
| 战争迷雾 | 锚点可配置 `light.region` / `light.radius` 点亮区域，未探索区域在小地图上遮罩 |
