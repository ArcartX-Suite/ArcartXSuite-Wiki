## 管理员命令

EventPacket 模块的管理命令通过Suite统一命令系统调度，前缀为 `/axs eventpacket`，需要 `arcartxsuite.admin` 权限。

| 命令 | 说明 |
|---|---|
| `/axs eventpacket help` | 查看所有可用子命令 |
| `/axs eventpacket status` | 查看 EventPacket 模块运行状态 |
| `/axs eventpacket fire <信号名> <玩家> [key=value...]` | 手动触发命令信号 |
| `/axs eventpacket clearlag` | 手动执行实体清理 |

### fire 子命令

`fire` 命令用于手动发送命令信号，触发所有 `trigger: command-signal` 且 `signal` 匹配的规则。

```bash
# 向玩家 Steve 发送信号 accept_mainline
/axs eventpacket fire accept_mainline Steve

# 向玩家 Steve 发送信号 boss_settlement，附带变量 boss_id=dragon
/axs eventpacket fire boss_settlement Steve boss_id=dragon
```

发送的变量可在规则动作中通过 `{boss_id}` 等上下文变量引用。变量以 `key=value` 格式追加在命令末尾。

### run 子命令

```bash
# 向玩家 Steve 执行名为 give_item 的回包预设，附带参数 DIAMOND_SWORD 1
/axs eventpacket run Steve give_item DIAMOND_SWORD 1
```

### clearlag 子命令

`clearlag` 命令立即执行一次实体清理，不受 `entity-cleanup.enabled` 配置限制，返回清理的实体数量。

## 权限

| 权限节点 | 默认 | 说明 |
|---|---|---|
| `arcartxsuite.admin` | OP | 使用 `/axs eventpacket` 管理命令的权限 |

## 上下文变量

规则动作参数支持 `{变量名}` 形式的上下文变量替换。未匹配的占位符原样保留。

### 玩家主体变量

| 变量 | 说明 |
|---|---|
| `{player_name}` | 玩家名（如 `Steve`） |
| `{player_display_name}` | 显示名（含前缀后缀，可能为空） |
| `{player_uuid}` | 玩家 UUID |
| `{player_world}` | 所在世界名 |
| `{player_x}` / `{player_y}` / `{player_z}` | 玩家所在方块坐标（整数） |
| `{player_health}` | 当前生命值 |
| `{player_max_health}` | 最大生命值 |
| `{player_level}` | 等级（经验等级） |
| `{player_ping}` | 网络延迟（毫秒） |

> `subject_*` 变量与 `player_*` 等价（如 `{subject_name}` = `{player_name}`），推荐使用 `player_*`。

### 接收者变量

仅 `ui-packet` 动作且 `recipients` 包含 `all-online` 或 `others` 时才有意义。

| 变量 | 说明 |
|---|---|
| `{receiver_name}` | 接收者玩家名 |
| `{receiver_display_name}` | 接收者显示名 |
| `{receiver_uuid}` | 接收者 UUID |
| `{receiver_role}` | 接收者角色（`self`/`all-online`/`others`） |

### 触发上下文变量

| 变量 | 说明 |
|---|---|
| `{trigger}` / `{trigger_type}` | 触发类型（如 `join`、`papi-increase`） |
| `{world}` | 玩家所在世界（同 `{player_world}`） |
| `{placeholder}` | PAPI 占位符（仅 PAPI 触发器） |
| `{old_value}` | 占位符旧值（字符串） |
| `{new_value}` | 占位符新值（字符串） |
| `{old_number}` | 旧数值（BigDecimal 去尾零字符串，非数值触发时为空） |
| `{new_number}` | 新数值 |
| `{delta_number}` | 数值变化量（`new_number - old_number`） |
| `{change_direction}` | 变化方向：`increase` / `decrease`（仅 papi-increase/decrease） |
| `{signal}` / `{command_signal}` | 信号名（command-signal / quest-* / objective-* / chemdah-level-change） |

### 账号信息变量

| 变量 | 说明 |
|---|---|
| `{account_type}` | 账号类型：`microsoft` / `littleskin` / `offline` |
| `{account_type_display}` | 账号类型显示名 |
| `{account_premium}` | 是否正版（`true` / `false`） |

### 时间变量

| 变量 | 说明 |
|---|---|
| `{timestamp_unix}` | Unix 时间戳（秒） |
| `{timestamp_local}` | 本地时间字符串（`yyyy-MM-dd HH:mm:ss`） |

### 动态变量

| 触发类型 | 变量 |
|---|---|
| `client-packet` | `{preset_id}`、`{arg1}`、`{arg2}`...（按客户端 data 顺序） |
| `quest-accept` / `quest-complete` / `quest-fail` | `{quest_id}` |
| `objective-complete` / `objective-continue` / `objective-restart` | `{quest_id}`、`{task_id}`、`{objective_type}`、`{objective_name}` |
| `chemdah-level-change` | `{level_option}`、`{old_level}`、`{new_level}`、`{old_experience}`、`{new_experience}`、`{level_delta}` |
| `mob-kill-count` | `{rule_id}`、`{kill_count}`、`{required_count}`、`{mob_world}`、`{mob_entity_type}`、`{mythic_mob_id}` |
| `script-js` / `script-aria` | `{rule_id}`、`{script_result}` |

### 预设字段表

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `type` | String | `op` | 执行类型：`op`（OP 身份）、`console`（控制台）、`player`（玩家身份） |
| `permission` | String | （空） | 触发权限门槛，空 = 任何玩家可触发 |
| `cooldown` | string/number | `0` | 冷却时间，支持 `5s`/`1m`/`1h`/`1d` 或数字（秒） |
| `allow-args` | boolean | `false` | 是否允许客户端透传额外参数 |
| `args-pattern` | String | `[\w.:-]{1,64}` | `allow-args` 为 true 时对每个参数的正则校验 |
| `commands` | list | （必填） | 要执行的命令列表 |

### 预设命令变量

在预设命令中保留花括号，触发时会填入实际值。

| 变量 | 触发时的值 |
| --- | --- |
| `{player}` | 触发玩家名 |
| `{uuid}` | 触发玩家 UUID |
| `{world}` | 触发玩家所在世界 |
| `{arg1}` | 第一个传入参数，其余按序写为 `{arg2}` 等 |

### 预设示例

```yaml
# packet-command-presets/example.yml

# OP 身份执行，需权限
example_op:
  type: op
  permission: "eventpacket.preset.example"
  cooldown: 0
  allow-args: false
  args-pattern: "[\w.:-]{1,64}"
  commands:
    - say 你好，我是 {player}
    - say 这里是 OP 身份执行

# 控制台执行，无需权限
example_console:
  type: console
  permission: ""
  cooldown: 0
  allow-args: false
  args-pattern: "[\w.:-]{1,64}"
  commands:
    - say 控制台正在响应 {player}

# 带参数透传
# 客户端调用: Packet.send('ArcartXEventPacket', 'give_item', 'DIAMOND_SWORD', '1')
example_with_args:
  type: op
  permission: "eventpacket.preset.give"
  cooldown: 5s
  allow-args: true
  args-pattern: "[A-Z_0-9]{1,64}"
  commands:
    - give {player} {arg1} {arg2}
```
