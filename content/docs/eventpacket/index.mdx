| 模块 ID | `eventpacket` |
| 主配置 | `plugins/ArcartX-Suite/data/eventpacket/config.yml` |
| 主要调整内容 | rules/ 中的触发条件与动作列表 |
| 重载 | `/axs reload eventpacket` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 选择一个默认规则。
2. 只调整提示文字。
3. 触发对应游戏事件。

## 检查是否配置成功

确认规则仅在预期事件发生时执行一次。

功能未生效时，先检查模块状态、所用定义 ID、玩家权限及客户端安装情况，随后对照[日志与报错提示](/docs/guide/config-management)逐项检查。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| 18 种触发器 | join、first-join、quit、papi-increase、papi-decrease、placeholder-threshold、mob-kill-count、command-signal、client-packet、quest-accept、quest-complete、quest-fail、objective-complete、objective-continue、objective-restart、chemdah-level-change、script-js、script-aria |
| 条件过滤 | 支持 PAPI 条件和上下文变量条件（`%placeholder% operator value`，支持 `==`/`!=`/`>=`/`<=`/`>`/`<`/`contains`/`regex`），详见 [条件系统](/docs/guide/conditions) |
| 重复与冷却 | 默认每玩家只触发一次，`repeatable: true` 可重复触发，支持 `cooldown`（如 `5s`/`1m`/`2h`/`1d`） |
| 变量替换 | 动作参数支持 `{player_name}`、`{player_uuid}`、`{world}`、`{trigger}`、`{placeholder}`、`{old_value}`、`{new_value}`、`{signal}` 等上下文变量 |
| 实体清理 | 内置 ClearLag 功能，定时清理掉落物/怪物/动物，支持警告倒计时和白名单 |
| 定时命令 | 可定义多个定时任务，支持日历触发（hourly/daily/weekly）和固定间隔两种模式 |
| 数据持久化 | 击杀进度和规则触发状态持久化到数据库，支持共享模式和自建模式 |
