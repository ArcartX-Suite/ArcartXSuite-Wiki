# 命令与占位符

## 玩家命令

`/abyss`（别名 `/axsabyss`），仅限玩家执行，权限 `arcartxsuite.abyss.use`。

| 命令 | 说明 |
|---|---|
| `/abyss` | 打开地牢浏览器 UI（无客户端时显示列表） |
| `/abyss enter <地牢>` | 进入指定地牢（检查体力/冷却/货币/物品/权限；别名 `join`；队长执行时带整队进本） |
| `/abyss leave` | 离开当前副本，传送回进本前位置（别名 `quit`） |
| `/abyss list` | 列出可进入的地牢 |
| `/abyss info` | 显示当前副本信息（地牢/状态/人数） |
| `/abyss stamina` | 查看当前体力 |
| `/abyss rank <地牢>` | 打开排行榜 UI（别名 `top`） |
| `/abyss party [子命令]` | 队伍面板/子命令，等同于 `/party`（如 `/abyss party invite`） |
| `/abyss ui` | 重开/刷新 UI（调试用） |

## 队伍命令

`/party`（别名 `/axsparty`），权限 `arcartxsuite.abyss.party`。

| 命令 | 说明 |
|---|---|
| `/party` | 打开队伍面板 UI |
| `/party create` | 创建队伍（队长身份） |
| `/party invite <玩家>` | 邀请玩家入队 |
| `/party accept` | 接受最新邀请 |
| `/party apply <队伍UUID>` | 申请加入公开队伍（直接加入或提交入队申请，视该队 joinmode） |
| `/party lobby` | 打开队伍大厅（列出公开队伍；无 UI 时输出文本列表） |
| `/party leave` | 离开队伍 |
| `/party ready` | 切换准备状态 |
| `/party kick <玩家>` | 踢出成员（队长，支持离线成员按 UUID） |
| `/party leader <玩家>` | 转让队长（别名 `transfer`） |
| `/party chat <消息>` | 队内聊天 |
| `/party list` | 列出队伍成员（别名 `members`） |
| `/party public` | 将队伍设为公开（队长，别名 `open`） |
| `/party private` | 将队伍设为私密（队长） |
| `/party joinmode <open\|apply>` | 设置加入方式：直接加入 / 需要审批（队长） |
| `/party dungeon <地牢>` | 设置队伍目标副本（队长） |
| `/party approve <玩家>` | 批准入队申请（队长） |
| `/party deny <玩家>` | 拒绝入队申请（队长） |
| `/party allowinvite` | 切换自己是否可被邀请入队 |
| `/party disband` | 解散队伍（队长） |

## 管理员命令

`/axs abyss <子命令>`，由 `ModuleCommandHandler` 注册，走 `/axs` 主命令权限。

| 命令 | 说明 |
|---|---|
| `/axs abyss help` | 管理命令帮助 |
| `/axs abyss status` | 模块状态（模板数/运行实例） |
| `/axs abyss list` | 列出地牢模板与运行中实例 |
| `/axs abyss info <地牢>` | 模板详情（世界来源/人数/时限/怪物组数） |
| `/axs abyss enter <地牢> [玩家]` | 强制进本（绕过条件检查，控制台需指定玩家） |
| `/axs abyss leave` | 离开当前副本 |
| `/axs abyss force_complete [玩家]` | 强制该玩家所在实例通关 |
| `/axs abyss force_fail [玩家]` | 强制该玩家所在实例失败 |
| `/axs abyss cancel <地牢>` | 取消该地牢全部运行中实例 |
| `/axs abyss stamina <玩家> give\|set <值>` | 体力管理 |
| `/axs abyss cooldown <玩家> clear\|check [地牢]` | 冷却管理 |
| `/axs abyss tp <地牢>` | 传送到该地牢实例世界 |
| `/axs abyss reload` | 重载全部地牢模板（`abysses/` 目录） |
| `/axs abyss puzzle` | 列出当前实例全部机关状态（需身在副本内） |
| `/axs abyss puzzle <机关id>` | 单机关详情（类型/进度/步数） |
| `/axs abyss puzzle <id> reset` | 重置进度+解除锁定 |
| `/axs abyss puzzle <id> solve` | 直接判定完成（触发 on-complete + 事件） |
| `/axs abyss puzzle <id> fail` | 强制锁定（触发 on-fail + 事件） |
| `/axs abyss puzzle <id> prompt [玩家]` | 给指定玩家打开 input 型机关的输入面板 |
| `/axs abyss design <地牢>` | 进入**设计模式**：复制世界进可写实例，玩法全冻结，标记杖+设计面板编辑配置 |
| `/axs abyss design save [world]` | 保存设计：YAML 回写地牢目录 + 模板重载；`world` 附加把实例世界回拷模板 `world/` |
| `/axs abyss design ui` | 重开设计主面板（会话内任意时刻可用） |
| `/axs abyss design exit` | 退出设计模式（未保存改动丢弃，等价面板「退出」） |

> `puzzle` 系列是**局内编辑**入口：只改当前副本实例的内存状态（进度/完成/锁定），不写回 `puzzles.yml`，不影响下一个副本实例。需要 `arcartxsuite.abyss.admin` 权限且玩家身在目标副本内。

### 设计模式（`/axs abyss design`）

管理员在**真实副本世界副本**里编辑地牢配置，所见即所得，无需手写 YAML 坐标。

- **冻结**：设计实例跳过 `prepare`/`startInstance`——怪组/任务/机关/障碍/交互/NPC/计时全部不初始化，纯可写世界
- **进入**：`/axs abyss design <地牢id>` → 复制世界 → 创造模式传送 → 发放**设计标记杖**（烈焰棒，背包第一格）→ 打开设计主面板
- **标记杖**：右键方块 = 命中已有对象开编辑 / 有标记任务时落点；选区模式左键=A 点、右键=B 点；**左键空气 = 重开主面板**；Shift+右键 = 取消标记
- **主面板**（`abyss_design`）：顶部流程节点链（floors=楼层→房间，classic=对象/任务/奖励三桶）+ 当前节点对象列表（[传送][编辑][删除]）+ 未保存角标 + 保存按钮
- **副面板**（`abyss_design_pick`）：节点内「+ 添加对象」→ 类型卡片（交互/障碍/怪组/NPC/机关/任务/奖励/宝箱/增益池）；点/区域类先标记再建，无定位类直接建
- **编辑面板**（`abyss_design_edit`）：按类型下发字段表单（文本/数字回车提交、开关注点切换、枚举点循环且显示中文、坐标/区域点「点我重标」后到世界里标记）+ 脚本/列表行编辑（追加/点行改/删）+ 怪组「刷怪点」字段点杖追加 spawn 项 + 障碍选区自动扫描非空气方块生成 `blocks`。所有枚举值（`AUTO_START`/`RIGHT_CLICK_BLOCK`/`combat` 等）显示为中文，对象行带类型徽标与色条
- **归属推断**：floors-region 模式按对象坐标落房间 box 自动归节点；机关 `steps` 指向的交互点自动吸附显示；**交叉引用吸附**——脚本行里的对象引用动作（`spawn_group`/`open_door`/`create_obstacle`/`puzzle_*`/`room_*` 等）若指向游离对象，自动把它收进引用者所在房间节点；无归属进「全局对象」桶
- **世界内标记**：每个带定位的对象在世界里渲染一个面向设计者的高亮浮动贴图（`nav_arrow`，仅自己可见）——新建/移动/删除实时同步，退出设计模式自动清除；ArcartX 贴图桥缺席时自动跳过
- **保存**：「保存配置」只回写 YAML+重载；「配置+世界」再把实例世界存盘回拷模板目录（仅 `world/` 目录型模板支持）
- **限制**：含 `pool` 随机拼接楼层的模板不支持实例内设计（运行时房间位置不确定，请改编辑 schematic）
- 关闭面板（Esc）不退出设计模式；**重开**：标记杖左键空气 或 `/axs abyss design ui`；`/axs abyss design exit` 或面板「退出」才退出

> 设计改动**不落盘即不生效**——对象增删改先记脏（未保存角标计数），保存确认后才写 YAML 并重载模板。

## 权限节点

| 权限节点 | 默认 | 说明 |
|---|---|---|
| `arcartxsuite.abyss.use` | `true` | `/abyss` 玩家命令 |
| `arcartxsuite.abyss.party` | `true` | `/party` 队伍命令 |
| `arcartxsuite.abyss.admin` | `op` | `/axs abyss` 管理子命令（含 `puzzle` 局内编辑） |
| `arcartxsuite.abyss.bypass` | `op` | 绕过副本内命令限制（管理/测试用） |

> 管理命令走 `/axs` 宿主权限（`arcartxsuite.admin`，默认 OP）。副本内命令控制：地牢 `disabled-commands` 绝对黑名单 + `world.command-control`（副本级黑/白名单，可覆盖全局 `restrictions`）+ 全局 `restrictions.blocked-commands`。

## PlaceholderAPI 占位符

模块注册扩展 `axsabyss`（`%axsabyss_*%`），需 PlaceholderAPI。

| 占位符 | 返回 | 说明 |
|---|---|---|
| `%axsabyss_stamina%` | 当前体力 | |
| `%axsabyss_stamina_max%` | 最大体力 | |
| `%axsabyss_in_dungeon%` | `true`/`false` | 是否在副本中 |
| `%axsabyss_dungeon_id%` | 地牢 ID | 副本外为空 |
| `%axsabyss_dungeon_name%` | 地牢显示名 | 副本外为空 |
| `%axsabyss_dungeon_time%` | 已进行秒数 | 副本外为 `0` |
| `%axsabyss_deaths%` | 本副本死亡数 | |
| `%axsabyss_alive_count%` | 存活玩家数 | |
| `%axsabyss_dungeon_kills%` | 本副本个人击杀 | 副本任务常用 |
| `%axsabyss_dungeon_total_kills%` | 本副本全队击杀 | |
| `%axsabyss_party_size%` | 队伍人数 | 无队伍为 `0` |
| `%axsabyss_party_name%` | 队伍名 | 无队伍为空 |
| `%axsabyss_party_leader%` | 队长名 | 离线队长显示 UUID 前 8 位 |
| `%axsabyss_cooldown_<地牢>%` | 剩余冷却秒数 | |
| `%axsabyss_completions_<地牢>%` | 该地牢通关次数 | |
| `%axsabyss_best_time_<地牢>%` | 该地牢最佳通关秒数 | |

## 消息文件

`messages.yml` 位于 `plugins/ArcartX-Suite/data/abyss/`，支持 `&` 颜色码与 `{0}`/`{1}` 占位符，覆盖进本提示、组队通知、死亡/通关/失败、体力不足、冷却中、UI 未启用等全部玩家可见文案。修改后 `/axs reload abyss` 生效。
