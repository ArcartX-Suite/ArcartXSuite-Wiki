## 玩家命令

`/abyss`（别名 `/axsabyss`），仅限玩家执行，权限 `arcartxsuite.abyss.use`。

| 命令 | 说明 |
|---|---|
| `/abyss` | 打开地牢浏览器 UI（无客户端时显示列表） |
| `/abyss enter <地牢>` | 进入指定地牢（检查体力/冷却/货币/物品/权限；别名 `join`；队长执行时带整队进本） |
| `/abyss leave` | 离开当前副本，传送回进本前位置（别名 `quit`） |
| `/abyss rejoin` | 在模板允许的时间内返回仍在运行的原副本。离线期间副本计时继续 |
| `/abyss run`、`/abyss tactical`、`/abyss rescue` | 打开本局战术面板，查看自救和队友救援选项 |
| `/abyss loot` | 查看当前或最近一局已登记的战利品 |
| `/abyss rewards` | 打开待领的翻牌、转盘或三选一奖励 |
| `/abyss list` | 列出可进入的地牢 |
| `/abyss info` | 显示当前副本信息（地牢/状态/人数） |
| `/abyss stamina` | 查看当前体力 |
| `/abyss rank <地牢>` | 打开排行榜 UI（别名 `top`） |
| `/abyss party [子命令]` | 队伍面板/子命令，等同于 `/party`（如 `/abyss party invite`） |
| `/abyss ui` | 重开/刷新 UI（调试用） |

救援、战利品回顾与撤离的操作见[自救、救援与本局战术](/docs/abyss/native-gameplay)。

## 队伍命令

`/party`（别名 `/axsparty`），权限 `arcartxsuite.abyss.party`。

| 命令 | 说明 |
|---|---|
| `/party` | 打开队伍面板 UI |
| `/party create` | 创建队伍（队长身份） |
| `/party invite <玩家>` | 邀请玩家入队 |
| `/party accept` | 接受最新邀请 |
| `/party apply <队伍UUID>` | 申请加入公开队伍（直接加入或提交入队申请，视该队 joinmode） |
| `/party lobby` | 打开队伍大厅（列出公开队伍；无 UI 时输出文本列表） |
| `/party leave` | 离开队伍 |
| `/party ready` | 切换准备状态 |
| `/party kick <玩家>` | 踢出成员（队长，支持离线成员按 UUID） |
| `/party leader <玩家>` | 转让队长（别名 `transfer`） |
| `/party chat <消息>` | 队内聊天 |
| `/party list` | 列出队伍成员（别名 `members`） |
| `/party public` | 将队伍设为公开（队长，别名 `open`） |
| `/party private` | 将队伍设为私密（队长） |
| `/party joinmode <open\|apply>` | 设置加入方式：直接加入 / 需要审批（队长） |
| `/party dungeon <地牢>` | 设置队伍目标副本（队长） |
| `/party approve <玩家>` | 批准入队申请（队长） |
| `/party deny <玩家>` | 拒绝入队申请（队长） |
| `/party allowinvite` | 切换自己是否可被邀请入队 |
| `/party disband` | 解散队伍（队长） |

### 在设计面板试跑草稿

对象编辑面板的「试跑事件」用于检查当前草稿的触发与阶段推进。完整操作顺序见[设计面板与试跑](/docs/abyss/design)。

### 区域模板与构件命令

| 命令 | 说明 |
| --- | --- |
| `/axs abyss region pos1` / `pos2` | 标记脚下方块为区域模板选区角点（两角任意顺序，跨世界自动重置） |

| `/axs abyss region remove <地牢> <名>` | 删除模板 |

### 区域模板（`/axs abyss region`）

把**任意世界**里手工建好的建筑圈选成模板，副本 `world-init` 脚本里用 `paste_region` 铺进副本世界——免写几千行 `fillblocks`。

1. 在主世界/建筑世界里搭好结构
2. `/axs abyss region pos1` / `pos2` 分别站两角标记（脚下为角点，顺序任意；换世界自动重置选区）
3. `/axs abyss region save <地牢> <名>` 快照到 `abysses/<地牢>/regions/<名>.yml`
4. `scripts.yml` 任意段调用 `paste_region <名> <x,y,z>` 铺放（[用法详见地牢模板编写·区域模板](/docs/abyss/layouts#区域模板-regions)）

- 模板按地牢绑定，存于地牢的 `regions/` 子目录。
- 快照保留完整方块状态，例如楼梯朝向、栅栏连接和玻璃板贴合。箱内物品、刷怪笼配置和告示牌文字需另行设置。
- 选区体积上限 131072 块（如 32×64×64）；模板名白名单 `[A-Za-z0-9_-]≤32`

## 权限节点

| 权限节点 | 默认 | 说明 |
|---|---|---|
| `arcartxsuite.abyss.use` | `true` | `/abyss` 玩家命令 |
| `arcartxsuite.abyss.party` | `true` | `/party` 队伍命令 |
| `arcartxsuite.abyss.admin` | `op` | `/axs abyss` 管理子命令（含 `puzzle` 局内编辑） |
| `arcartxsuite.abyss.bypass` | `op` | 绕过副本内命令限制（管理/测试用） |

> 管理命令走 `/axs` Suite权限（`arcartxsuite.admin`，默认 OP）。副本内命令控制：地牢 `disabled-commands` 绝对黑名单 + `world.command-control`（副本级黑/白名单，可覆盖全局 `restrictions`）+ 全局 `restrictions.blocked-commands`。

## 消息文件

`messages.yml` 位于 `plugins/ArcartX-Suite/data/abyss/`，支持 `&` 颜色码与 `{0}`/`{1}` 占位符，覆盖进本提示、组队通知、死亡/通关/失败、体力不足、冷却中、UI 未启用等全部玩家可见文案。修改后 `/axs reload abyss` 生效。
