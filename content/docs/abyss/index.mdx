| 重载 | `/axs reload abyss` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。本模块还需要安装 `PlaceholderAPI`。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

需要从零制作并验证一条流程时，先阅读[完整按钮开战示例](/docs/abyss/walkthrough)。它提供同一地牢的六个文件，以及普通、额外挑战和超时失败三条测试路线。

1. 复制默认示例地牢并修改入口设置。
2. 执行 `/abyss list`。
3. 执行 `/abyss enter <地牢ID>`。

## 检查是否配置成功

走完一个测试关卡，检查任务推进、退出与结算。

`/abyss list` 找不到测试地牢时，核对 `abysses/button_trial/` 的文件位置和重载日志。能进入却没有刷怪时，从[按钮开战示例](/docs/abyss/walkthrough#重载和单人验证)的金块交互开始，按准备、刷怪、通关的顺序逐项核对。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| 三种世界来源 | `void` 虚空生成 / `world/` 世界文件夹复制 / schematic 粘贴（需 WorldEdit 或 FAWE） |
| 怪物波次 | 怪物组按 `spawn-timing` 触发（自动/延迟/上一组结束/脚本），`vanilla:` 前缀强制原版，默认走 MythicMobs 并自动回退原版 |
| 生命周期脚本 | `world-init` / `init` / `start` / `complete` / `fail` / `player-death` / `all-death` / `exit` 脚本段 + 70+ 内置动作 + `wait` 挂起 |
| 区域模板 | `/axs abyss region pos1\|pos2\|save` 圈选任意世界建筑存为模板，`paste_region` 脚本动作铺进副本世界（保留方块朝向/状态） |
| 副本任务 | NPC 对话接取、条件提交（PAPI 条件），`quest_step` 智能动作一次点击完成接取/提交 |
| 交互点 | 右键方块/左键/挖掘/放置/踩上/进入区域/右键实体，支持一次性、条件、失败消息节流 |
| 障碍物 | 方块组自动放置/移除，可选 ENTER/LEAVE/PERSIST 触发脚本 |
| 定时任务 | `TIMED`（指定秒触发）/`INTERVAL`（循环）/`EVENT`（怪物击杀等事件）三种副本内任务 |
