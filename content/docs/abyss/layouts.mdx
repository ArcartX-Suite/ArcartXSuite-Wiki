固定路线使用楼层和房间定义。需要每次重新拼装房间时，阅读[ProcGen 随机地牢](/docs/abyss/procgen)。

## floors.yml + rooms.yml — 多层房间地牢

`config.yml` 设 `mode: floors` 后启用：地牢由若干**层（floor）**组成，每层是**房间图**——房间在世界里真实互连（走廊物理可走），玩家自由探索/回退，不必按 rooms 列表顺序访问（类元气骑士迷宫结构）。房间 `region`/`doors` 定义边界和物理门洞，拓扑由 world-init 的建筑布局决定——门洞后接走廊=真通路，挖死=假门/装饰。

### 楼层布局（floors.yml）

```yaml
defaults:
  lock-material: BARRIER     # 锁门填充材质
  border-pullback: true      # 战斗房锁门期间离开区域拉回（逃逸双保险）
  room-spacing: 200          # pool 模式相邻房锚点间距（格）
  paste-y: 64                # pool 模式 schematic 粘贴基准高度
  advance-timeout: 60        # portal 推进兜底秒数（0=不兜底）

floors:
  - id: f1
    name: "第 1 层"
    source: region              # region=固定区域 | pool=schematic 随机拼接
    spawn: "0,65,0,90,0"        # 层入口站位（region 绝对坐标）
    rooms: [entry, combat_a, altar_a, combat_b, boss_1, chest_a]
                                # region 模式：本层全部房间的引用集合（顺序不决定推进路线）
    boss-room: boss_1           # 终点房（显式指定！不配则退回"链尾房"的线性语义）
    advance: portal             # portal=终点房清完踩出口传送 | auto=清完自动传送
    advance-timeout: 90         # portal 兜底：终点清完 90s 无人踩出口自动推层
    on-enter: [...]             # 层开始脚本
    on-clear: [...]             # 层清完脚本
  - id: f2
    source: pool                # 随机拼接（world.template 建议 void + FAWE）
    pool: [combat_a, combat_b, shop_a, treasure_a]
    room-count: 3               # 池内随机抽取数（0=全用且打乱顺序）
    boss-room: boss_2
    direction: x                # 拼接排列轴 x|z
    advance: portal
```

| 字段 | 说明 |
|---|---|
| `source: region` | 房间已手工建在世界模板里，坐标写世界绝对值 |
| `source: pool` | 虚空世界 + 房间 `.schem` 随机抽取粘贴（需 WorldEdit/FAWE，进本时校验） |
| `advance: portal` | 层/房清完激活出口区，玩家踩 `exit` 传送；`advance-timeout` 超时自动推 |
| `advance: auto` | 清完 3 秒后自动传送下一目标 |

### 房间定义（rooms.yml）

```yaml
rooms:
  corridor_a:
    type: combat                 # combat=锁门清怪 | safe/shop=不锁 | boss=战斗(语义标记)
    schematic: "rooms/a.schem"   # pool 模式必填（相对地牢目录）；region 忽略
    origin: "0,0,0"              # region 房间原点（默认 0,0,0 = 坐标写绝对值）
    region: ["0,60,0", "29,80,29"]  # 房间 box 两角（相对 origin）
    spawn: "1,64,15,90,0"        # 进房站位（相对 origin）
    exit: ["29,63,13", "31,67,17"]  # 出口传送区（可选）
    doors:                        # 物理门盒（锁=填 lock-material，开=还原原方块）
      - region: ["30,64,14", "30,66,16"]
        material: BARRIER
    wave-rest: 4                  # 房内 TRIGGERED 组休整兜底（组自身 delay/rest 优先）
    groups:                       # 房内怪组（格式同 monsters.yml，坐标相对 origin）
      wave1:
        spawn-timing: AUTO_START  # 房内语义：AUTO_START=锁门即刷 / DELAYED=锁门后延迟 / TRIGGERED=组联动
        monsters:
          - mob-id: vanilla:zombie
            location: "15,64,15"
            amount: 4
    on-enter: [...]               # 玩家首次进房
    on-lock: [...]                # 锁门瞬间
    on-clear: [...]               # 房内组全清（无怪房进房即清）
```

### 运行规则

- **房间图遍历**：引擎每 tick 扫描层内**全部**房间做进出检测——进任意房触发 on-enter/锁门，可回退/绕支线/走回头路；`rooms` 列表只是集合而非路线
- **终点语义**：`boss-room` 显式指定层终点——终点房清完 → 层清 → 进下一层；**非终点房**清完只解锁自家门，不自动传送
- **多门洞**：`doors` 是列表，一房可配任意多个门洞（锁门时全部填塞、清完还原原方块）；门洞是否通向真房间由 world-init 的建筑布局决定——封死=假门/装饰，通走廊=真通路
- 房间物化：进本时按层生成房间链；pool 房沿轴粘贴，一切坐标（region/spawn/doors/groups/exit）自动按锚点偏移为绝对值
- 怪组物化：房内组注册为 `f{层}_r{房序}_{模板id}:{组名}`；`trigger-after` 引用房内短名自动加前缀
- 事件：`axs.abyss.room_enter` / `room_clear` / `floor_enter` / `floor_clear`
- 脚本变量：`{floor}` `{floor_name}` `{floors_total}` `{room}` 写入实例变量
- 脚本动作：`floor_next`（强制推层）/ `room_lock <房>` / `room_unlock <房>` / `room_status <房> <变量>`
- 无怪组的安全房进房即清（不广播"肃清"）；最终层终点房清完自动 `complete_dungeon`
- Boss 之门模式：world-init 把终点房门洞封死 → 战斗房 `on-clear` 累加 `fN_cleared` 变量 → 首个肃清房触发 `fN_gate` 段 `fillblocks AIR` 开门（example 副本的实现方式，纯脚本无引擎依赖）

## 内置示例：元气试炼之地（example）

`abysses/example/` 是一个**零外部资源**即可跑通的元气骑士式**三层迷宫**地牢——`world.template: void` 虚空世界，全部建筑由 `scripts.yml` 的 `world-init` 段用 `fillblocks` 程序化生成（每层 7 房×3 层，40×40 大房（内空 38×38）+ 16×8 走廊物理互连成图，祭坛/Boss 房挑高 22，无需 schematic）。

| 层 | 拓扑 | 演示点 |
|---|---|---|
| f1 苔痕前哨 | 入口—战斗A—战斗B—Boss / 入口—祭坛 / 战斗B—宝箱 | 向导 NPC（Adyeshach+Chemdah 会话+委托）、随机波次包+休整预告、金币祭坛三选一、Boss 之门（肃清任一战斗房开门） |
| f2 熔岩矿道 | 入口—战斗A—战斗B—谜题 / 入口—商店 / 战斗B—战斗C—Boss | 商店 UI+台座购买、彩窗提示序列拉杆机关、唤魔者+增援 |
| f3 深渊王座 | 入口—战斗A—Boss（环形）/ 祭坛—战斗B—宝箱厅 / 战斗B—精英 | 灵魂沙+岩浆块陷阱带（obstacles）、精英卫队房、终层独立宝箱池、凋零+两阶段增援 |

**贯穿机制**：击杀掉全队金币（tasks.yml `monster_kill` 事件）、祭坛/商店 `%axsabyss_var_coins%` 条件扣费、每层 Boss 后 `buff_offer` 三选一天赋、`guide_point` 路标链（向导→东廊→首战）、portal 出口垫传送 + 走廊可回溯、房间可任意顺序探索。

**外部配套**：示例模板包含 Chemdah NPC 对话和 `sk_slayer` 任务。展示选项写在任务的 `addon.axs-view` 中。模板加载后将配套文件部署到 Chemdah 对应目录并重载；未安装相关模块时，只使用当前可用的功能。

## 区域模板 regions/

手工搭好的建筑可以整片圈选存为模板，副本脚本一键铺放——比逐行 `fillblocks` 快几个量级。

**管理**（见 [命令页·区域模板](/docs/abyss/commands#区域模板axs-abyss-region)）：`/axs abyss region pos1|pos2` 圈选 → `save <地牢> <名>` 存到 `abysses/<地牢>/regions/<名>.yml`。

**使用**（scripts.yml 任意段，world-init 最常用）：

```yaml
world-init:
  - "paste_region 神庙 0,60,0"         # 默认跳过 AIR——结构嵌入已有地形
  - "paste_region 遗迹 100,60,0 full"  # full=连空气一起覆盖——虚空世界铺房/挖空腔体
```

模板是调色板（BlockData 串，保留朝向/状态）+ 逐层索引的 YAML——**方块实体内容不迁移**（箱内物品/刷怪笼/告示牌文字这些纯 NBT 不复制）。铺放同 `fillblocks` 免物理更新，不会触发邻接级联。
