## 存储与布局

界面左侧为装备、中央为人物，右侧为原版背包、个人仓库和快捷栏。仓库区与仓库主界面共用物品、分类、排序和容量，在任一入口取放都能看到相同结果。

仓库未启用时不显示扩展存储，仍可使用原版物品栏和装备区域。

## 仓库操作

- 条目数量和物品说明显示仓库中的总量。
- 左键取出最多一组，右键取当前展示一组的一半；取出后物品跟随鼠标，可放入背包，仓库条目自动补充展示。
- 拿起物品后，仓库网格切换为存入区域；点击存回，匹配物品自动合并。
- 默认排序按置顶优先、首次存入顺序排列。点击格子右上角 ☆ 置顶，★ 取消；仅悬停或已置顶时显示星标。其它排序不执行置顶切换。
- 搜索、分类和翻页用于仓库，不会重排玩家原版背包。

## 第一次使用

1. 启用 Warehouse 与 ExtraBackpack，确认客户端已安装配套 ArcartX。
2. 按需修改模块配置，通过 `/axs reload extrabackpack` 重载。
3. 打开物品栏，在仓库区取放物品；扩容通过设置窗口操作。

## 检查是否配置成功

确认扩展区和个人仓库展示同一份物品及容量。默认排序下观察星标状态，修改仓库分类后确认扩展区同步。没有仓库时不应出现独立的额外库存。

## 设置与容量

设置窗口显示已用容量、上限、单格价格、剩余可购数量及预计花费。容量和价格来自 Warehouse 的个人仓库定义，不按分类分别出售。

| 功能 | 配置或说明 |
| --- | --- |
| 分类规则 | [Warehouse 分类配置](/docs/warehouse/categories) |
| 购买容量 | [槽位扩容](/docs/extrabackpack/slot-expansion) |
| 自动存入 | 使用 Warehouse 的服务器和玩家个人开关 |
| 工作台退出溢出 | 自动存入开启时尝试存仓库，否则按原版退回或掉落 |
| 物品销毁 | 对光标物品发起确认后执行 |
