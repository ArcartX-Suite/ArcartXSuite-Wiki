| 项目 | 说明 |
| --- | --- |
| 模块 ID | `extrabackpack` |
| 主配置 | `plugins/ArcartX-Suite/data/extrabackpack/config.yml` |
| 主要调整内容 | 分类匹配、初始容量与扩容价格 |
| 重载 | `/axs reload extrabackpack` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 检查默认分类。
2. 从服务器配置的背包入口打开界面。
3. 存取一个匹配分类的物品。

## 检查是否配置成功

确认物品进入正确分类，扩容后容量增加。

功能未生效时，先检查模块状态、所用定义 ID、玩家权限及客户端安装情况，随后对照[日志与报错提示](/docs/guide/config-management)逐项检查。

## 可以配置的功能

| 功能 | 说明 |
| --- | --- |
| 共通存储 | 物品直接存于玩家个人仓库，背包 UI 与仓库 UI 是同一存储的两个入口 |
| 分类页过滤 | 页签是仓库内容的过滤器：显示匹配规则的槽位 + 剩余空格，支持严格放入校验 |
| 原版背包共存 | UI 替换原版物品栏界面，原版背包与快捷栏作为原生槽位保留 |
| NBT 自动归类 | 根据物品 NBT/PDC 路径匹配规则判定物品归属页签，支持 `pdc:`、`material`、`display-name`、`lore` 等多种路径 |
| 兜底分类 | 未匹配任何分类规则的物品归入标记为 `default` 的兜底页签 |
| 付费解锁槽位 | 容量 = 仓库已解锁格数，逐格购买，价格统一走仓库 `slot-price` 配置；背包与仓库 UI 双入口均可购买 |
| 快捷栏交互 | UI 底部展示原版快捷栏 9 格，点击可将快捷栏物品存入额外背包 |
| 数据迁移 | 支持 `/axs migrate` 跨数据库源迁移，支持 `/axs purge` 按玩家/全量清除数据 |
