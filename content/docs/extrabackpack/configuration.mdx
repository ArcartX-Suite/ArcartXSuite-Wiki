## 先改哪些内容

分类匹配、初始容量与扩容价格。先使用默认示例完成一次测试，再按本页逐项调整。

配置位置：`plugins/ArcartX-Suite/data/extrabackpack/config.yml`。定义文件与子目录均相对此模块目录。本文中的 YAML 片段用于修改对应小节，请保留文件中的其他设置。

修改后执行 `/axs reload extrabackpack`；涉及插件安装或全局设置的变更请重启后验证。

配置文件位于 `plugins/ArcartX-Suite/data/extrabackpack/config.yml`，修改后执行 `/axs reload extrabackpack` 生效。

当前配置版本（`config-version`）为 **2**，模块支持自动迁移（1→2）。

### 界面显示（ui）

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `register-ui-on-enable` | boolean | `true` | 启动时是否自动注册背包 UI 到 ArcartX |
| `overwrite-ui-files` | boolean | `false` | 是否强制覆盖用户已修改的 UI 文件 |

### 分类背包（extra-backpack）

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enabled` | boolean | `false` | 是否启用额外背包功能 |
| `categories` | map | `{}` | 分类页定义，键名即分类 ID（自动小写归一化） |

> `enabled: true` 但 `categories` 为空时，模块会输出警告日志且功能不会生效。

### categories 分类字段表

每个分类页的配置字段：

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `display-name` | string | 分类 ID | 分类显示名称（显示在 UI 标签上） |
| `priority` | int | 当前分类序号 | 分类排序优先级，数值越小越靠前 |
| `default` | boolean | `false` | 是否为兜底分类（未匹配其他分类的物品归入此处） |
| `slots.max` | int | `999` | 该页网格显示上限（应 ≥ 仓库 `max-slots`） |
| `match.nbt.path` | string | `""` | NBT 匹配路径（如 `pdc:arcartx:item_category`、`material`、`lore`） |
| `match.nbt.values` | list | `[]` | 匹配的标签值列表，物品标签值在此列表中则归入该分类 |

容量与扩容价格使用仓库中的 `warehouses.personal.base-slots`、`max-slots` 和 `slot-price` 配置。分类页只调整匹配规则和展示顺序。

### Lore 匹配配置

```yaml
extra-backpack:
  enabled: true
  categories:
    quest_item:
      display-name: "任务物品"
      priority: 5
      slots:
        max: 999
      match:
        nbt:
          path: "lore"
          values: ["任务物品", "不可丢弃"]
    consumable:
      display-name: "消耗品"
      priority: 15
      slots:
        max: 999
      match:
        nbt:
          path: "material"
          values: ["potion", "golden_apple", "enchanted_golden_apple"]
    fallback:
      display-name: "其他"
      priority: 9999
      default: true
      slots:
        max: 999
```

## 消息文件

消息文件位于 `plugins/ArcartX-Suite/data/extrabackpack/messages.yml`，支持 `{0}`、`{1}` 等位置参数：

| 消息键 | 默认文本 | 参数 |
| --- | --- | --- |
| `extra-backpack.disabled` | `&c额外背包功能未启用。` | - |
| `extra-backpack.operation-failed` | `操作失败，请查看控制台。` | - |
| `extra-backpack.ui-required` | `请先打开额外背包界面。` | - |
| `extra-backpack.page-full` | `&c仓库槽位已满，物品未能存入。` | - |
| `extra-backpack.buy-invalid` | `&c请输入有效的购买数量。` | - |
| `extra-backpack.buy-not-configured` | `&c该分类页未配置槽位价格，无法购买。` | - |
| `extra-backpack.buy-maxed` | `&c该分类页槽位已达上限。` | - |
| `extra-backpack.buy-success` | `&a已购买 {0} 个槽位，当前容量 {1} 格。` | `{0}`=购买数量，`{1}`=新容量 |
| `extra-backpack.buy-hint` | `&f每个槽位 {0}，剩余可购买 {1} 个` | `{0}`=单价，`{1}`=剩余可购买数 |
| `extra-backpack.unknown-currency` | `&c未知货币。` | - |
| `extra-backpack.no-available-slot` | `&c无可用额外槽位。` | - |
| `extra-backpack.item-changed` | `&c物品已发生变化，请刷新后重试。` | - |
| `extra-backpack.destroy-confirm` | `&e请确认销毁该物品。` | - |
| `extra-backpack.destroy-success` | `&a物品已销毁。` | - |
