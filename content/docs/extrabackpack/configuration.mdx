## 配置位置

主配置为 `plugins/ArcartX-Suite/data/extrabackpack/config.yml`，配置版本为 2。默认模板导出到 `plugins/ArcartX-Suite/ui/extrabackpack_v2.yml`。

| 字段 | 默认值 | 作用 |
| --- | --- | --- |
| `extra-backpack.enabled` | `true` | 启用随身背包入口；关闭时不注册本模块 UI 和监听 |
| `ui.register-ui-on-enable` | `true` | 启动时注册 UI |
| `ui.overwrite-ui-files` | `false` | 是否用内置模板覆盖导出的 UI 文件 |
| `storage.shared` | `true` | 本模块数据连接沿用宿主存储配置 |

实际物品存储来自 Warehouse。修改本模块的数据库连接，不会把玩家个人仓库物品移动到另一份额外库存。

## 分类、容量和价格

当前仓库区域使用 Warehouse 的 `categories` 与 `sort-profiles`。分类规则、自动存入、个人仓库容量和扩容价格都在 `plugins/ArcartX-Suite/data/warehouse/config.yml` 配置。

- 分类与默认排序：[仓库分类与搜索](/docs/warehouse/categories)。
- 容量与单格价格：[槽位扩容](/docs/extrabackpack/slot-expansion)。
- 自动存入及工作台溢出：[自动存入与材料恢复](/docs/warehouse/material-recovery)。

分类只负责筛选，不分别出售容量。界面分页也不等于存储容量。

## 自定义界面

修改导出的 UI 后保持 `ui.overwrite-ui-files: false`，以免重载覆盖。使用新版模板时，应合并初始化中的 `whLayoutEnabled` 布局标记；服务端在下发前填写本服务器的仓库能力，保证打开时布局已确定。

物品总量由独立 Text 显示，原版槽位和仓库条目的交互协议不同。自定义时保留条目稳定 ID、图标点击穿透与服务端动作参数。

修改界面配置后执行 `/axs reload extrabackpack`；修改仓库分类或容量后重载 Warehouse。
