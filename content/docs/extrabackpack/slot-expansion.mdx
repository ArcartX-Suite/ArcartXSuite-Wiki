# 槽位扩容

> **福利模块**

ExtraBackpack 的容量与玩家个人仓库完全共通：**背包格子就是仓库格子**。容量由仓库统一管理——初始 `base-slots` 格，玩家按 `slot-price` 逐格付费购买至 `max-slots`。背包 UI 与仓库 UI 提供双入口购买，效果完全相同。

## 容量模型

| 字段 | 配置路径 | 说明 |
| --- | --- | --- |
| 初始槽位 | `warehouses.personal.base-slots` | 玩家初始解锁格数（默认 32） |
| 购买上限 | `warehouses.personal.max-slots` | 逐格购买可达的最大格数（默认 999） |
| 单格价格 | `warehouses.personal.slot-price.amount` | 每格价格 |
| 价格货币 | `warehouses.personal.slot-price.currency` | 扣费货币 ID |

```yaml
# ArcartXWarehouse.yml（仓库配置统一管理，不在 ExtraBackpack 配置中）
warehouses:
  personal:
    base-slots: 32
    max-slots: 999
    slot-price:
      currency: "points"
      amount: 100
```

### 解锁数解析

已解锁格数 = `base-slots` + `extra_slots`（`warehouse_personal` 表字段）：

```java
long unlocked = definition.baseSlots() + Math.max(0L, record.extraSlots());
```

| 条件 | 结果 |
| --- | --- |
| 新玩家 | `extra_slots = 0` → 解锁 `base-slots` 格 |
| 每次购买 | `extra_slots + 1` → 解锁数 +1 |
| 旧版等级制玩家 | 一次性迁移：`extra_slots += 旧等级容量 - base-slots`，`level` 回落默认值 |

> 容量读取经 `personalUnlockedSlots()`，写入经 `addPersonalExtraSlots()` 原子递增，购买全程在仓库锁内完成，无并发漏洞。

## 购买流程

两个入口等价，都走 `WarehouseAccess.purchaseSlot()` → 逐格购买：

**背包 UI**：`⚙` 打开设置面板 → 数量输入 + 购买按钮 → `buy_slots` 包（带 action token）→ 循环 `purchaseSlot()` ×N。

**仓库 UI**：左栏「+1 格」按钮（原等级行改造）→ `warehouse_upgrade` 包（带 action token）→ `purchasePersonalSlot()` 一次。

```
扣款流程：
1. 校验 unlocked < max-slots，否则提示已满
2. 校验 slot-price 已配置，否则提示不可购买
3. withdrawCost() 扣费（失败提示并终止）
4. addPersonalExtraSlots(+1) 原子递增（失败退款）
5. 刷新双方视图，发布 axs.extrabackpack.upgraded / axs.warehouse 事件
```

## 对分类页的影响

容量共通后，分类页配置中的以下字段**不再生效**（保留解析以兼容旧配置）：

| 字段 | 旧语义 | 现状 |
| --- | --- | --- |
| `slots.initial` | 分类初始容量 | 弃用——容量由仓库统一管理 |
| `price.per-slot` / `price.currency` | 分类扩容价格 | 弃用——价格由仓库 `slot-price` 统一配置 |
| `slots.max` | 分类容量上限 | 语义变为「该页网格显示上限」，应 ≥ 仓库 `max-slots` |

分类页现在是**过滤器**：每页显示匹配该页规则的仓库槽位 + 剩余空格；空格在所有页签间共享（同一空闲池）。

## 管理命令与 API

| 操作 | 入口 | 说明 |
| --- | --- | --- |
| 赠送槽位 | `/axs extrabackpack give <玩家> <分类> <数量>` | `WarehouseAccess.grantSlots()`，分类参数兼容保留（全仓共通） |
| 重置槽位 | `/axs extrabackpack reset <玩家> <分类>` | `WarehouseAccess.resetSlots()`，`extra_slots` 归零 |
| 查询 | `/axs extrabackpack info <玩家>` | 显示已解锁/已用格数（仓库快照） |
| PAPI | `%axsextrabackpack_used%` / `%axsextrabackpack_capacity%` | 仓库 used / unlocked |

## 与旧版的差异

| 维度 | 旧模型（1.4.x） | 新模型（1.5.0） |
| --- | --- | --- |
| 存储 | `extra_backpack_slots` 独立表 | 直写 `warehouse_slots`（个人仓库） |
| 分类页 | 独立容量分区 | 仓库内容过滤器 |
| 扩容粒度 | 每分类独立价格/上限 | 全仓统一逐格解锁 |
| 价格配置 | `categories.*.price` | `warehouses.personal.slot-price` |
| 仓库联动 | 仅拾取溢出兜底 | 完全共通存储，两 UI 互为镜像 |
| 旧数据 | — | `extrabackpack.db` 弃用（旧表数据不再读取） |
