---
title: "槽位扩容"
description: "在仓库配置中设置共用容量和单格价格，通过背包或仓库界面购买槽位。"
---

ExtraBackpack 与玩家个人仓库共用容量。分类页用于筛选显示物品，不分别出售独立容量；在背包或仓库入口扩容，影响的是同一份个人可用格数。

## 配置容量与价格

在 Warehouse 的 `plugins/ArcartX-Suite/data/warehouse/ArcartXWarehouse.yml` 中修改对应小节：

```yaml
warehouses:
  personal:
    base-slots: 32
    max-slots: 999
    slot-price:
      currency: points
      amount: 100
```

| 字段 | 功能 |
| --- | --- |
| `base-slots` | 玩家初始解锁格数 |
| `max-slots` | 可购买的最大格数 |
| `slot-price.currency` | 扣费货币 ID，需与全局货币配置一致 |
| `slot-price.amount` | 每格价格 |

以上是片段，在现有 `warehouses.personal` 中修改，保留其他仓库设置。分类的显示与物品识别另见[分类配置](/docs/extrabackpack/categories)。

## 玩家怎样购买

- 背包界面：打开设置面板，按界面输入购买数量并确认。
- 仓库界面：使用增加格数的购买按钮。

购买前需确认货币可用、余额足够且未达到上限。购买后同时查看背包与仓库的可用格数，核对扣费和实际增加数量。

## 分类页与总容量

分类页不是独立的容量分区，不能把各页显示的空格相加当成总容量。分类的 `slots.max` 控制该页网格显示上限，应结合实际仓库容量设置，不在分类中重复配置价格。

修改容量与价格后重载对应模块，并用普通测试账号验证余额不足、正常购买和达到上限三种情况。已有玩家数据时，修改基础容量前先备份并确认实际显示结果。
