Announcer 模块通过 `/axs announcer` 命令提供公告广播、字幕播放与状态查询功能。所有管理命令需要 `arcartxsuite.admin` 权限。模块本身不输出独立的 PlaceholderAPI 占位符，但公告文本与字幕文本中的 PAPI 变量会按接收玩家解析。

## 管理员命令

所有命令通过 `/axs announcer <action>` 触发，需要 `arcartxsuite.admin` 权限。

### 通用命令

| 命令 | 说明 |
|---|---|
| `/axs announcer help` | 显示所有可用子命令帮助 |
| `/axs announcer status` | 查看模块运行状态 |
| `/axs reload announcer` | 重载 Announcer 模块（配置 + 条目 + 字幕组 + UI） |

### 公告广播命令

| 命令 | 说明 |
|---|---|
| `/axs announcer broadcast <文本>` | 本服加入广播队列，当前展示结束后播报 |
| `/axs announcer broadcastnow <文本>` | 本服立即广播，打断当前展示 |
| `/axs announcer gbroadcast <文本>` | 跨服加入广播队列，转发到其他子服 |
| `/axs announcer gbroadcastnow <文本>` | 跨服立即广播，转发到其他子服 |

### 字幕命令

| 命令 | 说明 |
|---|---|
| `/axs announcer subtitle list` | 列出所有已加载的字幕组 |
| `/axs announcer subtitle play <玩家> <组ID>` | 为指定玩家播放字幕组 |
| `/axs announcer subtitle stop <玩家>` | 停止指定玩家的字幕播放 |

### Tab 补全

| 参数位置 | 补全内容 |
|---|---|
| 第 3 参数（subtitle 子命令） | `list` / `play` / `stop` |
| 第 4 参数（play/stop 玩家名） | 在线玩家名 |
| 第 5 参数（play 字幕组 ID） | 已加载的字幕组 ID |

## 权限节点

| 权限节点 | 默认 | 说明 |
|---|---|---|
| `arcartxsuite.admin` | `op` | 使用 `/axs announcer` 管理命令 |

> Announcer 模块无玩家命令，所有命令均为管理员命令。公告展示与字幕播放对全体在线玩家生效，无需额外权限。

## status 命令输出

`/axs announcer status` 显示以下信息：

| 输出行 | 说明 |
|---|---|
| 活跃公告数 | `enabled: true` 且 `text` 非空的条目数量 |
| 已初始化玩家数 | 客户端已就绪的在线玩家数量 |
| 字幕组数量 | 已加载的字幕组总数 |
| 字幕播放中人数 | 当前正在播放字幕的玩家数量 |
| 待播队列长度 | 手动广播队列中待播报的消息数量 |
| 跨服通道状态 | `已启用` 或 `未启用` |
