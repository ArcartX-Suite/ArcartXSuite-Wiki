> **付费模块** — 公告轮播是 Announcer 模块的核心功能，按配置顺序循环播放公告条目到 ArcartX 客户端 HUD，支持自动轮播、手动广播与点击执行命令。

## 条目配置

每个公告条目写在 `entries-directory`（默认 `announcer`）目录下的 `.yml` 文件中。模块启动时扫描目录加载所有条目，目录不存在时自动创建并导出示例文件 `default.yml`。

- 文件名升序加载，同一 ID 后定义的覆盖先定义的
- `enabled: false` 或 `text` 为空的条目不参与轮播

### 条目字段

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | `boolean` | `true` | 是否启用该条目参与轮播 |
| `text` | `string` | — | 公告展示文本，支持 PlaceholderAPI 变量与颜色代码 |
| `click-command` | `string` | — | 点击公告时执行的命令，留空表示无点击事件；`<player>` 替换为点击者名 |

```yaml
# data/announcer/default.yml
welcome:
  enabled: true
  text: "欢迎来到服务器，祝你游玩愉快。"
  click-command: ""

player:
  enabled: true
  text: "你好，%player_name%。"
  click-command: "say <player> 点击了公告"
```

```yaml
# data/announcer/events.yml — 同一目录下可拆分多个文件
double_exp:
  enabled: true
  text: "&e双倍经验活动进行中！"
  click-command: ""

maintenance:
  enabled: false
  text: "&c服务器即将维护，请做好准备。"
  click-command: ""
```

## 自动轮播

按 `check-interval-ticks` 周期检查是否到达广播时间，到达后按顺序取下一条启用条目展示，播完一轮后回到首条。

| 参数 | 配置项 | 默认值 | 说明 |
|---|---|---|---|
| 检查周期 | `settings.check-interval-ticks` | `20` tick | 后台检查间隔 |
| 轮播冷却 | `settings.cooldown-ms` | `30000` ms | 一整轮播完后的冷却时间 |
| 条目间隔 | `settings.between-entry-interval-ms` | `30000` ms | 同一轮中相邻条目切换间隔 |
| 自动播放 | `settings.auto-play` | `true` | 是否自动开始轮播 |

> 间隔时间有 1 秒下限保护。`auto-play: false` 时不自动滚动，仅响应手动广播。

## 手动广播

| 模式 | 命令 | 行为 |
|---|---|---|
| 排队广播 | `/axs announcer broadcast` / `gbroadcast` | 文本加入待播队列，当前展示结束后播报 |
| 立即广播 | `/axs announcer broadcastnow` / `gbroadcastnow` | 打断当前展示，立即播报 |

手动广播展示时长为 `between-entry-interval-ms`，不触发轮播冷却，队列消费完毕后恢复自动轮播。

## 点击命令

条目配置非空 `click-command` 时，HUD 显示可点击区域。玩家点击后以控制台身份执行命令。

```yaml
welcome:
  enabled: true
  text: "欢迎来到服务器！点击此处领取新手礼包。"
  click-command: "kit give <player> starter"
```

> `<player>` 占位符替换为点击者玩家名（经安全校验）。命令以控制台身份执行，拥有最高权限，请谨慎配置。

## 文本滚动

公告文本过长时在 HUD 中从右向左滚动。滚动动画的结束时机由服务端估算的文本宽度决定，估算字号由 `settings.text-width-font-size` 配置（默认 60），应与 HUD 文本控件字号大致匹配。

## 调试

开启 `settings.debug: true` 后输出展示同步与点击处理的详细日志。

`/axs announcer status` 可查看：活跃公告数、已初始化玩家数、待播队列长度、跨服通道状态。

## UI 自定义

公告 HUD 支持自定义，修改 `ui/announcer_hud.yml` 即可调整布局与样式。自定义时保持 `packetHandler.display` 的变量赋值逻辑与点击区域绑定不变。

> UI 自定义请参考 [图标指南](/docs/guide/icons)。若需在公告 HUD 中展示物品图标，可参考 [物品来源](/docs/guide/item-sources) 获取物品 JSON。公告显示条件可参考 [条件指南](/docs/guide/conditions)。
