| 项目 | 说明 |
| --- | --- |
| 模块 ID | `announcer` |
| 主配置 | `plugins/ArcartX-Suite/data/announcer/config.yml` |
| 主要调整内容 | announcer/ 公告文字、播放间隔与 subtitle/ 字幕组 |
| 重载 | `/axs reload announcer` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

在测试服的 `plugins/ArcartX-Suite/data/announcer/config.yml` 中确认 `settings.auto-play: true`，并保留默认 `entries-directory: "announcer"`。在 `plugins/ArcartX-Suite/data/announcer/announcer/wiki_trial.yml` 保存以下完整条目文件。

```yaml
wiki_trial:
  enabled: true
  text: "轮播验收：这条文字来自 wiki_trial.yml"
  click-command: ""
```

用管理员执行 `/axs reload announcer`。再用普通玩家进服，等当前一轮播放到测试条目。默认条目之间相隔约 30 秒，另有滚动和轮间等待时间。可以在测试服暂时停用其他条目，只保留这一条。

## 检查是否配置成功

1. 玩家应在公告 HUD 看到「轮播验收」整句自动滚过。
2. 把 `wiki_trial.enabled` 改为 `false`，重载并重新进服。其他已启用公告继续播放，测试句应消失。再启用该条目并重载，应重新出现。
3. 管理员可以另用 `/axs announcer broadcastnow 手动广播验收` 检查手动入口。能看到手动文字时，继续用第一步验证轮播文件。

`/axs announcer status` 的「活跃公告」为 0 时，先查 `entries-directory`、条目 `enabled` 和 `text`。有活跃公告但只有手动广播出现时，检查 `settings.auto-play`。完全看不到 HUD 时，核对「已初始化玩家」和 ArcartX 客户端。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| 自动轮播 | 按配置顺序循环播放公告条目，可配置冷却时间与条目间隔 |
| 手动广播 | 支持排队广播与立即广播两种模式，立即广播会打断当前展示 |
| 点击执行命令 | 每条公告可配置 `click-command`，玩家点击 HUD 时以控制台身份执行命令 |
| PAPI 解析 | 公告文本与字幕文本支持 PlaceholderAPI 变量，按接收玩家解析 |
| 多 UI 支持 | 公告 HUD 与字幕 HUD 均支持字符串或列表形式的多 UI ID，同一 payload 同时发送到多个 HUD |
| 轮播节奏控制 | 可配置检查周期（tick）、轮播冷却（毫秒）、条目间隔（毫秒） |
| 文本宽度估算 | 服务端根据字号估算公告文本渲染宽度，驱动客户端滚动动画 |
| 跨服广播 | 手动广播可转发到其他子服，带去重与节点过滤 |
| QQ 转发 | 公告可自动转发到 QQ 群（需 QQBot 模块启用） |
