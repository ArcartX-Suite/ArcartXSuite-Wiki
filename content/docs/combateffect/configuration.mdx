## 先改哪些内容

伤害飘字样式、连击设置与特效定义。先使用默认示例完成一次测试，再按本页逐项调整。

配置位置：`plugins/ArcartX-Suite/data/combateffect/config.yml`。定义文件与子目录均相对此模块目录。本文中的 YAML 片段用于修改对应小节，请保留文件中的其他设置。

修改后执行 `/axs reload combateffect`；涉及插件安装或全局设置的变更请重启后验证。

CombatEffect 模块的配置文件位于模块数据目录下，首次启动时自动导出默认配置。配置采用动态同步策略（`SyncPolicy` 动态节），以下配置节变更时可热重载：`kill-effect`、`combo-tracker`、`death-buffer`、`keybind-trigger`、`state-trigger`、`digis-display`。

## 文件结构

| 文件 | 说明 | 首次导出 |
|---|---|---|
| `config.yml` | 主配置文件 | 是 |
| `messages.yml` | 消息本地化文件 | 是 |
| `packets/default.yml` | 默认包定义文件 | 是（目录为空时导出） |
| `ui/combat_kill_effect.yml` | 击杀/命中特效 HUD | 是 |
| `ui/combo_effect.yml` | 连击特效 HUD | 是 |
| `ui/death_buffer.yml` | 死亡缓冲界面 | 是 |
| `damage_display/ArcartXSuite-damage.yml` | 伤害飘字样式 | 是（导出到 ArcartX 目录） |
| `damage_display/ArcartXSuite-heal.yml` | 治疗飘字样式 | 是 |
| `damage_display/ArcartXSuite-critical.yml` | 暴击飘字样式 | 是 |
| `damage_display/ArcartXSuite-dodged.yml` | 闪避飘字样式 | 是 |
| `damage_display/ArcartXSuite-advantaged.yml` | 元素克制优势飘字样式 | 是 |
| `damage_display/ArcartXSuite-disadvantaged.yml` | 元素克制劣势飘字样式 | 是 |

> UI 文件导出到 `plugins/ArcartX-Suite/data/combateffect/ui/`，damage_display 文件导出到 `plugins/ArcartX/damage_display/`（ArcartX 插件目录）。`ui.overwrite-ui-files` 为 `true` 时强制覆盖用户已修改的 UI 文件。

### config-version 与 ui

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `config-version` | int | `1` | 配置版本号，破坏性改动时递增 |
| `ui.overwrite-ui-files` | boolean | `false` | 是否强制覆盖用户已修改的 UI 文件 |

### kill-effect 击杀/攻击特效

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `kill-effect.settings.debug` | boolean | `false` | 是否输出详细发包信息 |
| `kill-effect.settings.blacklist.mythic-mob-ids` | `List<String>` | `[]` | MythicMob ID 黑名单（大小写不敏感） |
| `kill-effect.settings.blacklist.entity-types` | `List<String>` | `[]` | Bukkit EntityType 黑名单（如 `ZOMBIE`、`PLAYER`） |
| `kill-effect.settings.entity-combat.enabled` | boolean | `true` | 实体战斗监听总开关 |
| `kill-effect.settings.entity-combat.include-players` | boolean | `true` | 是否处理玩家目标（PVP） |
| `kill-effect.settings.entity-combat.include-non-player-living` | boolean | `true` | 是否处理非玩家活体实体 |
| `kill-effect.packets-directory` | string | `packets` | 包定义目录（相对模块数据目录） |

### combo-tracker 连击追踪

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `combo-tracker.enabled` | boolean | `false` | 是否启用连击追踪 |
| `combo-tracker.source` | string | `auto` | 连击来源：`auto` / `chronos` / `bukkit` |
| `combo-tracker.timeout` | long | `2000` | 连击超时重置时间（毫秒），最小 200 |
| `combo-tracker.chronos-groups` | `List<String>` | `["攻击", "连击"]` | Chronos 状态组过滤，仅这些组的状态进入才计为连击 |
| `combo-tracker.sync-variable` | boolean | `true` | 是否同步连击数到客户端服务器变量 |
| `combo-tracker.variable-name` | string | `combo_count` | 客户端变量名，UI 可通过 `{server.combo_count}` 引用 |
| `combo-tracker.per-target` | boolean | `false` | 切换攻击目标是否重置连击 |
| `combo-tracker.debug` | boolean | `false` | 是否开启连击追踪调试日志 |

### death-buffer 死亡缓冲

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `death-buffer.enabled` | boolean | `false` | 是否启用死亡缓冲 |
| `death-buffer.duration` | long | `3000` | 缓冲持续时间（毫秒），最小 500 |
| `death-buffer.visuals.shader` | string | `""` | ArcartX Shader 名称（灰度/模糊等） |
| `death-buffer.visuals.third-person-camera` | boolean | `true` | 是否切换到第三人称视角 |
| `death-buffer.visuals.camera-preset` | string | `""` | ArcartX 预设相机 ID（电影级俯拍） |
| `death-buffer.visuals.chronos.enabled` | boolean | `false` | 是否启用 Chronos 状态切换 |
| `death-buffer.visuals.chronos.state-id` | string | `死亡` | 强制玩家进入的 Chronos 状态 ID |
| `death-buffer.block-auto-respawn` | boolean | `true` | 缓冲期间阻止其他插件触发的自动复活 |
| `death-buffer.world-blacklist` | `List<String>` | `[]` | 不启用死亡缓冲的世界列表 |
| `death-buffer.debug` | boolean | `false` | 是否开启死亡缓冲调试日志 |

### keybind-trigger 与 state-trigger

| 字段 | 类型 | 默认值 | 说明 |

| `state-trigger.enabled` | boolean | `false` | 是否启用 Chronos 状态/控制器触发（需 Chronos） |

## damage_display 飘字样式

飘字样式文件导出到 `plugins/ArcartX/damage_display/` 目录，由 ArcartX 客户端读取。每个样式文件定义数字贴图、宽高、随机偏移与小数位数：

```yaml
# ArcartXSuite-damage.yml
ArcartXSuite-damage:
  textureWidth: 44
  textureHeight: 66
  randomMin: 0
  randomMax: 0.2
  decimalPlaces: 1
  textures:
    - "damage/damage/0.png"
    - "damage/damage/1.png"
    - "damage/damage/2.png"
    - "damage/damage/3.png"
    - "damage/damage/4.png"
    - "damage/damage/5.png"
    - "damage/damage/6.png"
    - "damage/damage/7.png"
    - "damage/damage/8.png"
    - "damage/damage/9.png"
    - "damage/damage/dot.png"
```

| 字段 | 说明 |
|---|---|
| `textureWidth` / `textureHeight` | 每张贴图的宽高（像素） |
| `randomMin` / `randomMax` | 位置随机值（世界坐标单位） |
| `decimalPlaces` | 小数位数：0 = 仅整数，1 = 1 位小数，2 = 2 位小数 |
| `textures` | 贴图列表：第 1-10 张对应数字 0-9，第 11 张为小数点，第 12 张为千位分隔逗号 |

> 闪避飘字（`ArcartXSuite-dodged`）固定 `damage=0`，永远不显示小数，无需配置 `decimalPlaces` 与小数点贴图。完整配置参考 [ArcartX 伤害飘字文档](https://wiki.arcartx.com/docs/core/2_simple/9_damage_display)。
