| 项目 | 说明 |
| --- | --- |
| 模块 ID | `combateffect` |
| 主配置 | `plugins/ArcartX-Suite/data/combateffect/config.yml` |
| 主要调整内容 | 伤害飘字样式、连击设置与特效定义 |
| 重载 | `/axs reload combateffect` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。本模块还需要安装 `ArcartX`。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 先保留默认特效。
2. 调整飘字字号或颜色。
3. 攻击一个测试目标。

## 检查是否配置成功

检查普通伤害、治疗与连击的显示效果。

功能未生效时，先检查模块状态、所用定义 ID、玩家权限及客户端安装情况，随后对照[日志与报错提示](/docs/guide/config-management)逐项检查。

## 可以配置的功能

| 特性 | 说明 |
|---|---|
| 击杀特效 | 玩家击杀活体实体时向攻击者发送击杀特效包，HUD 显示击杀贴图与计数 |
| 攻击特效 | 玩家攻击活体实体时触发命中特效，高频事件支持冷却控制 |
| 黑名单过滤 | 支持 MythicMob ID 黑名单与 Bukkit EntityType 黑名单 |
| 实体战斗过滤 | 可配置处理玩家目标与非玩家活体实体 |
| 连击追踪 | 追踪连续攻击次数，超时自动重置，支持 Chronos 状态事件或 Bukkit 攻击事件作为来源 |
| 目标锁定 | 可选切换攻击目标时重置连击，适用于 Boss 战场景 |
| 客户端同步 | 实时同步连击数到 ArcartX 客户端服务器变量 `{server.combo_count}` |
| 里程碑触发 | 连击达到指定数量时触发特效包，支持单次触发与重复触发两种模式 |
| 死亡缓冲 | 拦截致死伤害，延迟真正死亡，期间播放 Shader / 相机 / Chronos 死亡动作 |
