## 先改哪些内容

只需要拾取后弹提示时，保留 `settings.mode: notification`，先测试一个原版物品，再调整通知数量与显示时间。需要主动扫描附近掉落物时，改用 `scanner` 并按[扫描模式](/docs/pickup/scanner-mode)设置范围与过滤；`filter` 只对扫描模式生效。

两种模式先分别验证。物品进入背包与提示出现是两个结果，测试时同时核对。范围扩大前先在近距离、少量物品场景下验证，再检查移动离开范围和背包已满时的表现。

通知模式、扫描范围、物品过滤与提示样式。先使用默认示例完成一次测试，再按本页逐项调整。

配置位置：`plugins/ArcartX-Suite/data/pickup/config.yml`。定义文件与子目录均相对此模块目录。本文中的 YAML 片段用于修改对应小节，请保留文件中的其他设置。

修改后执行 `/axs reload pickup`；涉及插件安装或全局设置的变更请重启后验证。

## 配置文件概览

Pickup 模块的主配置位于 `data/pickup/config.yml`，消息文件为 `messages.yml`。修改后执行 `/axs reload pickup` 生效。

配置文件的 `config-version` 当前为 `4`，使用自动生成的值。

### 基础设置（settings）

| 配置项 | 类型 | 默认值 | 校验规则 | 说明 |
| --- | --- | --- | --- | --- |
| `settings.debug` | boolean | `false` | — | 是否输出调试日志，包含发包详情、HUD 打开状态、拾取流程诊断 |
| `settings.mode` | string | `notification` | 枚举：`notification` / `scanner` | 工作模式，不区分大小写，非 `scanner` 一律视为 `notification` |

### 界面显示（ui）

统一管理所有 UI ID 与注册行为。扫描模式的 HUD 常驻展示，详细面板只在主动打开时显示。

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `ui.register-ui-on-enable` | boolean | `true` | 插件启动/重载时是否自动注册 UI |
| `ui.overwrite-ui-files` | boolean | `false` | 是否强制覆盖 UI 文件（通知模式 `pickup_hud.yml` 按配置动态生成；扫描模式 `loot_panel.yml` / `loot_interact.yml` 按资源导出） |

### notification 节（通知模式配置）

| 配置项 | 类型 | 默认值 | 校验规则 | 说明 |
| --- | --- | --- | --- | --- |
| `notification.max-visible` | int | `4` | 范围 1~16 | 同时最多显示的提示条数，超出后旧提示向上挤出 |
| `notification.entry-ttl-ms` | long | `3000` | 范围 500~30000 | 每条提示在 HUD 上存活时间（毫秒），超时自动隐藏 |

> `notification.max-visible` 与 `notification.entry-ttl-ms` 决定 `pickup_hud.yml` 的生成参数。修改后需开启 `ui.overwrite-ui-files` 或删除 `ui/pickup_hud.yml` 以重新生成。

### scanner 节（扫描模式配置）

| 配置项 | 类型 | 默认值 | 校验规则 | 说明 |
| --- | --- | --- | --- | --- |
| `scanner.scan-radius` | double | `5.0` | 范围 1.0~32.0 | 扫描附近掉落物的半径（格） |
| `scanner.scan-interval-ticks` | int | `5` | 范围 1~100 | 扫描间隔（ticks，5 = 250ms） |
| `scanner.display-rows` | int | `5` | 范围 1~16 | HUD 每页显示行数，选择跨页时自动翻页，不限制清单总长度 |
| `scanner.max-candidates` | int | `512` | 范围 32~4096 | 一次扫描纳入的可收取实体上限；达到上限时显示提示 |
| `scanner.disable-auto-pickup` | boolean | `true` | — | 是否禁用自动拾取（玩家靠近掉落物时不会自动吸入背包） |
| `scanner.warehouse-auto-deposit` | boolean | `false` | — | 点击拾取后先尝试入库，遵守 Warehouse 服务器与个人开关；剩余尝试放入背包 |
| `scanner.pickup-delay-ticks` | int | `40` | 最小 0 | 实体生成后至少存活的 tick 数，同时要求自身拾取冷却结束、物品归属允许 |
| `scanner.merge-same-items` | boolean | `true` | — | 完整物品信息一致时合并数量，单击逐个尝试拾取该组实体 |

### 快捷键与分批收取

以下路径均位于模块配置的 `scanner` 节。按键的 ID 必须在宿主配置 `keybinds` 中注册，五个 ID 不得重复；完整注册示例见[附近战利品清单](/docs/pickup/scanner-mode#在宿主注册按键)。

| 配置项 | 默认值 | 作用 |
| --- | --- | --- |
| `keybind.name` | `AXS_PICKUP_PICK` | 直接收取当前类，默认 F |
| `keybind.previous` | `AXS_PICKUP_PREVIOUS` | 上一类，默认左方向键 |
| `keybind.next` | `AXS_PICKUP_NEXT` | 下一类，默认右方向键 |
| `keybind.collect-all` | `AXS_PICKUP_ALL` | 按批量规则收取全部，默认 J |
| `keybind.details` | `AXS_PICKUP_DETAILS` | 打开或关闭可选详细面板，默认 K |
| `batch.enabled` | `true` | 是否启用全部收取，不影响当前类收取 |
| `batch.mode` | `all` | `all` 收取通过清单过滤的候选；`matching` 还需命中 `batch.matcher` |
| `batch.matcher` | 空匹配器 | 通用物品匹配规则；matching 模式下留空不会收取任何物品 |
| `batch.entities-per-tick` | `8` | 全模块每 tick 最多处理的实体数，范围 1~64，各玩家轮流执行 |
| `batch.time-budget-ms` | `4` | 每 tick 软时间预算，范围 1~10；不能中途打断单次仓库调用 |
| `batch.chat-summary` | `false` | 是否在聊天栏发送一次汇总；HUD 始终提供收取结果 |

每次收取会固定当时的实体和数量；排队期间新出现的物品不会持续加入。离线、切换世界、关闭功能或停止模块时，剩余请求停止。

### filter 节（过滤系统，仅扫描模式生效）

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `filter.mode` | string | `blacklist` | 过滤模式：`blacklist`（名单内不显示）或 `whitelist`（只显示名单内） |
| `filter.min-amount` | int | `1` | 最小堆叠数量，低于此值的掉落物不显示 |

#### 材质过滤

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `filter.material-blacklist.material-ids` | list | `[DIRT, COBBLESTONE, GRAVEL, SAND, NETHERRACK, COBBLED_DEEPSLATE]` | 材质黑名单（`mode=blacklist` 时，匹配到的掉落物不显示） |
| `filter.material-whitelist.material-ids` | list | `[]` | 材质白名单（`mode=whitelist` 时，只有匹配到的掉落物才显示；非空时启用） |

#### 名称过滤

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `filter.name-blacklist.name-regex` | list | `[]` | 名称黑名单正则，匹配到的不显示 |

#### Lore 过滤

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `filter.lore-blacklist.lore-regex` | list | `[]` | Lore 黑名单正则，物品 Lore 中任意一行匹配到则不显示 |
| `filter.lore-whitelist.lore-regex` | list | `[]` | Lore 白名单正则（非空时启用，物品 Lore 中必须至少有一行匹配才显示） |

#### NBT 键过滤

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `filter.nbt-blacklist.nbt-keys` | list | `[]` | NBT 键黑名单，物品 NBT 中包含指定键则不显示（支持嵌套路径如 `custom.trash`） |
| `filter.nbt-whitelist.nbt-keys` | list | `[]` | NBT 键白名单（非空时启用，物品 NBT 中必须包含至少一个指定键才显示） |

> 五维过滤按顺序依次检查：最小数量 → 材质黑/白名单 → 名称正则 → Lore 正则 → NBT 键。白名单规则仅在配置非空时生效。过滤配置基于 `ItemMatcher` 体系，详见 [物品匹配条件](/docs/guide/conditions)。

### 通知模式示例

以下片段只调整通知模式。修改显示行数或持续时间后，按[通知 HUD](/docs/pickup/notification-hud)中的方法更新模板。

```yaml
settings:
  mode: notification
notification:
  max-visible: 4
  entry-ttl-ms: 3000
```

### 扫描模式与仓库联动

以下片段启用清单、五行显示与仓库优先收取；其余字段保留原配置。完整按键和批量设置见[附近战利品清单](/docs/pickup/scanner-mode)。

```yaml
settings:
  mode: scanner
scanner:
  display-rows: 5
  warehouse-auto-deposit: true
  batch:
    enabled: true
    mode: all
```

### 白名单与物品说明过滤

此例只显示同时满足“钻石剑／钻石镐之一”和“Lore 包含稀有字样”的物品。不同白名单维度需要同时通过。

```yaml
settings:
  mode: scanner
filter:
  mode: whitelist
  material-whitelist:
    material-ids:
      - DIAMOND_SWORD
      - DIAMOND_PICKAXE
  lore-whitelist:
    lore-regex:
      - '.*稀有.*'
```

## 消息文件

消息文件 `messages.yml` 支持颜色码（`&` 前缀）与 `{0}` `{1}` 占位符。修改后执行 `/axs reload pickup` 生效。

| 消息键 | 说明 |
| --- | --- |
| `prefix` | 通用消息前缀 |
| `player-only` | 非玩家执行命令时的提示 |
| `no-permission` | 无权限提示 |
| `module-disabled` | 模块未启用提示 |
| `toggle.enabled` | 拾取功能已开启 |
| `toggle.disabled` | 拾取功能已关闭 |
| `status.title` | 状态查询标题 |
| `status.mode` | 当前模式（参数 `{0}` 为模式名称） |
| `status.state` | 功能状态（参数 `{0}` 为状态标签） |
| `mode.scanner` | 扫描模式名称 |
| `mode.notification` | 通知模式名称 |
| `state.on` | 已开启标签 |
| `state.off` | 已关闭标签 |
| `player.help.title` | 帮助标题 |
| `player.help.on` | `/pickup on` 帮助 |
| `player.help.off` | `/pickup off` 帮助 |
| `player.help.status` | `/pickup status` 帮助 |
| `player.help.collect` | 当前类收取和全部收取命令帮助 |
| `player.help.selection` | 切换清单选择命令帮助 |
| `player.help.details` | 详细面板命令帮助 |
| `hints.scanner-only` | 在通知模式使用扫描专用操作的提示 |
| `hints.no-items` | 没有可操作物品或对应操作未启用的提示 |
| `hints.collection-summary` | 收取汇总：`{0}` 仓库数量、`{1}` 背包数量、`{2}` 未收取数量 |
| `hints.collection-summary-quiet` | 关闭入库聊天通知时的汇总，只报告背包和未收取数量 |
