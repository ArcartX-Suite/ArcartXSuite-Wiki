## 玩家命令

玩家命令绑定到 `/pickup`（别名 `/axspickup`），需持有 `arcartxsuite.pickup.use` 权限。命令行为随当前工作模式（通知/扫描）生效。

| 命令 | 说明 | 权限 |
| --- | --- | --- |
| `/pickup` | 切换拾取功能开关（toggle） | `arcartxsuite.pickup.use` |
| `/pickup on` | 开启拾取功能 | `arcartxsuite.pickup.use` |
| `/pickup off` | 关闭拾取功能 | `arcartxsuite.pickup.use` |
| `/pickup toggle` | 切换拾取功能开关（同 `/pickup`） | `arcartxsuite.pickup.use` |
| `/pickup collect` | 收取当前类，扫描模式专用 | `arcartxsuite.pickup.use` |
| `/pickup all` | 收取符合批量规则的候选 | `arcartxsuite.pickup.use` |
| `/pickup previous` | 选择上一类 | `arcartxsuite.pickup.use` |
| `/pickup next` | 选择下一类 | `arcartxsuite.pickup.use` |
| `/pickup details` | 打开或关闭详细面板 | `arcartxsuite.pickup.use` |
| `/pickup status` | 查看当前拾取状态（模式 + 开关） | `arcartxsuite.pickup.use` |
| `/pickup help` | 查看可用子命令 | `arcartxsuite.pickup.use` |

### 命令详解

**`/pickup`（无参数）**

切换拾取功能开关。若当前已开启则关闭，已关闭则开启。切换后立即生效：
- 通知模式：关闭时立即关闭 HUD 并清理待发队列；开启时立即重新打开 HUD
- 扫描模式：关闭时立即关闭 `loot_panel` HUD 与 `loot_interact` 菜单并清理状态；开启时立即重新打开 HUD

**`/pickup on` / `/pickup off`**

显式开启或关闭拾取功能，不切换当前状态。

**`/pickup status`**

查看当前拾取状态，显示工作模式（通知模式 / 扫描模式）与功能开关状态（已开启 / 已关闭）。

> 命令仅限玩家执行，控制台执行时返回 `player-only` 提示。模块未启用时返回 `module-disabled` 提示。

## 管理员命令

管理员命令通过Suite `/axs` 命令执行：

| 命令 | 说明 | 权限 |
| --- | --- | --- |
| `/axs reload pickup` | 重载 Pickup 模块（配置 + 消息 + UI） | `arcartxsuite.admin` |
| `/axs load pickup` | 热加载 Pickup 模块（从 `modules/` 扫描） | `arcartxsuite.admin` |
| `/axs unload pickup` | 热卸载 Pickup 模块 | `arcartxsuite.admin` |

> 重载时模块会先停止当前服务（关闭所有玩家 HUD/菜单），再重新加载配置并启动服务。扫描模式下重载会为所有在线玩家重新打开常驻 HUD。
>
> 持久启用/禁用模块通过Suite `config.yml` 的 `modules.pickup.enabled` 控制；`/axs load`/`/axs unload` 仅做本次运行期的热加载/热卸载。

## 权限节点表

| 权限节点 | 默认 | 说明 |
| --- | --- | --- |
| `arcartxsuite.pickup.use` | op | 使用 `/pickup` 命令与切换拾取功能 |
| `arcartxsuite.admin` | op | 使用 `/axs reload\|load\|unload pickup` 管理命令 |

## UI 界面

Pickup 模块根据工作模式使用不同的 ArcartX UI 界面：

| 界面 | 模式 | 说明 |
| --- | --- | --- |
| `ui/pickup_hud.yml` | 通知模式 | 滚动队列展示最近拾取记录，根据 `max-visible` 与 `entry-ttl-ms` 动态生成 |
| `ui/loot_panel.yml` | 扫描模式 | 常驻 HUD，展示附近掉落物列表，支持滚轮与点击 |
| `ui/loot_interact.yml` | 扫描模式 | 可选详细面板，只有按详情键或 details 命令时打开，支持分页与物品说明 |

> `pickup_hud.yml` 为动态生成文件，修改 `max-visible` 或 `entry-ttl-ms` 后需开启 `ui.overwrite-ui-files` 或手动删除旧文件以重新生成。UI 图标渲染使用 `Slot` 组件，详见 [UI 图标](/docs/guide/icons)。
