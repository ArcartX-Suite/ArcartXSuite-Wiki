# 通知模式 HUD

> **付费模块**

通知模式（`settings.mode: notification`）是 Pickup 模块的轻量拾取提示模式。玩家正常拾取地面掉落物时，HUD 以滚动队列展示最近 N 条拾取记录，每条包含物品图标、名称与数量，超时后自动消失。

## HUD 生成

通知模式的 UI 文件 `ui/pickup_hud.yml` 在模块启动时根据两个配置参数**动态生成**：

| 生成参数 | 配置路径 | 默认值 | 影响 |
| --- | --- | --- | --- |
| 最大显示条数 | `notification.max-visible` | `4` | 同时显示的提示条目数 |
| 条目存活时间 | `notification.entry-ttl-ms` | `3000` | 每条提示的显示时长（毫秒） |

| 条件 | 行为 |
| --- | --- |
| 文件不存在 | 生成新文件 |
| `ui.overwrite-ui-files` 为 `true` | 强制覆盖重新生成 |
| 文件已存在且 `overwrite-ui-files` 为 `false` | 保留旧文件，不重新生成 |

<Callout type="warn">
修改 `max-visible` 或 `entry-ttl-ms` 后，需开启 `ui.overwrite-ui-files` 或手动删除 `ui/pickup_hud.yml` 才能重新生成。否则 HUD 仍使用旧参数的模板。
</Callout>

## 显示行为

- 新拾取提示插入队列首位，旧条目依次下移，最旧的条目被挤出
- 每条提示显示 `entry-ttl-ms` 毫秒后自动隐藏
- HUD 固定位于屏幕右下角，纵向排列条目，每条含物品图标、名称与数量

## Warehouse 补发

Warehouse 模块自动入库拦截拾取时，会主动补发 HUD 提示，玩家仍能看到拾取通知，体验与手动拾取一致。详见 [联动](/docs/pickup/integration)。

## EventBus 事件

每次实际拾取发布 `axs.pickup.item_pickup` 事件（`material`、`amount`），供其他模块订阅。详见 [联动](/docs/pickup/integration)。

## 玩家开关

玩家可通过 `/pickup` 命令开关个人拾取通知：关闭时立即关闭 HUD 并清空待发提示，开启时立即重新打开。

## 自定义 HUD 样式

如需自定义 HUD 外观（位置、背景、字体等），可直接编辑 `ui/pickup_hud.yml`。修改后请关闭 `ui.overwrite-ui-files`，否则重载时会被重新生成的默认模板覆盖。UI 语法详见 [界面](/docs/guide/multi-ui) 与 [图标](/docs/guide/icons)。
