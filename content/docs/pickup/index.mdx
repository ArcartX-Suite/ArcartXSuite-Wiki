title: "拾取提示"
description: "显示拾取通知，或让玩家主动扫描附近掉落物。"
---

| 项目 | 说明 |
| --- | --- |
| 模块 ID | `pickup` |
| 主配置 | `plugins/ArcartX-Suite/data/pickup/config.yml` |
| 主要调整内容 | 通知模式、扫描范围、物品过滤与提示样式 |
| 重载 | `/axs reload pickup` |

## 开始前

确认 ArcartX 客户端可用，且 `/axs status` 显示本模块已加载。可选插件只在使用对应功能时安装，具体要求见功能配置页。

## 第一次使用

1. 使用通知模式时按[通知 HUD](/docs/pickup/notification-hud)配置。使用扫描模式时按[扫描测试](/docs/pickup/scanner-mode#先完成一次收取)设置 `settings.mode: scanner` 和对应按键。
2. 执行 `/axs reload pickup`。让具有 `arcartxsuite.pickup.use` 的普通玩家执行 `/pickup on`。
3. 丢出铁锭和金锭并等待冷却结束。通知模式靠近后正常拾取。扫描模式用左／右键切换，F 收取当前类，J 批量收取，K 查看详情。

## 检查是否配置成功

检查物品已进入背包，并出现对应拾取提示。

扫描模式中能用 `/pickup collect` 收取却无法用 F 时，检查客户端实际键位和宿主 `keybinds`。丢出的物品根本不进清单时，检查拾取冷却、扫描距离和过滤规则。滚轮与鼠标选择在 K 打开的详情面板内使用。

## 可以配置的功能

| 功能 | 说明 |
| --- | --- |
| 拾取通知 HUD | 通知模式下，玩家拾取物品时在屏幕右下角弹出提示，包含物品图标、名称与数量，支持多条堆叠与自动消失 |
| 掉落物扫描面板 | 扫描模式下，以稳定顺序展示附近掉落物，新增类别追加到末尾，按键切换时自动翻页 |
| 选中高亮 | 常驻扫描清单显示当前选中项，使用左／右方向键切换 |
| 详情内鼠标操作 | 用 K 打开详情后，可用滚轮切换条目，也可点击物品条目收取 |
| 交互菜单 | 快捷键直接收取当前类；详细面板仅作为可选入口，提供分页、鼠标选择与物品说明 |
| 五维过滤 | 材质黑/白名单、物品名称正则、Lore 正则、NBT 键匹配、最小堆叠数量 |
| 合并显示 | 同名同类物品合并为一条，显示总数量 |
| 拾取延迟 | 掉落物落地一定时间后才开始显示，防止刚扔出的物品立即出现 |
| 仓库联动 | 扫描模式拾取后可选自动存入 Warehouse 仓库模块 |
