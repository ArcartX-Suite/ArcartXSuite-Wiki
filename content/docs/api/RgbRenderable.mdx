## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.RgbRenderable;

RgbRenderable api = AxsCapabilities.get(RgbRenderable.class);
if (api == null) {
    // 当前功能不可用，向玩家说明或使用你的替代流程。
    return;
}
```

每次业务操作时重新获取接口；模块未加载或暂时不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface RgbRenderable {

    @NotNull String render(@NotNull String entryId, @Nullable OfflinePlayer player);

    @NotNull List<String> entryIds();
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `render` | 渲染指定渐变条目。 | `entryId`：渐变条目 id；`player`：关联玩家（用于 PlaceholderAPI 变量，可为 null） | 渲染后的文本；条目不存在时返回空串 |
| `entryIds` | 已配置的渐变条目 id 列表。 | 无参数 | `List<String>` 已配置的渐变条目 ID |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
