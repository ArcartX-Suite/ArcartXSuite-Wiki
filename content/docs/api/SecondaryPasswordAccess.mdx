| --- | --- |
| 提供模块 | Suite 宿主 |
| 完整类型 | `xuanmo.arcartxsuite.api.capability.SecondaryPasswordAccess` |

## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.SecondaryPasswordAccess;

SecondaryPasswordAccess api = AxsCapabilities.get(SecondaryPasswordAccess.class);
if (api == null) return;
```

涉及玩家的调用在 Bukkit 主线程发起。

## 方法声明

```java
public interface SecondaryPasswordAccess {
    boolean isPasswordSet(@NotNull Player player);
    boolean isUnlocked(@NotNull Player player);
    boolean verify(@NotNull Player player, @NotNull String password);
    boolean set(@NotNull Player player, @NotNull String oldPassword,
                @NotNull String newPassword);
    boolean clear(@NotNull Player player, @NotNull String currentPassword);
    int minLength();
    int maxLength();
    void lock(@NotNull Player player);
}
```

## 参数与返回值

| 方法 | 参数与作用 | 返回值 |
| --- | --- | --- |
| `isPasswordSet` | 目标玩家，检查是否已设置 | 是否已设置 |
| `isUnlocked` | 目标玩家，检查本次会话 | 是否已解锁 |
| `verify` | 玩家和输入的密码，验证成功后可解锁 | 验证结果 |
| `set` | 玩家、旧密码、新密码。更换已有密码时提供旧密码 | 是否设置成功 |
| `clear` | 玩家与当前密码，确认后清除 | 是否清除成功 |
| `minLength`、`maxLength` | 无参数，读取允许的长度 | 字符数 |
| `lock` | 玩家，请求重新锁定会话 | 无返回值 |

## 调用示例

```java
if (!api.isPasswordSet(player)) {
    player.sendMessage("请先设置二级密码。");
    return;
}
if (!api.isUnlocked(player)) {
    player.sendMessage("请先在界面中解锁，再执行此操作。");
    return;
}
// 继续你的业务操作
```

## 调用注意事项

界面收集输入后调用对应方法，按返回结果决定业务是否继续。长度校验使用接口返回值。未设置密码时验证可能按提供方约定视为已授权，需要强制设置时先检查 `isPasswordSet`。获取接口的通用方式见[快速开始](/docs/api/quick-start)。
