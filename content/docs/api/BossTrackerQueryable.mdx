## 方法声明

以下为公开调用契约，保留参数类型与空值标注。Java 类型与当前配套 API JAR 保持一致。

```java
public interface BossTrackerQueryable {

    boolean isTrackedBoss(@NotNull UUID entityUuid);

    int activeSessionCount();

    int activeViewerCount();

    @NotNull List<BossSessionInfo> activeSessions(@Nullable String mobIdFilter);

    record BossSessionInfo(
        @NotNull UUID entityUuid,
        @NotNull String mythicMobId,
        @NotNull String displayName,
        double health,
        double maxHealth,
        int participantCount,
        int trackedPlayerCount,
        double totalDamage
    ) {}
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `isTrackedBoss` | 查询实体是否为被追踪的配置 Boss。 | `entityUuid`：实体 UUID（`UUID`） | `boolean`：用于判断上面所述的查询或操作结果（true / false） |
| `activeSessionCount` | 当前活跃 Boss 会话数。 | 无参数 | `int` 数值，具体统计含义见本行用途 |
| `activeViewerCount` | 正在观看 Boss 面板的玩家总数。 | 无参数 | `int` 数值，具体统计含义见本行用途 |
| `activeSessions` | 当前活跃 Boss 会话列表。 | `mobIdFilter`：MythicMob id 过滤，null 表示不过滤 | `List<BossSessionInfo>`：符合条件的结果集合 |
