## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.BossTrackerQueryable;

BossTrackerQueryable api = AxsCapabilities.get(BossTrackerQueryable.class);
if (api == null) {
    // 当前功能不可用，向玩家说明或使用你的替代流程。
    return;
}
```

每次业务操作时重新获取接口；模块未加载或暂时不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface BossTrackerQueryable {

    boolean isTrackedBoss(@NotNull UUID entityUuid);

    int activeSessionCount();

    int activeViewerCount();

    @NotNull List<BossSessionInfo> activeSessions(@Nullable String mobIdFilter);

    record BossSessionInfo(
        @NotNull UUID entityUuid,
        @NotNull String mythicMobId,
        @NotNull String displayName,
        double health,
        double maxHealth,
        int participantCount,
        int trackedPlayerCount,
        double totalDamage
    ) {}
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `isTrackedBoss` | 查询实体是否为被追踪的配置 Boss。 | `entityUuid`：实体 UUID（`UUID`） | `true` 表示实体是被追踪的 Boss |
| `activeSessionCount` | 当前活跃 Boss 会话数。 | 无参数 | `int` 当前活跃 Boss 会话数。 |
| `activeViewerCount` | 正在观看 Boss 面板的玩家总数。 | 无参数 | `int` 正在观看 Boss 面板的玩家总数。 |
| `activeSessions` | 当前活跃 Boss 会话列表。 | `mobIdFilter`：MythicMob id 过滤，null 表示不过滤 | `List<BossSessionInfo>` 活跃 Boss 会话列表 |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
