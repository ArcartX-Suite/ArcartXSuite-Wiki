## 方法声明

```java
public interface OnlineRewardsQueryable {

    boolean hasSignedToday(@NotNull UUID playerUuid);

    int todayOnlineMinutes(@NotNull UUID playerUuid);

    int weeklyOnlineMinutes(@NotNull UUID playerUuid);

    int monthlyOnlineMinutes(@NotNull UUID playerUuid);

    boolean signIn(@NotNull Player player);

    boolean makeupSignIn(@NotNull Player player, @NotNull String date);

    boolean addMakeupCards(@NotNull Player player, int amount);

    void grantDailyRewards(@NotNull Player player);

    boolean addOnlineMinutes(@NotNull Player player, int minutes);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `hasSignedToday` | 查询玩家今日是否已签到。 | `playerUuid`：玩家 UUID（`UUID`） | `true` 表示玩家今天已签到 |
| `todayOnlineMinutes` | 查询玩家今日已在线分钟数。 | `playerUuid`：玩家 UUID（`UUID`） | `int` 查询玩家今日已在线分钟数。 |
| `weeklyOnlineMinutes` | 查询玩家本周已在线分钟数。 | `playerUuid`：玩家 UUID（`UUID`） | `int` 查询玩家本周已在线分钟数。 |
| `monthlyOnlineMinutes` | 查询玩家本月已在线分钟数。 | `playerUuid`：玩家 UUID（`UUID`） | `int` 查询玩家本月已在线分钟数。 |
| `signIn` | 为玩家执行签到（如果当天未签到）。 | `player`：目标玩家（`Player`） | 是否成功签到（已签到返回 false） |
| `makeupSignIn` | 为玩家执行补签（指定日期必须是本月今天之前）。 | `player`：目标玩家（`Player`）；`date` 补签日期，格式为 yyyy-MM-dd（`String`） | 是否成功补签 |
| `addMakeupCards` | 为玩家增加补签卡数量。 | `player`：目标玩家（`Player`）；`amount`：数量或数值（`int`） | `true` 表示补签卡数量已更新 |
| `grantDailyRewards` | 为玩家发放今日在线阶段奖励（如果已达到阶段）。 | `player`：目标玩家（`Player`） | 无返回值 |
| `addOnlineMinutes` | 给玩家增加在线时长（可用于联动活动或 GM 补偿）。 | `player`：目标玩家（`Player`）；`minutes` 增加的在线分钟数（`int`） | `true` 表示在线时长已更新 |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
