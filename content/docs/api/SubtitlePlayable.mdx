## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.SubtitlePlayable;

SubtitlePlayable api = AxsCapabilities.get(SubtitlePlayable.class);
if (api == null) {
    // 当前功能不可用，向玩家说明或使用你的替代流程。
    return;
}
```

每次业务操作时重新获取接口；模块未加载或暂时不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface SubtitlePlayable {

    boolean playGroup(@NotNull Player player, @NotNull String groupId);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `playGroup` | 为指定玩家播放字幕组。 | `player`：目标玩家；`groupId`：字幕组 id | `true` 表示播放成功 |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
