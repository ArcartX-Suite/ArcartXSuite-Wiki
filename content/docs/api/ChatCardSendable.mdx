## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.ChatCardSendable;

ChatCardSendable api = AxsCapabilities.get(ChatCardSendable.class);
if (api == null) {
    // 当前功能不可用，向玩家说明或使用你的替代流程。
    return;
}
```

每次业务操作时重新获取接口；模块未加载或暂时不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface ChatCardSendable {

    boolean sendChatCard(@NotNull Player player, @NotNull String cardId, @NotNull Map<String, String> data);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `sendChatCard` | 向指定玩家发送聊天卡片。 | `player`：目标玩家；`cardId`：卡片 id；`data`：附加数据 | `true` 表示发送成功 |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
