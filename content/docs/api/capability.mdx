# Capability API

Capability 是 Suite 推荐的跨模块通信机制。模块通过 `ModuleContext` 注册自己提供的能力接口，其他模块通过类型查找来调用，实现松耦合的模块间协作。

## 工作原理

```
┌──────────┐  registerCapability   ┌──────────────┐  getCapability   ┌──────────┐
│ Title    │ ─────────────────────→│  Capability  │←──────────────── │ EventPkt │
│ Module   │  TitleGrantable.class │  Registry    │  TitleGrantable  │ Module   │
└──────────┘                       └──────────────┘                  └──────────┘
```

1. **提供方**在 `startService()` 中注册 Capability
2. **使用方**通过 `Supplier` 延迟查找，避免加载顺序问题
3. 模块 `onDisable` 时宿主自动注销其注册的所有 Capability

### registerCapability / getCapability

```java
// 提供方：注册
context.registerCapability(TitleGrantable.class, titleService);

// 使用方：查找（务必判空）
TitleGrantable title = context.getCapability(TitleGrantable.class);
if (title != null) {
    title.giveTitle(player.getUniqueId(), "hero", "7d", "MyModule");
}
```

## 公开 Capability：外部插件入口

`context.getCapability()` 仅供 AXS 模块内部使用。面向**外部 Bukkit 插件**，Suite 提供统一静态门面 `AxsCapabilities`，并配合 `@PublicCapability` 注解做可见性过滤：

- 只有标注 `@PublicCapability` 的接口才能被 `AxsCapabilities.get()` 返回；未标记的类型对外一律返回 `null`（模块内部 `getCapability` 不受限）
- 宿主启动时把门面直连 `ModuleRegistry` 的 capability 注册表；模块热卸载后对应 capability 自动摘除，`get()` 返回 `null`
- 公开 capability 的约定：入参用富对象（spec/record），阻塞操作返回 `CompletableFuture`

### 外部插件接入

插件 `plugin.yml` 声明 `depend: [ArcartXSuite]`（或 `softdepend`），构建时 `compileOnly` 依赖 `axs-api`：

```java
MapNavigable map = AxsCapabilities.get(MapNavigable.class);
if (map != null) {
    map.openMenuFor(player, targetId);
}
```

- `AxsCapabilities.get(Class)` — 返回实现实例；类型未公开、未注册或本体未就绪时返回 `null`
- `AxsCapabilities.has(Class)` — 判断指定公开 capability 当前是否可用

外部插件无需再为每个模块编写 `AxsXxxApi` 静态门面，`AxsCapabilities` 是唯一入口。

## 内置 Capability 接口

| `titleId` | 称号 id |
| `duration` | 持续时间（如 `"permanent"`、`"7d"`） |
| `source` | 来源标识（如 `"EventPacket"`） |

### MailDispatchable

邮件发送能力（**内部专用**，未标记 `@PublicCapability`，外部插件请使用 `AxsMailService`）。由 Mail 模块实现。两个方法均可在任意线程调用（同步执行，内部落库阻塞至完成后返回）。

```java
public interface MailDispatchable {
    MailSendResult sendMail(MailSendRequest request);
    MailSendResult dispatchPreset(MailPresetRequest request);
}
```

- `sendMail` — 发送带混合附件（物品+货币）的系统邮件，收件人无需在线
- `dispatchPreset` — 按预设模板发送邮件，收件人用玩家名（支持离线玩家）

Mail 模块未启用时返回 `failure`，调用方应自行降级处理。

### AxsMailService

邮件公开服务接口（**公开 capability**，`@PublicCapability` + `@Stable`）。由 Mail 模块实现，面向外部 Bukkit 插件。所有方法返回 `CompletableFuture`，异步执行——不要在 Bukkit 主线程 `join()`/`get()`，应用 `thenAccept`/`whenComplete` 回调。

```java
// 获取（外部插件唯一入口；AXS 模块内部用 getCapability(AxsMailService.class) 取同一实例）
AxsMailService service = AxsCapabilities.get(AxsMailService.class);
if (service == null) return; // mail 模块未启用
```

| 方法 | 返回 | 说明 |
|------|------|------|
| `send(AxsMailRequest)` | `CompletableFuture<AxsDeliveryReceipt>` | 发送系统邮件（含物品/货币/命令附件），`idempotencyKey` 去重 |
| `sendDurable(AxsMailRequest)` | `CompletableFuture<AxsDeliveryReceipt>` | 恢复持久化的发送意图（当前与 `send` 行为一致） |
| `getMail(UUID, long)` | `CompletableFuture<AxsMailView>` | 查询玩家单封邮件 |
| `getInbox(UUID, AxsMailQuery)` | `CompletableFuture<List<AxsMailView>>` | 查询收件箱 |
| `getUnreadCount(UUID)` | `CompletableFuture<Integer>` | 查询未读数 |
| `markRead(UUID, long)` | `CompletableFuture<AxsMailView>` | 标记已读并返回详情 |
| `claim(UUID, long)` | `CompletableFuture<AxsClaimResult>` | 领取全部可领附件（物品附件需玩家在线） |
| `delete(UUID, long)` | `CompletableFuture<AxsDeleteResult>` | 删除邮件（有未领取受保护附件时拒绝） |

### MapNavigable

地图导航能力（**公开 capability**，`@PublicCapability` + `@Stable`）。由 Map 模块实现。地图是展示层与事件源：来源推送外部目标、接收导航点击回调，导航的实际执行（信标、路径标记、追踪状态）由来源全权负责。

```java
public interface MapNavigable {
    void upsertExternalTarget(Player player, MapExternalTargetSpec spec, boolean select);
    void upsertExternalTargets(Player player, List<MapExternalTargetSpec> specs);
    void reconcileExternalTargets(Player player, String source, List<MapExternalTargetSpec> specs);
    void clearExternalTargets(Player player, String source, boolean syncView);
    void setExternalNavigated(Player player, String targetId, boolean navigated);
    void registerNavigationSource(Plugin owner, String source, MapNavigationHandler handler);
    void unregisterNavigationSource(String source);
    void clearTrack(Player player);
    void openMenuFor(Player player, String targetId);
}
```

| 方法 | 说明 |
|------|------|
| `upsertExternalTarget` | 新增/更新单个外部目标（紫色标记，不占玩家路径点上限），`select=true` 时切到目标世界并选中 |
| `upsertExternalTargets` | 批量推送外部目标，一次视图同步 |
| `reconcileExternalTargets` | 用给定集合**原子替换**某来源的全部目标：单次同步、仍存在的目标选中态不闪断；空列表 = 清空该来源 |
| `clearExternalTargets` | 清除指定来源的所有外部目标（`source` 为空串 = 全部来源） |
| `setExternalNavigated` | 来源回推导航状态，驱动面板"导航 ↔ 取消"按钮切换 |
| `registerNavigationSource` | 按 `source` 注册导航回调；玩家点击该来源目标的"导航/取消"时回调；`owner` 插件禁用时自动注销 |
| `unregisterNavigationSource` | 注销指定来源的导航回调 |
| `clearTrack` | 清除玩家当前的地图导航（锚点/路径点追踪）——来源开始自身导航时调用，实现导航互斥 |
| `openMenuFor` | 打开地图并选中目标；`targetId` 依次匹配外部目标 → 路径点 → 标记点，未命中时按世界 ID 兜底打开 |

`MapExternalTargetSpec` 为 record：`targetId` / `source` / `worldId` / `title` / `description` / `x` / `y` / `z` / `iconId` / `navigated` / `sortOrder`（有省略后三个字段的便捷构造）。

`MapNavigationHandler` 回调接口：

```java
public interface MapNavigationHandler {
    boolean onNavigateRequest(Player player, String targetId); // true=已接管；false=提示导航失败
    default void onCancelRequest(Player player, String targetId) {} // 停止自身导航，标记保留
}
```

监测事件（EventBus 主题，可经 `EventBusCapability` 订阅）：

| 主题 | 触发时机 |
|------|----------|
| `axs.map.nav_started` | 玩家开始地图导航（payload 含 `type`/`id`/`world`）——来源应停止自身导航实现互斥 |
| `axs.map.nav_cleared` | 玩家停止地图导航 |
| `axs.map.external_navigate` | 面板点击外部目标"导航"（转发回调的同时发布，供监测/兜底） |
| `axs.map.external_nav_cancel` | 面板点击外部目标"取消" |

### PickupNotifiable

拾取通知能力（**公开 capability**）。由 Pickup 模块（通知模式）实现；scanner 模式下不注册，`get()` 返回 `null`。

```java
public interface PickupNotifiable {
    boolean isNotificationActive(UUID playerId);
    boolean notifyPickup(Player player, ItemStack itemStack, int amount);
}
```

`notifyPickup` 用于"物品已被其他模块接管、但玩家确实拾取了"的补发场景（如 Warehouse 自动入库取消 `EntityPickupItemEvent`）。前置校验通过后**会同步发布 EventBus 主题 `axs.pickup.item_pickup`**（payload 含 `material`/`amount`），与原版监听器路径语义一致——每次补发即一次拾取。请在 Bukkit 主线程调用。

### PickupInterceptor

### AxsMarketService

市场公开服务接口（**公开 capability**）。由 Market 模块实现，覆盖拍卖行 / 系统商店 / 回收 / 玩家商店的 UI 打开与常用操作。所有方法请在 Bukkit 主线程调用。

```java
public interface AxsMarketService {
    enum MarketView { AUCTION, AUCTION_SELL, SHOP_LIST, SHOP, RECYCLE,
                      HISTORY, SELL, PLAYER_SHOP, MY_LISTINGS }
    void openUi(Player player, MarketView view);
    CompletableFuture<Boolean> createAuctionListing(Player player, ItemStack item,
                              double startingBid, String currency, long durationSeconds);
    CompletableFuture<Boolean> cancelListing(Player player, long listingId);
    CompletableFuture<Boolean> searchAuction(Player player, String keyword);
    int auctionCount();
    int shopCount();
    int myListingCount(Player player);
    boolean playerShopEnabled();
}
```

写操作返回 `CompletableFuture<Boolean>`：操作在调用线程同步完成（涉及背包与落库，须主线程调用），返回的 Future 已完成，`false` 表示校验失败（价格/货币/黑名单/数量上限等，失败原因已通过消息发给玩家）。`createAuctionListing` 有防复制约束：`item` 必须与玩家主手物品匹配，上架从主手扣除，不支持上架玩家未持有的物品。

市场事件订阅 EventBus 主题 `axs.market.*`（`listing_created` / `auction_purchased` / `shop_dynamic_triggered`），详见 [EventBus 已注册主题](./event-bus#已注册主题列表)。

### RegionQueryable

区域查询能力（**公开 capability**）。由 Regions 模块实现。返回 API 侧只读 `RegionInfo` record（`owners`/`members` 为不可变集合拷贝），不暴露模块内部 `Region` 类型。请在 Bukkit 主线程调用——Region 内部成员集合非并发容器，快照拷贝遇异步并发修改可能抛出 `ConcurrentModificationException`。

```java
public interface RegionQueryable {
    List<RegionInfo> regionsAt(String world, int x, int y, int z); // 按优先级排序
    List<RegionInfo> regionsInWorld(String world);
    List<RegionInfo> allRegions();
    int countRegionsByOwner(UUID owner);

    record RegionInfo(String id, String world,
                      int minX, int minY, int minZ,
                      int maxX, int maxY, int maxZ,
                      int priority, String parentId,
                      Set<UUID> owners, Set<UUID> members) {
        boolean contains(String world, int x, int y, int z);
        boolean hasAccess(UUID playerUuid); // owner 或 member，不含权限组判定
    }
}
```

区域变更订阅 `axs.regions.region_change`。

```java
                          String itemKey, String itemName, int amount) {}
}
```

`CaseDrawResult` 屏蔽内部 `PoolItem` 类型：`itemKey`/`itemName` 无奖品时为 `null`，`poolIndex` 为 1 基索引（无奖品 `-1`）。

### EventBusCapability

模块间解耦事件总线（pub/sub 模式）。由宿主注册唯一实例，任何模块可发布/订阅主题。

```java
public interface EventBusCapability {
    void publish(String topic, Player player, Object payload);
    void publish(String topic, Player player, Map<String, String> payload); // 向后兼容
    void registerPublisher(String topic);
    boolean hasPublisher(String topic);
    String subscribe(String topic, EventHandler handler);  // 支持通配符 "axs.market.*"
    void unsubscribe(String subscriptionId);
    record BusEvent(String topic, Player player, Object typedPayload, long timestamp) {}
    @FunctionalInterface interface EventHandler { void handle(BusEvent event); }
}
```

```java
EventBusCapability bus = context.getCapability(EventBusCapability.class);
if (bus != null) {
    // 发布（AXS 内置主题统一 axs.<模块id>.<事件名> 前缀）
    bus.publish("axs.market.listing_created", player, Map.of("price", "1000"));
    // 订阅
    String subId = bus.subscribe("axs.market.*", event -> {
        logger.info(event.player().getName() + " 触发了 " + event.topic());
    });
    // 取消订阅
    bus.unsubscribe(subId);
}
```
