## 方法声明

以下为公开调用契约，保留参数类型与空值标注。Java 类型与当前配套 API JAR 保持一致。

```java
public interface LoginViewQueryable {

    boolean isAuthenticated(@NotNull Player player);

    boolean isRegistered(@NotNull Player player);

}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `isAuthenticated` | 查询玩家当前是否已通过认证（含 session 恢复判定）。 可从任意线程调用。注意：内存缓存未命中时会同步执行一次数据库 session 查询（重启/重连恢复判定），高频路径请缓存结果或异步调用。 | `player`：目标玩家（`Player`） | `boolean`：用于判断上面所述的查询或操作结果（true / false） |
| `isRegistered` | 查询玩家是否已有注册账号。 可从任意线程调用。自建认证模式下每次调用都会执行一次数据库查询 （AuthMe 模式走其本地缓存），高频路径请缓存结果或异步调用。 | `player`：目标玩家（`Player`） | `boolean`：用于判断上面所述的查询或操作结果（true / false） |
| `openFor` | 为玩家打开登录界面（已认证且无 force 时为空操作）。 涉及 UI 打开，请在 Bukkit 主线程调用。 | `player`：目标玩家（`Player`） | 无返回值；按本行说明执行操作 |
| `openFor` | 为玩家打开登录界面。 涉及 UI 打开，请在 Bukkit 主线程调用。 | `force`：true 时即使已认证也强制打开（用于改密等场景） | 无返回值；按本行说明执行操作 |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。

先在对应模块配置中准备所引用的 ID，再调用接口。检查布尔值、结果对象或异常，只有成功后才更新第三方插件自己的业务状态。
