## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.AbyssReconnectAccess;

AbyssReconnectAccess api = AxsCapabilities.get(AbyssReconnectAccess.class);
if (api == null) {
    // 提供模块未启用，向玩家显示功能暂不可用
    return;
}
```

每次业务操作重新获取接口。主线程发起接口调用，返回异步结果的方法还需处理异常完成。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

以下声明来自当前已合入主分支的公开 API，包含可用的方法、结果类型和枚举。

```java
public interface AbyssReconnectAccess {
    record Status(UUID runId, long deadline, boolean eligible, String code) { }
    Status reconnectStatus(UUID player);
    Status requestReconnect(UUID player, UUID runId);
}
```

## 参数与返回值

| 方法 | 参数 | 返回类型 |
| --- | --- | --- |
| `reconnectStatus(player)` | 原成员 UUID | `Status` |
| `requestReconnect(player, runId)` | 原成员 UUID、资格中给出的原实例 UUID | `Status` |

### 查询回归资格 reconnectStatus(player)

返回 runId、deadline、eligible 与 code，先判断是否允许回归。

### 请求回归 requestReconnect(player, runId)

尝试回归并返回最新状态。回归可能失败，应读取 code。

## 调用示例

以下片段接在获取接口后。示例中的业务对象和 ID 由接入插件提供。

```java
var status = api.reconnectStatus(player.getUniqueId());
if (!status.eligible()) {
    player.sendMessage(status.code());
    return;
}
var result = api.requestReconnect(player.getUniqueId(), status.runId());
player.sendMessage(result.code());
```

## 调用注意事项

- 模板 requirements.reconnect-grace-seconds 默认 0，上限 600 秒。只有仍保留资格的原成员可以回到原实例。
- 限定同进程中仍运行的实例。副本计时在离线期间继续，原来的副本死亡状态也会保留。
- Status.eligible 表示资格，操作后的 code 表达执行结果。不要把仍有资格误认为已完成传送。
