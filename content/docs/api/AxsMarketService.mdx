## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.AxsMarketService;

AxsMarketService api = AxsCapabilities.get(AxsMarketService.class);
if (api == null) {
    // 当前功能不可用，向玩家说明或使用你的替代流程。
    return;
}
```

每次业务操作时重新获取接口；模块未加载或暂时不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface AxsMarketService {

    enum MarketView {

        AUCTION,

        AUCTION_SELL,

        SHOP_LIST,

        SHOP,

        RECYCLE,

        HISTORY,

        SELL,

        PLAYER_SHOP,

        MY_LISTINGS
    }

    void openUi(@NotNull Player player, @NotNull MarketView view);

    boolean openSystemShop(@NotNull Player player, @NotNull String id);
    boolean openAuctionLot(@NotNull Player player, long listingId);
    boolean openPlayerStore(@NotNull Player player, @NotNull UUID owner);
    boolean openOwnStoreEditor(@NotNull Player player);
    boolean openRecycleProtection(@NotNull Player player);
    boolean openTradeManagement(@NotNull Player player);

    @NotNull CompletableFuture<Boolean> createAuctionListing(@NotNull Player player, @NotNull ItemStack item,
                              double startingBid, @Nullable String currency, long durationSeconds);

    @NotNull CompletableFuture<Boolean> cancelListing(@NotNull Player player, long listingId);

    @NotNull CompletableFuture<Boolean> searchAuction(@NotNull Player player, @Nullable String keyword);

    int auctionCount();

    int shopCount();

    int myListingCount(@NotNull Player player);

    boolean playerShopEnabled();
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `openUi` | 为玩家打开指定市场 UI 视图。 | `player`：目标玩家（`Player`）；`view` 要打开的市场页面（`MarketView`） | 无返回值 |
| `openSystemShop` | 打开指定系统商店 | `player` 为目标玩家，`id` 为商店 ID | `true` 表示服务端记录商店界面已打开 |
| `openAuctionLot` | 打开单件拍品的竞价厅 | `player` 为目标玩家，`listingId` 为挂单编号 | `true` 表示接受打开请求 |
| `openPlayerStore` | 打开某位玩家的独立店铺 | `player` 为访客，`owner` 为店主 UUID | `true` 表示接受打开请求 |
| `openOwnStoreEditor` | 打开玩家自己的店铺编辑器 | `player` 为店主 | `true` 表示玩家商店已启用并发起打开 |
| `openRecycleProtection` | 打开玩家自己的回收保护界面 | `player` 为目标玩家 | `true` 表示回收功能已启用并发起打开 |
| `openTradeManagement` | 打开交易管理页面 | `player` 为具有 `arcartxsuite.market.admin` 的操作者 | `true` 表示通过权限检查并发起打开 |
| `createAuctionListing` | 上架玩家当前主手的物品，成功后由市场扣除。物品类型和元数据须与主手匹配，数量不得超过主手持有量 | `player` 为卖家，`item` 为待上架物品，`startingBid` 为起拍价，`currency` 为空时使用默认货币 ID，`durationSeconds` 为持续秒数 | 已完成的 `CompletableFuture<Boolean>`，`true` 表示上架成功 |
| `cancelListing` | 取消玩家的一条拍卖挂单 | `player` 为卖家，`listingId` 为拍卖编号 | 已完成的 `CompletableFuture<Boolean>`，`true` 表示取消成功 |
| `searchAuction` | 请求打开拍卖界面并搜索 | `player` 为目标玩家，`keyword` 为关键词，可为 `null` | 已完成的 `CompletableFuture<Boolean>`，`true` 表示已发起搜索 |
| `auctionCount` | 当前活跃拍卖挂单总数。 | 无参数 | `int` 当前活跃拍卖挂单总数。 |
| `shopCount` | 系统商店条目数。 | 无参数 | `int` 系统商店条目数。 |
| `myListingCount` | 玩家当前自己的拍卖挂单数。 | `player`：目标玩家（`Player`） | `int` 玩家当前自己的拍卖挂单数。 |
| `playerShopEnabled` | 玩家商店功能是否启用。 | 无参数 | `true` 表示玩家店铺已启用 |

## 调用注意事项

在 Bukkit 主线程调用。上架或撤单后读取对应结果，再更新调用方的业务状态。界面请求的布尔值反映服务端的处理结果，客户端展示以玩家实际看到的页面为准。
