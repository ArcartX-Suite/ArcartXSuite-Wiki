## 方法声明

以下为公开调用契约，保留参数类型与空值标注。Java 类型与当前配套 API JAR 保持一致。

```java
public interface AbyssPartyAccess {

    @Nullable PartySnapshot partyOf(@NotNull UUID player);

    boolean isInParty(@NotNull UUID player);

    boolean isLeader(@NotNull UUID player);

    @Nullable PartySnapshot getParty(@NotNull UUID partyId);

    @NotNull List<PartySnapshot> publicParties();

    @NotNull PartySnapshot createParty(@NotNull Player leader, @Nullable String name,
                                       @NotNull String mode, int maxSize);

    boolean disband(@NotNull UUID partyId);

    @Nullable String addMember(@NotNull UUID partyId, @NotNull UUID player);

    boolean removeMember(@NotNull UUID partyId, @NotNull UUID player);

    boolean transferLeader(@NotNull UUID partyId, @NotNull UUID newLeader);

    void registerJoinValidator(@NotNull String mode, @NotNull JoinValidator validator);

    void unregisterJoinValidator(@NotNull String mode);

    @FunctionalInterface
    interface JoinValidator {

        @Nullable String check(@NotNull PartySnapshot party, @NotNull UUID applicant);
    }

    record PartySnapshot(
        @NotNull UUID id,
        @NotNull String name,
        @NotNull String mode,
        @NotNull UUID leader,
        @NotNull List<UUID> members,
        int maxSize,
        @Nullable String dungeonId
    ) {}
}
```

## 参数与返回值

| 方法 | 参数 | 结果 |
| --- | --- | --- |
| `partyOf` | 玩家 UUID | 当前队伍快照，未组队时返回 `null` |
| `isInParty` | 玩家 UUID | 是否已加入队伍 |
| `isLeader` | 玩家 UUID | 是否为队长 |
| `getParty` | 队伍 UUID | 队伍快照，队伍不存在时返回 `null` |
| `publicParties` | 无 | 组队大厅中的公开队伍快照列表 |
| `createParty` | 队长、队伍名、模式、人数上限 | 创建队伍并返回快照。队长已有队伍时返回原队伍 |
| `disband` | 队伍 UUID | 是否成功解散 |
| `addMember` | 队伍 UUID、玩家 UUID | 成功返回 `null`，失败返回原因。仍检查人数上限和加入条件 |
| `removeMember` | 队伍 UUID、玩家 UUID | 是否成功移除，支持离线成员 |
| `transferLeader` | 队伍 UUID、新队长 UUID | 是否成功转让，新队长须是现有成员 |
| `registerJoinValidator` | 队伍模式、校验器 | 注册加入条件，同一模式重复注册会替换旧校验器 |
| `unregisterJoinValidator` | 队伍模式 | 移除该模式的校验器 |
| `JoinValidator.check` | 队伍快照、申请者 UUID | 允许时返回 `null`，拒绝时返回提示文字 |

### 创建队伍

- `name` 可填 `null` 以生成队伍名。
- `mode` 可填 `free`、`guild` 或自定义模式。副本 `requirements.party-mode` 可限制允许进入的队伍模式。
- `maxSize` 小于或等于 0 时采用全局 `party.max-members`。

### 校验入队

校验器用于邀请、大厅、审批和直接加人。插件停用时调用 `unregisterJoinValidator` 移除注册。

公会插件可按以下方式限制入队。

```java
api.registerJoinValidator("guild", (party, applicant) ->
    sameGuild(party.leader(), applicant) ? null : "仅同公会成员可加入");
```

## 调用注意事项

先在对应模块配置中准备所引用的 ID，再调用接口。检查布尔值、结果对象或异常，只有成功后才更新第三方插件自己的业务状态。
