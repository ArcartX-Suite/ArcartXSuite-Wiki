## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.EssentialsQueryable;

EssentialsQueryable api = AxsCapabilities.get(EssentialsQueryable.class);
if (api == null) {
    // 当前功能不可用，向玩家说明或使用你的替代流程。
    return;
}
```

每次业务操作时重新获取接口；模块未加载或暂时不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface EssentialsQueryable {

    boolean isAfk(@NotNull UUID playerUuid);

    boolean isVanished(@NotNull UUID playerUuid);

    boolean isMuted(@NotNull UUID playerUuid);

    @Nullable
    String getNickname(@NotNull UUID playerUuid);

    boolean isFlying(@NotNull UUID playerUuid);

    boolean isGodMode(@NotNull UUID playerUuid);

    @Nullable
    Location getSpawn(@NotNull World world);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `isAfk` | 查询玩家是否处于 AFK 状态。 | `playerUuid`：玩家 UUID（`UUID`） | `true` 表示玩家处于挂机状态 |
| `isVanished` | 查询玩家是否处于隐身状态。 | `playerUuid`：玩家 UUID（`UUID`） | `true` 表示玩家处于隐身状态 |
| `isMuted` | 查询玩家是否被禁言（Essentials 侧）。 | `playerUuid`：玩家 UUID（`UUID`） | `true` 表示玩家被 Essentials 禁言 |
| `getNickname` | 获取玩家自定义昵称，未设置时返回 null。 | `playerUuid`：玩家 UUID（`UUID`） | `String` 文字或标识符；没有对应结果时可为 null |
| `isFlying` | 查询玩家是否处于飞行模式。 | `playerUuid`：玩家 UUID（`UUID`） | `true` 表示玩家已开启飞行模式 |
| `isGodMode` | 查询玩家是否处于无敌模式。 | `playerUuid`：玩家 UUID（`UUID`） | `true` 表示玩家已开启无敌模式 |
| `getSpawn` | 查询指定世界的出生点（经 Essentials 的 SpawnBackend：Multiverse-Core 已加载 时返回该世界的 MV spawn，否则返回本地存储的全局 spawn）。 未设置或 Essentials 模块未启用时返回 null——不回退世界默认出生点， 兜底策略由调用方决定。 | `world`：上下文世界（MV 后端按世界取 spawn；本地后端忽略该参数） | `Location` 适用的出生点。未设置时为 null |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
