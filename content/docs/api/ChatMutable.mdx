## 方法声明

以下为公开调用契约，保留参数类型与空值标注。Java 类型与当前配套 API JAR 保持一致。

```java
public interface ChatMutable {

    @NotNull
    String mutePlayer(@NotNull String playerName, @Nullable Instant expiresAt, @Nullable String reason, @Nullable String mutedBy);

    @NotNull
    String unmutePlayer(@NotNull String playerName);

    boolean isMuted(@NotNull UUID playerUuid);

    @NotNull
    List<MuteInfo> listMutes();

    record MuteInfo(
        @NotNull UUID playerUuid,
        @Nullable String playerName,
        @Nullable String mutedBy,
        @Nullable String reason,
        @Nullable Instant createdAt,
        @Nullable Instant expiresAt
    ) {}
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `mutePlayer` | 禁言指定玩家。 | `playerName`：目标玩家名称；`expiresAt`：过期时间，null 表示永久禁言；`reason`：禁言原因，可为 null；`mutedBy`：执行者名称，可为 null | 操作结果消息（成功或失败原因） |
| `unmutePlayer` | 解除指定玩家的禁言。 | `playerName`：目标玩家名称 | 操作结果消息（成功或失败原因） |
| `isMuted` | 查询玩家是否当前处于禁言状态。 | `playerUuid`：目标玩家 UUID | 是否被禁言 |
| `listMutes` | 列出当前所有处于生效状态的禁言记录。 仅返回缓存中未过期的禁言记录。离线玩家的禁言可能不在缓存中， 调用方不应将此结果视为完整的持久化禁言列表。 | 无参数 | 禁言信息列表，无禁言时返回空列表 |
