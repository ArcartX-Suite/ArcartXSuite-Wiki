## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.PropAccessible;

PropAccessible api = AxsCapabilities.get(PropAccessible.class);
if (api == null) {
    // 当前功能不可用，向玩家说明或使用你的替代流程。
    return;
}
```

每次业务操作时重新获取接口；模块未加载或暂时不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface PropAccessible {

    @NotNull List<String> propIds();

    @NotNull PropApplyResult applyPropToMainHand(@NotNull Player player, @NotNull String propId);

    record PropApplyResult(boolean success, @NotNull String message) {}
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `propIds` | 已注册的道具 id 列表。 | 无参数 | `List<String>` 已注册的道具 ID |
| `applyPropToMainHand` | 将指定道具效果应用到玩家主手物品上。 | `player`：目标玩家；`propId`：道具 id | 应用结果（成功/失败原因） |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
