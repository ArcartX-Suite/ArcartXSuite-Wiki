## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.TabRefreshable;

TabRefreshable api = AxsCapabilities.get(TabRefreshable.class);
if (api == null) {
    // 当前功能不可用，向玩家说明或使用你的替代流程。
    return;
}
```

每次业务操作时重新获取接口；模块未加载或暂时不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface TabRefreshable {

    void requestViewerRefresh(@NotNull Player viewer, @Nullable String reason);

    void requestGlobalRefresh(@Nullable String reason);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `requestViewerRefresh` | 请求刷新指定玩家可见的 Tab。 | `viewer`：目标玩家；`reason`：触发原因（日志用） | 无返回值 |
| `requestGlobalRefresh` | 请求刷新所有在线玩家的 Tab。 | `reason`：触发原因（日志用） | 无返回值 |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
