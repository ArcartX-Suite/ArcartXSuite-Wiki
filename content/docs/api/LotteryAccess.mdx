## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.LotteryAccess;

LotteryAccess api = AxsCapabilities.get(LotteryAccess.class);
if (api == null) {
    // 当前功能不可用，向玩家说明或使用你的替代流程。
    return;
}
```

每次业务操作时重新获取接口；模块未加载或暂时不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface LotteryAccess {

    long getPoint(@NotNull UUID playerUuid, @NotNull String pointId);

    @NotNull Map<String, Long> getPoints(@NotNull UUID playerUuid);

    boolean givePoints(@NotNull UUID playerUuid, @NotNull String pointId, long amount);

    boolean exchange(@NotNull Player player, @NotNull String itemId);

    @NotNull List<CaseDrawResult> openCase(@NotNull Player player, @NotNull String poolId, int count);

    record CaseDrawResult(
        @NotNull String rarity,
        int poolIndex,
        @Nullable String itemKey,
        @Nullable String itemName,
        int amount
    ) {}
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `getPoint` | 查询玩家指定积分余额。 | `playerUuid`：玩家 UUID（`UUID`）；`pointId`：对应条目的 ID（`String`） | `long` 查询玩家指定积分余额。 |
| `getPoints` | 查询玩家全部积分余额 | `playerUuid` 为玩家 UUID | `Map<String, Long>`，以积分 ID 为键，余额为值 |
| `givePoints` | 为玩家增加抽奖积分。 | `playerUuid`：玩家 UUID（`UUID`）；`pointId`：对应条目的 ID（`String`）；`amount`：数量或数值（`long`） | 是否成功 |
| `exchange` | 为玩家执行一次兑换商店兑换。 | `player`：目标玩家（`Player`）；`itemId`：对应条目的 ID（`String`） | 是否成功 |
| `openCase` | 为玩家批量开启 CASE 奖池（开箱动画照常播放）。 | `poolId`：奖池 id；`count`：开启次数 | 每次开启的抽取结果 |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
