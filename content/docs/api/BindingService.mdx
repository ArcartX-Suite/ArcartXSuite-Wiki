| 项目 | 说明 |
| --- | --- |
| 提供模块 | Suite 宿主 |
| 完整类型 | `xuanmo.arcartxsuite.api.capability.BindingService` |

## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.BindingService;

BindingService bindings = AxsCapabilities.get(BindingService.class);
if (bindings == null) return;

var visibleBindings = bindings.snapshot();
```

## 方法声明

```java
public interface BindingService {
    List<Binding> snapshot();
    CompletionStage<BindingResult> requestFromQq(long qqId, String profileName);
    CompletionStage<BindingResult> revokeByQq(long verifiedQqId);
    CompletionStage<BindingResult> revokeByProfile(UUID profileId);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `snapshot` | 读取绑定投影 | 无参数 | 账号 ID、档案 UUID、档案名、QQ 和绑定时间。数据过期或不可用时返回空列表 |
| `requestFromQq` | 为已有账号发起一次性绑定 | `qqId` 为已验证的 QQ 号，`profileName` 为目标档案名 | 异步返回 `BindingResult` |
| `revokeByQq` | 按 QQ 身份解除绑定 | `verifiedQqId` 为已验证的 QQ 号 | 异步返回 `BindingResult` |
| `revokeByProfile` | 按游戏档案解除绑定 | `profileId` 为游戏档案 UUID | 异步返回 `BindingResult` |

`BindingResult.success()` 表示操作是否成功，`message()` 返回反馈信息。

## 调用注意事项

调用前由 QQ 等接入端验证外部操作者身份。每次决定是否允许操作前重新读取投影。玩家使用当前游戏连接通过 [AuthRuntimeCapability](/docs/api/AuthRuntimeCapability) 的 `confirmBinding` 完成确认。中心节点需要相应的 `binding-read` 或 `binding-write` 权限。
