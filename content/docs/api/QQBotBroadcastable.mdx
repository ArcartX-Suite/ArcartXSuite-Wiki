## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.QQBotBroadcastable;

QQBotBroadcastable api = AxsCapabilities.get(QQBotBroadcastable.class);
if (api == null) {
    // 当前功能不可用，向玩家说明或使用你的替代流程。
    return;
}
```

每次业务操作时重新获取接口；模块未加载或暂时不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface QQBotBroadcastable {

    void sendToGroup(long groupId, @NotNull String message);

    void sendToAllGroups(@NotNull String message);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `sendToGroup` | 向指定 QQ 群发送消息。 | `groupId`：QQ 群号；`message`：消息内容 | 无返回值 |
| `sendToAllGroups` | 向所有已配置的 QQ 群发送消息。 | `message`：消息内容 | 无返回值 |

## 调用注意事项

该接口不返回消息回执。断线、超时或发送频率达到上限时，调用方不能据此判断通知成功；需要反馈时使用 [QQBotDelivery](/docs/api/QQBotDelivery)。目标群必须在 QQbot 配置中声明，消息始终作为纯文本发送。

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
