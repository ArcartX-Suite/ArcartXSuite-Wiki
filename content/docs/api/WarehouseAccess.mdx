## 方法声明

以下为公开调用契约，保留参数类型与空值标注。Java 类型与当前配套 API JAR 保持一致。

```java
public interface WarehouseAccess {

    boolean isAvailable(@NotNull Player player);

    @NotNull Snapshot snapshot(@NotNull Player player);

    @NotNull List<SlotItem> slots(@NotNull Player player);

    @NotNull DepositResult deposit(@NotNull Player player, @NotNull ItemStack itemStack);

    @NotNull SlotWriteResult setSlot(@NotNull Player player, int slotIndex, @Nullable ItemStack itemStack);

    @NotNull WithdrawResult withdraw(@NotNull Player player, int slotIndex, int amount);

    @NotNull PurchaseResult purchaseSlot(@NotNull Player player);

    @NotNull SlotPrice slotPrice(@NotNull Player player, int amount);

    long grantSlots(@NotNull OfflinePlayer target, int amount);

    boolean resetSlots(@NotNull OfflinePlayer target);

    record Snapshot(
        boolean available,
        long unlockedSlots,
        long usedSlots,
        long maxSlots,
        boolean canPurchase,
        @NotNull SlotPrice nextSlotPrice
    ) {}

    record SlotItem(
        int slot,
        @NotNull ItemStack itemStack,
        @NotNull String displayName,
        @NotNull String categoryId
    ) {}

    record SlotPrice(
        @NotNull String currencyId,
        @NotNull BigDecimal amount
    ) {}

    record DepositResult(
        boolean success,
        long storedAmount,
        int remainingAmount,
        @NotNull String message
    ) {}

    record SlotWriteResult(
        boolean success,
        @NotNull String message
    ) {}

    record WithdrawResult(
        boolean success,
        int takenAmount,
        @Nullable ItemStack itemStack,
        @NotNull String message
    ) {}

    record PurchaseResult(
        boolean success,
        long newUnlockedSlots,
        @NotNull String message
    ) {}
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `isAvailable` | Returns whether the personal warehouse is enabled and usable for the player. | `player`：目标玩家（`Player`） | `boolean`：用于判断上面所述的查询或操作结果（true / false） |
| `snapshot` | Returns the player's personal warehouse snapshot: unlocked slot count, used slot count, purchase availability, and the next-slot price. | `player`：目标玩家（`Player`） | `Snapshot` 结果对象 |
| `slots` | Returns all occupied slots of the player's personal warehouse in slot order. | `player`：目标玩家（`Player`） | `List<SlotItem>`：符合条件的结果集合 |
| `deposit` | Stores as much of the item stack as the warehouse can hold (merges into existing stacks first, then fills free slots). | `player`：目标玩家（`Player`）；`itemStack`：物品（`ItemStack`） | `DepositResult` 结果对象 |
| `setSlot` | Writes an item stack to a specific warehouse slot index. `itemStack` may be null/air to clear the slot. Fails when the index is out of the unlocked range. | `player`：目标玩家（`Player`）；`slotIndex`：调用参数（`int`）；`itemStack`：物品（`ItemStack`），允许为 null | `SlotWriteResult` 结果对象 |
| `withdraw` | Removes up to `amount` items from one warehouse slot. | `player`：目标玩家（`Player`）；`slotIndex`：调用参数（`int`）；`amount`：数量或数值（`int`） | `WithdrawResult` 结果对象 |
| `purchaseSlot` | Purchases one additional warehouse slot at the configured price. | `player`：目标玩家（`Player`） | `PurchaseResult` 结果对象 |
| `slotPrice` | Returns the price of purchasing `amount` additional slots. | `player`：目标玩家（`Player`）；`amount`：数量或数值（`int`） | `SlotPrice` 结果对象 |
| `grantSlots` | Admin: grants `amount` additional unlocked slots (clamped to the configured maximum). Works for offline players. | `target`：调用参数（`OfflinePlayer`）；`amount`：数量或数值（`int`） | actually granted slot count; `-1` on invalid arguments |
| `resetSlots` | Admin: resets purchased slots to zero (unlocked falls back to base-slots). | `target`：调用参数（`OfflinePlayer`） | `boolean`：用于判断上面所述的查询或操作结果（true / false） |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。

先在对应模块配置中准备所引用的 ID，再调用接口。检查布尔值、结果对象或异常，只有成功后才更新第三方插件自己的业务状态。
