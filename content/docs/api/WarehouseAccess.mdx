## 方法声明

以下为公开调用契约，保留参数类型与空值标注。Java 类型与当前配套 API JAR 保持一致。

```java
public interface WarehouseAccess {

    boolean isAvailable(@NotNull Player player);

    @NotNull Snapshot snapshot(@NotNull Player player);

    @NotNull List<SlotItem> slots(@NotNull Player player);

    @NotNull DepositResult deposit(@NotNull Player player, @NotNull ItemStack itemStack);

    @NotNull SlotWriteResult setSlot(@NotNull Player player, int slotIndex, @Nullable ItemStack itemStack);

    @NotNull WithdrawResult withdraw(@NotNull Player player, int slotIndex, int amount);

    @NotNull PurchaseResult purchaseSlot(@NotNull Player player);

    @NotNull SlotPrice slotPrice(@NotNull Player player, int amount);

    long grantSlots(@NotNull OfflinePlayer target, int amount);

    boolean resetSlots(@NotNull OfflinePlayer target);

    record Snapshot(
        boolean available,
        long unlockedSlots,
        long usedSlots,
        long maxSlots,
        boolean canPurchase,
        @NotNull SlotPrice nextSlotPrice
    ) {}

    record SlotItem(
        int slot,
        @NotNull ItemStack itemStack,
        @NotNull String displayName,
        @NotNull String categoryId
    ) {}

    record SlotPrice(
        @NotNull String currencyId,
        @NotNull BigDecimal amount
    ) {}

    record DepositResult(
        boolean success,
        long storedAmount,
        int remainingAmount,
        @NotNull String message
    ) {}

    record SlotWriteResult(
        boolean success,
        @NotNull String message
    ) {}

    record WithdrawResult(
        boolean success,
        int takenAmount,
        @Nullable ItemStack itemStack,
        @NotNull String message
    ) {}

    record PurchaseResult(
        boolean success,
        long newUnlockedSlots,
        @NotNull String message
    ) {}
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `isAvailable` | 查询个人仓库是否已启用且允许该玩家使用。 | `player`：目标玩家（`Player`） | `boolean`：用于判断上面所述的查询或操作结果（true / false） |
| `snapshot` | 读取已解锁槽位、已用槽位、能否扩容与下一格价格。 | `player`：目标玩家（`Player`） | `Snapshot` 结果对象 |
| `slots` | 按槽位顺序列出个人仓库中已存物品。 | `player`：目标玩家（`Player`） | `List<SlotItem>`：符合条件的结果集合 |
| `deposit` | 先合并已有物品堆，再使用空槽位，按仓库容量尽量存入。 | `player`：目标玩家（`Player`）；`itemStack`：物品（`ItemStack`） | `DepositResult` 结果对象 |
| `setSlot` | 写入指定仓库槽位。物品为 null 或空气时清空槽位，超出已解锁范围时失败。 | `player`：目标玩家（`Player`）；`slotIndex`：调用参数（`int`）；`itemStack`：物品（`ItemStack`），允许为 null | `SlotWriteResult` 结果对象 |
| `withdraw` | 从指定仓库槽位取出至多 `amount` 件物品。 | `player`：目标玩家（`Player`）；`slotIndex`：调用参数（`int`）；`amount`：数量或数值（`int`） | `WithdrawResult` 结果对象 |
| `purchaseSlot` | 按配置价格购买一个仓库槽位。 | `player`：目标玩家（`Player`） | `PurchaseResult` 结果对象 |
| `slotPrice` | 计算额外购买 `amount` 格仓库所需价格。 | `player`：目标玩家（`Player`）；`amount`：数量或数值（`int`） | `SlotPrice` 结果对象 |
| `grantSlots` | 为目标玩家增加槽位，受配置上限限制，支持离线玩家。 | `target`：调用参数（`OfflinePlayer`）；`amount`：数量或数值（`int`） | 返回实际增加的槽位数，参数无效时返回 `-1` |
| `resetSlots` | 清零额外购买的槽位，容量回到基础槽位。 | `target`：调用参数（`OfflinePlayer`） | `boolean`：用于判断上面所述的查询或操作结果（true / false） |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。

先在对应模块配置中准备所引用的 ID，再调用接口。检查布尔值、结果对象或异常，只有成功后才更新第三方插件自己的业务状态。
