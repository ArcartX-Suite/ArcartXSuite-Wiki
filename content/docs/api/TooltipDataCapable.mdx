## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.TooltipDataCapable;

TooltipDataCapable api = AxsCapabilities.get(TooltipDataCapable.class);
if (api == null) {
    // 当前功能不可用，向玩家说明或使用你的替代流程。
    return;
}
```

每次业务操作时重新获取接口；模块未加载或暂时不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface TooltipDataCapable {

    @NotNull List<String> getTooltipLines(@NotNull Player player);

    @NotNull List<String> getTooltipLines(@NotNull Player player, @NotNull ItemStack itemStack);

    @NotNull String getStructuredData(@NotNull Player player);

    @NotNull ItemStack injectLore(@NotNull ItemStack itemStack, @NotNull List<String> lines);

    boolean hasTooltipData(@NotNull Player player, @NotNull ItemStack itemStack);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `getTooltipLines` | 获取玩家当前手持物品的 tooltip 文本行。 文本行由客户端 mod 采集，包含 TACZ 枪属性和 Apotheosis affix 等动态内容。 | `player`：玩家 | tooltip 文本行列表，无数据时返回空列表 |
| `getTooltipLines` | 获取玩家指定物品的 tooltip 文本行。 | `player`：玩家（用于确定数据来源）；`itemStack`：物品栈 | tooltip 文本行列表，无数据时返回空列表 |
| `getStructuredData` | 获取玩家当前手持物品的结构化数据（JSON 字符串）。 包含 TACZ 枪属性的数值字段（damage、armorIgnore、headshotMultiplier 等）， 供业务逻辑使用。 | `player`：玩家 | 结构化数据 JSON 字符串，无数据时返回 "{}" |
| `hasTooltipData` | 判断指定物品是否有缓存的 tooltip 数据。 | `player`：玩家；`itemStack`：物品栈 | `true` 表示有缓存的 tooltip 数据 |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
