| 项目 | 说明 |
| --- | --- |

## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.InteractionState;

InteractionState api = AxsCapabilities.get(InteractionState.class);
if (api == null) {
    // 当前功能不可用，向玩家说明或使用你的替代流程。
    return;
}
```

每次业务操作时重新获取接口；模块未加载或暂时不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface InteractionState {

    boolean isPlayerInteracting(@NotNull Player player);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `isPlayerInteracting` | 查询指定玩家是否正在与本模块进行活跃交互。 "活跃交互"包括但不限于：正在对话、NPC 选择器已打开、正在浏览菜单等。 | `player`：目标玩家 | `true` 表示玩家正在交互，其他模块应让步 |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
