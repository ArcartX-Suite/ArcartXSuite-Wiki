## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.BattlePassAccess;

BattlePassAccess api = AxsCapabilities.get(BattlePassAccess.class);
if (api == null) {
    // 当前功能不可用，向玩家说明或使用你的替代流程。
    return;
}
```

每次业务操作时重新获取接口；模块未加载或暂时不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface BattlePassAccess {

    boolean isSeasonActive();

    int addXp(@NotNull Player player, int xp);

    void setXp(@NotNull Player player, int xp);

    void removeXp(@NotNull Player player, int xp);

    void setLevel(@NotNull Player player, int level);

    boolean unlockTier(@NotNull Player player, @NotNull String tier);

    int claimAllRewards(@NotNull Player player);

    void updateTaskProgress(@NotNull Player player, @NotNull String taskId, int increment);

    void resetProgress(@NotNull UUID playerUuid);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `isSeasonActive` | 当前赛季是否进行中。 | 无参数 | `true` 表示赛季正在进行 |
| `addXp` | 为玩家增加战令经验。 | `player`：目标玩家（`Player`）；`xp`：经验值（`int`） | 实际增加后的总经验 |
| `setXp` | 直接设置玩家战令经验。 | `player`：目标玩家（`Player`）；`xp`：经验值（`int`） | 无返回值 |
| `removeXp` | 扣减玩家战令经验。 | `player`：目标玩家（`Player`）；`xp`：经验值（`int`） | 无返回值 |
| `setLevel` | 直接设置玩家战令等级。 | `player`：目标玩家（`Player`）；`level`：等级（`int`） | 无返回值 |
| `unlockTier` | 解锁玩家战令档位。 | `tier`：档位名：`"PREMIUM"` / `"DELUXE"`（大小写不敏感） | 是否成功 |
| `claimAllRewards` | 一键领取玩家全部可领奖励。 | `player`：目标玩家（`Player`） | 领取的奖励份数 |
| `updateTaskProgress` | 为玩家推进指定任务进度。 | `taskId`：任务 id；`increment`：进度增量 | 无返回值 |
| `resetProgress` | 重置玩家本赛季进度（等级/经验/任务/领取记录）。 | `playerUuid`：玩家 UUID（`UUID`） | 无返回值 |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
