## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.PickupNotifiable;

PickupNotifiable api = AxsCapabilities.get(PickupNotifiable.class);
if (api == null) {
    // 当前功能不可用，向玩家说明或使用你的替代流程。
    return;
}
```

每次业务操作时重新获取接口；模块未加载或暂时不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface PickupNotifiable {

    boolean isNotificationActive(UUID playerId);

    boolean notifyPickup(@NotNull Player player, @NotNull ItemStack itemStack, int amount) ;
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `isNotificationActive` | 查询该玩家的拾取 HUD 通知是否处于活跃状态。 | `playerId`：玩家 UUID | `true` 表示通知模式已启用且该玩家未关闭 |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
