| 提供模块 | [vanilla](/docs/vanilla) |

## 获取接口

```java
import java.util.List;
import org.bukkit.Material;
import org.bukkit.inventory.ItemStack;
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.VanillaRecipeAccess;

VanillaRecipeAccess api = AxsCapabilities.get(VanillaRecipeAccess.class);
if (api != null) {
    var ingredient = new VanillaRecipeAccess.Ingredient(List.of(Material.IRON_INGOT), List.of());
    var definition = new VanillaRecipeAccess.Definition(
        "demo_iron_nuggets", VanillaRecipeAccess.Station.SHAPELESS, List.of(ingredient),
        new ItemStack(Material.IRON_NUGGET, 9), "", 0, 0, null
    );
    registration = api.register(plugin, definition);
}
```

示例中的 `registration` 为调用插件保留的 `VanillaRecipeAccess.Registration` 字段，停用时调用 `close()` 注销配方。API 从 Bukkit 主线程调用。

## 方法声明

```java
public interface VanillaRecipeAccess {
    Registration register(Plugin owner, Definition definition);
    Registration registerModule(String ownerModuleId, Definition definition);
    List<Entry> recipes();
    Optional<Entry> recipe(NamespacedKey key);
    CompletableFuture<Preview> preview(Player player, NamespacedKey key);
    CompletableFuture<FillReceipt> fill(Player player, NamespacedKey key, long expectedRevision);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `register` | 注册插件配方 | `owner` 为调用插件，`definition` 为配方定义 | 可关闭的 `Registration` |
| `registerModule` | 注册 Suite 模块配方 | `ownerModuleId` 为调用模块 ID，`definition` 为配方定义 | 可关闭的 `Registration` |
| `recipes` | 查询配方 | 无参数 | 配方条目列表 |
| `recipe` | 查询指定配方 | `key` 为配方的命名空间键 | `Optional<Entry>`，查无结果时为空 |
| `preview` | 预览玩家可用材料 | `player` 为目标玩家，`key` 为配方键 | 异步返回配方及是否可填料 |
| `fill` | 向当前工作区填料 | `player` 为目标玩家，`key` 为配方键，`expectedRevision` 取自查询结果 | 异步返回是否填入、配方版本和提示 |

## 调用注意事项

有序合成按从左到右、从上到下提供九格，空位使用 `Ingredient.blank()`。无序合成提供一至九项。锻造依次填写模板、基材、添加物，酿造依次填写瓶中原料和酿造材料。材料类型列表与精确物品列表每项只选其一。
