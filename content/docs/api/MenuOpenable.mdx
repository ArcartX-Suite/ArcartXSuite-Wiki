## 获取接口

```java
import xuanmo.arcartxsuite.api.AxsCapabilities;
import xuanmo.arcartxsuite.api.capability.MenuOpenable;

MenuOpenable api = AxsCapabilities.get(MenuOpenable.class);
if (api == null) {
    // 当前功能不可用，向玩家说明或使用你的替代流程。
    return;
}
```

每次业务操作时重新获取接口；模块未加载或暂时不可用时返回 `null`。接入方式见[快速开始](/docs/api/quick-start)。

## 方法声明

```java
public interface MenuOpenable {

    boolean openMenu(@NotNull Player player, @NotNull String menuId);

    void refreshMenu(@NotNull Player player);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `openMenu` | 为玩家打开指定菜单。 | `player`：目标玩家；`menuId`：菜单定义 ID | 是否成功打开 |
| `refreshMenu` | 刷新玩家当前打开的菜单内容。 | `player`：目标玩家（`Player`） | 无返回值 |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
