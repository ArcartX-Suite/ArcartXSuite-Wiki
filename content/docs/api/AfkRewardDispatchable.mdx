## 方法声明

```java
public interface AfkRewardDispatchable {

    boolean isAfk(@NotNull UUID playerUuid);

    @Nullable
    String getAreaName(@NotNull UUID playerUuid);

    int getAfkSeconds(@NotNull UUID playerUuid);

    @Nullable
    String getAfkMode(@NotNull UUID playerUuid);

    boolean startManualAfk(@NotNull Player player, @NotNull String areaName);
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `isAfk` | 查询玩家是否正在挂机（REGION 或 MANUAL 模式）。 | `playerUuid`：玩家 UUID（`UUID`） | `true` 表示正在挂机 |
| `getAreaName` | 获取玩家当前挂机区域名，未挂机时返回 null。 | `playerUuid`：玩家 UUID（`UUID`） | `String` 文字或标识符；没有对应结果时可为 null |
| `getAfkSeconds` | 获取玩家本次挂机已持续秒数，未挂机时返回 0。 | `playerUuid`：玩家 UUID（`UUID`） | `int` 获取玩家本次挂机已持续秒数，未挂机时返回 0。 |
| `getAfkMode` | 获取玩家当前挂机模式，未挂机时返回 null。 | `playerUuid`：玩家 UUID（`UUID`） | "REGION" / "MANUAL" / null |
| `startManualAfk` | 让指定玩家开始原地挂机到指定区域。 供 Essentials 等模块在 AFK 超时后自动触发原地挂机。 | `player`：目标玩家；`areaName`：区域名 | `true` 表示成功启动 |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
