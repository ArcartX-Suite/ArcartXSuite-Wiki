# API 概览

Suite 提供 **`axs-api`** 模块作为第三方开发的稳定接口层。所有公开 API 均位于 `xuanmo.arcartxsuite.api` 包下，第三方模块只需 `compileOnly` 依赖 `axs-api` 即可开发自定义模块。

## 架构分层

```
axs-api/  (接口层 — 模块唯一可见)
  ├── AXSModule          模块生命周期接口
  ├── AbstractAXSModule   模块抽象基类（声明式生命周期）
  ├── ModuleContext       宿主暴露给模块的上下文
  ├── ModuleDescriptor    模块元数据描述符
  ├── bridge/             桥接 API（UI/Packet/Item/Prop 等）
  ├── capability/         跨模块能力通信接口
  ├── event/              Bukkit 事件类
  ├── message/            消息外部化（MessageProvider）
  ├── crossserver/        跨服 API
  ├── config/             配置诊断规约
  ├── storage/            存储层
  ├── command/            模块命令处理
  └── ...                 其他子包
axs-core/  (宿主实现 — 模块不可见，可安全混淆)
```

模块通过 `ModuleContext` 获取基础设施能力，禁止直接引用宿主实现类（`xuanmo.arcartxsuite.bridge.*` 等），否则混淆后可能无法加载。

## API 稳定性标记

所有公开接口使用 `@ApiStability` 注解标记稳定性级别：

| 注解 | 含义 |
|------|------|
| `@ApiStability.Stable` | 稳定 API，向后兼容，不会在小版本中破坏 |
| `@ApiStability.Experimental` | 实验性 API，可能在未来版本中修改或移除 |
| `@ApiStability.Internal` | 内部 API，仅供 Suite 内部模块使用，第三方不应依赖 |
| `@ApiStability.ScheduledForRemoval` | 已弃用 API，将在下一个大版本中移除 |

## 快速开始

```kotlin
// build.gradle.kts
dependencies {
    compileOnly(files("libs/axs-api-x.x.x.jar"))
    compileOnly("org.spigotmc:spigot-api:1.20.1-R0.1-SNAPSHOT")
}
```

```java
public class MyModule extends AbstractAXSModule {

    @Override
    public ModuleDescriptor descriptor() {
        return ModuleDescriptor.builder("mymodule")
            .name("MyModule").version("1.0.0")
            .mainClass(getClass().getName()).build();
    }

    @Override
    protected void loadConfiguration(File configFile) {
        // 解析配置
    }

    @Override
    protected void startService() {
        PacketBridgeAPI bridge = packetBridge;
        if (bridge != null && bridge.isAvailable()) {
            // 使用桥接 API
        }
    }

    @Override
    protected void stopService() {
        // 释放资源
    }
}
```

## 版本管理

`axs-api` 采用语义化版本。`module.yml` 中的 `api-version` 字段声明模块所依赖的 API 大版本。宿主在加载模块时会检查兼容性。

| API 版本 | 关键变更 |
|----------|----------|
| 1.0 | 基础架构：AXSModule、ModuleContext、ModuleRegistry |
| 1.1 | Bridge API 接口化（PacketBridgeAPI、ClientBridgeAPI、ItemBridgeAPI） |
| 1.2 | Prop/Waypoint/Adyeshach/WorldTexture 桥接；跨服 API |
| 1.3 | SoundPlayer 桥接；VanillaItemNameBridge；ContentModerator |
| 1.5 | ModuleContext 按 ISP 拆分为子接口；ModuleConfig/ModuleUiSpec 声明式规约 |
| 1.6 | SchedulerAPI 统一调度 |
