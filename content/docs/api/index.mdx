使用公开 API，为你的插件接入菜单、称号、邮件、地图、奖励等功能。先阅读[快速开始](/docs/api/quick-start)，再按业务选择接口。

## 接入步骤

1. 使用与服务器发行版本配套的 `axs-api` JAR 作为编译依赖。
2. 在插件描述文件声明 Suite 依赖。
3. 通过 `AxsCapabilities.get(接口.class)` 获取功能，处理不可用结果。
4. 准备模块配置中的目标 ID，执行调用并检查返回结果。
5. 测试模块关闭、重载与目标 ID 不存在时的行为。
