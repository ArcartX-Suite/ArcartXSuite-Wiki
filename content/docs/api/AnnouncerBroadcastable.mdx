## 方法声明

以下为公开调用契约，保留参数类型与空值标注。Java 类型与当前配套 API JAR 保持一致。

```java
public interface AnnouncerBroadcastable {

    void broadcastNow(@NotNull String text);
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `broadcastNow` | 立即播报一条公告（强制打断当前展示，本服生效）。 | `text`：公告文本 | 无返回值；按本行说明执行操作 |
| `broadcastNow` | 立即播报一条公告。 | `text`：公告文本；`forward`：是否跨服转发到其他子服 | 无返回值；按本行说明执行操作 |
| `enqueue` | 将公告加入队列，当前展示结束后播报。 | `text`：公告文本；`forward`：是否跨服转发 | 无返回值；按本行说明执行操作 |
