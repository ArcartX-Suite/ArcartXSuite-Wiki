## 方法声明

```java
public interface RegionQueryable {

    @NotNull List<RegionInfo> regionsAt(@NotNull String world, int x, int y, int z);

    @NotNull List<RegionInfo> regionsInWorld(@NotNull String world);

    @NotNull List<RegionInfo> allRegions();

    int countRegionsByOwner(@NotNull UUID owner);

    record RegionInfo(
        @NotNull String id,
        @NotNull String world,
        int minX, int minY, int minZ,
        int maxX, int maxY, int maxZ,
        int priority,
        @Nullable String parentId,
        @NotNull Set<UUID> owners,
        @NotNull Set<UUID> members
    ) {}
}
```

## 参数与返回值

| 方法 | 用途 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `regionsAt` | 查询指定坐标命中的全部区域（按优先级排序）。 | `world` 世界名称（`String`）；`x` 方块坐标 X（`int`）；`y` 方块坐标 Y（`int`）；`z` 方块坐标 Z（`int`） | `List<RegionInfo>` 命中的区域，按优先级排序 |
| `regionsInWorld` | 查询指定世界中的全部区域。 | `world` 世界名称（`String`） | `List<RegionInfo>` 该世界的区域列表 |
| `allRegions` | 查询全部区域。 | 无参数 | `List<RegionInfo>` 全部区域列表 |
| `countRegionsByOwner` | 统计某玩家作为 owner 的区域数量。 | `owner`：调用方插件（`UUID`） | `int` 统计某玩家作为 owner 的区域数量。 |

## 调用注意事项

涉及 Bukkit 玩家、世界、物品或界面的调用放在 Bukkit 主线程执行；接口有明确线程说明时以该方法约定为准。
