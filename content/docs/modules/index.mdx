# 模块总览

ArcartXSuite 提供 29 个功能模块，分为免费模块、付费模块和福利模块三类。每个模块独立 jar，按需启用。

---

## 免费模块（12 个）

| 模块 | 说明 | UI |
|------|------|:--:|
| [RGB](/docs/rgb) | 渐变文本渲染，PAPI 输出扫光效果 | — |
| [Pickup](/docs/pickup) | 物品拾取 HUD 弹出提示 + 扫描器模式 | HUD |
| [Announcer](/docs/announcer) | 公告 / 字幕轮播系统，可点击执行命令 | HUD |
| [LoginView](/docs/loginview) | ArcartX UI 登录/注册面板，支持 AuthMe 桥接 | UI |
| [OnlineRewards](/docs/onlinerewards) | 在线奖励 / 每日签到 / 连续签到 / 补签卡 | — |
| [CombatEffect](/docs/combateffect) | 战斗特效（击杀/连击/伤害飘字） | — |
| [EventPacket](/docs/eventpacket) | 事件引擎，9种触发器 × 11种动作自由组合 | — |
| [Prop](/docs/prop) | 快捷道具栏，客户端按键绑定临时属性加成 | — |
| [Essentials](/docs/essentials) | 基础工具（传送/家/Warp/一键砍树/背包整理/UI 菜单） | UI |
| [Regions](/docs/regions) | 区域保护（40+ 标志/优先级继承/世界规则） | — |
| [AfkReward](/docs/afkreward) | 区域挂机 + 原地挂机双模式、周期命令奖励 | — |
| [Tooltip](/docs/tooltip) | 物品提示桥接（TACZ/Apotheosis tooltip 采集） | — |
